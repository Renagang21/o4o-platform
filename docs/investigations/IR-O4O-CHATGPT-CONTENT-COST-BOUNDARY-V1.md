## 판정

콘텐츠 도구 11종은 기존 인증된 연결에서 조회·초안 저장을 수행한다. 조사 범위에서 제거할 유료 생성 호출은 발견하지 않았다. 이번 변경은 런타임·API·권한·DB 변경 없이 이 경계를 회귀 테스트로 보강한다. 메일 도구·초기화면 자체 웹 API는 이번 변경 대상이 아니다.

사용자 ChatGPT가 생성하고 o4o는 권한 있는 자료 조회와 기존 저장을 담당한다. 자체 웹 요청은 기존 o4o 유료 생성 경로를 유지한다. 요청 문자열의 `origin`, `connectionId`, 모델·키 필드로 비용 경로를 선택하지 않는다. SIWC는 참여 조건 확인 이후 별도 작업이다.

## 검증 범위와 한계

- 실제 `ExternalAiToolService`의 입력 검증·트랜잭션 분기·현재 연결 scope·허용 작업공간·중복 요청·저장 오류 처리를 실행한다. 도메인 어댑터는 이 단위 테스트에서 mock이다.
- 기존 MCP HTTP 테스트에서 검증된 Bearer 연결 ID가 전달되고 도구 인자에 주입한 연결 ID는 SDK에서 제거되는지 확인한다. 직접 서비스 입력의 알 수 없는 필드는 거부한다. OAuth 실제 왕복 테스트는 아니다.
- 실제 콘텐츠 어댑터와 직접 저장 서비스 14개 파일의 AST를 검사해 직접 추론 의존성·호출 유입을 감지한다. 별칭 import·동적 import·require·직접 fetch·대표 생성 메서드를 넣은 결함 표본도 검사한다.
- 이 AST 검사는 전체 전이 의존성 분석이나 임의 우회 코드에 대한 보안 증명이 아니다. 새 저장 소비처 추가 시 검사 대상·실행 검증을 함께 검토해야 한다. 기존 정상 네트워크 기능까지 전역 차단하는 런타임 가드는 도입하지 않는다.
- 실제 공급자 청구 0원, 운영 설정 활성화, 실제 ChatGPT 앱 공개·사용 성공, 전체 어댑터 DB 저장 통합 검증은 주장하지 않는다. 운영 사용량 수집은 1차 보고서의 미완료 항목으로 남는다.

## 기능별 차이와 다음 변경 위치

| 업무 | 현재 계약 | 부족한 점 | 후속 작업 |
|---|---|---|---|
| 상품 선택 | search_products → 선택한 작업공간의 상품 ID | 상담자료에만 있는 성분·용도 검색이 해결되지 않음 | 4차 상담 검색 수정. 현재 일반 검색을 완료된 상담 검색으로 취급하지 않음 |
| 상품 사실 조회 | get_product_context → local 입력/정본·설명/기존 소비자 콘텐츠 페이지 | 구조화 상담자료의 근거·버전·공개 대상 계약 없음 | 3차 논리 유형·접근 정책 정리 후 허용 자료만 전달 |
| 소비자 안내 초안 | save/update_product_content_draft → 기존 다국어 비공개 페이지 | 중앙 상담자료·중앙 QR 표준설명서 저장 아님 | 현재 기능 재사용. 중앙 자료 생성·저장 완료라고 안내하지 않음 |
| 공급자 설명 초안 | save_content_draft/store_description → 공급자 STORE draft | 중앙 관리자 확정 자료와 권한·검수 단계가 다름 | 5차 관리자 준비 흐름에서 별도 대상·검토·버전 계약 확정 |
| 구조화 상담자료 작성 | 전용 저장 계약 없음 | 섹션·출처·주의사항·자료 대상·버전 검증 필요 | 3차에서 형식 확정, 5차에서 관리자 검토·재사용 흐름 연결 |
| QR 표준설명서 | 기존 소비자 콘텐츠/자료와 구별 필요 | 중앙 공통 원본·매장 사용·게시/QR 연결 단계 미확정 | 3·5차에서 정의. 외부 도구에 자동 게시 권한 부여하지 않음 |
| 출력 맞춤 | 일반 안내문은 ChatGPT가 제공된 자료로 작성 가능 | 약사/승인 근무자/소비자·매장 표현 설정의 신뢰할 계약 없음 | 6차 출력 설정. 표현 선택은 자료 접근 권한을 만들지 않음 |

### 구조화 자료를 지금 그대로 노출하지 않는 이유

현재 중앙 상담자료 리더는 B2B 유형과 연결되어 있으며, 매장용 외부 연결에는 약사·승인 직원 등 서로 다른 이용자가 있다. 일반 매장 읽기 scope에 상담자료 전체를 추가하면 자료별 공개 대상이 정리되기 전에 접근 범위를 확대할 수 있다. 3차에서 B2B·상담자료·QR 논리 구분, 기존 자료 연결 보존, 누락 자료 상태, 이용자 자격과 허용 audience를 먼저 확정한다. `get_product_context`의 기존 B2B 본문을 구조화 상담자료라고 이름만 바꿔 전달하지 않는다. 일반 B2B 설명을 상담자료의 자동 대체로 추가하지 않는다.

### 후속 읽기·저장의 수용 기준

상품 ID는 서버가 선택한 매장의 실제 취급 관계에서 도출한다. 읽기 결과는 자료 종류·출처·버전·언어·허용 대상·누락/오래됨 상태를 구분한다. ChatGPT가 만든 내용은 기존 소유·비공개 초안·멱등·리비전 규칙으로 저장하며 중앙 승인·게시와 분리한다. 실패·연결 해제·권한 거부를 이유로 o4o 유료 생성에 자동 전환하지 않는다. 외부 ChatGPT 구독·모델 토큰을 수집하지 않는다.
