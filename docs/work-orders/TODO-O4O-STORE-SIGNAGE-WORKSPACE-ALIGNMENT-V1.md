## 확정 범위

일반 콘텐츠와 사이니지를 업무 화면에서 분리한다. 사이니지는 동영상함 → 재생목록 → 재생 설정 흐름이다.
동영상함의 출처는 커뮤니티·가입한 약국협업체·직접 등록한 외부 영상/보관 파일이다.
O4O 채널 소유를 외부 영상 등록 조건으로 삼지 않는다. 기존 파일 저장소·사본·재생 엔진·목록 모델을 재사용한다.
약국경영자 통합 가입 승인에서 매장을 자동 연결하며 별도 최초 약국 신청을 하지 않는다.
사용자용 사업 명칭은 ‘약국대상 세미프렌챠이즈 서비스’, 메뉴는 ‘이용 사업·가입 관리’로 통일한다.

## 조사 후 재점검·보정

- 신규 단일 승인 서비스는 이미 조직/owner/약사 자격/약국 원장/기본 사업을 연결한다. 기존 원장 삭제는 범위가 아니다.
- 별도 신청 화면·메뉴·POST 최초 신청 경로는 남아 있다. 읽기 원장과 매도·폐업·사업자 변경·직원 초대는 보존한다.
- `/services`와 `/store/businesses`는 같은 업무다. My Home도 헤더와 보조 메뉴에 중복돼 있다.
- 공통 PharmacyBusinessInfo가 조회 실패에도 `/pharmacy`로 이동한다. Store 앱은 그 경로가 없어 원래 오류가 사라진다.
- 운영 테스트 계정은 owner 매장 1개·active 약국 원장·사업자/면허 정보를 보유하지만 자격 원장은 unrequested다.
  운영 자료는 이 PR에서 바꾸지 않는다. 합성 계정 준비 코드와 격리 DB 검증을 보완하고 반영 방법을 기록한다.
- 사이니지 동영상/재생목록/일정은 1,800줄 단일 화면이다. 기존 동작과 매장 변경 시 늦은 응답 폐기 로직을 보존한다.
- 협업체 자료 복사는 assetType=content이며 첨부 영상이 동영상함에 연결되지 않는다. 가입/게시 확인을 거치는 영상 가져오기를 연결한다.
- from-signage가 body의 organizationId를 별도로 받는다. 서버가 확인한 재생목록 소유 매장과 일치해야 한다.
- 태블릿 ScreenSet·TV 재생·사본 기반 store_playlists와 운영자 signage_playlists는 서로 다른 계약이다.
  이번 작업에서 DB 통합·신규 재생용 테이블·Channel 복구·자동 목록 교체를 하지 않는다.
