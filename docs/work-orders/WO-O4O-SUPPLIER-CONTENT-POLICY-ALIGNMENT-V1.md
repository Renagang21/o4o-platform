## 정책 결정

1. 공급자 자료함은 원본 보관 장소다. 저장 기본값은 비공개이며 저장·제품 등록이 커뮤니티 게시나 서비스 등재를 유발하지 않는다.
2. 커뮤니티 게시와 서비스 등재는 독립된 선택이다. 커뮤니티는 일반 회원의 가입·게시판 권한으로 별도 작성기에서 내용을 확인한 뒤 게시한다. 공급자 역할 자체가 커뮤니티 발행 권한을 부여하지 않는다.
3. 약국 협력사업은 각각 독립 서비스다. 콘텐츠 요청은 활성 사업을 대상으로 해당 사업의 회원 전용 자료함에 검토 사본을 접수하며, 담당 운영자가 승인·게시 또는 사유를 남겨 반려한다. 커뮤니티 가입은 사업 등재 요청의 선행 조건이 아니다.
4. 같은 자료·사업의 살아 있는 수신은 하나이며 원본 수정·삭제가 이미 보낸 사본에 자동 전파되지 않는다. 공급자는 자기 요청의 결과를 확인한다. 다른 사업·미가입 약국의 자료 접근은 허용하지 않는다.
5. 기존 catalog 기반 CMS 제공 계약과 제품 등록·협업체별 공급 제안·이벤트의 독립성은 유지한다. pharmacy는 예/아니요 선택과 명시적 저장을 통해 기본 공급에 등재한다.
