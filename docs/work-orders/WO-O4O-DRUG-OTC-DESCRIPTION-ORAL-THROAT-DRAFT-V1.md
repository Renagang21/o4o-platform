# 1. 목적

약국에서 가장 많이 상담하는 구강·인후질환 일반의약품의 소비자 설명서를 작성한다.

소비자는 대부분 다음 증상으로 제품을 찾는다.

- 입안이 헐었어요.
- 구내염이 생겼어요.
- 목이 아파요.
- 목이 따갑고 칼칼해요.
- 침 삼킬 때 아파요.
- 목이 붓는 것 같아요.
- 입 냄새가 심해요.
- 가글을 어떻게 사용하나요?
- 트로키는 씹어 먹나요?
- 목 스프레이는 어떻게 사용하나요?

이번 작업은 제품별 설명서가 아니라

허가사항·제형·투여경로·사용법이 같은 그룹별 대표 설명서를 만드는 것이 목적이다.

```text

```

```text
맵고 뜨거운 음식은 통증을 심하게 할 수 있습니다.
```

```text
씹지 말고 입안에서 천천히 녹여 사용합니다.
```

```text
삼키지 않습니다.
```

목 스프레이

```text

```

구강 외용제

```text
환부에만 사용합니다.
```

고열

```text
고열, 심한 목 통증, 삼키기 어려움, 호흡곤란이 있으면 진료를 받아야 합니다.
```
