## 3. 조사 중 잡은 판정 결함 2건

이 두 건을 잡지 못했으면 **정상 문서 수천 건을 안전 문제로 오보**할 뻔했다.

### ① 매장 템플릿 상용구를 "원문에 없는 내용 추가" 로 오판 — 7,177건

효능 비교에 `tile`·`badge` 를 넣었더니, 매장 템플릿 상용구
(`품목기준코드 …의 공식 허가사항을 기준으로 작성했습니다`, `매장 약사에게 먼저 문의하세요`,
`제품명이 아니라 성분과 함량으로 확인하세요`)가 전부 "공식에 없는 어휘" 로 집계됐다.

표본을 열어보니 **전부 원문 충실본**이었다:
```
공식: 이 약은 치은염(잇몸염), 치은출혈, 보철(의치)에 의한 염증의 통증 완화에 사용합니다.
현행: [intro] 이 약은 치은염(잇몸염), 치은출혈, 보철(의치)에 의한 염증의 통증 완화에 사용합니다.
```
→ 효능 비교를 `intro` 와 효능 라벨 절로 한정하고, **어휘 추가는 판정 근거에서 제외**했다
(관측용 `OBS_EXTRA_EFFICACY_VOCAB` 30건으로만 남김). 실질 위험은 **수치·용량·연령의 추가**다.

### ② 연령 비교 범위 비대칭 — 303건

공식은 **용법+주의 절만**, 현행은 **문서 전체**에서 연령을 뽑아 비교했다.
공식의 이상반응·상호작용 절에 있는 연령을 놓쳐 **없는 모순**이 만들어졌다.

독립검증이 CONTRADICTED 723 중 **303건을 재현하지 못해** 드러났다. 실측 확인:
```
헤모퀸탑연질캡슐  공식 연령 lo=8 hi=6 / 현행 lo=8 hi=6  → 동일. 모순 아님
진셀몬큐텐정      공식 연령 lo=12 hi=6 / 현행 lo=12 hi=6 → 동일. 모순 아님
```
→ **양쪽 모두 문서 전체**에서 뽑도록 고쳤다. CONTRADICTED 723 → **441**, 재증명 **441/441**.
