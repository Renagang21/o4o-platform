# Main 첫 자동화 PC 설치·연결 안내

> 상태: ACTIVE · 작성일: 2026-10-28
> 사용자 지시: O4O 메인에서 첫 AI 자동화를 시작하면 필요한 PC 프로그램 설치를 그 흐름 안에서 진행한다.

기존 설치 패키지·검증 다운로드·pairing·LNA 안내·실행 계약을 재사용한다. 내 정보로 이동시키는 방식을 주 진입점으로 삼지 않는다. 새로운 Core/Task/Memory/DB·인증·HTTP 실행 창구는 만들지 않는다.

- 서버가 Work 요청을 PC 미연결/오프라인으로 사전 중단한 경우(행동 0·history 0) 메인에서 설치·실행·현재 계정 연결 안내를 자동으로 펼친다. 요청 유형을 클라이언트 키워드로 판정하지 않는다.
- 요청·첨부는 현재 페이지 React state에 남긴다. 설치/연결 완료만으로 업무를 자동 실행하지 않고 사용자가 ‘설치·연결 후 요청 계속’을 눌러 기존 서버 경계로 보낸다. 기존 run 재개 앵커와 명시적 확인만 승계한다. 문장을 고쳤다면 이전 work 강제를 승계하지 않는다.
- 이미 행동이 있었던 작업에는 첫 요청 재전송 버튼을 만들지 않는다. 기존 resume/takeover 계약을 유지한다.
- 일반 대화·이미 가능한 원격 실행에는 설치를 요구하지 않는다. 모바일/Mac에서는 localhost를 PC로 오인하지 않고, 실행할 Windows PC에서 같은 계정으로 메인 ‘PC 연결 준비’를 사용하도록 안내한다.
- 계정/업무공간 변경 시 이전 PC 준비 요청을 이어가지 않는다. 이전 문맥에서 늦게 온 준비 응답도 버린다. 초기 안내 localStorage flag를 설치 증거로 사용하지 않는다.
- 메인의 ‘PC 연결 준비’와 약국 주문 준비의 연결 버튼으로 같은 안내를 직접 열 수 있다. 내 정보의 관리 경로는 유지한다.

검증: 사전 실패/확인·첨부 보존/명시적 재시도/일반 대화·원격 PC/모바일/부분 실행/계정·scope 변경/늦은 응답 및 기존 연결·약국 준비 회귀, typecheck/lint/build, desktop/mobile browser smoke.

기본 종료점은 구현·검증·commit·push 후 main 병합 전이다. 운영 반영 및 실제 사용자 PC 적용은 별도 실행 증거로 구분한다.
