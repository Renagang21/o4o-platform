## 1. 목적과 재사용

사용자가 목표를 말하면 현재 자료와 기능으로 진행하고, 필요한 순간에만 최소한의 도움을 받으며 다음 실행에 경험을 활용한다. 처음부터 모든 약국 프로그램의 절차를 정의하지 않는다. 공통 거래처/주문 접점과 약국별 조건을 구분하고, 공통 경험은 추천 후보이지 강제 절차가 아니다.

기존 AI Core/Extension, Task, Memory, 권한, provider, quota 예약/정산, 실행 기록, SQLite migration/backup, PC 인증/명령·DOM/UIA 경계를 재사용한다. 상품 DB/공급자 상품 등록 AI, 신규 인증/정산/주문 원장은 만들지 않는다. 주문 확정·결제·제3자 로그인은 사용자 직접 수행이다. PC에서 받은 업무 자료의 기본 보관은 SQLite이며 서버 저장은 별도 사용자 허가가 있을 때만이다. 업무 데이터와 Experience·매뉴얼·자격정보는 구분한다.
