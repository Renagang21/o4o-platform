## 1. 목표와 유지할 기준

상담의 출발점은 소비자의 질문과 현재 상담 맥락이다. 상품 자료가 필요한 경우에만 **현재 매장 취급 상품 탐색 → 연결된 O4O 공통 상품의 승인 표준자료 조회 → 약사 검토 → 고객 설명**으로 이어진다. 상품명이 없는 질문도 처리하고, 상품을 참조할 필요가 없는 대화는 상품 선택 없이 이어간다.

- 매장 엑셀은 취급 상품과 공통 상품의 연결을 준비한다. 같은 상품의 표준 상담자료를 매장마다 다시 생성하지 않는다.
- 공통 상품 자료는 중앙 관리자가 근거를 검토·승인한다. 매장 자체 상품·매장 게시 안내·공통 B2B 자료의 소유권과 준비 상태를 구분한다.
- 관리자에서 용도별 실행 수단을 선택한다. 브라우저 기능도 지원하는 용도의 선택 항목으로 취급한다. 처음 연결하는 제공자의 연동은 필요하지만 이미 연결한 제공자 교체 때문에 상담 화면을 다시 개발하지 않는다.
- 상담 중 필요한 맥락만 일시적으로 유지한다. 확인한 상품자료·콘텐츠·업무 자산을 재사용하며, 상담 원문을 영구 이력·Task·Memory·학습 데이터로 축적하지 않는다.
- 기존 Core/Extension, 모델 설정, 가격·한도·회계, 매장 권한 및 자료 원장을 확장한다. 별도 Assistant·모델 registry·회계 원장을 복제하지 않는다.
- 취급 상품은 실시간 재고 보유 보장이 아니다. 상품 탐색 결과만으로 판매·주문·게시·고객 공유를 자동 실행하지 않는다.
