## 범위와 판정

가입·역할·조직 원장은 변경하지 않는다. 공통 계정 생성과 서비스별 가입·승인을 분리한다.
메인용 membership을 복제하거나 Demo 권한을 우회하지 않는다. 신규 migration과 운영 데이터 backfill은 포함하지 않는다.
실제 데모 가입 데이터는 계정별로 다르므로, 모든 서비스 이용 권한이 있다고 가정하지 않는다.
새 가입과 승인 상태 변경은 통제된 로컬 fixture로 검증하며 운영에서는 읽기와 본인 로그인만 사용한다.

운영 확인은 배포된 SHA·본인 API 응답·메인 표시의 일치를 기준으로 한다. 준비되지 않은 사업이나 미가입 상태를 가입으로 표시하지 않는다.

## 로컬 검증

- PostgreSQL 임시 테이블·transaction rollback을 사용해 승인 전후·정지·다른 계정 분리를 검증했다. 영구 데이터 변경은 없다.
- 메인 관련 기존 회귀 109개와 추가 계정 전환 검사, API 단위 5개·PostgreSQL 통합 1개 통과.
- API·web-neture 빌드 통과. clean 환경에서는 security-core·market-trial의 개별 사전 빌드도 실행했다.
- Chromium 1440px·390px에서 승인 후 가입 목록 추가·탐색 제외, 정지 후 이용 진입 제거, 탭 복귀 재조회 확인. 화면 오류·가로 넘침 없음.
- 실제 Demo의 가입 원장은 변경하지 않았으며, 존재하지 않는 가입을 표시하지 않는다.
