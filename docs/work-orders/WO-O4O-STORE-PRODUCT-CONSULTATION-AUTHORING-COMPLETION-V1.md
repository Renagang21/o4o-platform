## 범위·소비처

변경은 web-store 내부 상품 설명 보조·직접 작성/재편집·로컬 authoring adapter에 한정한다. ProductDescriptionAssist의 기존 소비처(로컬 상품 등록/설명 관리·QR·다국어·제작 자료)는 비제어 기본값을 유지하며, 상품 연계 작성/직접 콘텐츠 재편집만 제어 상태를 저장한다. ProductEvidencePicker 기본 본문 추가 모드와 다국어 소비처를 유지하고 근거 선택 모드를 추가한다. packages/Core·공통 메뉴·권한·API·DB schema 변경은 없다.

외부 MCP/OAuth·연결 설정·등록·서버 주도 AI 자동화·정기 상품 worker·운영 데이터·실계정은 변경하지 않는다. ChatGPT 계정/구독/대화는 O4O에 저장하지 않는다. 상담자료의 상품 참조 메타데이터는 표시/작성 문맥이며 서버의 실제 productRef 소속 검증과 링크 원장을 대체하지 않는다. 기존 자료함의 저장/공개 경계와 서버 수정 동시성 계약은 유지한다. 본 기능의 재조회는 atomic revision 잠금을 새로 제공하는 것이 아니다.

기본 종료는 검증·commit/push 인계이며 main 병합·배포는 이번 완료에 포함하지 않는다.
