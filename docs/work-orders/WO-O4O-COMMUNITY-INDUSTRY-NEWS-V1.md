## 최소 구현 경계

기존 cms_contents의 community-editorial 예약 범위와 초안을 재사용한다. AI 일일 실행 예약/결과도 같은 비공개 예약 범위(kind=news-review, status=draft)에 저장하여 새 테이블·migration·queue·추천 플랫폼을 만들지 않는다. 기존 공통 AI Core·관리자 모델 설정·원자 quota·사용량 기록을 사용한다. 운영 데이터·실계정·실제 유료 모델 호출로 테스트하지 않는다. 수집 차단을 다른 프록시/실행 채널로 우회하지 않는다.

## 2026-10-21 구현·검증 결과

독립적으로 검증 가능한 1단계는 **운영자가 등록한 뉴스 초안**의 정리다. 자동 기사 수집이나 자동 정기 실행을 구현한 것으로 해석하지 않는다. 미처리 초안의 제목 160자·제공 요약 240자까지만 입력하고, 출력은 최대 1,800토큰·24초·provider 1회 시도다. 실행 전에 한국 날짜별 예약을 커밋하며 실패·프로세스 중단도 그날의 실행을 소비한다. 완료 결과는 입력 기사 ID·URL이 일치하는 기존 편집 초안에만 적용할 수 있다. 결과 반영·게시·회원/공개 범위는 운영자가 직접 저장한다. 기존 중앙 AI 활성화·모델·quota·가격 설정을 사용한다. 새 테이블·migration·의존성·workflow 변경은 없다.

- `pnpm install --frozen-lockfile`, `pnpm run build:packages`: 통과.
- API `tsc --noEmit -p tsconfig.build.json`, 웹 `pnpm --dir services/web-neture run build`: 통과. 기존 Browserslist 노후·번들 크기 경고가 있다.
- API 뉴스 정책·예약·AI adapter 16개 테스트: 통과. 실제 모델은 mock이며 유료 호출 없음.

- Chromium 실제 웹 빌드·API fixture: PC 1440 / 모바일 390에서 홈·출처·추천 표시·운영자 뉴스 탭·초안 적용 확인. 가로 넘침·JavaScript 예외 없음. 운영 로그인/실제 API 검증으로 간주하지 않는다.
- 변경 파일 ESLint, `git diff --check`, 문서 민감정보 검사: 통과.

## 남은 외부 연결

실제 세 매체 요청은 2026-10-21에도 프록시 CONNECT 403이다. 런타임 허용 목록에서 데일리팜·약사공론은 확인되지만 접속은 거부되며 메디파나(`medipana.com`, `www.medipana.com`)는 목록에 없다. 환경 설정 적용 후 각 사이트의 제공 피드/API·수집 허용 경로를 실제 확인해야 한다. 검증되지 않은 RSS 주소나 HTML 선택자를 추정하여 수집기를 만들지 않는다. 이 단계가 해소되면 제공된 제목·요약의 수집·중복 방지·정기 실행을 연결하고 운영 공개 검증 후 병합·배포한다.
