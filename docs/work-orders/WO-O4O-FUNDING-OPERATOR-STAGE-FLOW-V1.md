## 조사와 범위

기준 main `b3f792578a497c0509ab844d0096d543709fee49`, branch `wo/funding-operator-stage-flow`.
모집 → 준비 → 결과 확정 → 이행 완료 → 종료의 수동 전환은 운영자와 개설자 API가 기존 `FundingWorkspaceService.changeStatus`를 공유하고, 행 잠금·현재 상태 검사·이력을 유지한다.

PG·주문·배송·정산 기능, 권한·API·schema·migration·운영 DB 변경은 이번 범위에 없다.

확인한 부족:

- 개설자 참여자 조회는 펀딩 ID가 같으면 다시 실행되지 않는다. 같은 펀딩의 단계 변경이나 운영자 입금 확인 후 새로고침·실패 재시도 경로가 없었다.
- 운영자 승인·반려·단계 전환의 늦은 응답은 다른 펀딩으로 이동한 화면의 오류·작업 상태에 영향을 줄 수 있었다. 단계 전환 후 참여 명단은 갱신하지 않았다.
- 단계별 담당 업무를 현재 참여 명단·지표·포럼 업무와 함께 안내하지 않았다.
