## 코드·문서 점검 후 개발 범위 보완

- 음성 안내 요청은 시작 버튼만 있고 마치기 동작이 아래 문장 번역 영역에 있었다. 같은 위치에서 시작/마치기를 제공하고, 음성이 끝나기 전 안내 준비/공유를 잠근다. 인식 결과에 입력 focus를 강제하여 화면 키보드를 열던 동작을 제거한다. 음성 미지원 기기의 해당 버튼은 노출하지 않고 기존 문자 입력을 제공한다.
- ‘같은 안내 다시 준비’가 실패한 AI 선택/선택 문단 번역의 옵션을 잃었다. 마지막 요청을 현재 화면 메모리에서만 재사용하여 상품·질문·언어·선택 문단과 작업 종류를 유지한다. 다섯 positional 인자 대신 명명된 요청 옵션을 사용한다. 언어·매장·모드·상담 세대 변경 때 재시도 요청도 폐기한다.
- 정상 heartbeat가 명시 종료/공유 등의 실패 안내까지 지웠다. 명시 작업 오류와 연결 확인 오류를 분리한다. 401/403으로 접근 거부를 확인하면 현재 연결·코드·늦은 응답 세대를 해제하고 기존 부모 화면의 입력/음성 정리를 사용한다. 503/일시 오류에서는 입력과 현재 상담을 유지한다.
- 새 회귀를 수정 전 실행하여 실패 7건을 확인했고 관련 34건을 수정 후 통과했다. 추가로 접근 거부 뒤 늦은 heartbeat가 상담을 되살리지 않는 경쟁 검사를 포함한다. 최종 수치는 CHECK에서 확정한다.
- 공통 이력은 사용자 기준으로 본문을 저장/조회하는 경로가 있다. 보존 정본의 당시 ‘미사용’ 서술과 현재 코드 연결의 차이는 공통 AI/개인정보 담당 후속 정합으로 보고한다. 운영 row 수·본문·보존 job은 조회하거나 변경하지 않는다.
- [상담·AI 데이터 범위 검토안](../design/DESIGN-O4O-STORE-CONSULTATION-DATA-SCOPE-V1.md)에 현재 상태와 후속 매장별 이력·직원 해제·비공개 전문 자료·방치 상태 파기·경험 재사용의 미결정 항목을 구분했다. Core/이력/정책·DB·API·의존성 변경 없음.
