## 확정 범위

O4O 거래 자격을 개인·법인 또는 과세 유형으로 구분하지 않는다. 사업자 기본정보에서 세금계산서 관련 정보로 **개인 / 법인**을 명시적으로 선택한다. 일반과세·간이과세·면세·비영리·기타는 새 선택지에서 제외한다. 이 값으로 거래 승인·결제·공급 제안 조건을 추가하지 않는다.

기존 `individual` / `corporation` 저장 코드를 유지한다. 과거 과세 유형 값은 개인·법인을 판정할 근거가 아니므로 자동 변환·일괄 변경하지 않는다. 조회 라벨과 API 읽기 호환은 유지하고, 기본정보 수정 시 재선택을 안내한다. DB migration과 운영 데이터 변경은 없다.

실제 세금계산서 발행 연동·과세 방식 판정·부가세 계산은 이번 변경 범위에 포함하지 않는다.

## 추가 사용자 지시 — 공급자 메뉴

공급자 사이드바의 **유통참여형 펀딩** 항목을 제거한다. desktop과 mobile drawer는 동일 메뉴 정의를 사용한다. 이번 지시는 메뉴 항목 제거이며 펀딩 서비스·원장·API를 폐기하는 작업은 아니다. 공급자 대시보드의 현황 카드와 독립 펀딩 서비스는 변경하지 않는다.

세미프랜차이즈 모집은 특정 협업체의 취급 약국 모집이며, 일반 판매자 모집과 원장·신청 관리 화면을 공유한다. 특정 협업체·모집 공급가·협업체 운영자 조건 승인이 추가되는 변형이다. 후속 사용자 지시에 따라 별도 세미프랜차이즈 모집 기능의 신규 진입을 종료한다. 사이드바·상품 상세의 생성 버튼을 제거하고, 과거 URL은 종료 안내로 바꾼다. 신규 생성 API는 기존 인증·공급자 인가 후 410으로 거부한다. 일반 판매자 모집과 과거 모집·신청·주문 이력은 보존한다.
