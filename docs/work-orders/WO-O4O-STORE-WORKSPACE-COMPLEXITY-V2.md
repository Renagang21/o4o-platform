## 범위

이전 내 매장 배치·패널·상태 정비의 연속 Phase다. 같은 전용 `wo/store-workspace-panels` 브랜치를 유지한다.
사용자 종료 범위는 push이며 main merge·배포하지 않는다. AI·공통 Core·서버·schema·권한·운영 데이터는 변경하지 않는다.
공통화는 O4O 전체 정비 때 판단한다. 이번 신규 함수 모듈은 각 업무의 단일 화면 소비용이며
여러 화면/서비스용 helper·공통 패키지·범용 업무 엔진을 신설하지 않는다.
