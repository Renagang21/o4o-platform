## 목적과 범위

사용자의 각 서비스 로그인 화면 디자인 개선 요청에 따라 최신 main `c9b72ee2ae`에서 독립 worktree와 branch `wo/service-login-design`으로 시작했다. [AGENTS.md](../../AGENTS.md), [SETUP.md](../../SETUP.md), [공통 모듈 변경 절차](../baseline/O4O-SHARED-MODULE-CHANGE-PROTOCOL-V1.md)를 따른다.

Neture(대표·공급자·펀딩·커뮤니티·CarePharm 호스트), O4O 약국, 내 매장, 분회, 강의, 관리자 로그인 화면에 공통 카드와 서비스별 포인트 색을 적용한다. 페이지형 화면은 desktop 소개 영역과 카드, mobile 단일 카드로 구성한다. 모달형 화면은 작은 viewport에서 내부 스크롤을 제공한다. 입력·버튼·계정 도움말·체험 진입의 간격과 타이포그래피를 정리한다.

공통 컴포넌트는 표현만 담당한다. 이메일·Google·카카오·Demo 동작, 서비스별 복귀 경로, 관리자 Google 전용 정책과 강의의 계정 센터 연결 계약을 유지한다. 회원가입·재설정 등 기존 폼과 업무 화면에는 새 스타일을 적용하지 않는다. 계정센터는 자체 로그인 화면이 아니며 원내 약품은 무로그인 앱이므로 새 인증 UI를 추가하지 않는다.

공통 소비처를 모두 빌드·검증하고 합성 인증/SDK로 브라우저 화면을 확인한다. 운영 로그인·DB 쓰기·병합·배포는 이번 개발 담당 범위에 포함하지 않는다.
