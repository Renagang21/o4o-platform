## 범위

사업 참여자 커뮤니티와 안내·자료의 운영 흐름을 중심으로 조사한다. 공급·주문·결제 로직, DB migration, 운영 데이터 변경은 이 정비의 기본 범위가 아니다. 기존 사업 회원 원장과 일반 커뮤니티 가입 원장을 합치지 않는다. 공유 UI는 Neture·약국 서비스 소비처를 함께 확인한다. main 병합·배포는 별도 요청 범위다.

## 조사 결과·수정 TODO

- 정상: 사업 원장과 일반 커뮤니티 가입은 분리. 사업 담당자는 활성 Neture 역할 + 활성 담당 행으로 판정한다. 참여자 포럼은 `sf:<사업 UUID>` 저장 범위를 사용한다.
- 정상: 사업 자료는 초안·게시·보관, 참여 약국 열람·독립 사본 계약을 유지한다.
- 정비: 공통 운영 UI에 옛 용어가 남아 있다. Neture·약국 경영지원 두 소비처를 함께 수정한다.
- 정비: 담당 사업 운영 화면에서 참여자 게시판으로 연결이 부족하다. 기존 사업/커뮤니티 경로와 약국 서비스의 공개 주소를 그대로 이용한다.
- 정비: 사업 게시글 화면은 담당 운영자 삭제는 제공하지만 공지 고정/해제는 누락했다. API `PATCH .../posts/:id/pin`과 기존 권한/사업 격리를 재사용한다. 게시판당 공지 1건이며 새 공지 고정 시 기존 고정은 해제된다.
- 정책 확정: 사용자가 현행 권한 유지·운영 흐름 정비를 선택했다. 사업별 admin/operator 분리는 이번 범위에 포함하지 않는다. 독립 커뮤니티의 권한 정책을 사업에 임의 이식하지 않는다.
