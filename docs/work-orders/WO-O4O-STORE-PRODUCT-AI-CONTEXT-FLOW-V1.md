## 목표·경계

매장 엑셀의 상품을 기존 ProductMaster와 연결하고, 정부 공개정보→제조사 자료를 근거로 준비된 AI 상담지원 자료를 재사용·보완하는 실제 흐름을 완성한다. 엑셀은 상품 식별 입력이며 POS 연동·가격·주문·재고 입력이 아니다. 바코드를 우선하고 이름은 선택 후보로만 사용한다. 근거가 없거나 본문이 없으면 설명을 만들지 않는다. 사용자 기여는 기존 관리자 검토 경로로 누적한다.

공통 상품 QR은 전체관리자가 별도로 작성·승인한 STORE 설명서를 표시한다. 엑셀 처리·AI 자료 승인·일반 사용자 입력으로 QR 설명서를 자동 생성/교체하지 않는다. 기존 매장 자체 자료·마케팅 QR과 공통 상품 QR은 서로 다른 자산이다.

운영 DB·실상품·유료 AI·MCP/OAuth·Job/Scheduler·IAM 변경, main merge·auto-merge·배포는 하지 않는다. 기존 자원·조직/회원 권한·관리자 정본 저장 계약을 재사용하고 새 원장/테이블은 먼저 만들지 않는다.

## 문서·코드 대조 결과와 구현 계약

기존 bulk-match는 이름/code 기반의 미리보기이며 매장 등록이나 설명 작성은 하지 않는다. 기존 description-intake는 준비한 JSON만 받는다. 새 파일 대조 경로는 현재 매장 권한 아래 바코드/상품명 열을 받고 명시적 선택을 기존 /store/products/list로 연결한다. 새 배치 원장은 만들지 않는다.

AI 항목·근거는 기존 후보 raw_payload에 보존하고 승인 canonical의 source_ref_id로 조회한다. B2B/언어를 정확히 맞추며 STORE 대체 조회는 없다. 구조화 항목은 자유 본문 편집과 함께 무효화하고, 같은 본문이어도 구조/출처가 바뀌면 새 승인으로 반영한다. 현재 등록상품만 읽는 API·작성 화면과 기존 약사 상담지원의 근거 입력을 연결한다. 공통 QR은 기존 관리자/STORE 경로를 유지한다.
