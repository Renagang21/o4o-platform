- frozen lockfile + store integrity 설치와 Store 의존 패키지 빌드 성공.
- Store 타입 검사·프로덕션 빌드 성공. Browserslist 데이터 및 큰 청크 경고는 유지.

- Chromium: 현재 수정 소스를 로컬 Vite로 실행하고 테스트 브라우저의 Store 요청만 로컬 응답으로 연결. API는 기존 승인된 테스트 계정의 실제 운영 응답을 TLS 검증해 조회.
