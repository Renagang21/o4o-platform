## 검증 및 남은 단계

- Admin 단위 테스트: 20개 파일, 378개 통과(신규 정책 회귀 8개).
- Chromium 브라우저: 14개 통과(정책 실패·복구·재조회·저장·reload를 desktop/mobile로 검증).
- 최초 단위 실행은 테스트 선택자가 저장 중 버튼 이름 변경 및 두 새로고침 버튼을 구분하지 못해 실패했다. 선택자를 수정하고 전체 재실행 통과.
- 최초 브라우저 실행은 기존 이메일 테스트 2개가 인증 확인 화면에서 시간 초과했다(12개 통과). 초기 의존성 변환·동시 build 영향 가능성을 확인하기 위해 build 종료 후 workers=1로 전체 재실행했고 14개 통과했다. 원인을 확정하거나 실패를 skip으로 바꾸지 않았다.
- 이전 정책·모델 조회 응답은 최신 요청 이후 또는 unmount 뒤에 반영하지 않는다. StrictMode 중복 조회 회귀로 늦은 이전 응답이 편집값을 덮어쓰지 않음을 검증했다.
- Admin 타입 검사 통과. 변경 파일 ESLint 오류·경고 0. 문서 민감정보 패턴 0.
- Vite 직접 production build 통과. tracked 버전 파일 변경 없음.
- 실제 Google 로그인·SMTP 발송·운영 AI 호출·DB write는 검증 대상이 아니다.
- PR required CI 및 Codex 검토 후 main 통합·배포는 사용자 승인 단계다. 클라우드 초안 게시와 개발 PR 배포는 별개다.
