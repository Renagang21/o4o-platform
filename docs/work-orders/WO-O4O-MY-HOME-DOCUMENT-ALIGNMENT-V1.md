## 목적과 승인 범위

개인 공간 이름을 **My Home**으로 통일한다. 독립 서비스의 참여·커뮤니티 활동과 매장 경영 현황을 모아 보고 내 매장으로 연결하는 역할, 여러 화면으로 나누는 구성, 로그인 후 공통 헤더 직접 진입을 현행 문서에 반영한다.

기준 문서 변경과 정본 색인의 관련 항목 추가·설명 갱신은 이번 문서 작업의 범위다. 소스 코드·URL·파일명·DB·API·권한·로그인 계약은 변경하지 않는다. 과거 WO·CHECK·IR·archive와 코드 식별자에 있는 MYPAGE는 보존한다. main 통합과 배포는 이 지시의 완료로 간주하지 않는다.

## 조사와 적용 대상

- 최신 main `5f9fcde7ef2a27b4c382260f318147601afc9387`에서 관련 Markdown 문서와 현재 Neture `/mypage` route를 대조한다.
- 종전 계정 관리 위치 문서는 서비스별 UI·web-account 범위와 과거 구현 기록을 담는다. 현행 `neture.co.kr` 공통 계정 정책과 새 개인 공간 역할을 우선하도록 적용 관계를 명시한다.
- [My Home 정본](../baseline/O4O-MY-HOME-CANONICAL-V1.md)을 작성하고 대표 홈·역할·서브도메인·인증·계정 관리·공통 헤더·공통화·공유 모듈·포인트·Demo 안내 및 정본 색인을 정렬한다.
- 각 도메인의 실제 활동·업무·통계 원장과 조회 권한은 유지한다. 문서 정책의 확정과 UI 구현·배포 완료를 구분한다.

## 완료 조건

1. 관련 현행 문서가 My Home 정본을 참조하고 명칭·역할·진입 위치에 모순이 없다.
2. 남은 MyPage 표현은 기술 식별자·호환 경로·당시 기록·종전 정책 설명으로 확인된다.
3. 변경 문서의 상대 링크, diff 공백, 민감정보 검사와 변경 범위를 검증한다.
