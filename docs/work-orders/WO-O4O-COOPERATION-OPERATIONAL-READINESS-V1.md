## 확인한 결함과 보완

공통 업무 화면에서 요약이 있으면 자료 전체 본문이 감춰지고 첨부를 열 수 없었다. 전용 자료 화면에도 첨부 표시가 없었다. 회원·운영자가 본문과 첨부를 확인하도록 보완한다. 기존 권한으로 반환된 자료만 표시하고 자동 다운로드는 하지 않는다. 첨부는 HTTP/HTTPS 주소만 링크하며 자격정보가 포함된 주소·실행 스킴·잘못된 값은 거절한다. 공통 업무 화면의 본문은 기존 plain text 처리를 유지한다.

공통화는 자료 표현에 한정한다. 가입 단위·권한·API 계약·DB·의존성·배포 설정은 변경하지 않는다.
