### 코드 대조 후 확정

- 이번 사용자 승인 기능에 필요한 신규 저장은 상담 도메인 `store_consultation_stations` 1개로 한정한다. 약국/상담 자리, 담당자, 상담 세대, 기기 연결 해시, 마지막 공유 내용/고객 답변과 연결 상태만 보관한다. 기존 설정/AI 이력/SSO 토큰 테이블에 고객 내용을 섞지 않는다. migration·manifest·격리 PostgreSQL fingerprint를 개발하되 운영에 적용하지 않는다.
- 대형/일반 구성은 기존 `organizations.metadata`의 `consultationLayout` enum만 사용한다. 전체 관리자 전용 설정과 기존 매장 인증 조회를 추가하며 서비스 이용권·Role·약사 확인을 생성하지 않는다.
- 고객 연결 자격은 무작위 1회 연결 코드와 해시로 보관하는 별도 기기 토큰이다. 고객 API는 쿠키/직원 토큰을 사용하지 않고 현재 상담에 한정된 공유 읽기·답변만 허용한다. 직원 해제·기능/약사 확인 취소는 다음 조회에서도 재검사한다.
- 상담 자리별 세대와 DB 원자 갱신으로 지연 응답·중복 연결·이전 고객 답변을 거절한다. 종료는 공유 화면과 현재 전달 상태를 비운다. 영구 상담/AI 이력 정책을 새로 확정하지 않는다.
- 기존 번역과 고정 직원 문구는 재사용한다. 매대 일반 직원용 입력은 기존 직원 응대 이용권 아래 별도 `counter-staff` 모드로 두며 약사 기능을 부여하지 않는다. 한국어 상담은 외부 번역 호출 없이 확인된 문장을 전달한다.
- 공통 진열 뷰어를 Store의 독립 공개 route에서도 재사용한다. 기존 서비스 공개 URL과 인쇄 링크는 유지한다. 새 공개 실행 화면은 직원 로그인 Provider/내 매장 헤더·탭 밖에 둔다.
