# WO-O4O-BUSINESS-PARTICIPANT-SERVICE-SPACE-V1

> 작성일: 2026-10-10 · 사용자 구현 승인 · PR #376에 기존 메인 복귀 수정과 함께 반영

## 목적

공통 커뮤니티는 약업계 전체의 정보·교류·단체활동을 담당한다. 약국 협력사업은 자기 서비스에서 참여 신청·사업 자료·참여자 게시판·업무 도구·Contact Us를 제공하고, 내 매장은 해당 약국의 실제 업무를 담당한다. 모든 서비스에서 대표 홈으로 복귀할 수 있어야 한다.

## 구현 범위

- pharmacy 서비스의 `/`는 소개 Home 대신 `/businesses/pharmacy/participation`으로 진입한다. `/businesses/:businessKey` 아래 신청·자료·게시판·도구를 제공한다.
- 사업 정보는 로그인 후 최소 신청 정보만 조회한다. 자료·게시판은 기존 서버 승인과 조직·사업별 권한을 유지한다.
- 게시글·댓글·게시판 개설 신청·소유 게시판·회원 관리는 기존 `sf:<UUID>` 원장과 API를 재사용한다. DB 이동·회원 추가·승인 자동화는 없다.
- 공통 커뮤니티 목록에는 독립 커뮤니티만 표시한다. 사업 게시판의 구 주소는 대응 사업 서비스로 인증 인계하며 세부 주소·쿼리를 보존한다.
- 대표 홈 개인화 목록의 현행 workspace 응답을 정규화한다. 사업 공간은 공통 커뮤니티 카드에 섞지 않고 내 서비스에서 연결한다.
- 내 매장의 사업 참여자 버튼도 해당 사업 서비스로 연결한다. 내 매장 업무·주문·자료 복사 계약은 유지한다.
- 공통 복귀 버튼을 `O4O 메인으로`로 명확히 표시한다. 기존 PR #376의 독립 로그인·인계 실패·약관 화면 복귀 보완을 함께 제공한다.
- 커뮤니티 Contact Us는 메뉴·푸터에서 제외한다. 강의는 강의 목록으로, 공급자는 로그인 후 신청·이용 상태로 진입한다. 이전 소개 소스 파일 삭제는 legacy 제거 트랙에 맡긴다.

## 경계와 인계

현재 구현은 운영 중인 협력사업의 service-owned 화면과 원장 재사용이다. 준비 중 사업의 대표 홈 카드·팝업·Partner 설명 페이지 및 AI 상단 재배치는 별도 대표 홈 구현 대상이다. 새 서브도메인·DB migration·권한 계약 변경을 만들지 않는다.

검증·push·PR 확인까지 진행하며 main 통합은 저장소 승인 절차를 따른다. 운영 반영 여부를 로컬 구현 완료와 구분하여 보고한다.
