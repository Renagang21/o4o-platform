# WO-O4O-BUSINESS-SPACE-WITHOUT-COMMUNITY-CONFIG-V1

> 2026-10-10 · 사용자 승인된 참여자 공간 정비의 운영 검증 후속 보완

PR #376 운영 반영 후 매장 경영자 체험 경로를 검증했다. 사업 정보와 신청 화면은 200으로 조회되지만 기본 사업의 communityKey가 없어서 게시판 안내만 표시됐고, 같은 값에 묶인 사업 자료·도구 접근도 미승인으로 처리되는 코드가 확인됐다.

기존 community_key가 있으면 그대로 사용한다. 없으면 `business:<businessKey>`를 참여자 API 주소로 계산하고 서버가 그 사업의 immutable ID로 `sf:<UUID>` 원장을 찾는다. 승인·조직 소속·계정 상태·담당 운영자 판정은 기존 함수의 동일한 SQL을 재사용한다. 독립 커뮤니티와 원장은 섞지 않으며 없는 사업 주소는 독립 커뮤니티로 재해석하지 않는다.

사업 정보 및 개인화 목록에서 이 기본 주소를 사용한다. 게시판 생성·가입·승인이나 데이터 이전은 자동으로 수행하지 않는다. 게시판 개설은 사업 공간에서 기존 담당 운영자/신청·심사 절차로 진행한다.

코드·회귀 검증·후속 PR·필수 CI·기존 승인에 따른 병합·배포 후 체험 경로를 다시 확인한다. DB 변경, 서비스 가입 부여, 권한 완화, 별도 소개 Home 추가는 범위에 없다.
