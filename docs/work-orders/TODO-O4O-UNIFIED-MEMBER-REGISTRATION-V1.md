|---|---|---|
| 공통 | 이름·닉네임·휴대전화. 이메일은 인증 수단에서 받아 운영자 정정만 허용 | 기본 계정과 회원 상태 |

사업자 항목은 상호·사업자번호·대표자·업태·종목·사업자 구분·개업일·우편번호·주소/상세주소·사업장 전화·담당자/전화/이메일(공급자 공개 문의 이메일과 구분)·세금계산서 이메일·사업자등록증이다. 정산 계좌·결제·상품 원장 같은 가입 외 업무를 회원 폼에 복제하지 않는다.

기존 users.businessInfo의 예약 키 o4oMembershipRegistrationV1을 가입 스냅샷으로 재사용하며 actor/권한/버전·필드 allowlist를 server에서 검증한다. 일반 self-profile/business patch에 예약 키를 허용하지 않는다. 승인 후 실제 조직/공급자/약사 원장에도 같은 transaction으로 반영한다. DB migration/기존 데이터 backfill을 추가하지 않는다. 기존 역할 자료는 읽기 호환으로 제공하며 선택한 가입 유형과 인가 role을 혼동하지 않는다.

공급자/약국/파트너의 게시된 약관은 본인 제출 시 기존 enrollment policy 계약으로 동의를 기록한다. 운영자 수정으로 동의를 대신 만들지 않는다. 직원 관리는 경영자 전용이며 운영자의 회원 해지/복구는 직원 및 사업체 원장을 쓰지 않는다. 기존정지/해지 읽기호환을 제공한다.
