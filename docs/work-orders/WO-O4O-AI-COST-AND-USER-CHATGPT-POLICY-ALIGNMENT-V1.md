# WO-O4O-AI-COST-AND-USER-CHATGPT-POLICY-ALIGNMENT-V1

> **상태**: ACTIVE · **작성일**: 2026-10-29
> **근거**: 사용자 요청 — AI 비용 절감·사용자 ChatGPT 연결 정책을 기존 진화 원칙의 하위 기술 운영 정책으로 공식 보관.
> **범위**: 문서 작성·정합성 검증·정본 색인 등재·commit/push·PR/CI/리뷰를 통한 main 병합 준비까지. 코드·DB·운영 설정·실제 배포 변경 없음.

## 목적과 변경 파일

- [기술 운영 정책](../baseline/O4O-AI-COST-AND-USER-CHATGPT-OPERATING-POLICY-V1.md)에 새롭게 확정한 선택·비용·연결·월간 점검·도입 판정 기준만 보완한다.
- [정본 지도](../CANONICAL-INDEX.md)에 하위 운영 정책으로 등재한다. 새로운 아키텍처 정본을 만들거나 기존 정본의 상태를 변경하지 않는다.
- 이 WO는 색인 행 추가를 명시한 문서 작업이다. 기존 기준 문서의 본문·과거 실행 기록은 재작성하지 않는다.

## 완료·인계 기준

정책 본문 전수 대조, 상대 링크·변경 범위·민감정보·diff 검사 후 문서만 commit/push한다. 같은 PR에서 CI·Codex 지적을 보완하고 main 병합 직전 상태로 인계한다. 검증 결과·SHA·PR·미해결 항목은 PR 설명과 완료 보고에 남긴다. main 병합·배포는 이번 작업에 포함하지 않는다.

외부 기술의 현재 지원 여부 조사, 첫 월간 점검 실행, Chrome/WebMCP 시험 및 실제 ChatGPT 연결 검증은 이번 문서 작업의 수행 결과가 아니다. 기존 월간 점검 원장을 찾지 못한 점과 첫 회차에서 기록 위치를 통합할 절차는 정책 §4에 명시한다.
