- [x] 현행 코드 확인: 홈은 실행/대기를 혼합하고 주문 허브로 연결한다. 자료 상태의 관리 링크는 유형 목록만 연다. 상품 소스 입력 전환은 입력 손실 경고를 표시한다. 이벤트·모집에는 이미 상품 연결이 있어 재사용한다.
