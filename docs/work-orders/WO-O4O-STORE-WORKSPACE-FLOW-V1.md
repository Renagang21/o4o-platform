## 결과

- 공통 매장·서비스 지정 매장·사업별 거래·제공 자료 탐색에 같은 4개 상단 업무 메뉴를 연결했다.
- 기존 menu resolver의 capability·직원 구성원 관리 필터를 유지하고 작업별 하위 메뉴로 조립했다.
- 신규 진입은 `/store/workspace/commerce`, `/store/workspace/studio`, `/store/workspace/use`와 같은 서비스 지정 경로다. 기존 URL은 유지한다.
- 콘텐츠 원본·독립 사본·제작·게시·배치의 경계를 유지했다. 저장된 direct 콘텐츠에서 기존 QR 생성 모달로 연결한다.
- QR 저장 후 배치·출력 진입, 사이니지 제작/스케줄 이동, 태블릿 제작/위치 운영 탭과 상단 업무 영역 동기화를 추가했다.
- QR 일반·동영상 생성 폼과 스타일, 사이니지 미디어 편집, 태블릿 고객 화면 미리보기를 페이지에서 추출했다.
- 공통 URL→서비스 지정 URL 전환에서 제작 router state·query·hash를 보존한다. 공개 QR은 실제 공개 서비스 origin을 사용한다.
- AI 기존 제작 도움은 유지한다. 새 AI 호출·Core·제공 업체·비용 설정은 별도 담당 범위다.
