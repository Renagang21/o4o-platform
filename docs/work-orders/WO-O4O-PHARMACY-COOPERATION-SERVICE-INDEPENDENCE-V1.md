# 약국 협력모델 독립 서비스와 내 약국 관계 문서 정정

> **상태**: COMPLETED
> **작성일**: 2026-10-16
> **근거**: 사용자의 약국 협력모델별 가입·승인 주체 정정 및 문서 수정 지시
> **범위**: 문서 정정. 코드·DB·권한·배포 변경 없음.

## 확정 기준

각 약국 협력모델은 독립 서비스다. 약국 개설약사는 각 서비스에서 가입 신청하고 해당 서비스 운영자의 승인을 받는다. 승인된 협력모델이 제공하는 부분이 그 약사의 내 약국에 표시되며 실제 약국 업무는 그곳에서 수행한다. 만성질환관리를 기존 pharmacy 서비스의 하위 모델로 해석하거나 pharmacy 가입을 선행 조건으로 삼지 않는다.

## 정본 반영

- [서비스 탐색 정본 §1.1–1.2](../baseline/O4O-HOME-SERVICE-DISCOVERY-V1.md): 가입·승인 주체, 내 약국 표시·실행, 만성질환관리 업무 배치.
- [역할·업무공간 정본 §3](../baseline/O4O-ROLE-WORKSPACE-ARCHITECTURE-V1.md): 독립 서비스라는 사업 의미와 기존 기술 저장 방식 구분.
- [서브도메인 의미 정본 §3-1-1](../baseline/O4O-SUBDOMAIN-SERVICE-SEMANTICS-V1.md): 서비스별 가입·승인과 내 약국의 관계.

기존 대화의 조사 요약은 위 기준으로 정정한다. 과거 WO·CHECK·IR의 당시 실행 기록, 기존 가입 원장과 serviceKey는 변경하지 않는다. 문서 수정은 실제 기능 구현·배포·연동 완료를 뜻하지 않는다. CGM 및 무료혈당기 외부 연동 규격은 별도 확인 대상이다.
