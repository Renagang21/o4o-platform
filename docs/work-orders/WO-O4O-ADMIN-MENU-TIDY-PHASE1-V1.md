## 확정 범위

동영상 제작, 사이니지 콘텐츠 조회, 이전 AppStore의 관리자 메뉴·전용 화면·내부 연결을 제거한다.
독립 정책 안내는 관련 화면에서 펼쳐 보는 도움말로 옮긴다. 포인트 운영은 삭제하지 않고 지급·차감·거래 조회·서비스 예산을 유지하며 사용 흐름을 정돈한다.
전체 관리자는 서비스 전반 설정과 운영 현황을 담당하며, 개별 이용자의 가입·승인·활동은 각 서비스가 맡는다. 별도의 담당자 교체 절차·변경 이력 메뉴를 신설하지 않는다.

이번 단계는 관리자 프런트에 한정한다. 공용 모듈 등록/상태 판정, 기존 권한 검사, 서비스 사이니지·미디어·상품 DB, 백엔드 API·데이터는 유지한다. DB write/DDL/migration, dependency·lockfile·배포 설정 변경은 없다.

- 과거 조사 [IR](../investigations/IR-O4O-ADMIN-INFORMATION-ARCHITECTURE-AND-MENU-ROLE-CENSUS-V1.md)은 당시 35개 메뉴와 이미 은퇴한 구현을 포함한다. 현재 메뉴 수와 AppStore 유지 판정의 근거로 재사용하지 않는다. 과거 기록 본문은 변경하지 않는다.
- 업무 경계: [역할별 업무공간 Architecture](../baseline/O4O-ROLE-WORKSPACE-ARCHITECTURE-V1.md). 이번 사용자 지시에 따라 전체 현황·공통 설정에 집중하며 서비스 회원·신청 승인이나 담당자 부재 시 예외 개입을 추가하지 않는다.

### 다음 단계의 순서와 착수 기준

1. 서비스 전반 설정: 카탈로그·사업 설정·운영자 지정의 중복을 확인하고 ‘서비스 선택 → 설정’ 초기 화면을 구체화한다.
2. 상품 DB: 기존 7개 업무의 목록·상세·쓰기 범위를 확인하고 ‘상품 관리 / 등록 검토 / 자료 보강 / 데이터 정비’ 묶음안을 논의한다. 이번 단계에서 탭이나 API를 바꾸지 않는다.
3. 공통 설정·운영 현황: 설정 탭·플랫폼 HUB·사용자 조회의 책임 범위를 정돈한다. 서비스 이용 업무는 각 서비스가 맡는다.
4. 공용 자료·게시: 큰 메뉴 통합은 실제 콘텐츠 소유·노출 범위를 확인한 뒤 결정한다.

각 단계는 해당 메뉴의 현행 코드·문서를 다시 조사하고 TODO를 확정한 후 구현한다. 이번 단계의 완료를 전체 관리자 재정비 완료로 보고하지 않는다.
