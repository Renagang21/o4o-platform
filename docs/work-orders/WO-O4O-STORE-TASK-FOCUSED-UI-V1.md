## 조사 후 보완

- 공통 shell의 큰 AI와 페이지별 시작 카드가 중복됨. Store 로컬에서 한 AI 세션을 유지하고 제목 다음 슬롯에 표시한다. 공통 패키지의 동명 shell은 수정하지 않는다.
- 같은 입력 UI를 작성 모달 내부 슬롯에도 제공한다. 계정/매장/서비스 경계와 지연 응답·중복 유료 요청 차단을 보존하며 업무 데이터 자동 전송은 추가하지 않는다.
- 목적지 카드 목록을 기존 상품 목록 / 내 콘텐츠 목록 / 실행 현황으로 대체한다. 이미 권한 필터를 통과한 config만 사용하고 전체 업무는 작은 보조 메뉴로 유지한다.
- 상품 추가·콘텐츠 작성은 기존 모달 동작을 사용한다. `?create=1`만으로 현재 작성 모달이 열리지는 않으므로 새 가짜 링크를 추가하지 않는다.
- 통합 작성 이력은 없으므로 자동 이어쓰기 버튼/가짜 최근 작업을 만들지 않는다. 홈 상품 수는 활성 listing 기준임을 표시한다.
- QR 경고·출력·통계는 현재 모드/선택에 맞게 배치한다. 태블릿 고급 설정은 항목 하나씩, 사이니지 일정 요약은 운영 문맥에 표시한다. 저장·게시·기기 동작은 서로 구분한다.
- Store 공통 mount `/store/*`와 `/work/kpa-society/store/*`, 서비스 미가입 매장, 승인 직원/Owner 메뉴 및 공통 UI 소비처를 함께 확인했다. 기존 테스트의 메뉴 커버리지·모드/query·AI 격리/실패 계약을 회귀 기준으로 사용한다.
- My Home 정본(User/Store 구분), 역할별 업무공간, 소비자 commerce/B2B, shared module protocol, 기존 Store 설계의 승인 반영 절을 대조했다. 과거 TODO를 현재 미완료로 역추론하지 않는다.

## 코드 정비 기준

중복된 목적지 카드 화면을 기존 업무 목록으로 대체하고 Store 로컬 shell로 제목·AI·빠른 작업의 배치를 모은다.
AI는 한 세션의 표시 위치만 바꾸며 화면/모달별 대화 상태·별도 엔진을 복제하지 않는다.
태블릿은 상세 작업 하나만 표시하되 이미 입력한 편집 상태는 유지한다. 전체 레거시 파일 재포맷·범용 추상화·공통 Core 개편은 포함하지 않는다.
