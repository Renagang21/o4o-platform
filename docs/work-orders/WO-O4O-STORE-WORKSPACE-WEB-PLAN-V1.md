## 범위

네 메뉴(내 매장 홈 / 상품·거래 / 콘텐츠 작업실 / 매장에서 활용)를 기준으로,
자료 보관·제작·적용 흐름과 PC·모바일 웹 반응형 화면 초안을 한 묶음으로 만든다.
실제 업무 화면의 메뉴 변경과 편집기 분리 구현은 기획 검토 이후다.
O4O 전체 AI Core + Extension은 별도 담당이며 이번 작업에서는 메뉴별 요구와 연결 위치만 정의한다.
O4O 부담 유료 AI를 배제하지 않는다. 기술·사업 변화에 대응할 공통 정책과 연계한다.
