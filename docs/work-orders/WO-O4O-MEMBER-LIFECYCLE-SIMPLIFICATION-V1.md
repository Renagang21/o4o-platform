# WO-O4O-MEMBER-LIFECYCLE-SIMPLIFICATION-V1

> 상태: COMPLETED · 작성일: 2026-11-03 · 범위: 사용자 승인 개발·로컬 검증·commit·push. main 통합·운영 활성화는 별도다.

## 사용자 결정

- Operator는 이용 정지, Admin은 계정·개인자료 완전삭제를 담당한다. Admin 삭제에 별도 Operator 정지를 강제하지 않는다.
- 직원은 하나의 약국 또는 사업체에만 소속된다. 직원 이용 해지와 계정 삭제를 구분하고 사업체 업무 자료는 유지한다.
- 약국 매도는 동일 조직 자료의 경영자 연결을 이전한다. 완전폐업은 별도 확인을 받아 약국 자료 파기를 실행한다.
- 공급자의 제품·거래 자료는 개인 계정 삭제와 분리하고 도메인 코드에서 처리한다.
- 일반 개인 자료·첨부는 제거하며 법정 최소 증빙·타인 자료·공유 객체·백업의 기존 경계는 유지한다.
- 개발 종료점은 push다. 운영 DB·파일 삭제, 배포·활성화, 새 migration·인프라 변경은 수행하지 않는다.

## 구현 범위

기존 계정 제거·회원 상세·Store 계약 파기 서비스를 재사용한다. 새 범용 workflow engine이나 소유권 추정 규칙을 만들지 않는다. 직원 단일 소속 검사는 기존 대상자 lock 안에서 실행한다. 매도는 사용자·조직·승인 약사 자격을 다시 확인하며 데이터 복사 없이 경영자 관계만 이전한다. 완전폐업은 조직 이용과 소속을 종료한 뒤 기존 Store inventory와 파일 파기·재시도를 실행한다. 일반 계약 종료의 기존 7일 경로는 유지한다.

계정 제거는 사업 자료를 사용자 FK cascade로 지우지 않는다. supplier 개인 연결·연락처를 제거하고 공급자 identity와 제품·거래는 유지한다. 개인 소속 및 완료된 폐업 case는 제거하되 미완료 폐업·미분류 개인 증빙파일은 완료로 표시하지 않는다.

## 개발 검증과 남은 경계

검증·실패 보완·운영 준비 한계는 [CHECK](../checks/CHECK-O4O-MEMBER-LIFECYCLE-SIMPLIFICATION-V1.md)를 따른다. 최신 정식 스키마에 남아 있는 writer fence 미등록과 미분류 domain/file inventory는 이 WO에서 운영 보완하지 않았다. 기능 OFF·운영 설정은 그대로이며 전체 실계정·외부 저장소 파기 완료를 선언하지 않는다.
