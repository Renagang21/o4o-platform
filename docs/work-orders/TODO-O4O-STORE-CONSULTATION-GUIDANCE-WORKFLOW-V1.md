- 약사 연결은 기존 코드에서 안내 문구였다. 실제 담당자 호출·접수 계약이 없다면 호출 완료로 표시하지 않고 정확한 행동으로 안내한다.
- 모델/키/과금/한도는 최신 main의 기존 실행 계약을 따른다. 별도 provider/Memory/의존성/인프라를 추가하지 않는다.

- 실제 마이크·현장 소음·언어별 약사 검수·실계정 업무는 합성 검증과 구분한다. 환경에서 수행할 수 없는 검증은 미실행으로 인계한다.
