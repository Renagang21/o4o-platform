## 유지 경계

Store 실행자산과 HQ 방송 카탈로그 저장 모델을 통합하지 않는다. 공통 필수 영상 API/화면은 기존 소비처를 조사하여 호환 범위를 검증한다. 데이터 변경은 격리 테스트만 사용하며 생산 DB에는 적용하지 않는다. 게시기간은 KST 입력/UTC 저장, 시작 이상·종료 미만이다. 외부 영상 주소 복사는 외부 호스팅 파일의 존속을 보장하지 않는다.
