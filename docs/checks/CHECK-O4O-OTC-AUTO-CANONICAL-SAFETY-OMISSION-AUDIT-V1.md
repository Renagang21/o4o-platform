## 4. 별건 발견 — **e약은요 원문 자체의 데이터 유실**

감사 중 근거 원문이 문장 도중 끊긴 것을 발견해 추적했다. **내 추출 결함이 아니라 DB 저장값 자체가 유실돼 있다.**

```text
raw content: "…신부전 환자(크레아티닌 청소율 \n\n이 약을 복용하기 전에 임부…"
                                        ↑ "< 10 mL/min)인 환자는 … 마십시오." 소실
```

원인: 원문의 맨 `<`(부등호)를 HTML 태그 시작으로 보고 **다음 `>` 까지 삭제**. 적재 시점 sanitize 결함으로 추정.

| 항목 | 수 |
|---|---:|
| e약은요 canonical 전체 | 19,177 |
| "크레아티닌 청소율" 포함 | 148 |
| └ 뒤에 수치 있음(정상) | **3** |
| └ **수치 유실** | **145** |
| 괄호 미닫힘 유실 일반형 | **174** |

> **영향**: ① 이 감사에서 세티리진 2그룹의 금기 목록을 전수 확인하지 못했다(판정은 **유실되지 않은 부분의 증거만으로** 성립 — §5). ② **e약은요 19,177건은 그 자체가 SPD STORE canonical** 이므로, 유실된 금기가 그대로 공개되고 있을 수 있다 — **본 WO 범위 밖이나 별도 점검 대상**(§6).
