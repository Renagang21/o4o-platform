## 7. SOURCE GAP 판정 (§3.11)

- **질환 수렴 대표 작성**: 무좀(항진균)·가려움·벌레물림·상처·화상·피부감염 = 원문상 **질환·사용 목적이 수렴** → 질환 중심 대표. 소비자가 "어떤 피부 문제에 쓰는가"로 판단하도록 질환 표제.
- **조성 추정 금지(WO §6)**: 외용 복합(항히스타민+국소마취+수렴 등)의 **스테로이드/항생제/항진균 종류/국소마취 포함 여부를 단정하지 않음**. 효능·부위·용법·원문 주의사항만 기술. 조성 세분 = HOLD_SOURCE.
- **약사 검토 강화(§3.9·§3.10)**: DERM-INFECT(항생 외용)는 내성·오남용 우려 → 기본값 약사 검토 강화(10일 이내·임의 장기사용 금지).
- **EXCLUDE**: 스테로이드 습진(D07·범위 밖)·먹는 피부약(D04A 경구 60).
- **성분 창작 0**: 모든 초안 §3·§4 원문 실조회 근거.

### 초안 1 — 무좀·백선 외용제 (항진균, D01A)

**어떤 경우에 사용하나** 발·몸·사타구니의 무좀(백선), 어루러기, 피부 칸디다 등 곰팡이(진균) 피부질환에 사용하는 항진균 외용제입니다.
**사용 방법** 1일 2~3회 질환 부위에 얇게 바르고 문지릅니다. 바르기 전 환부를 씻고 물기를 없애며, 발가락 사이까지 건조하게 합니다. 곰팡이 질환은 증상이 사라진 뒤에도 재발 방지를 위해 **충분한 기간(부위에 따라 1~4주) 규칙적으로** 사용합니다.
**사용 시 주의사항** 만 2세 이하 소아는 사용하지 않습니다. 임부·수유부, 프로필렌글리콜 과민 경험자는 사용 전 약사와 상담하세요. 수건·양말 등은 매일 갈아 재감염을 막습니다.
**병원에 가야 하는 경우** **손발톱까지 침범했거나 넓게 퍼진 경우에는 진료가 필요합니다.** 7일 정도 사용해도 좋아지지 않으면 사용을 중단하고 진료를 받으세요.
**사용 확인 포인트** 무좀약은 바르는 부위·기간을 지키는 것이 중요하며, 습진·세균감염과 구분이 필요하면 약사에게 확인하세요.

**병원에 가야 하는 경우** **고름, 심한 통증, 발열이 있으면 진료가 필요합니다.** 감염이 번지거나 7일 정도 사용해도 좋아지지 않으면 중단하고 진료를 받으세요.
**사용 확인 포인트** 항생제 외용제는 내성 우려가 있어 **꼭 필요한 감염에 짧게** 쓰는 것이 원칙이며, 사용 전 약사에게 확인하세요.

## 9. 안전성 처리 (WO §8·§11)

**질환별 절대 비혼합(WO §11)**: 무좀·가려움·벌레물림·상처·화상·피부감염을 **각각 별도 대표**로 작성. 바르는 약↔먹는 약도 분리(D04A 경구 60 제외). 질환별 안전문구:

| 질환 | 안전문구(초안 반영) |
|---|---|
| 무좀 | 손발톱 침범·넓게 퍼짐 → 진료 |
| 가려움 | 원인불명 전신 가려움 → 진료 |
| 벌레물림 | 호흡곤란·얼굴 부종·전신 두드러기 → 즉시 진료 |
| 상처 | 깊은 상처·출혈 심함 → 진료 우선 |
| 화상 | 넓은 화상·물집 심함 → 진료 |
| 피부감염 | 고름·심한 통증·발열 → 진료 |
| 공통 | 7일 미개선 → 중단·진료 |

## 10. HOLD_SOURCE / 제외

**HOLD_SOURCE:** D06B 외용 화학요법(여드름·항바이러스 등) 207(g127) — 질환 세분 필요 · D01A/D04A 외용 복합 조성 세분(스테로이드/마취/수렴 포함 여부 미표기).

**EXCLUDE / 범위 밖:**
- **습진·피부염 스테로이드 외용**: D07 계열 — WO 조사 ATC(D01~D06)·스테로이드 제외 대상. 가이드 §3.10 수동 큐레이션 → 별도 트랙.
- **먹는 피부약**: D04A 경구 60(정·시럽) — 바르는 약↔먹는 약 혼합 금지.
- 안연고·치질 연고·질정·구강 연고·의약외품·건강기능식품·처방약 = 범위 외.
