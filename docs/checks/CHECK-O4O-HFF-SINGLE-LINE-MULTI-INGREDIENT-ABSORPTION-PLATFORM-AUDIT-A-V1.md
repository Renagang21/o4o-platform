# CHECK — HFF 단일형 라인 다중원료 흡수 플랫폼 전수 감사 (Agent A) V1

- 상위 WO: `WO-O4O-HFF-SINGLE-NUTRIENT-MULTI-INGREDIENT-MISCLASSIFICATION-AUDIT-AND-LUTEIN-CORRECTION-V1` §2 — "**다른 단일 영양소 배치에서 동일 다중원료 흡수 패턴 존재 여부 (공통 결함 여부 확정)**" 딜리버러블.
- 발단: `CHECK-O4O-HFF-COMBO-NEW-CANDIDATE-TOP3-REVIEW-A-V1` §3-3 — single-Zn LIVE 1건(아연+셀렌+크롬) 흡수 발견 → 전 단일형 라인으로 감사 확장.
- 성격: **read-only · DB write 0**. 원문(G:드라이브 raw 44,885) BASE_STANDARD / MAIN_FNCTN 재파싱. LIVE 수정·apply 미실행.
- 방법: 단일형 LIVE 산출물(로컬 artifact) 34개 파일 = **2,900 제품**의 원문에서 기능성 표시량 spec 을 **강건 파서**(비표준 포맷 `X:(값/basis)의 %` — 표시량 접두 누락·선행 괄호 포함)로 재추출 → 기능성 원료 ≥2 = 복합 제품 흡수(lut-va류) 판정. MAIN_FNCTN 기능성 블록 교차로 defect vs 항산화 부원료 분리.

## 0. 결론

**lut-va(루테인+비타민A) 흡수 결함은 고립 사고가 아니라 기능성(botanical/지용성) 단일형 라인 전반의 공통 결함이다.**

| 라인군 | 감사 제품 | 흡수 의심 | 판정 |
|--------|:-:|:-:|------|
| **미네랄/비타민 단일형** (아연·마그네슘·칼슘·철·셀레늄·비오틴·엽산·비타민 A/B군/C/D/E/K 등 21라인) | 1,473 | **1** | 사실상 clean (isolated) |
| **기능성 단일형** (루테인·오메가3·가르시니아·코엔자임Q10·감마리놀렌산·녹차·밀크씨슬·MSM·프로폴리스·은행잎·테아닌·옥타코사놀·글루코사민 등 13라인) | 1,427 | **258** | **공통 결함(systemic)** |

- 미네랄/비타민 라인은 원료 분류 키가 독립 + 단일 셀렉터 "표시량 spec ≥2 → 복합 제외" 규칙 정상 → 흡수 거의 없음.
- 기능성 라인은 지용성 원료(오메가3·감마리놀렌산·Q10·루테인)에 **비타민E(항산화)** 동반, 다이어트 원료(가르시니아·녹차)에 **식이섬유** 동반이 일반적 → 2원료 등록 제품을 단일로 흡수하며 **부가 기능성 누락**.

## 1. 미네랄/비타민 단일형 = clean (흡수 1)

- 1,473 제품 중 기능성 spec ≥2 = **1건**뿐:
  - **stmt `20040015107573` "정상적인 면역기능에 필요한 프로그램"** — 실제 **아연+셀렌+크롬 3원료**인데 `single-nutrient-zinc` 로 게시(셀레늄·크롬 누락). 원인: `셀렌:(55㎍/7,500mg)` 비표준 포맷(표시량 접두 누락·선행 괄호) → 셀렉터 미포착. (본 결함은 신규-후보 검수 CHECK §3-3 에서 최초 보고.)
- 그 외 1,472 제품 = 정확히 1 기능성 → clean. **미네랄/비타민 라인은 교정 불요.**

## 2. 기능성 단일형 = 공통 결함 (흡수 258)

MAIN_FNCTN 기능성 블록 교차로 3분류:

| 범주 | 정의 | 건수 | 조치 |
|------|------|:-:|------|
| **A. CONFIRMED** | 부가 원료가 MAIN_FNCTN 에 **독립 기능성 블록** 보유 → 등록 기능성 누락 확정 | **110** | 교정 대상(확정) |
| **C. 기타(indeterminate)** | 부가 원료 spec 존재하나 MAIN_FNCTN 브래킷 미형식 → 자동판정 불가(**표본검증 결과 대부분 진짜 dual-functional**) | **114** | 제품별 MAIN_FNCTN 확인 후 교정 |

## 4. 판정 — 교정 방식

- **제품 단위 교정 아님 → 라인별 그룹 재분류 + 기존 canonical SPD 대체** (lut-va 교정 설계와 동일 구조, 규모 확대).
- 각 흡수 제품: 실제 등록 기능성 원료 집합 확정 → 해당 복합 조합으로 재게시(`batch:single-nutrient-combo-*`), 기존 단일 SPD 은퇴/대체. source_ref_id·QR·rollback 영향 검토.
- **미네랄/비타민 라인**: 교정 불요(§1 Zn 1건만 별도).

## 5. 한계·주의 (정직 고지)

- **A+C=224 는 추정**(A 확정 110 + C 표본상 대부분 진짜지만 100% 아님). 교정 전 **제품별 MAIN_FNCTN 등록 기능성 검증 필수**.
- **B(35) 오교정 금지** — 비타민E 항산화 부원료(등록 기능성 아님)를 기능성으로 게시하면 역과대표시.
- 강건 파서도 초-비표준 포맷은 누락 가능 → **258 은 하한**(실제 흡수 ≥258).
- 로컬 artifact 를 단일형 LIVE 모집단 대용으로 사용 — 정확한 LIVE 소속(batch tag)은 교정 시 DB 대조로 확정.
- 비타민C 라인은 대표 파일(100) 만 반영 — 파일럿 잔여분 후속 확인.
