## 4. 후보 그룹 산출 방식

DB 실측 결과 **ProductDrugExtension의 성분/함량/제형 정규화 필드(ingredient_summary·active_ingredients·strength·dosage_form·efficacy_text)는 OTC 57,572건 전부 NULL** (임상텍스트 미채움 정책과 정합). manufacturer_name·mfds_code만 100% 채워짐.

→ WO §4 대체 순서에 따라 **ProductMaster 파생 그룹핑** 사용:

```
성분  = name 끝 괄호 안 문자열  substring(name, '\(([^()]+)\)\s*$')
함량  = specification 첫 토큰   split_part(specification,' / ',1)
제형  = name 내 제형 키워드(연질캡슐/캡슐/정/시럽/과립/…) 우선순위 매칭
```

집계 축: `(성분, 함량, 제형)` · drug_category='otc' 한정.
지표: 제조사 수(distinct manufacturer_name) · master 수 · 포장단위 다양성(distinct specification) · e약은요 보유(shared_product_descriptions source_type='mfds_easy_drug' join).
포장단위/바코드/낱알 수량은 그룹 분리 기준에서 **제외**(가이드 §3.2).

## 10. 가이드 문서 업데이트 여부

작성 중 발견 → `O4O-DRUG-STORE-DESCRIPTION-WRITING-GUIDE-V1.md` 갱신 (additive):

1. **§7.4 예시 추가** — 에르도스테인 300mg 캡슐 (실 O4O 데이터 기반 **첫 비-해열진통제(거담제) 예시**). 기존 §7 예시가 해열진통제 3종에 편중돼 있어 성분군 다양성 보강 (§9 "새 성분군 반복 표현 기준 발견").
2. **분류 표기 주의 note** — "분류(일반의약품/전문의약품)는 O4O `drug_category` 기준이며, 실제 판매 시 품목별 허가구분은 약사가 확인" 문구를 §3에 추가. 거담제처럼 현장 처방 동반이 잦은 그룹의 위험을 명문화.

가이드 미존재 상태였으므로 사용자 작성본(Downloads)을 `docs/guides/`에 배치 후 위 2건 반영.
