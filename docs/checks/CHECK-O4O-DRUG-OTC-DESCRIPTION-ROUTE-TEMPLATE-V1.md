## 3. 경구 템플릿(기준) vs 비경구 템플릿

**경구(가이드 §5, 변경 없음):**

```md
## [성분] [함량] [제형]
| 항목 | 내용 |  (성분 / 분류 / 작용 / 주요 증상 / 선택 포인트 / 주의 대상)
**효능·효과** / **복용 안내** / **주의 대상** / **성분 기준 선택**
```

**비경구 공통(신규):**


## 4. route별 템플릿 + 필수 주의 문구

### 4.1 외용 크림/연고/겔 (약효군: D01 항진균·D07 스테로이드·D06 항생·D10 여드름·D02 보호·D03 상처)

- 요약표 사용 부위/경로 = "피부 외용(도포)".
- 사용 안내: 사용 부위 한정, 하루 도포 횟수, 도포 전 세척·건조.
- 필수 주의: **상처·점막·눈 주위 주의**, 증상 악화·수 주 미개선 시 상담. (스테로이드) **얼굴·겨드랑·성기부·장기·광범위 사용 금지**. (항생제) **임의 장기 사용 금지(내성)**.
- 분류: 항진균 = 검토강화 / **스테로이드·항생제 = 수동 큐레이션**.

### 4.2 파스/첩부 (M02: 케토프로펜·디클로페낙·피록시캄·플루르비프로펜)

- 사용 부위/경로 = "피부 부착(경피)".
- 사용 안내: 부착 부위·1회 부착 시간·교체 간격.
- 필수 주의: **상처·습진 부위 금지**, **광과민(자외선 노출 피함)**, 같은 NSAID(경구 포함) 중복 주의, 천식·임부 주의.
- 분류: 약사 검토 강화.

### 4.3 점안 (S01XA20 인공눈물·S01GX08 항알레르기·S01GA51 충혈)

- 사용 부위/경로 = "점안(눈)".
- 사용 안내: 1회 점적 수·횟수, 점안 전 손 세척, 용기 끝 눈·손 접촉 금지.
- 필수 주의: **콘택트렌즈 착용 시 제거 후 점안·재착용 간격**, **개봉 후 사용기간**, 다른 점안제와 5분 이상 간격, 충혈·통증·시야 이상 시 중단·상담. (충혈완화) 장기연속 사용 금지.
- 분류: 인공눈물·항알레르기·충혈 = 검토강화 / **항생·스테로이드·복합 점안 = 수동**.
- **과병합 금지:** S01XA20을 CMC·트레할로스·히알루론산·포비돈·카보머로 성분 분리.

### 4.4 점비/비강 (R01AA 옥시메타졸린·자일로메타졸린·R01AX 염화나트륨)

- 사용 부위/경로 = "비강 분무/점비".
- 사용 안내: 1회 분무 수·1일 횟수, 사용 전 코 풀기.
- 필수 주의: **연속 사용 제한(3~7일, 반동성 비충혈)**, 심혈관 질환·고혈압·갑상선 주의, 소아·임부 주의, 용기 공유 금지.
- 분류: 세척(생리식염) = 검토강화 / **충혈완화(교감신경작용) = 수동 큐레이션 성향**.

### 4.5 좌제 (해열 좌제·치질 좌제)

- 사용 부위/경로 = "직장 삽입(항문)".
- 사용 안내: **경구 복용하지 않습니다**, 삽입 방법·깊이, 배변 후 사용, 냉장 보관 시 실온 안정.
- 필수 주의: 소아·임부 용량 기준, 출혈·통증 지속 시 상담, 항문 열상 주의.
- 분류: 수동 큐레이션.

### 4.6 질정/질좌제 (G01AF 항진균 — 클로트리마졸 등, 클로트리마졸 100mg는 20그룹서 작성 완료)

- 사용 부위/경로 = "질 내 삽입".
- 사용 안내: **경구 복용하지 않습니다**, 질 내 깊숙이 삽입(취침 전), 연속 사용 일수.
- 필수 주의: **임부·수유부 상담**, 생리 중 사용·탐폰 병용 주의, 재발·발열·악취 분비물·복통 시 중단·상담, 라텍스(콘돔) 약화 가능.
- 분류: 수동 큐레이션.

### 4.7 트로키/구강정/가글 (인후·구강 살균, R02)

- 사용 부위/경로 = "구강·인후".
- 사용 안내: **삼킴/녹임/헹굼 구분** — 트로키=천천히 녹임(씹거나 삼키지 않음), 가글=입에 머금고 헹군 뒤 뱉음.
- 필수 주의: 사용 후 일정 시간 음식·음료 제한, 소아 사용 가능 여부, 증상 지속 시 상담.
- 분류: 약사 검토 강화.

## 6. 농도/용량/포장단위 기준

**분리 기준:** 성분 다름 / 농도·함량 다름 / 제형 다름 / 투여경로 다름 / 효능·사용법 다름.

**분리하지 않음:** 튜브 용량(20g) / 병 용량(15ml) / 1회용 개수 / 파스 매수 / 포장단위 / 바코드.

**필수 주의(실측 함정):** 점안·외용의 `specification` 첫 토큰은 **농도가 아니라 병/튜브/1회용 용량**인 경우가 많다(예: `0.5밀리리터`, `14밀리리터`, `20그램`). 이는 그룹 분리 기준이 아니며(§3.2), 그룹 확정 시 **원문에서 `%`·`mg/g`·`mg/ml` 농도를 재확인**한다. 예: 히드로퀴논 2%, 포비돈요오드액 10%, 미녹시딜 3%/5%는 **농도가 다르면 분리**하나 튜브 크기 차이는 통합.

## 7. 100그룹 작성에 적용할 기준

1. 비경구 그룹은 §3~§4 `사용 안내` 템플릿으로 작성(복용 안내 금지).
2. 후보 산출 시 `specification` 용량 토큰을 그룹 키에서 제외하고 **농도로 재파싱**, 인공눈물 S01XA20 성분 분리, 노이즈(순·1회용·무향·향·국가명) 제거(DICTIONARY-SEED 재사용).
3. 분류 기본값 적용: 자동 0, 스테로이드·항생·좌제·질정·미백 = 수동.
4. 100 draft 우선순위 = **경구(단일 32 + 복합 검토강화) 먼저, route는 검토강화 가능한 외용 항진균·파스·점안·트로키부터** 편입(수동군은 후순위).
5. 완료 그룹(클로트리마졸 100mg 질정 등) 제외.
