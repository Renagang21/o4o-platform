## 6. master 중복 0 증명

전개 규칙: master는 `substring(name,'\(성분\)$')` + `split_part(spec,' / ',1)=함량` + `name 제형키워드`로 **정확히 한 groupKey**에만 매핑(1 master = 1 ing·str·form).

| 검사 | 결과 | 방법 |
|---|---:|---|
| **Batch 01 ∩ Batch 02 후보** | **0** | 후보 9그룹 전개 master 290 distinct ∩ Batch01 10그룹 전개 586 = **0** (라이브 SELECT) |
| Batch 02 후보 내부 중복 | **0** | 290 master 중 2개 이상 groupKey에 매핑되는 master = **0 / 290** |
| Batch 02 최종 8그룹(질정 제외) master | 250 | 290 − 클로트리마졸 40. Batch01 교집합 여전히 **0**, 내부 중복 **0** |

> 근거: 나프록센**나트륨**275정(B01) vs 나프록센250연질(B02) = 염·함량·제형 상이 / 이부프로펜200정·200연질(B01) vs 400연질(B02) = 함량 상이 / 클로닉신125**정**(B01) vs 125**연질캡슐**(B02) = 제형 상이 / 알파칼시돌0.5㎍(B01) vs 1㎍(B02) = 함량 상이. 전부 disjoint.
