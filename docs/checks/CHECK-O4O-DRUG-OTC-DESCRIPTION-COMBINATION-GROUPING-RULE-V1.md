## 3. 복합제 후보 산출 방식 + 데이터 제약 (중요)

**O4O DB는 OTC 복합제의 구조화된 성분 조합을 보유하지 않는다:**
- `product_drug_extensions.active_ingredients` / `ingredient_summary` = OTC 전부 NULL(보수정책 mirror).
- `product_masters.name` 괄호 성분에 **전체 조합을 나열한 경우는 14건뿐** — 대부분 대표성분 1개 또는 브랜드어만 표기.
- `specification` 함량은 **대표성분 1개 함량**만 → 복합제의 조합 함량 전체를 표현하지 못함.

따라서 복합제 그룹핑의 유일한 신뢰 신호는 **ATC_CODE**다. WHO ATC는 복합제에 전용 코드를 부여하며, **5레벨 후미 2자리 ≥50**이 "combinations"를 뜻한다(예: N02BE51 파라세타몰 복합, A07FA51 정장 복합균, B03AE01 철분 복합).

**복합제 규모(name 키워드 기준, 노이즈 제외):**

| 구분 | 값 |
| --- | --: |
| name 복합키워드 OTC | 1,395 |
| 그중 ATC7 보유 | 394 (28%) |
| 괄호에 다성분 나열 | 14 |

## 4. 병합 가능 조건 (확정)

아래를 **모두** 충족해야 같은 복합제 설명서 그룹 후보로 본다.

```text
1. ATC7 조합코드 동일 (5레벨 후미 ≥50, WHO 'combinations')
2. 대표 함량(specification 첫 토큰) 동일
3. 제형 동일
4. 투여경로 동일 (경구/외용/점안/좌제)
5. OTC 중심
6. 효능·효과 실질 동일 (e약은요 원문 확인)
7. e약은요 grounding 충분
```

> **주의(복합제 특유 한계):** 함량은 대표성분 1개만 표기되므로 "함량 조합 전체 일치"를 DB로 보장할 수 없다. 따라서 **복합제는 병합 조건을 만족해도 기본값을 `약사 검토 강화`로 두고**, 원문으로 조합 성분·함량을 확인한 뒤 확정한다.

출력 형식(운영 시): 후보그룹 / ATC7 / 대표함량 / 제형 / 투여경로 / 제조사수 / master수 / e약은요 / 병합가능 / 비고.

## 5. 분리해야 하는 조건 (하나라도 해당 시)

```text
- ATC7 조합코드가 다름
- 브랜드어(플러스/더블/파워/콤비)만 있고 실제 단일성분 → 복합제 아님, 단일축으로 처리
- ATC 조합코드가 없음(전체 name 키워드의 72%) → 조합 성분 확인 불가 → 보류
- 제형·투여경로 다름
- OTC/RX 혼입 큼
- 효능·효과가 다름 (감기약: 성분 유사하나 타깃 증상 상이)
- 복용/사용법·주의사항 차이 큼
- 근거 원문 부족
```

**특히 주의 약효군:** 종합감기약 / 진해거담 복합 / 위장·소화 복합 / 피부 외용 복합 / 점안 복합 / 비염·코감기 복합 / 진통소염 복합(파스). 이들은 성분 조합이 유사해도 타깃 증상·경로가 갈려 병합 부적합이 많다.

## 6. grounding 판단 (복합제 상향)

복합제 자동초안 조건은 단일성분보다 높다:

```text
효능·효과 근거 + 성분 조합 근거 + 함량 조합 근거 + 복용/사용법 근거 + 주의 대상 근거 모두 확인
```

부족 시 `약사 검토 강화` / `수동 큐레이션` / `보류` / `제외`. 성분 조합·함량 조합 근거는 O4O DB 구조화 필드로 확인 불가(§3)하므로 **원문(e약은요) 확인이 사실상 필수** → 복합제 자동초안 비율은 낮다. AI 임의 보강 금지(§3.8).

## 10. 100그룹 확장 기여 가능성

**판단: 복합제 축의 경구 기여는 6~14그룹으로 제한적. 100그룹은 복합제만으로 불가.**

| 축 | 신규 groupable 그룹(경구) | 비고 |
| --- | --: | --- |
| 단일·경구 (선행 CHECK) | 32 | 자동 3 / 검토강화 21 / 저grounding 8 |
| 복합·경구 (본 CHECK) | 6~14 | 전부 약사검토강화 |
| **경구 축 합계** | **~38~46** | 여전히 100 미달 |
| 비경구 route (단일+복합) | 단일 ~15 + 복합 28 = ~43 | **route WO 소관, 최대 기여원** |

→ 100 도달은 **비경구 route 축(외용 파스/크림·점안·좌제·비강, ~43그룹)** 확장이 결정적. 복합제는 소수(경구 6~14) 기여. 두 축을 모두 열면 32 + 14 + 43 ≈ 89~90 → 100 근접(추가 저grounding/함량변형 포함 시 도달 가능).

## 11. 후속 WO 제안

1. **`WO-O4O-DRUG-OTC-DESCRIPTION-HIGH-RISK-GROUP-CURATION-V1`** (최우선) — 비경구 route(외용 파스 M02 / 크림·연고 D01·D06 / 점안 S01 / 좌제 / 비강 R01) + 복합 외용 28그룹 + 민감군(§3.9) route별 템플릿·수동 큐레이션. **100 도달 최대 기여원.**
2. `WO-O4O-DRUG-OTC-DESCRIPTION-100-GROUP-DRAFT-V1` — 위 완료 후 혼합 축(단일 경구 32 + 복합 경구 6~14 + route ~43).
