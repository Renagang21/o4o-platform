## 3. 엔진 보강 (Cycle 1 엔진 유지 + 규칙 추가)

새 파이프라인을 만들지 않고 검증된 엔진에 규칙만 더했다.

**성상**
- 품질 문구 어미 변형을 하나의 규칙으로 통합(`가 있고 / 를 가지며 / 를 가지고 있는 / 를 지닌` 등)
- 구분자 확장(`이미.이취` `이미∙이취` `이미와 이취`)
- 향미 절이 없는 형태 `이미, 이취가 없는 X` → `free from off-taste and off-odour`
- 색 범위 `미백색~미황색` → `off-white to pale yellow`
- 색+성질 붙음 `갈색투명` → `brown clear`
- 색 괄호 동의어 `빨간 갈색(적갈색)` → `red-brown (reddish brown)`
- `[멀티비타민 정제]` 처럼 대괄호 안이 여러 어절인 경우 형상 설명기에 위임

**규격·기타**
- 표시량 대괄호 표기 `표시량[8.5mg/2g]의 …`
- 표시량 괄호 안의 한글 — `3,000억 CFU/g`(억 환산) · `1회 섭취기준`(per serving) · `니코틴산아미드로서`(as …)
- 콜론 없는 형태 `납(mg/kg) 1.0이하`
- 마릿수/부피 변형 `100,000,000개/2g 이상` `100이하(ml 당)` `3,000이하/1 ml당`
- 슬롯 전체가 괄호 주석인 경우 `(시험방법: 관능검사를 실시하여 …)`
- 유통기한 `제조일부터` `제조일로 부터` `24 개월` `24개월까지`

**항목명**
- 한글 괄호 단위 `세균수(1ml당)` → `Bacterial count (per mL)`
- `X(Y으로서)` → `X (as y)` · `X 중 Y` → `Y in x` · `A와 B의 합` → `Sum of a and b`
- 쉼표 나열 `카테킨, 카페인산, 탁시폴린, 페룰릭산`
- 번호 표기 확장(`ⓛ` `ㆍ` `1 ` 등)

**보관 문구 — 정규화 색인**
같은 문장이 띄어쓰기·구분자·어미만 바꿔 수백 가지로 나타난다. **저작한 문장에만** 정규화 열쇠를
걸어 변형을 자동 흡수한다(`피하여/피해/피하고` · `보관하십시오/보관한다/보관` · `영·유아/영유아`).
부정형(`마십시오`)은 건드리지 않는다 — 의미가 뒤집히면 안 되기 때문이다.

