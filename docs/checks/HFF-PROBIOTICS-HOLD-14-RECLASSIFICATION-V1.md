## A. 내부 해소 가능 (9) — 외부 근거·새 모델 불요

### A-1. SOURCE_ABNORMAL 중 **표기 재확정 가능** (3)

원문에 **값이 온전히 존재하고 자기일관**하다(이중표기가 서로 일치, 또는 값·단위가 분리됐을 뿐 완전). 데이터 결함이 아니라 **표기 정규화** 문제 → 저자가 원문을 읽어 단일 확정값으로 grounding 기입하면 해소. 외부(MFDS) 정정 불요.

| 20040017014271 | 락토베베F | `102,000,000(1억2백만)` | 1.02억 CFU (양 표기 **일치**) | 저자 재확정 가능 |

- **주의**: 현재 가드는 괄호 병기(gloss)를 이중 토큰으로 읽어 `H-COUNT-MISMATCH`/`PRE-SRC-CFU-UNVERIFIABLE` 로 BLOCK 한다. 두 표기가 일치함을 사람이 확인해 declaredCfu 를 단일값으로 기입하면 통과. **부수적으로** 파서의 한글 gloss 지원 강화 시 자동화 가능(공통 rules.ts → orchestrator 소관, in-scope 개선). 어느 경로든 **외부 데이터 의존 0**.

### A-2. OUT_OF_SCOPE 중 **검증된 KW 라인 라우팅** (6)

데이터·grounding 정상. 선정 필터(KIDS/WOMENS) 철자 갭으로 Batch003 frozen selection 에 유입돼 in-place 격리된 것. 제품형은 이미 검증된 **아동/여성 유산균 라인**(KW-CP01~04, PASS) 범위 → 선정 필터 정정 후 KW 라인으로 작성 가능. 새 모델·외부 근거 불요.

- **KIDS (4)**: 리웰키드업 / 바이오스타임…포 칠드런 / 코알라팔스 포도맛 / 코알라팔스 딸기맛
- **WOMENS (2)**: 닥터에디션 페미퓨어 / 시크릿 프로바이오틱스
