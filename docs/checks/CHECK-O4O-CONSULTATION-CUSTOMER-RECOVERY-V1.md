## 보완 내용

조사에서 재현한 세 문제를 한 흐름으로 수정했다. 고객 조회와 답변 전송의 401/403은 같은 기기 해제 함수를 사용한다. 화면·입력·음성·기기 연결을 즉시 비우고 요청 세대를 무효화해 늦은 조회가 이전 화면을 복원하지 못한다. 브라우저 저장소 제거가 실패하더라도 메모리 연결은 해제한다. 서버의 credential 폐기·직원 인가 동작을 새로 만들거나 변경하지 않는다.

기존 화면/기기 세대와 별도로 현재 제출 작업을 식별한다. 새 상담 세대·대기·기기 해제·숨김/종료에서 이전 제출을 분리하고 잠금을 해제하므로 다음 고객은 이전 timeout을 기다리지 않는다. 과거 요청의 성공·실패·finally는 새 고객의 입력·전송 잠금에 관여하지 않는다. 일시 조회 장애의 같은 세대 초안 복원과 전송 장애의 입력 보존·명시 재시도는 유지한다. 서버 멱등성/정확히 한 번 전송을 추가했다고 주장하지 않는다.

기기 연결 저장 실패는 별도 연결 상태로 표시한다. 상담 임시 알림의 초기화·새 고객 전환에 지워지지 않으며 연결 해제/새 연결의 실제 저장 결과에 맞춰 갱신한다.

## 경계와 소비처

변경은 Store 고객 상담 컴포넌트와 그 회귀, 관련 안내 문서에 한정한다. 직원 상담·공통 음성 hook·공통 인증·API client 구현·서버·schema·역할·토큰 발급·의존성·배포 설정은 변경하지 않는다. 고객 요청의 credentials=omit·직원 Bearer/조직 header 미사용 계약을 유지한다. 화면의 민감 문장은 저장소에 남기지 않는다.

실제 계정의 접근 해제·운영 pairing·기기 상태 변경·실제 AI 요청은 실행하지 않는다. 실장치·현장 소음·언어/전문 품질은 별도 검수이며 합성 결과로 완료 처리하지 않는다.
