## 6. `1회 2캡슐(900mg)` 해석 — 보수적 판정 (보고)

`Lacto Bloom` SRV_USE = "1회 **2캡슐(900mg)**" 은 **2캡슐 합계**가 900mg 이라는 뜻이다.
1캡슐 = 450mg 은 **원문에 없다**(나누기 + 캡슐 균등 가정 필요) → `unitWeight = null` 로 두었다.

- 결과: 가드가 **환산 불가**로 판정 → 캡슐당 균수 미생성 (초안도 명시적으로 "1캡슐 중량은 공식 표기에 없다"고 기술)
- **가드 모델 한계**: `ServingSpec` 에 "1회 총 중량" 필드가 없어, 원문이 1회 총량(900mg)을 직접 주는데도
  표현할 수 없다. 기준량 900mg = 1회 900mg 은 사실 **원문만으로 확정 가능**하다.
- 보수적(오탐) 방향이라 이번 배치는 그대로 진행. 30-C 종료 후 `servingTotalWeight` 필드 추가 검토.
