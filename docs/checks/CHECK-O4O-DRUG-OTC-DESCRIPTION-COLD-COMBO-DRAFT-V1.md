## 3. DB read-only 확인

- 접속: `cloud-sql-proxy-v2 netureyoutube:asia-northeast3:o4o-platform-db` (127.0.0.1:5433, OAuth 액세스 토큰) + `psql` user `o4o_api`, db `o4o_platform`.
- 인증: DB 비밀번호는 `apps/api-server/.env`(DB_PASSWORD)에서 세션 환경변수(PGPASSWORD)로만 사용(디스크 미저장·보고 미기재).
- 실행: **SELECT 전용**. 한글 정규식은 UTF-8 `.sql` + `psql -f`(인라인 `-c` 한글은 CP949로 깨짐 재확인).
- 원문: `shared_product_descriptions.content`(source_type=`mfds_easy_drug`, e약은요), join key `master_id`.
- 데이터 제약(STAGE1 재확인): `product_drug_extensions`의 임상/성분 필드(ingredient_summary·active_ingredients·efficacy_text 등)는 **OTC 전량 NULL**. 따라서 WO §9 초안 SQL(pde 성분/효능 기반)은 그대로 동작하지 않으며, **route·성분·조합은 `atc_code` + `product_masters.name` + `SPD content`로 파생**.

### 4.2 핵심 발견 — 감기약 복합제의 적응증이 하나로 수렴 (과분할 금지 근거)

실측 원문 대조 결과, **R05X·R01BA5x·R05FA/FB 복합제의 허가 효능·효과가 사실상 동일 문구**다:

> "감기의 여러 증상(**콧물, 코막힘, 재채기, 인후통, 기침, 가래, 오한, 발열, 두통, 관절통, 근육통**)의 완화"

ATC 차이는 **주도 성분(슈도에페드린→R01BA, 진해거담 포함→R05F, 일반→R05X)** 을 반영할 뿐 라벨 적응증은 "종합감기"로 같다. 따라서 WO §3의 증상축(종합/코감기/코막힘/기침/가래/인후통…)은 **제품 적응증이 아니라 조성 강조점**이다. 가이드 §3.2(포장/형태 과분할 금지)·§3.3(성분+함량+제형 그룹) 원칙상 **동일 적응증을 증상 이름만 바꿔 10~15개로 쪼개면 실질 중복 설명서**가 된다.

→ 본 batch는 **적응증·조성·제형이 실제로 다른 축**만 별도 초안화한다. WO §5 목표(8~15)는 **적응증 수렴으로 축소**하고 사유를 명시(WO §5 "grounding 부족 시 목표 수 축소·사유 기록" 적용). 실제 구분되는 축:

1. 종합감기약 — 성인 정/캡슐 (슈도에페드린 함유형)
2. 종합감기약 — 주간/야간 복합형
3. 종합감기약 — 성인 액제/드링크
4. 소아 종합감기 시럽 (연령별 mL)
5. **코감기·알레르기비염 항히스타민 복합** (적응증 상이 — 해열진통·기침 없음)
6. (needs_review) 해열진통 복합제 N02BE5x
7. (별도 트랙) 생약 기침약 / 단일 거담·항히스타민

## 5. 원문 grounding (핵심 확정)

각 대표 제품 SPD content(효능·효과 / 용법·용량 / 경고 / 사용상 주의사항 / 상호작용)를 직접 조회. 조성·수치·연령은 원문 값만 사용, 창작 0.

**종합감기 복합제 공통 확정(원문 근거):**

- **아세트아미노펜 경고**: "일일 최대 4,000mg 초과 금지 — 간손상", "아세트아미노펜 포함 다른 제품과 병용 금지", "정기 음주자(1일 3잔↑) 상담", 중대 피부반응(급성전신발진고름물집증·스티븐스-존슨증후군·독성표피괴사용해) 발진 시 즉시 중단.
- **슈도에페드린(함유형)**: 중증/조절되지 않는 고혈압 **금기**, MAO억제제 복용/중단 2주 이내 금기, **허혈성 대장염(급격한 복통·직장출혈)** 주의, 심장·갑상선·당뇨·고혈압·녹내장·배뇨곤란(전립선비대) 상담. 일부 제품 임신 30주 이후 금기.

- "5~6회 복용해도 개선 없으면 중지".

**어떤 경우에 선택하나**
콧물·코막힘·재채기·인후통·기침·가래와 함께 오한·발열·두통·몸살이 있는 감기 증상의 완화에 허가 범위 안에서 사용합니다.

**주의 대상**
만 3개월 미만 영아, 중증 또는 조절되지 않는 고혈압, 이 약·다른 감기약으로 천식을 경험한 사람은 복용하지 않습니다. 수두·인플루엔자가 있거나 의심되는 만 15세 미만 어린이, 고혈압·심장질환·갑상선질환·당뇨병·녹내장·배뇨곤란(전립선비대), 간질환이나 잦은 음주, 임부·수유부는 복용 전 약사와 상담하세요. 슈도에페드린이 든 제품은 드물게 급격한 복통·직장출혈(허혈성 대장염)이 나타날 수 있고, **복용 후 졸음이 올 수 있어 운전·기계 조작에 주의**합니다. 발진 등 피부 이상반응이 나타나면 즉시 복용을 중단하고, 5~6회 복용해도 나아지지 않으면 중지 후 상담하세요.

**성분 확인 포인트**
감기약은 제품명보다 어떤 증상에 맞춘 성분 조합(해열진통·항히스타민·비충혈제·진해·거담)인지 확인하는 것이 중요합니다.
