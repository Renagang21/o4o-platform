## 4. 선정 이유 · 검증 포인트

### P1 — 부스코판당의정 (일반 경구 정제)

- **선정**: 가장 단순한 기준선. 용법 57자(최단), 연령 분기 0, 외용 표현 0. **다른 4건의 대조군**.
- **번역 확인**: 효능 목록이 길고 질환명이 나열됨(위·십이지장궤양, 담낭염, 요로결석, 월경곤란…) → **T-03 누락 금지** vs **T-07 재표현 허용**의 경계. 목록을 줄이면 T-03 위반.
- **디자인 확인**: 최소 구조 → 모바일 1열 기준선 확보. 긴 질환 목록의 `sd-why` 표현.

### P2 — 콜대원키즈콜드에스시럽 (연령별 용량)

- **선정**: 연령 분기 **14회**로 풀 내 최다. 만 15세/11세/7세/3세/2세 + 분수 용량(1⅓포, 2/3포, 1/2포).
- **번역 확인**: **T-02 최대 위험**. 분수(`1⅓`·`2/3`)·연령 경계(`이상`/`미만`)를 영문에서 정확히. 소비자 톤으로 푼다고 "for children" 식으로 뭉개면 **T-09 위반**.
- **디자인 확인**: 연령×용량 = **표로 표현하고 싶어지는 전형** → GUIDE §8-E(표 금지·`sd-core` 대체) 실전 검증.
- ⚠️ **원문 오류 의심**: 용법에 성인 `1회 2정씩`(정제) 과 `만 15세 이상은 2포`(산제)가 **혼재**. 제형은 시럽. → **T-05 시험 사례**(번역에서 고치지 않고 기록).

### P3 — 누코미트액 (복잡한 용법·용량)

- **선정**: 용법 **756자로 풀 내 최장**, 연령 분기 0 → P2와 축이 겹치지 않는 순수 "복잡도".
- **번역 확인**: 희석 용액 4종·분무 장비(안면마스크·마우스피스·기관누공·Croupette)·`1~10 mL를 2~6시간마다` 등 **수치와 조건이 밀집**(T-02). 문장 분할(T-07)이 필요한데 조건이 어긋나면 T-09 위반.
- **디자인 확인**: 단일 섹션이 비대 → `sd-intake` 한 덩어리의 가독성·모바일 스크롤.
- ⚠️ **주의**: 흡입·의료 처치 맥락(기관지경 검사 등). 허가상 일반의약품이나 **매장 상담 자료로 적절한지는 파일럿에서 판단**.

### P4 — 케토린점안액 (점안)

- **선정**: 투여경로가 유일하게 **점안**. 풀 내 점안액 46건 중 주의사항이 충실(598자)한 건.
- **번역 확인**: **G-02 직결** — `1회 1적, 1일 2~4회 점안`을 "apply"로 뭉개면 안 됨. GLOSSARY §3 `점안 = in the eye` / §5 안전 표현 검증.
- **디자인 확인**: 짧은 본문(1,137자) → 카드가 과도하게 비지 않는지. 640 경계에서 2열 전환 시 여백.

### P5 — 미니보라30 (주의사항 최장)

- **선정**: 주의사항 **1,147자로 풀 내 최장**. 21일 복용 + 7일 휴약의 **주기형 용법**.
- **번역 확인**: 금기·경고가 대량 → **T-03 누락 0** 검증의 최대 사례. **G-03**(금기를 권고로 약화 금지) 시험.
- **디자인 확인**: **§8-A 미해결 항목의 실증** — 주의사항 전용 class 가 없어 1,147자를 강조 없이 평문으로 흘릴 수밖에 없음. 렌더러 WO 필요성의 근거 확보.
- ⚠️ **민감 약효군**(경구피임약, DR-008) → **약사 검토 강화** 대상. 번역 결과를 자동 채택하지 않는다.
