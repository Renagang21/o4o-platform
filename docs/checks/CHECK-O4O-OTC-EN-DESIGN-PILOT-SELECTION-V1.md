## 4. 처방 배제 교차검증 (read-only)

초안의 `source_identifier_value` 는 **품목기준코드가 아니라 groupKey**(`성분|함량|제형`)라 코드 조인이 불가하다. 따라서 **성분명으로 허가마스터를 역조회**했다.

| 성분 | 허가마스터 `전문일반구분` | 판정 |
|---|---|---|
| 데소게스트렐 | **일반의약품 8건** (순아리정 등) — 전문 0 | ✅ OTC |
| 클로트리마졸 | **일반의약품 157건** — 전문 0 | ✅ OTC |

> 허가마스터 전체 분포: 전문 162,857 / 일반 86,360 / 한약재 41,583 / 원료 1,149.
> P5(데소게스트렐)는 미니필이라 전문의약품일 것으로 의심했으나 **일반의약품으로 확인**됐다. 의심을 기록으로 남긴다.

## 5. 파일럿 실행 전 확정 필요 (선정 범위 밖)

| # | 사실 | 함의 |
|---|---|---|
| **A** | 95건 전부 **draft · needs_review**, canonical 승격 미실행 | 번역·디자인 결과물을 **어디에 둘지** 미정. 한국어가 아직 검토 중인데 영문을 확정하면 한국어 변경 시 영문이 어긋난다 → **파일럿은 산출물 저장 없이 검증만** 하거나, 승격 이후로 미루거나 결정 필요 |
| **B** | 초안은 **구조화 JSON**(`efficacy`/`usage`/`caution`/`summaryTable`/`bodyMarkdown`) — HTML 아님 | 디자인 GUIDE 는 `sd-*` 계약(CR-020) 전제. **JSON → `sd-*` 매핑 규칙이 없다.** 다만 필드가 이미 구조화돼 있어 매핑은 **변환**이지 "설명서 수정"이 아니다 → 초판이 우려한 §5-A 쟁점은 **대체로 해소** |
| **C** | `bodyMarkdown` 에 **마크다운 표**(`\| 항목 \| 내용 \|`)가 있으나, **같은 데이터가 `summaryTable` JSON 에 구조화**돼 있음 | 표를 그대로 HTML `<table>` 로 렌더하면 디자인 GUIDE **§8-E(표 찌그러짐·잘림)** 에 직격. **`summaryTable` 을 `sd-core > sd-item` 으로 매핑하면 표 없이 해결** → §8-E 우회 경로 확보 |
| **D** | `bodyMarkdown` 에 **내부 편집 주석**이 있음. 예(P3): `> 같은 성분 550mg 정은 전문의약품이다(§6). 이 설명서는 275mg OTC 그룹에 한정한다.` | 소비자 화면에 나가면 안 되는 **작성자용 메모**. 번역·렌더 대상에서 제외해야 함(HFF-R07 "편집 라벨 금지"의 의약품 대응) |
| **E** | **점안·외용(연고/크림/패치)이 95건에 하나도 없다.** 비경구는 P4 질정 1건뿐 | WO 의 "외용 또는 점안"을 **문자 그대로 충족 불가** → P4(질 내 투여)로 대체함. 점안·외용 검증은 해당 그룹 작성 후로 이월 |

## 6. 모집단 조사 근거 (초판 조사 — 보존)

**왜 e약은요가 대상이 아닌가**를 뒷받침하는 실측이다.

### 6-1. `shared_product_descriptions` 한국어 canonical STORE 전수

| source_type | 행 | 고유 content | 제품군 | `sd-*` |
|---|---:|---:|---|---:|
| `mfds_easy_drug` | 19,177 | 3,597 | DRUG | 0 |
| `mfds_drug_otc_nutrition_combo` | 1,915 | **16** | DRUG | 0 |
| `manual` | 30 | — | 건강기능식품 | 15 |
| `manual` | 14 | — | 일반 | 0 |

- **e약은요 19,177건 = 식약처 원문**(`<p><strong>효능·효과</strong><br>…`). 매장용으로 *작성된* 설명서가 아니라 **작성의 원천**이다.
- DB 에 canonical 로 올라간 authored 그룹 설명서는 **16건(자양강장·비타민 복합)뿐**이며 전부 경구. 5유형을 채울 수 없다.
- **DRUG 설명서 21,092건 중 `sd-*` 마크업 = 0.**

### 6-2. e약은요 섹션 라벨 실측

`효능·효과 / 용법·용량 / 경고 / **사용상 주의사항** / 상호작용 / 이상반응 / 저장방법`

> GLOSSARY §1 은 **"사용상**의** 주의사항"** 으로 등재 — **표기 불일치**. 경고·상호작용·이상반응 3종은 미등재.
> 초안(`content_json`)은 이 라벨 체계를 쓰지 않으므로 **파일럿 직접 영향은 없으나**, 향후 원문 대조 시 필요 → GLOSSARY 보완 후보로 남긴다(TEST-LOG 경로).

## 8. 건별 선정 이유 · 검증 포인트

### P1 — 트리메부틴말레산염 200mg 정 (기준선)

- **선정**: 용법 50자·주의사항 76자로 **양쪽 최단**, 연령 분기 0. 나머지 4건의 대조군.
- **번역**: 가장 단순 → **T-06/T-07(소비자 톤·재표현)의 순수 시험**. 정보가 적어 T-03 압박이 없다.
- **디자인**: 본문이 짧을 때 `sd-card` 가 비어 보이지 않는지. 모바일 1열 기준선.

### P2 — 니자티딘 75mg 정 (연령별 용량)

- **선정**: 연령 분기 5회로 95건 중 최다.
- **번역**: **T-02 직격** — 연령 경계(`이상`/`미만`)를 영문에서 정확히. 소비자 톤으로 "for adults and children" 식 뭉갬 = **T-09 위반**.
- **디자인**: 연령×용량 → **표 유혹**. `summaryTable` 매핑으로 표 없이 해결되는지(§5-C).

### P3 — 나프록센나트륨 275mg 정 (복잡한 용법)

- **선정**: 본문 842자·용법 139자로 **양쪽 최장**.
- **번역**: 조건이 밀집 → 문장 분할(T-07) 필요. **함량축 주의** — 같은 성분 550mg 은 전문의약품(DR-005). 영문에서 함량 범위를 넓히면 **RX 를 OTC 로 오도**한다 = T-02·T-09 중대 위반.
- **디자인**: §5-D **내부 편집 주석 제외** 실전 검증.

### P4 — 클로트리마졸 100mg 질정 (비경구)

- **선정**: 95건 중 **유일한 비경구**. `doseForm='정'` 이지만 실제는 **질 내 투여**.
- **번역**: **G-01 직격** — "take/swallow" 금지, "insert". `doseForm='정'` 만 보고 번역하면 **경구로 오역**한다. DR-003·DR-009.
- **디자인**: 투여 부위 안내가 색·아이콘 없이 문장으로 전달되는지.
- ⚠️ **데이터 함정**: groupKey `클로트리마졸|100밀리그램|정` 에 **투여경로 축이 없다**. 파일럿에서 route 표기 필요성을 확인한다.

### P5 — 데소게스트렐 0.075mg 정 (주의사항 최장)

- **선정**: 주의사항 237자로 95건 중 최장.
- **번역**: **T-03 누락 0** 최대 사례. **G-03**(금기를 권고로 약화 금지) 시험.
- **디자인**: **§8-A 미해결 항목의 실증** — 주의사항 전용 class 부재로 최장 주의사항을 강조 없이 평문 처리. 렌더러 WO 근거 확보.
- ⚠️ **민감 약효군**(DR-008) → 번역 결과 자동 채택 금지, 약사 검토 강화.
