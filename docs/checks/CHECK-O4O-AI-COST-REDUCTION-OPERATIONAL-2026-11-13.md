## 실제 실행과 결과

운영 사이트 `store.neture.co.kr`의 테스트 로그인 버튼으로 경영자·직원 Demo를 각각 로그인했다. 계정 값을 직접 입력하거나 약사 자격/직원 권한을 변경하지 않았다. 현재 로그인에서 발생한 실제 인증 헤더를 메모리에만 사용해 같은 API의 요청을 보냈다. 토큰·쿠키·계정 값·고객 원문을 보고서/저장소에 기록하지 않았다.

관리형 환경에 데스크톱 제어 도구가 없어 Playwright/Chromium으로 확인했다. 최초 Chromium 직접 탐색은 환경 proxy 인증서 신뢰 오류가 났다. 제공된 CA bundle을 신뢰하는 Playwright 요청 계층과 환경 proxy로 자원을 검증·전달해 화면을 열었으며 전체 TLS 검증을 끄지 않았다. 따라서 아래 시간은 이 환경의 proxy·클라이언트 왕복을 포함하고 사용자의 로컬 브라우저 성능을 대표하지 않는다.

### 운영 번역 비교

현재 허용된 경영자 Demo의 `floor-staff` 모드에서 공개된 `welcome` 인사말만 사용했다. 언어 `en`, 방향 `to-customer`, station 미지정으로 고정했다. 고객·건강정보, 상품 사실·전문 판단은 전송하지 않았다. 계정·언어·모드·입력을 같게 두고 선택 필드 `reuseSession`만 비교했다. 기준 2회는 세션 생략, 다음 2회는 같은 UUID를 사용했다. 자동 재시도는 추가하지 않았다.

측정 창: **2026-11-13 08:53:05.555~08:53:15.593 KST** (2026-11-12 23:53:05.555~23:53:15.593 UTC).

| 요청 | HTTP | 클라이언트 왕복 | 결과 |
|---|---:|---:|---|
| 기준 1, 세션 없음 | 200 | 3,124 ms | 정상 |
| 기준 2, 세션 없음 | 200 | 2,456 ms | 정상 |
| 동일 세션 첫 요청 | 200 | 4,003 ms | 정상 |
| 동일 세션 반복 요청 | 200 | 453 ms | 첫 결과와 동일 |

네 응답 모두 `private, no-store`이고 번역문은 길이·SHA-256 비교로 서로 같음을 확인했다. 마지막 요청의 빠른 응답은 서버 재사용 동작과 일치하지만, **동일 출력/짧은 시간만으로 실제 공급자 호출 횟수나 과금 감소를 증명하지는 않는다.** 마지막 요청의 원장 미생성을 확인하지 못했다. 표본 4개로 운영 p50/p95·부하 개선·일반 절감률을 판정하지 않는다. 첫 기준 요청과 첫 재사용 요청의 차이는 warming·proxy·공급자 변동 등과 구분되지 않는다.

실제 운영 AI 경로에 HTTP 요청을 4회 보냈다. 공급자 내부 attempt·retry/fallback 횟수, 사용 모델·가격 버전, token과 예상 비용, 확정 청구는 **미확인**이다. 4회 HTTP를 4회 유료 호출이라고 세거나 비용을 0원으로 기록하지 않는다.
