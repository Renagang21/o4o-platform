## 1. 최종 실행 SQL 요약

candidate ↔ master 연결은 WO 초안의 `product_identifiers.normalized_value` 조인 대신 **`product_candidates.matched_product_master_id` 직접 조인**을 사용했다 (커버리지 53,721/53,721 = 100%, 더 견고).

```sql
-- drug_unspecified 원문 전문일반구분 분포
SELECT COALESCE(pc.raw_payload->'source'->>'전문일반구분','(NULL)') AS rx_otc_raw,
       COUNT(*)::int AS count
FROM product_masters pm
JOIN product_candidates pc ON pc.matched_product_master_id = pm.id
WHERE pm.regulatory_type='DRUG' AND pm.drug_category='drug_unspecified'
GROUP BY 1 ORDER BY count DESC;
```

> `제형구분`, `비고`, `isCancelled` 는 모두 `pc.raw_payload->'source'->>...` / `pc.raw_payload->>...` 에서 추출.
> 연결 보호는 각 링크 테이블의 `master_id` = `product_masters.id` 기준 COUNT DISTINCT.
