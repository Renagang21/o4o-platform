## 6. SOURCE GAP 판정 (§3.11)

- **대표 설명서 허용 게이트(§3.11.3)**: 치질 국소치료(C05A) 4개 제형은 효능(치열·치핵 아픔·가려움·부종·출혈 일시완화)이 **원문상 동일 수렴** ✅ · 용법 표현 가능 ✅ · 주의사항 route별 일관 ✅ → **제형(route)별로 분리해 대표 작성**. 좌제·도포 연고·주입형·경구를 **하나로 묶지 않음**(WO §6 금지).
- **조성 미표기(SOURCE GAP)**: C05A 국소 복합은 국소마취·수렴·혈관수축(dl-메틸에페드린)·스코폴리아·글리시리진 등 **조성이 name·원문에 성분 단위로 완전 표기되지 않음**. → **스테로이드/국소마취/항염 포함 여부를 추정하지 않고**(WO §6 금지), 효능·route·원문 주의사항만으로 제형별 대표를 작성. 조성 세분은 HOLD_SOURCE.
- **HOLD**: C05B 정맥류 외용(grounded 0)·C05CX 기타 모세혈관제(grounded 9/211)는 치질 적응 불명확 → HOLD_SOURCE.
- **성분 창작 0 / 사용법 창작 0**: 모든 초안 §3 원문 실조회 근거.

## 8. 안전성 처리 (WO §8·§11·§15)

핵심은 **제형별 사용법 분리**와 출혈·심한 증상 경고. 처리 결과:

1. **제형 분리(WO §6 금지 준수)**: 좌제(항문 삽입)·연고/크림(항문 주위 도포)·주입형(항문 내 주입)·경구(먹는 약)를 **4개 별도 대표**로 작성. 하나로 묶지 않음.
2. **route 문구**: 좌제="먹는 약 아님·항문 삽입" / 연고="항문 주위 도포·사용 부위·횟수 확인" / 주입형="항문 안쪽 주입·사용법 정확히 확인" / 경구="먹는 치질 보조약".
3. **출혈 경고**: "항문 출혈이 반복되거나 양이 많으면 치질로만 판단하지 말고 진료" — 4건 전체.
