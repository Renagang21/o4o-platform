## 3. ATC7 hybrid 그룹핑 기준 (확정)

```text
norm_key = COALESCE(ATC_CODE 7자리, cleaned_ingredient_name)
그룹 단위 = (norm_key, 함량, 제형, 투여경로, OTC/RX)
```

- ATC7 커버(OTC): distinct ATC7 = **247코드**, 성분완전코드는 OTC의 ~37%만 커버 → **name 파싱 보조 필수(hybrid)**.
- ATC7 은 염명·어순·오타를 **성분 단위로 수렴**시키는 1차 키.
- **병합 금지 축**: ATC7 이 같아도 함량·제형·투여경로·OTC/RX 가 다르면 별개 그룹(가이드 §3.5·§3.6).

### 3.1 ⚠ ATC7 과병합 예외 (신규 발견 — 무조건 수렴 금지)

일부 ATC7 은 **표기변형이 아니라 서로 다른 실제 주성분**을 묶는다. 이 경우 ATC7 단독 병합은 오병합이다.

| A07FA01 | 정장 생균 | 바실루스리케니포르미스 / 락토바실루스아시도필루스 / 엔테로코쿠스페슘 / 사카로마이세스 … (12종) | **병합금지** — 균주별 별개 |

## 7. 100그룹 확장 가능성 판단

**판단: C(보류) 유지 — 이 seed 로도 단일·경구 신규는 32(품질 A 3)에서 늘지 않는다.**

- 표기변형 사전·노이즈 필터는 **후보 품질·수렴**을 개선하지만 신규 성분을 만들지 않는다.
- 100 도달은 여전히 (a) 복합제(grounded 67그룹) 또는 (b) 국소·비경비 route 축을 열어야 산술적으로 가능(선행 §14).
- 본 seed 는 그 두 축을 열 때 **정규화·노이즈 기반**으로 재사용된다(전제 도구).

**조건부 가능(B):** 복합제 그룹핑 규칙 + route 템플릿 선행 시 "혼합 축(단일 32 + 복합제 40~50 + route 10~15)" 으로 100 재정의 가능.
