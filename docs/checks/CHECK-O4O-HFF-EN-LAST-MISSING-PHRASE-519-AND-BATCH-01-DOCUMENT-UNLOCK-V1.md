## 11. 함정 기록

1. **생산 0건을 자산 부족으로 단정하지 말 것.** 이번엔 1,581 문서가 이미 커버돼 있었고 게이트 결함이 전량을 막고 있었다. 0건이면 먼저 **원인별 분해**(NO_ENTRY / CLEAN / NUMBER)를 하라.
2. **한국어 잔존 검사 범위는 번역 대상 슬롯으로.** 기존 승인 EN 도 제품명은 한국어다.
3. **섭취방법 템플릿은 괄호 용량을 반드시 포함.** 누락하면 실제 복용량 정보가 사라진다.
4. **`<li><b>라벨</b>`은 별도 슬롯이다.** 최말단 li 정규식으로는 잡히지 않는다.
5. **safe-target 필드명 불일치는 가드가 잡는다.** UPDATE 가 0/11 로 나오면 write 실패가 아니라 필드 문제부터 의심하라.
6. JSDOM 대량 렌더는 힙 초과가 난다. **구조 시그니처 + 고위험 전량**으로 커버하라.
