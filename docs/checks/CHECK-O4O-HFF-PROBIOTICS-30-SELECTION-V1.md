## 4. 승인이 필요한 예외 2건

### 4-1. `안티비오 프로(베트남)` — 연령 버킷 유일 후보

- 풀 234건 중 **유일하게** 연령별 용법이 있는 제품(성인 1일 3회 2포 / 소아 1일 2회 1포).
- ⚠️ 제품명에 `(베트남)` 표기. `수출` 문자열이 없어 SQL 필터를 통과했으나 **베트남 시장용으로 추정**되며,
  고정 조건 "수출전용 제외" 와 걸릴 수 있다. 원문에 수출 여부를 확정할 필드는 **없다**(추정 금지).
- 검증 가치: 기준량이 포가 아닌 **g 단위**(1억 CFU/g)이고 1회 2포(2그램) → 기준량 연결 축을 정면 시험.
- **거부 시**: 연령 버킷 0 → 다른 버킷으로 1건 재배분(29 → 30 유지).

### 4-2. 연령 숫자 구간 제품 부재

- SRV_USE 에 실제 숫자 연령 구간을 가진 제품은 풀 234건 중 **0건**.
- 유일 보유 제품 `디노키즈생유산균` 은 기존 25건에 포함 → 중복 0 조건과 충돌.
- 대신 **"이름은 키즈인데 원문에 연령 근거가 없는" 제품이 15건** 존재한다(예: `베이비&키즈 생유산균`,
  `프리미엄 프로바이오틱스 키즈` — SRV_USE 는 `1일 1회, 1회 1포` 뿐).
  이번 30건에도 `닥터프로바 유기농 키즈`, `더트리플B 키즈` 가 포함돼 **연령 소구 금지**(`PRE-F-AGE-001`)와
  **제품명 유도**(`E-NAME`) 규칙은 정면으로 검증된다.
