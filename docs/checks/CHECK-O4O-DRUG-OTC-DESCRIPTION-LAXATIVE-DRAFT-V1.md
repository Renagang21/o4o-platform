## 6. SOURCE GAP 판정 (§3.11)

- **성분 식별 가능(대표 작성)**: 비사코딜(A06AB)·락툴로오스/락티톨/마크로골(A06AD)·차전자피(A06AC) = ATC5 + name + e약은요 원문 grounding 확보 → 대표 초안.
- **대표 설명서 허용 게이트(§3.11.3) 통과 여부**:
  - LAX-STIMULANT/OSMOTIC/BULK = 효능(변비) 수렴 ✅ · 용법 표현 가능 ✅ · **주의사항이 작용 방식별로 크게 다름**(자극성=의존성/단기, 삼투=수분/전해질, 팽창=충분한 물) → 게이트 원칙에 따라 **bucket(작용 방식)을 분리해 대표 작성**, 하나의 "변비약" 대표로 뭉개지 않음.
- **게이트 불통과 → HOLD**:
  - LAX-SOFTENER(A06AA) = grounding 0 → 원문 없음 → 대표도 작성하지 않고 HOLD_SOURCE.
  - LAX-COMBO(A06AX) = 조성 미표기 + grounding 4/338 → 작용 방식 판별 불가·주의사항 조성 의존 큼 → HOLD_SOURCE.
- **성분 창작 0**: 브랜드명·기억 기반 성분·작용 방식 추정 없음. 모든 초안은 §4 원문 실조회 근거.
