## 보조 지표

비교 기준은 이전 자기 브랜치 commit `dc10add17`이다. 함수 본문 행 수는 TypeScript AST의 시작·끝으로 산출했다.
조건 문법 수는 if·삼항·반복만 포함하며 표준 cyclomatic complexity 점수나 전체 코드 복잡도 판정이 아니다.
