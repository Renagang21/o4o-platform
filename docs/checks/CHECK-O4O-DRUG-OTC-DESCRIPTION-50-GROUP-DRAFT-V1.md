## 4. 후보 그룹 산출 방식

`product_masters`에서 성분·함량·제형 파싱, 단일 스캔 집계. 키:

```text
성분 = name 끝 괄호 안 문자열   substring(name, '\(([^()]+)\)\s*$')
함량 = specification 첫 토큰(한글 '밀리그램'/'마이크로그램')
제형 = name 내 제형 키워드(정/캡슐/연질캡슐)
```

필터: `drug_category='otc'`, 복합제 명칭 제외(`복합|플러스|콤비|더블|에스|플러|+`), 성분에 `/`·`,` 없는 단일성분, 위 26+3 그룹 제외. e약은요 join(`source_type='mfds_easy_drug'`). 정렬: 제조사 DESC → master DESC.

## 16. 가이드 보완 필요 사항

이번 배치에서 발견된 additive 후보(가이드 반영 여부는 사용자 판단):

1. **표기 변형 정규화 규칙** — 같은 활성성분의 다중 표기(염 표기 순서·「디.씨」·「L-」 등)를 하나의 그룹으로 병합하는 규칙. §3.5(함량축)·§3.6(투여경로축)에 이어 "성분명 표기 정규화" 항으로 추가 검토.
2. **저 grounding 그룹 취급** — e약은요 ≤10건 생약/영양(은행엽·포도엽·아르기닌티디아시케이트)은 원문 축약 여지가 적으므로 자동 초안 대상에서 제외하고 검토 강화/수동으로 분류하는 기준.
3. **민감 약효군(피임·호르몬) 프레이밍** — 피임약 등은 성분 설명서라도 상담 연결 문구를 강화.

> 이번 세션에서는 가이드 파일을 **수정하지 않았다**(WO가 GitHub 저장 전제 작업을 제한). 위 3건은 제안 상태로 남긴다.

## 18. 100그룹 확장 전 선행 과제

이번 40그룹에서 **clean 단일성분 OTC 풀 소진**을 확인했다. 100그룹은 다음 선행 없이는 불가하다.

1. **itemSeq/주성분코드 기반 그룹핑 정규화 (최우선)** — 이름 파싱은 표기변형으로 실제 그룹을 조각내고 가짜 신규를 만든다(§5). 주성분코드로 병합하면 (a) 중복 제거 (b) 이름에 성분이 없는 상품까지 포함되어 실제 그룹 수가 크게 늘어난다.
2. **복합제 그룹 처리 기준** — 단일성분만으로는 100개가 부족. 카피 많은 복합제(감기약·종합소화제 등)를 성분 조합 단위 그룹으로 다룰 기준 필요.
3. **투여경로 사전 필터** — 질정·외용·점안·점비를 원문 용법으로 사전 분리(20그룹 클로트리마졸 사례).
4. **함량축 RX 필터** — 성분별 고함량 전문 품목 사전 배제.
5. **저 grounding/생약·영양 취급 기준** — e약은요 부족 그룹의 자동/수동 분리.
6. **민감 약효군 프레이밍** — 피임·호르몬 등 상담 필수 그룹.

**정량 판단:** 자동 초안 가능 비율은 20그룹 55% → 40그룹(이번) 60%로 안정적이나, "카피 많은 clean 신규" 공급이 이름 파싱 기준으로 소진되었다. 100그룹은 **선행 과제 1(주성분코드 정규화)을 별도 WO로 먼저 수행**한 뒤 재개하는 것이 타당하다.
