### 용법·용량: "더 구체적일 때만" 을 수치로 판정했다

원문 1,282건은 **서로 다른 문장이 112개뿐**이고, 상위 3개 정형구가 983건(77%)이다.

이 정형구는 매장 일반 안내(`기초 단계 마지막에 적당량을 덜어 얼굴 전체에 부드럽게 펴 발라 주세요`)보다
**덜 구체적이다.** 공식이라는 이유만으로 갈아끼우면 설명서가 나빠진다.

판정축을 **수치 지시(횟수·시간·용량)의 유무**로 잡았다. 실측상 정형구에는 수치가 없고,
수치가 있는 문장은 매장 안내가 담지 못하는 지시를 담는다.
