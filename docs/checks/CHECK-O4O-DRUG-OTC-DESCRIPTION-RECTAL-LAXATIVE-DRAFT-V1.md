## 3. DB read-only 조사

- 접속: `cloud-sql-proxy netureyoutube:asia-northeast3:o4o-platform-db`(127.0.0.1:5434, ADC) + `psql` user `o4o_api`. **SELECT 전용**. 자격증명은 Cloud Run env에서 직접 추출(리터럴 미노출).
- 원문: `shared_product_descriptions.content`(source_type=`mfds_easy_drug`, e약은요), join `master_id`.
- 대상: `product_masters`(regulatory_type=`DRUG`, drug_category=`otc`) JOIN `product_drug_extensions`(atc_code LIKE `A06%`), 직장 제형 신호(`관장|좌약|좌제`) 필터.
- **데이터 제약(재확인)**: `product_drug_extensions` 성분 필드는 **OTC 전량 NULL**. 조성은 name·ATC·e약은요 원문에서만 추론.

**직장 제형 분포(A06, 치질·질정 제외):**
- A06AG(관장제) 29 = 관장 name 12 · 글리세린 8 · grounded 22 → 대부분 글리세린 관장.
- A06AB 좌약/좌제 신호 11 + A06AX 6 = **좌약 17건**(비사코딜 좌약 등), grounded 11.

**PEDIA(소아용)**: 별도 bucket 불필요. 글리세린 관장·비사코딜 좌약 원문에 **연령별 용법이 내장**(글리세린: 1세 미만~성인 / 비사코딜: 6~12세)되어 대표 초안 내 연령 문구로 흡수(WO §4).

**좌약 ≠ 관장제 분리 준수(WO §6 금지)**: 두 bucket을 하나로 묶지 않고 route(주입 vs 삽입)·사용법·용량 단위가 달라 **별도 대표 초안**으로 분리했다.

## 6. SOURCE GAP 판정 (§3.11)

- **성분 식별 가능(대표 작성)**: 글리세린 관장(A06AG04)·비사코딜 좌약(A06AB02) = ATC + name + e약은요 원문 grounding 확보 → 대표 초안.
- **대표 설명서 허용 게이트(§3.11.3)**: 두 bucket 모두 효능(변비·장내용물 배설) 수렴 ✅ · 용법 표현 가능 ✅ · 주의사항이 route·제형에 일관 ✅ → 대표 작성. 단 **좌약과 관장제는 사용법이 근본적으로 달라 하나로 묶지 않음**(§4).
- **HOLD**: 미grounded·조성 미식별 관장/좌약 잔여(13건) → HOLD_SOURCE.
- **성분 창작 0 / 사용법 창작 0 / 소아 용량 창작 0**: 모든 초안은 §3 원문 실조회 근거.

## 7. 대표 초안 2건 (dry-run, DB write 0)

## 8. 안전성 처리 (WO §8·§11·§15)

핵심은 **좌약과 관장제를 절대 섞지 않고, "먹는 약이 아니라 항문으로 사용하는 약"을 분명히 하는 것.** 처리 결과:

1. **직장용 공통**: "먹는 약이 아니라 항문으로 주입/삽입하는 약" 문구를 사용 안내 첫 문장에 배치(2건).
2. **반복 사용 주의**: 관장(의존성·연용 회피)·좌약(자극성·장 기능 저하) 각각 원문 근거로 반복/장기 사용 경고.
3. **심한 증상 경고**: "심한 복통·구토·혈변·원인 모를 체중감소 → 사용 말고 진료"를 2건 전체에 포함.
4. **관장제 전용**: 무리한 주입 금지·통증/출혈 시 중단·내복 금지·잔액 재사용 금지.
5. **좌약 전용**: 삽입 후 불편·심한 복통 시 중단·장기 사용 금지.
6. **소아**: 연령별 용법·제품별 허가 용법 확인 문구 포함(글리세린은 1세 미만까지 용량 명시).

## 9. HOLD_SOURCE / 제외

**HOLD_SOURCE:** 미grounded·조성 미식별 관장 잔여 7 + 좌약 잔여 6 = 13건(비-글리세린 관장·비-비사코딜 좌약).

**EXCLUDE / 범위 밖:**
- **치질 좌제·질정/질좌제**: A06(변비약 ATC)에는 존재하지 않음(치질 좌제 = C05 계열, 질정 = G01 계열). 조사 필터(`치질|치핵|치열|질정|질좌|질염|칸디다`)로 재확인 결과 A06 직장 후보 내 **crossover 0** → 별도 트랙(`WO-...-HEMORRHOID-SUPPOSITORY-DRAFT-V1` 등).
- 경구 변비약·처방 변비약·지사제·정장제·소화제·한방 변비약·건강기능식품·원료성 품목 = 범위 외.
