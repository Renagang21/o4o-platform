## 7. SOURCE GAP 판정 (§3.11)

- **1세대↔2세대 분리(WO §6·§11 금지)**: 졸림·항콜린 부작용 프로파일이 달라 **별도 대표**. 하나로 묶지 않음.
- **먹는 약↔비강분무제 분리**: 경구(항히스타민·비충혈 복합)와 비강(점비·세척)을 별도 대표. 눈에 넣는 약·피부약과도 분리.
- **조성 추정 금지(WO §6)**: 슈도에페드린/페닐레프린·비강 스테로이드 포함 여부, "졸림 없음"을 **단정하지 않음**. 원문 효능·주의만 기술. 조성 세분 = HOLD.
- **감기약 분리(WO §3)**: 코감기 복합(인후통·기침 overlap)은 종합감기 트랙에서 처리 → 재작성하지 않음.
- **약사 검토 강화(§3.9)**: 경구 비충혈 복합(고혈압/심장/MAO)·비강 비충혈(반동성).
- **성분 창작 0**: 모든 초안 §3 원문 실조회 근거.

**핵심 3요소 모두 반영:** ① **졸림**(1·2세대 초안) ② **고혈압·전립선비대·녹내장**(1세대 항콜린·경구 비충혈·비강 비충혈 초안) ③ **점비제 장기사용 금지·반동성 비충혈**(비강 비충혈 초안).

**절대 비혼합(WO §11):** 1세대↔2세대·경구↔비강·비충혈 복합↔단순 항히스타민을 각각 별도 대표. 먹는 약↔코 분무↔눈약↔피부약 분리. 종합감기 복합은 감기 트랙 참조.

## 10. HOLD_SOURCE / 제외

**HOLD_SOURCE:** R01B 경구 비충혈 기타 365(g5) · R01AC 크로몰린 비강분무 4(g0) · R06 조성 세분(항히스타민+비충혈 복합 조성 미표기).
