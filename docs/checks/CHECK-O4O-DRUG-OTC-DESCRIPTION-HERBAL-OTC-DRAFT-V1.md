## 7. SOURCE GAP 판정 (설계표준 §8·WRITING-GUIDE §3.11)

- **지배적 SOURCE GAP**: 한방 OTC는 조성(생약 구성)뿐 아니라 **효능·용법·주의 원문 자체가 DB에 거의 없다**(grounded 0.2%). 양약 트랙(효능은 있고 조성만 gap)보다 훨씬 심한 gap.
- **대표 허용 게이트(§3.11.3)**: grounded 4개 처방만 효능·용법·주의 원문 확보 → 적응증 대표 작성. 나머지는 게이트 불통과(원문 0) → **대표도 만들지 않고 HOLD_SOURCE**.
- **처방·조성 추정 금지(WO §5·§6)**: "갈근탕이다/소청룡탕 계열이다"식 처방 단정 없이, 원문 효능·용법만 기술. 생약 구성은 원문·ext에 없으므로 성분 세분 = HOLD.
- **HOLD 철학(설계표준 §8.1)**: 원문 없는 한방을 추정해 설명서를 만드는 것보다 비워 두는 것이 우선. 후속 MFDS 허가사항 ETL로 해소.
- **성분 창작 0**: 4개 대표 초안 전부 §4 원문 실조회 근거.
