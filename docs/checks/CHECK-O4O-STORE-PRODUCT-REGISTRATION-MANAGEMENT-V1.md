## 문제와 변경

- 표준 상품 검색은 디바운스 대기 중 이전 결과가 남고, 추가 응답이 닫힌 창·새 매장의 완료 상태를 바꿀 수 있었다.
  서비스 내부 `useStandardProductSelection`이 입력·분류·페이지·재시도와 최신 응답을 소유한다.
  조건 수정 즉시 이전 행을 숨기며 300ms 검색, 오류/정상 0건 구분, 안전한 오류와 재시도,
  분류·검색 변경 시 1페이지, 범위를 벗어난 마지막 페이지 보정을 제공한다.
  같은 필터·검색어를 다시 선택해도 로딩에 머물지 않는다.
- 표준 상품 추가는 동기 잠금으로 직렬화한다. success를 확인한 뒤 등록됨 표시·부모 갱신을 실행한다.
  실패 항목은 다시 시도할 수 있으며 이미 완료한 항목은 재전송하지 않는다.
  닫기·매장/서비스 전환은 새 controller를 생성해 이전 완료·알림을 격리한다.
- 직접 등록 제품은 기존 `StoreLocalProductsManager`를 유지한다. 서비스 내부 API adapter가
  이전 조회의 성공/실패를 최신 조회 결과로 수렴시켜 공통 화면이 늦은 응답에 덮이지 않도록 한다.
  매장 소유자 검사·쓰기 잠금·응답 ID 확인과 고정 오류를 적용했다. 이전 매장의 후속 조회는 보내지 않는다.
  전체 manager는 매장·서비스별로 새로 생성하며 다국어 보조 조회 오류는 별도 안내·재시도를 제공한다.
- 저장 중 폼·에디터·이미지/본문 변경과 새 작업을 막고 제출 당시 값을 유지한다.
  native form submit으로 Enter·footer 저장을 통일하고 동기 잠금으로 연속 제출을 차단한다.
  저장 중 같은 편집 창을 닫고 다시 열어 이전 완료가 새 초안을 닫는 경로를 막는다.
- 수정 폼에서 카테고리·설명·요약·표시 가격·갤러리를 비우면 기존 값이 남던 문제를 고쳤다.
  기존 서버가 지원하는 빈 문자열·배열을 명시적으로 보낸다. 바코드·대표 이미지 삭제 전송은 유지한다.
  이미지/동영상/오디오를 포함한 본문은 텍스트가 없어도 보존한다.
- 본문 가져오기는 현재 매장의 `source: mine`만 조회한다. 입력 수정·페이지·닫기·매장 전환 시
  이전 선택과 응답을 무효화하고 success:false도 오류로 처리한다. 재시도·정상 빈 결과를 구분한다.
  선택된 최신 본문만 복사하며 상품명은 바꾸지 않는다. 교체/덧붙이기 동작은 유지한다.
- 서비스 내부 native dialog가 이름·초기 초점·Escape·배경 비활성화·초점 복귀를 제공한다.
  중첩 본문 가져오기 Escape는 부모 초안을 닫지 않는다. 일반 입력에는 label 연결을 추가했다.
  모바일 표 스크롤 안내·작업 버튼 접근, 목록 헤더·페이지 탐색 줄바꿈을 확인했다.
  태블릿 진열·마케팅 자산·다국어 자료함 링크는 현재 매장 route prefix를 유지한다.
