## 5. §4-1 사실 오류의 뿌리 — grounding 판정 오류

내가 `장건강`을 `calculationAllowed=true`(기준량=1회분)로 잘못 넣었다. 실제로는:

```text
1정 = 1200mg,  1일 2회  →  1일 총량 2400mg = 기준량 2.4g
∴ 기준량은 1회분이 아니라 **1일분**. "기준량 = 1회" 서술은 틀렸다.
1정당 균수(10억÷2 = 5억)는 원문에 없는 파생 → 쓰지 않는다.
```

또한 작성기가 `eq=false` 경로에서 `unitWeight` 유무를 보지 않고 항상
`1단위의 중량은 공식 표기에 없어` 를 썼다 — 1정 1200mg 이 **원문에 있는데도**.

조치:
1. grounding `calculationAllowed=false` 로 정정
2. 작성기 `eq=false` 분기에 `unitWeight != null` 케이스 추가 —
   `1정 1200mg, 1일 2회 — 표시 균수는 기준량 2.4g 기준입니다` (사실만, 파생 없음)
3. `씹거나`+`녹여서` 동시 표기

**정정 후 실화면 재확인**: `1정 1200mg, 1일 2회 — 표시 균수는 기준량 2.4g 기준` · 모순 제거 확인.
