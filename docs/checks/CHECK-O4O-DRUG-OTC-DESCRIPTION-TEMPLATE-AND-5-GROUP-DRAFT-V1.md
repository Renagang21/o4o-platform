## 3. 제외한 그룹 (WO §4)

이번 5개 산출물에서 제외:

```text
에르도스테인 300mg 캡슐  (pilot 이미 작성)
아세트아미노펜 500mg 정제 / 이부프로펜 400mg 정제 / 덱시부프로펜 300mg 연질캡슐  (가이드 §7 기존 예시)

```

또한 함량·제형이 다른 하위 그룹은 대상 그룹에서 분리:
- 나프록센나트륨 550mg 정 / 412.5mg 정 → **전문의약품(RX)**, 대상 제외
- 트리메부틴말레산염 150mg·200mg·300mg 정 → 300mg은 **RX**, 나머지는 별도 함량 그룹으로 대상 제외
- 알마게이트 현탁액/과립 등 비-정제 제형 → 대상 제외

## 10. AI 에이전트 프롬프트 초안

```text
[역할]
너는 O4O 약국 매장용 일반의약품(OTC) 설명서를 작성한다.

- 성분 + 함량 + 제형 그룹

9. 하단에 "성분 기준 선택" GMP 공통 문구를 반드시 넣는다.

[출력]
가이드 §5 템플릿(요약표 + 효능·효과 + 복용 안내 + 주의 대상 + 성분 기준 선택).
```

## 13. 가이드 문서 업데이트 여부

작성 중 발견 → `O4O-DRUG-STORE-DESCRIPTION-WRITING-GUIDE-V1.md` 갱신 (additive):

1. **§3.5 신설** — "함량축은 허가구분(OTC/RX)까지 가를 수 있음". 나프록센 275mg(OTC) vs 550mg(RX), 트리메부틴 100mg(OTC) vs 300mg(RX) 실측을 근거로, 그룹은 반드시 (성분 + 함량 + 제형) 3축으로 묶어야 함을 명문화. `specification` 함량 표기가 `mg`이 아닌 한글 `밀리그램`임(파싱 주의)도 기록.
2. **§7.5~§7.9 예시 5개 추가** — 세티리진(항히스타민)·알벤다졸(구충)·알마게이트(제산)·나프록센(NSAID)·트리메부틴(위장운동조절). 기존 예시가 해열진통제+거담제에 편중돼 있어 성분군 다양성 보강(가이드 §9 "새 성분군 반복 표현 기준 발견").

기존 구조/규칙 변경 없음. 순수 additive.
