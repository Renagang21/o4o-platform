## 변경 결과

사이니지 스케줄·재생목록, 채널 개요·상품 조회, QR 사용처·통계, 태블릿 적용·되돌리기를 로컬 훅으로 분리했다.
기존 조회 helper와 공통 UI를 재사용하며 새 전역 상태 라이브러리·공통 Core·API·schema·인증·AI 코드를 변경하지 않았다.

조회 대상·매장·요청 순서·unmount가 바뀐 뒤 오래된 응답을 배제한다. 스케줄 저장, 재생목록 변경,
QR 사용처 작업, 태블릿 직접 적용·되돌리기의 중복 실행을 방지한다. 모든 매장 API에 전역 중복 차단을 도입한 것은 아니다.
재생목록 일괄 추가는 성공 항목을 제외한 실패 선택만 남긴다. 채널 상품 조회 실패는 빈 편집 목록으로 표현하지 않는다.
재생목록 작업 오류와 조회 오류를 분리해 작업 실패가 확인된 목록을 숨기지 않도록 한다.
