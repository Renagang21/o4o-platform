50그룹 WO는 수행 중 품질 기준에 따라 40개 그룹으로 조정되었다(`CHECK-...-50-GROUP-DRAFT-V1`).

| 항목 | 값 |
| --- | --- |
| 최종 작성 그룹 | 40 |
| OTC 순도 | 40/40 100% OTC (rx 0) |
| 단일성분 | 40/40 |
| 투여경로 | 40/40 경구 |
| e약은요 원문 | 40/40 확보 |
| DB write | 0 |

자동화 분류(40 기준 환산):

```text
자동 초안 가능: 24
약사 검토 강화: 14
수동 큐레이션: 2   (데소게스트렐 경구피임약 / 아르기닌티디아시케이트 저 grounding)
제외: 0
```

40개로 조정된 이유: 기 작성 26개 그룹 제외 시, 이름 파싱 기준 clean 단일성분 OTC 후보 풀이 제조사 4개 이상 구간에서 ~36–40개로 소진. 남은 후보는 (a) 성분 표기변형 중복, (b) 제조사 2~3개 저카피 꼬리, (c) 원문 근거 부족, (d) 민감 약효군. 이 소진 자체가 §5·§6·§7 보완 기준의 실증이다.

## 4. 가이드 보완 항목

### 4.1 성분 표기변형 정규화 (가이드 §3.7 신설)

- 상품명 문자열만으로 그룹 판단 금지. 염명·어순·기호·약어·띄어쓰기 차이로 같은 성분이 분산됨.
- 예: 말레인산트리메부틴=트리메부틴말레산염, 염산세티리진=세티리진염산염, 덱시부프로펜디.씨=덱시부프로펜, 엘-카르니틴=엘카르니틴=L-카르니틴.
- 정규화 우선순위: itemSeq/item identifier → MFDS 품목기준코드/주성분코드 → 허가 주성분명 → 표기변형 사전 → 상품명 괄호 파싱(보조).
- 표기변형이 정규화되어도 함량·제형·투여경로·OTC/RX가 다르면 그룹 분리(§3.5·§3.6 연계).

### 4.2 저 grounding 그룹 처리 (가이드 §3.8 신설)

- e약은요 원문 존재만으로 자동 초안 가능 분류 금지.
- 자동 초안 조건: 효능·효과 / 복용·사용법 / 주의 대상 / 성분 작용 설명 근거가 모두 충분히 확인.
- 근거 부족 시 `약사 검토 강화` / `수동 큐레이션` / `보류`.
- 금지 원칙: 근거 부족 시 AI가 일반 약리 지식으로 임의 보강 금지. 필요 시 허가 원문·추가 공공 원천 확인 후 작성.

### 4.3 민감 약효군 프레이밍 (가이드 §3.9 신설)

- 대상: 경구피임약, 수면유도제, 항혈전/저용량 아스피린, 질정/질내 삽입제, 강한 NSAID, 철분제, 간·담도계 약물.
- clean 데이터라도 기본값 `약사 검토 강화`.
- 단, 질환명·증상명·사용 목적 회피 금지(약국 매장용 특성). 복용 조건·주의 대상·상담 필요 조건을 명확히.
- 피해야 할 표현: "안심하고 복용", "부담 없이 사용", "누구나 사용 가능", "치료 가능" 등 오남용 유도 표현.
- 권장 방향: 사용 목적·복용 조건 구체화, 상담 대상 표시, 오남용 저감 문장, 신뢰성·근거 훼손 금지.

## 6. 반영하지 않은 항목

- **신규 설명서 초안**: 작성하지 않음(WO 범위 밖).
- **itemSeq/주성분코드 기반 실제 정규화 로직/스크립트**: 문서에 기준만 명문화. 구현·데이터 정규화는 100그룹 확장 선행 WO로 분리(§8).
- **투여경로 사전 필터 / 함량축 RX 필터의 실제 쿼리화**: 기준은 §3.6·§3.5·§3.9에 존재하나 자동 필터 구현은 후속.

## 8. 다음 100그룹 확장 전 조건

`WO-O4O-DRUG-OTC-DESCRIPTION-100-GROUP-DRAFT-V1`은 아래 조건 충족 후 진행한다.

1. **itemSeq 또는 주성분코드 기반 그룹핑 정규화** — 이름 괄호 파싱 대신 상위 identifier로 표기변형 병합(§3.7). 표기변형 중복 제거 가능해야 함.
2. **투여경로 사전 필터** — name '정/캡슐'이라도 질정·트로키·설하정·점안 등 비경구를 원문 용법으로 사전 배제(§3.6).

5. **저 grounding 그룹 보류 기준 적용** — 4개 근거(효능/용법/주의/작용) 미충족 그룹을 자동 초안에서 제외(§3.8).
