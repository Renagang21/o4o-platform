## 5. 후보 산출 SQL / 방식 요약

`product_masters`에서 성분·함량·제형을 파싱해 OTC 그룹을 집계(단일 스캔). 그룹핑 키:

```text
성분  = name 끝 괄호 안 문자열   substring(name, '\(([^()]+)\)\s*$')
함량  = specification 첫 토큰     split_part(specification, ' / ', 1)   (단위는 한글 '밀리그램')
제형  = name 내 제형 키워드(연질캡슐/캡슐/정)
```

집계 지표: 제조사 수(distinct manufacturer_name) · master 수 · 포장 다양성(distinct specification) · e약은요 보유(shared_product_descriptions source_type='mfds_easy_drug' join). 필터: `drug_category='otc'`, 복합제 명칭 제외, 성분에 `/`·`,` 없는 단일성분, `HAVING 제조사≥10 AND e약은요≥12`. 정렬: 제조사 DESC → master DESC. 상위 22개 산출 후 약효군 다양성을 고려해 20개 확정.

OTC 순도(otc/rx)와 단일성분성은 `drug_category IN ('otc','rx')` 재집계로 별도 검증.
