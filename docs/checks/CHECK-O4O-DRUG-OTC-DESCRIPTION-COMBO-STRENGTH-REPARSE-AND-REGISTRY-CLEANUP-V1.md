## 2. 목적

설명서 품질을 높이기 전에 registry의 **그룹 기준(group_key)** 을 바로잡는다. BATCH-ORAL-COMBO에서 시럽·과립의 `strength_key`가 **농도가 아니라 용기 용량(ml·g)** 으로 파싱되어 **동일 제품이 여러 group_key로 분할**된 문제와, **route 오분류**를 정비 제안한다. 설명서 본문은 확정하지 않는다.

## 5. 재통합 실행 제안 (비-감기약·비-영양제 한정)

> 감기약·영양제 제외 스코프에 따라, 아래 **정비 대상 2종만** 재통합 제안한다. 값 확정은 원본 spec 재파싱(§7) 후.

### 5.1 아락실과립 (a06ac51, 변비 팽창성 완하제) — 2행 → 1그룹 병합 제안

- 현재: `...a06ac51_combo::4g::granule`(236, g4) + `...a06ac51_combo::na::granule`(262, g1)
- 문제: `4g`는 1포(sachet) 총 중량으로 추정 → **성분 함량이 아니라 포 용량**. `na`는 파싱 실패.
- 제안: 팽창성 완하제 과립은 **함량(mg/포)이 아니라 성분 조합 기준으로 그룹핑**하는 것이 자연스러움 → 두 행을 **`...a06ac51_combo::__reparse__::granule` 단일 group_key로 병합** 제안(strength는 원문 성분 함량 확정 후 기입, 미확정 시 `combo` 관례상 성분 조합 슬러그로 대체). g는 4+1 합산 후보군.
- 판정: **재통합 가능**. 병합 후 needs_review 1건으로 유지(BATCH-ORAL-COMBO §9.8 대표 초안 골격 재사용).

### 5.2 오네론액 (a04ad51, 멀미약 복합) — 1행, strength 재파싱만

- 현재: `...a04ad51_combo::20ml::liquid`(223, g8)
- 문제: `20ml`는 1회 복용 병 용량/1회분 → 농도 아님.
- 제안: 원문에서 성분별 mg/ml 농도 확인 후 `strength_key` 교정. 제품 내 파편 중복은 없으므로 **병합 불필요, 값 교정만**.
- 판정: **재통합 불요, strength 값 교정 대상**. 단 멀미약은 항콜린 민감(BATCH-ORAL-COMBO §9.11 manual_curation) → 설명서 작성은 별도.

## 8. registry 업데이트 제안 (직접 변경 아님 — 중앙 승인)

> 본 CHECK는 registry 파일을 **변경하지 않는다**. 아래는 제안.

1. **아락실과립 2행(236·262) → 1 group_key 병합**(§5.1). strength는 원문 성분 함량 확정 후.
2. **라이센드플러스액(265) → excluded** + route=topical 재배정(§6).
3. **토스롱액(268)·키미테정(246) → 계열/제형 재확인**(§6). 확인 전 blocked 유지.
4. **감기약 시럽 파편 11행(액티피드3·베비맥3·콜민에이2·테라플루2·모드콜노즈1·챔프노즈? 코스펜에이1) → 파편 flag 유지 + `notes`에 "strength=용기용량, 감기약 defer, 후속 reparse" 표기 제안**. 이번 batch에서 병합 실행하지 않음(감기약 scope 제외).
5. **strength 파싱 규칙 보강(정규화 WO 연계):** liquid/granule는 `병 용량(ml)·포 중량(g)`을 strength_key로 채택 금지. 성분 농도(`mg/ml`·`%`·`mg/포`)만. 파싱 실패 시 `na` 대신 **성분 조합 슬러그** 로 group_key 확정(용량 분할 방지).

## 11. 후속 WO 제안

1. **strength 원본 재파싱(read-only):** 정비 대상(아락실·오네론) + 필요 시 감기약 시럽의 원본 spec 문자열을 production DB read-only로 조회 → `mg/ml`·`%`·`mg/포` 농도 확정 → registry strength_key 교정 제안(값 확정판).
2. **비-감기약·비-영양제 복합 원문 grounding 확정 batch:** §7 "작성 진행 가능" ~30건의 조합·주의를 원문으로 확정 → 계열 골격을 제품군별 초안으로 확장.
3. **route 재배정 WO:** 라이센드(외용)·키미테(패치)·토스롱(진해거담) 재분류.
4. **(후순위) 감기약 전용 WO:** defer된 감기·비염·진해거담 복합 ~33건 — 사용자 지시로 현재 보류.
