## 1. 방법 (단순 출현 금지)

NB_DOC(사용상주의사항)에서 첨가제별 **함유 경고 템플릿**을 판정:

| 첨가제 | 함유 신호(NB_DOC) | 부정 신호 |
|---|---|---|
| 아스파탐 | `아스파탐…함유` / `…페닐케톤뇨(페닐알라닌)` | `아스파탐…함유하지 않` |
| 대두유 | `대두유(대두레시틴)…함유` | `…함유하지 않` |
| 유당 | `유당…함유` / `…갈락토오스 불내성·Lapp·포도당-갈락토스` | `무유당` / `…함유하지 않` |
| 색소 | `황색N호(타르색소)…함유` | `…함유하지 않` |

- **함유** = 함유 경고 실재 · **비함유** = 토큰 없음 or 부정문 · **원문없음** = NB_DOC 부재(no_item) · **판정불가** = 토큰 有·문맥 불명(**실측 0**).
- 표본 검증(원문 인용): 아스파탐 "함유되어 있는…아스파탐…페닐알라닌", 유당 "이 약은 유당을 함유하고 있으므로, 갈락토오스 불내성", 색소 "이 약은 황색4호(타르트라진)을 함유하고 있으므로".

## 4. 핵심 발견 (GROUP-SPLIT 가설 정정)

1. **아스파탐은 예측된 그룹에 없다.** GROUP-SPLIT §4-1 은 16 아세틸시스테인·12 아세트아미노펜을 **아스파탐(HIGH)** 축으로 지목했으나, **공개 master 실측 아스파탐 함유 = 0** (이 제품군은 아스파탐 무함유 — [NB-DOC-BULK-FETCH §3-1](./CHECK-O4O-OTC-NB-DOC-BULK-FETCH-V1.md)). 유일한 아스파탐 함유는 **암브록솔 에이펙트정 1건**.
2. **대두유 함유 = 0** (공개 master 전무).
3. **실제 축은 유당·색소.** 유당 98 + 색소 57 이 분리의 대부분. 유당은 흔한 부형제라 다수 그룹에 걸침(라벨 그룹 04 세티리진 정에도 유당 37 — 라벨 축과 별개로 유당 안전 문구 필요).
4. **트리메부틴 100/200 유당 21 master 는 현재 문구 이미 존재** → INSERT 불필요.
5. **원문없음 115 master 미배정** — no_item(취소/변경 품목). 추가 원천(재수집) 확보 전까지 어느 서브그룹에도 넣지 않음.

## 5. 서브그룹 분리 대상 · 예상 INSERT

| 서브그룹(그룹#첨가제) | ko | en |

| 시트룰린#색소 | 10 | 10 |
| 암브록솔#유당 / #색소 / #아스파탐 | 3 / 2 / 1 | 동 |
| 아세트아미노펜#유당 / #색소 | 3 / 3 | 동 |
| 트리메부틴200#색소 | 3 | 3 |
| 로라타딘 연질#유당 | 2 | 2 |

> **INSERT 모델 주의**: master 는 `(master_id, status='canonical')` partial-unique → master 당 canonical 1개. 다중 함유(색소+유당 25·아스파탐+유당 1)는 **한 서브그룹 설명서에 두 경고 병기**. 따라서 실제 write 단위 = **distinct 130 master**(ko) + 130(en), 경고 인스턴스는 156. ko/en 동일 master 집합.
