## 6. SOURCE GAP 판정 (§3.11)

- **성분 식별 가능(대표 작성)**: 약용탄(A07BA)·스멕타이트(A07BC)·로페라미드(A07DA)·니푸록사지드(A07AX) = name+ATC5로 성분 확정 + e약은요 원문 grounding 확보 → 대표 초안.
- **조성 미표기(SOURCE GAP)**: A07BB 복합·A07XA 정로환류 생약 복합 = 원료·분량이 name·pde·원문 어디에도 없음. **대표 설명서 허용 게이트(§3.11.3) 통과 여부**:
  - 효능 수렴 ✅ (설사·복통 수반 설사·체함·묽은변·토사로 동일 수렴)
  - 용법 표현 가능 ✅ (연령별 1일 3회·4시간 간격·연용 제한)
  - 주의사항 조성 의존성 ⚠️ 부분(생약 조성별 차이 존재하나 발열·혈변·연용 경고는 공통) → **대표 설명서 작성 허용**, 조성 세분(정로환 vs 비스무트 vs 베르베린)만 HOLD_SOURCE.
- **성분 창작 0**: 브랜드명·기억 기반 조성 추정 없음. 모든 초안은 §4 원문 실조회 근거.

## 8. 감염성/응급 상황 구분 (WO §11)

지사제는 안전성 문구가 특히 중요하다. 모든 초안에 다음을 공통 포함했다.

1. **고열 동반 시 진료 필요**
2. **혈변·흑변 시 즉시 진료**
3. **탈수 예방을 위한 수분·전해질 보충**
4. **소아·고령자 탈수 위험 → 조기 진료 권고**

추가 구분:
- **감염성 설사(고열·혈변)**: 로페라미드(장운동 억제)는 오히려 위험 → 초안 3에 명시 금기·경고.
- **세균성 설사**: 니푸록사지드(초안 5)는 세균성 급성 설사 대상이나 18세 미만 금기·3일 한정·약사 검토 강화.
- **항생제 필요 상황**: 전신 항생제(A07A 계열 등)는 본 WO 범위 밖 → 초안 대상 아님.
