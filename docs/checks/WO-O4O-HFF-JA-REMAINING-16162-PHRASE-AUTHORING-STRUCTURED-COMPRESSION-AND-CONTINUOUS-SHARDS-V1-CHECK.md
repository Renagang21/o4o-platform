## 2. 신설: 조립 사고 게이트

`apps/api-server/src/scripts/hff-ja-b04-gate.mjs`

기존 게이트(수치 보존·한글·간체자)는 "무엇이 빠졌는가"만 본다. 이 트랙에서 실측된 사고는 그 검사를
**모두 통과하면서** 뜻을 망가뜨렸다. 게이트는 고치지 않고 **막는다** — 걸린 문서는 생산하지 않고 문제 큐로 간다.

| 규칙 | 잡는 사고 |
|---|---|
| `PARTICLE_DUP` | 조사 겹침 `をが` — 서로 다른 규칙이 같은 자리에 조사 부착 |
| `KANJI_DUP` | 수식 중복 `濃濃褐色` `黄黄緑色` |
| `END_DUP` | `。。` `のの` |
| `CLAIM_RUN` | 구분 기호 없이 `役立つ` 연속 = 기능성 경계 소실 |
| `ABNORMAL_AFTER_NUM` | 수치 뒤 `異常` = 하한 `以上` 역전 |

**게이트 자체의 오탐도 실측으로 잡아 교정했다** (오탐은 정상 문서를 잃게 하므로 결함과 동급으로 다뤘다):

| 초안 | 오탐 | 교정 |
|---|---:|---|
| `[をがにはでとも][をがに]` | `ことがある` 의 `とが` | 불가능한 짝만 (`をが|がを|…`) |
| `[\d%)]\s*異常` | 항목 번호 `(2) 異常が生じた…` 1,516건 | `[\d%]異常` (숫자 즉시 인접만) |
| 태그 무시 스캔 | `</li><li>` 를 넘어 매칭 → 26,362건 | 태그를 `・` 경계로 치환 후 스캔 |
| 문서 단위 방향 검사 | `이상사례`(異常)를 하한으로 계산 | 규격 값 문자열 단위로만 사용 |

## 3. 발견된 결함 — 수치 문맥 `이상` → `異常`

`80 이상 120 이하`(하한 80, 상한 120)가 일반 경로에서 `80異常120以下` 로 옮겨졌다. **부등호 방향이 뒤집히는 의미 역전**이다.

- **원인**: 안전 문맥의 `이상`(이상반응 → 異常)이 수치 문맥까지 적용됨
- **교정**: 규격 수치 문형으로 확정될 때만 동작하는 **선행 가드** 추가. 매칭 실패 시 아무것도 바꾸지 않는다
- **교정 확인**: 규격표 값 4,038종 대상 방향 위반 13 → **0**
