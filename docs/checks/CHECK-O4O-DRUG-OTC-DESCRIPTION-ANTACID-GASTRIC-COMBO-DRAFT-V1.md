## 5. grounding 및 SOURCE GAP 판정

- 조성이 **단일·성분 식별 가능**(name+ATC5로 성분 확정)한 A02AA/A02AB/A02AC/A02BA(파모티딘)/A02BX(알긴산) = e약은요 원문 grounding 확보 → **대표 초안 작성**.
- 조성이 **복합·미표기**(A02AD 기타·A02AF·A02AG·A02AH·A02AX 종합위장약)는 원료·분량이 name·pde·원문 어디에도 없음 → **SOURCE GAP**. 효능·용법이 수렴하는 범위의 **종합위장약 대표 초안 1건만** 작성하고, 조성 세분(제산염 종류·시메티콘 포함·건위생약·감초 함유)은 **HOLD_SOURCE**.
- **성분 창작 0**: 브랜드명·기억 기반 조성 추정 없음. 모든 초안은 위 §4 원문 실조회에 근거.
