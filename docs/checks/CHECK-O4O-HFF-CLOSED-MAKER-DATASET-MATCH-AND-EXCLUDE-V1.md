## 5. 판정 및 반영 정책 (승인 대기)

- **제외 대상(태그) = STRICT 585건** → 후보 `review_note`/tag `market:closed-maker` + 후순위(제작 대상 제외). **hard delete 아님.**
- 주의: 대기업(아모레·씨제이·삼양사·콜마비앤에이치 등)은 **회사는 활성이나 해당 건강기능식품제조업 license(사업장) 폐업** — "그 품목이 폐업한 제조 license 하에 신고됨" = 단종·이관 신호이나 **품목별 확인 여지** 존재. 그래서 **삭제가 아니라 제외 표시** + 이중게이트.
- **DB 반영은 승인 후**(이중게이트). 본 CHECK 는 read-only 매칭표까지.
