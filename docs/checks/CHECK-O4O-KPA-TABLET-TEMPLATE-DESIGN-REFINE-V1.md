# CHECK-O4O-KPA-TABLET-TEMPLATE-DESIGN-REFINE-V1

> 성격: 프론트(kiosk-core) — 5개 템플릿을 실제 화면으로 렌더해 보고 디자인 정비.
> Date: 2026-07-16

---

## 0. 결론

5개 템플릿을 배포본에서 실제 콘텐츠로 풀사이즈 렌더해 스크린샷으로 점검했다. 가장 명확한 문제 — **제품 집중/진열형이 제품을 부각하지 못함** — 을 수정했다(flex order 재정렬, 실측 확인). 나머지는 아래 §3 에 진단으로 남긴다.

## 1. 점검 방법

구강 코너 세트의 `templateKey` 를 5종으로 순회 PATCH 하며 공개 태블릿 화면(비로그인)을 fullPage 캡처, 완료 후 `corner_overview_qr` 로 원복. 검증용 진열 상품(케어가글액 8,500원) 존치.

## 2. 수정 — 제품 템플릿이 제품을 먼저 보이게

`product_focus`(상품 집중형)·`product_grid_qr`(제품 진열형)이 **제품을 콘텐츠 카드 아래에 작게** 보여줬다(이름/의도와 어긋남).

수정: 브라우즈 root 가 flex column 이므로 **블록 이동 없이 flex `order`** 로 재정렬.

| 자식 | 제품 템플릿 | 그 외 |
|------|:----------:|:-----:|
| 헤더/코너설명/상단QR/hero | 0 | 0 |
| 제품 body | **4** | 5 |
| 콘텐츠 카드 | **6** | 4 |
| 하단 QR 배너 | 7 | (미표시) |

- 제품 템플릿: 헤더 → **제품** → 콘텐츠 → 하단 QR.
- 그 외: 콘텐츠 → 제품 (기존과 동일 — 회귀 없음).
- JSX 이동 없음 → 회귀 위험 최소. template-layout 분기는 screen set 소비(KPA)에서만 활성 → k-cosmetics/glycopharm 무영향.

**실측**: product_focus·product_grid_qr 모두 `제품 top(0) < 콘텐츠 top(456)` → 제품이 먼저. tsc 0 / build 0 / 배포 success.

## 3. 남은 진단 (후속 판단용 — 이번 미수정)

| 템플릿 | 관찰 |
|--------|------|
| basic / corner_overview_qr | 콘텐츠 카드 중심으로 비교적 정돈됨. 헤더가 단조로움(순수 볼드 텍스트). |
| product_focus / product_grid_qr | 제품 리드(수정됨). 단 렌더 제품이 1개뿐이라 상단 우측 여백이 큼 — **데이터 이슈**(supplier 상품 `product_name=null` 로 필터됨). 실데이터 다수면 채워짐. |
| idle_touch_video | 하단 터치 안내 바 정상(별도 WO 반영). 영상 없을 때 상단 hero 가 큰 검은 여백 — 영상 지정 유도 or placeholder 개선 여지. |
| 공통 | 4개 템플릿이 시각적으로 유사(헤더+카드+QR). 위계·여백·헤더 스타일은 취향/반복 튜닝 영역 → 방향 확인 후 진행 권장. |

> 템플릿 레이아웃은 이전 WO(§3.4 등)들이 의도적으로 정한 순서/컴팩트 헤더 결정을 담고 있어, 광범위 재디자인은 그 결정과 충돌할 수 있다. 추가 폴리시는 방향 합의 후 반복 진행이 안전.

## 4. 후속 (요구/방향 확인 시)

```
supplier 상품 카탈로그 병합(product_name null) — 제품 그리드가 실제로 여러 개 뜨게
헤더/섹션 시각 계층 폴리시(공통) — 취향 영역, 방향 합의 후
idle_touch_video 영상 미지정 placeholder 개선
```

*5 템플릿 실측 점검. 제품 집중/진열형이 제품을 콘텐츠 아래로 밀던 문제 → flex order 재정렬(제품 4 / 콘텐츠 6 / 하단QR 7), 제품 리드 실측 확인. JSX 이동/타 서비스 영향 없음. 나머지 폴리시는 진단만 남기고 방향 확인 후 진행.*
