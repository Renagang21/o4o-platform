## 4. D07 강도·복합 구조 (자동화 경계의 근거)

ATC 4번째 문자 = **스테로이드 강도**(WHO): AA 약함 · AB 중등도 · AC 강력 · AD 매우강력. 3번째 그룹: A plain · C +항생제 · B +소독 · X 기타.

| atc5 | 의미 | OTC | RX | OTC grounded |
|---|---|---:|---:|---:|
| **D07AA** | **약한 스테로이드(plain)** | **193** | 54 | 105 |
| D07AB | 중등도(plain) | 11 | 111 | 5 |
| **D07AC** | **강력(plain)** | **0** | **526** | — |
| **D07AD** | **매우강력(plain)** | **0** | **90** | — |
| D07CA | 약한 + 항생제 복합 | 98 | 4 | 44 |
| D07CC | 중등도 + 항생제 복합 | 228 | 157 | 172 |
| D07XA | 기타 | 76 | — | 42 |

**결정적 경계**: **강력(D07AC)·매우강력(D07AD)은 OTC 0 = 전량 전문의약품.** OTC 스테로이드는 **약한(D07AA) 중심 + 일부 중등도 + 항생제 복합**이다.

**OTC 스테로이드 성분 종류**: 히드로코르티손 **153**(약한, 주력) · 프레드니솔론 32 · 덱사메타손 11 · **베타메타손 0**(강력은 RX) · 트리암시놀론 0(구강 A01) · 데소나이드 0.

**허가 문구 빈도(D07 OTC grounded 368):** 눈 주위/안검 금지 **301** · 소아 주의 **368(전량)** · 감염 금기 **368(전량)** · 장기/2주 제한 **85** · 얼굴 21 · 생식기 0.

## 8. 자동 작성 대표 초안 1건 (dry-run, DB write 0)

> **WO §6: 자동 가능 범위만 작성.** 아토피·안검·생식기·장기·광범위 = **작성 금지**(수동). 설계표준 §12-A + Selection·Counseling. 원문(더마큐어 히드로코르티손 등) grounded.

### 초안 1 — 약한 스테로이드 외용제 (벌레물림·접촉성 피부염·경미한 습진) · 자동 가능

**어떤 경우에 사용하나** 벌레물린 데, 접촉성 피부염, 경미한 습진·피부 가려움 등 가벼운 피부 염증·가려움을 단기간 완화하는 약한 스테로이드 외용제입니다.
**사용 방법** 1일 1~3회 적당량을 병변 부위에 얇게 바릅니다. **치료기간은 7일 이내로 제한합니다.** 안과용으로 쓰지 않으며, 의사 감독 없이 밀봉붕대(랩 등)를 하지 않습니다.
**주의사항** **세균·곰팡이·바이러스·옴 등 피부 감염이 있는 부위, 화상·궤양·여드름·입 주위 피부염에는 사용하지 않습니다.** 임부·수유부, 유·소아(특히 2세 미만), 고령자는 사용 전 약사와 상담하세요. **얼굴·눈 주위·생식기 등 민감 부위, 넓은 부위, 장기간 사용은 약사 상담이 필요합니다.**
**병원에 가야 하는 경우** **증상이 반복되거나 7일 이상 지속·악화, 진물·고름·발열(감염 의심), 얼굴·눈 주위·생식기 병변, 아토피가 의심되면** 자가치료를 멈추고 진료를 받으세요.
**Selection Point**
```
가벼운 벌레물림·접촉성 피부염     → 약한 스테로이드 단기 사용 가능
반복되는 습진·아토피 의심         → 진료 권장(자가치료 반복 금지)
얼굴·눈 주위·생식기·2세 미만      → 약사·의료진 확인
```
**Counseling Point**
```
■ 7일 이상 계속 사용하지 않습니다
■ 얼굴·눈 주위·생식기에는 함부로 사용하지 않습니다
■ 감염(진물·고름)이 있는 부위에는 사용하지 않습니다
■ 증상이 반복되면 진료가 필요합니다
```
**성분 기준 선택** *(공통 GMP 문구)*

> **작성 금지(수동)**: 아토피 전용·안검·생식기·장기사용·광범위·항생제 복합·중등도 이상 = 별도 대표 작성하지 않고 약사 큐레이션 대상.

## 9. Safety Block (WO §9)

약한 스테로이드라도 **부위·기간·감염**이 안전 핵심(자동 초안·상담에 반영):

```
■ 얼굴·안면          → 장기 사용 금지·주의
■ 안검(눈 주위)      → 사용하지 않음
■ 점막·생식기        → 사용하지 않음(수동)
■ 영아(2세 미만)     → 사용 전 상담
■ 임신·수유          → 사용 전 상담
■ 장기사용(7일 초과) → 금지, 반복 시 진료
■ 피부 감염(진물·고름·곰팡이·물집) → 사용 금지·진료
```

## 10. SOURCE GAP / HOLD / EXCLUDE

- **HOLD_SOURCE / 추정 금지(WO §11)**: 스테로이드 강도·항생제·항진균·복합 조성을 **원문에 없으면 추정하지 않는다.** 브랜드명만 있고 조성 미표기 복합 = 수동 큐레이션.
- **EXCLUDE(범위 밖)**:
  - **강력(D07AC) 526·매우강력(D07AD) 90·중등도 RX 111·복합 RX** = 전문의약품.
  - D07 밖 스테로이드(구강·안과·비강·치질) = 각 Primary Use 트랙.

## 13. 표준 사례 — 고위험 외용제 큐레이션

- **자동화 경계 = 강도(ATC 4번째자) + 부위 + 기간 + 감염 + 복합**. 약한 단일 스테로이드의 경미 질환·단기(7일)만 자동, 나머지는 수동/RX.
