## 3. 소급검사 결과 — 초기 5건 파일럿의 기존 오류

초기 5건은 **"위반 5건 발견·수정 → GO(조건부)"로 종결 선언**된 산출물이었다. 최신 가드(V2)로 소급하니 **실제 위반 6건이 추가 검출**됐다.

| 유형 | 산출물 | 내용 |
|---|---|---|
| **기준량 ↔ 1포 중량 연결 가정** | 프로바 | 원문 `1억/2,000mg` + `1회 1포`(포 중량 없음) → **"1포(2,000mg)당 1억"** |
| | 디노키즈 | 원문 `100억/2g` + `1회 1포` → **"1포(2g)당 100억"** |
| **1일 200억 잘못 산출** | 락토핏 | 원문 `100억/4g` + `1회 1포`(포 중량 없음) → 포=4g 가정 후 ×2회 → **"1일 200억"**. 4g이 1일분(2포)이면 실제 **100억 = 2배 오차** |
| **최상급·비교 표현** | 듀오락 | `sd-tag "섭취 부담 최소"` |
| | 뉴로랩스 | `"…가장 작은 한 알에 담았습니다"` |
| | 프로바 | `"높은 숫자보다"` · `"높은 함량보다 부담 없는 시작"` |
| **연령 경계 임의 명확화** | 디노키즈 | 원문 하이픈 `4-9세`·`6개월-4세` → 물결 `4~9세` 표기 + **`"6개월 이상"`** 경계 확정 |
| **제형에서 부재·편의성 추론** | (20-A a2) | `"실온보관 — 별도 냉장 조건이 표시되어 있지 않습니다"` |

> **락토핏 "1일 200억"은 그 파일럿이 REVIEW 에서 "이번 파일럿의 최대 수확"이라고 선언한 항목 자체**였다.
> → **자체 검수는 자기가 세운 가정을 검사하지 못한다.** ([REVIEW-V1 §2 Q2 정정](../guides/products/health-functional-food/pilot-probiotics/REVIEW-V1.md))

전량 정정 후 수작업 전수 재검사(25제품·50파일): **A-추가 0 / 연령-추가 0 / en 강화 0**, 잔여 검출은 전부 오탐 → **"실제 위반 0" 선언**.

## 4. 자동 가드 재검사 — **이 CHECK 의 핵심**

§3에서 "정정 완료 · 실제 위반 0"으로 선언한 **바로 그 25건**을 자동 가드([CHECK-…-GROUNDING-GUARD-AUTOMATION-V1](CHECK-O4O-PRODUCT-DESCRIPTION-GROUNDING-GUARD-AUTOMATION-V1.md))로 재검사했다.

```text

```

| 제품 | 검출 규칙 | 내용 | 사람이 놓친 구조적 이유 |
|---|---|---|---|
| **하루하루 장편한** (20-A) | `A-UNIT-BASIS-001` | 원문 `100억/400mg` + `1회 1캡슐`(**캡슐 중량 미표시**)인데 **"캡슐 1개(400mg)당 100억" + "1일 섭취 100억"** | **락토핏과 동일 함정의 재발.** 수작업 §A 가 "400mg = 캡슐 중량"이라고 **가정한 채 통과**시켰고, 전수 소급검사도 **같은 가정을 공유**해 못 잡음 |
| **듀오락** (5건) | `D-CLAIM-UNGROUNDED-001` | `"맛·향 부담이 없고"` · `"매일 부담 없이"` | 소급검사 sweep 정규식에서 **`부담` 을 누락** |
| **돌피니** (20-D) | `G-FORM-GENERALIZATION-001` | `"물 없이 씹어서"` — 원문은 `씹어서` 뿐 | **씹어서 ≠ 물 없이.** 사람이 자연스럽게 연결해버림 |

## 6. 최종 판정 — **CONDITIONAL PASS**

> 유산균·CFU형 설명서 제작 방식은 **CONDITIONAL PASS** 로 판정한다. 작성 전 구조화 가드와 작성 후 자동 전수검사를 적용하면 제품별 grounding, 기준량, 연령 범위 및 ko/en 정합을 통제할 수 있음이 확인됐다. 그러나 **수작업 검수만으로는 동일 가정을 공유한 오류와 언어 간 비대칭을 놓쳤으므로, 자동 가드 없는 대량 제작은 허용하지 않는다.**

### WO §12 기준 대조

| 기준 | 충족 |
|---|---|
| 사실·수치 오류 없음 | ✅ (정정 후 BLOCKED 0) |
| ko/en 정합 | ✅ 불일치 0 |
| 제품별 차이 충분 반영 | ✅ 제조사 18곳·제형 3종·균수 1억~100억·섭취 1~3회·연령별 1건 |
| 공통 골격이 과도한 복제를 만들지 않음 | ✅ 단순 치환 0 |
| 확장 가능한 제작 규칙 확정 | ⚠️ **조건부** — 자동 가드 전제 |

**FAIL 아님 근거**: 단순 치환 설명서 0, 기준량 해석 오류는 전량 검출·정정, 제품별 grounding↔문구 연결은 §A 로 통제됨.
**PASS 아님 근거**: 통제가 **가드에 의존**하며, 가드 없이는 3소배치 중 1소배치에서 실제 위반 3건 + 선행 산출물에서 10건(6+4)이 발생했다.
