## 2. 저작 (§3 · §4)

### 2-1. 정밀 규격 문형 3종 추가 — 범용 fallback 아님

§5 가 금지한 것은 **의미 경계를 만드는 범용 자동화**다. 아래는 고정 문형을 통째로 확정하는 규칙이며
문장을 쪼개거나 잇지 않는다. 매칭 실패 시 조용히 null 을 돌려준다.

| 문형 | 대응 |
|------|------|
| `최종 제품 표시량 X의 N~M%` (X 에 한글 없음) | `最終製品表示量Xの N〜M%` |
| `표시량 X의 N~M%` (괄호 없는 형태) | `表示量Xの N〜M%` |
| KO 저작기 홍삼 인트로 템플릿 | 제품명·수치 원문 유지, 나머지 고정 문형 |

인트로 템플릿은 KO 저작기가 기계 생성한 문형이라 대응도 고정이다(약 265 문구).
