## 6. grounding 가용성 (전체 제작 실현 조건)

- **후보 41,261 전량 MAIN_FNCTN(인정 기능성)·BASE_STANDARD(성분·함량)·PRDUCT·ENTRPS 보존**(선행 시판감사 §1) → **공식 grounding 확보**.
- 이는 [15 legacy photo 트랙](CHECK-O4O-HFF-BATCH-0-GROUNDING-ESTABLISH-V1.md)(원 표시사항 전무로 grounding 불가, HOLD)과 **결정적으로 다름** — 후보 풀은 grounding이 데이터에 있으므로 **그룹 대표 설명서 제작이 실제 가능**.
- 제품 특정값(정확 함량·품목보고번호)은 BASE_STANDARD/STTEMNT_NO로 이미 있음 → 대표 설명서 + 제품별 치환(제품명·제조사·함량) 전략 성립.

## 7. 권장 제작 전략 (그룹화 기반, 전체 제작)

- **Tier 1 (최고 효율):** 상위 ~57개 표준 고시형 단일 기능성 그룹(≥50품목) → 대표 설명서 57종으로 **8,461품목** 커버. ~175그룹(≥20)까지 확장 시 **12,042품목**.
- **Tier 2:** 중빈도 그룹(≥5, 857그룹 → 17,729품목) 대표+변형.
- **Tier 3:** 단독/복합 고유(16,308품목) — 원료 모듈 조합으로 반자동 생성(복합제=구성 원료별 표준 문단 결합).
- 각 그룹 대표 설명서 = MAIN_FNCTN(인정 기능성) grounding + 제품별 (제품명·제조사·함량) 치환. HFF-R02(제품 단위) 유지 위해 대표는 템플릿, 최종은 제품별 인스턴스.
