## 5. 자동 가드가 잡은 것 (오탐 2건 → 규칙·작성기 수정)

초안 1차에서 `B-SUPERLATIVE-001` **BLOCKED 2**. 둘 다 **오탐**이었고 원인이 같았다 —
이미 확립된 원칙("제품명은 표기 가능", "원문 인용은 우리 주장이 아님")이 **B 규칙에만 적용돼 있지 않았다**.

| 제품 | 검출 | 실제 |
|---|---|---|
| 프리미엄 유산균 17 | `프리미엄` / `Premium` | **제품명**. CP1 의 `(베트남)`, CP2 의 `온 가족이` 와 같은 유형 |
| 라파힐 프로바이오틱스365 | `최대` | **원문 보관 조건 인용** — "공기의 노출을 최대한 차단" |

### 조치 ①: 제품명·원문 인용을 최상급 판정에서 제외

`stripQuotedAndName()` 신설. **완화가 검출력을 깎지 않도록 쌍으로 고정**(회귀 4건):

```text
제품명 안의 "프리미엄"            → 통과
원문 인용 안의 "최대한"           → 통과
"이 그룹에서 가장 균수가 많은"     → BLOCKED 유지
"타사 대비 프리미엄 원료"          → BLOCKED 유지
```

### 조치 ②: `productNameEn` 입력 추가

en 초안의 `Premium Lactic Acid Bacteria 17` 은 **영문 제품명**인데 가드는 한국어 제품명만 알았다.
→ 작성자가 정한 음역 표기를 입력으로 받는다. **가드는 이 값을 창작하지 않고**, 제품명을
최상급 주장으로 오인하지 않는 데만 쓴다.

### 조치 ③: 보관 원문 절단 중단 — **CP2 와 같은 실수의 반복**

라파힐의 보관 서술이 `① .② 개봉 후에는 공기의 노출을 최대한 차단` 이었다.
작성기가 보관 원문을 60자에서 **잘랐기** 때문이다. CP2 에서 성상 절단을 고쳤는데
**보관에 같은 절단이 남아 있었다.** → 자르지 않도록 수정.

> 절단은 두 가지를 동시에 망가뜨린다: ① 문장이 깨진다 ② 원문과 문자열이 달라져
> **인용 판정이 무력화**된다(그래서 "최대한"이 우리 주장으로 오인됐다).
