## 핵심 — 가드 사각지대 수동 검증

가드 파서(parseCfu/parseBasis)는 **핵심 기준량·프로바이오틱스 CFU만** 자동 검증. **2번째·3번째 기능성분(아연/셀레늄/비타민D/K/프락토올리고당/포스파티딜세린 등)은 자동 검증 안 됨** → `grounding._secondFunctional`/`_thirdFunctional`에 수기 grounding + 원문 BASE_STANDARD 대조 수동검증. 전건 일치(예: 에버비건 아연 8.5mg/2g·셀레늄 55μg/2g, 메모리메이트 PS 300mg/2,100mg·비타민E 11mg/2,100mg).

## 대표 검수 (3원료)

- **칼마디**(칼슘+마그네슘+비타민D): 칼슘 300mg·마그네슘 150mg·비타민D 10μg, 표시기준 1.8g. 골다공증=공식 위험감소. 칼슘 core.
- **메모리메이트**(은행잎+PS+비타민E): 은행잎 28mg(기억력·혈행)·PS 300mg(인지력)·비타민E 11mg(항산화), 표시기준 2,100mg. 은행잎 core. 과일반화 0(타 오메가 제품의 눈/기억 기능 미채택).
- **에버비건유산균**(프로바이오틱스+아연+셀레늄): 20억 CFU·아연 8.5mg·셀레늄 55μg. 프로바이오틱스(CFU) core.
