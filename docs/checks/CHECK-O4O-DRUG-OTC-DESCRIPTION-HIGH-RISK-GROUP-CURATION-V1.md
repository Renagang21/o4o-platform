## 7. route별 템플릿 필요 여부

**필요(경구 템플릿으로 불충분).** 경구 = `효능·효과 / 복용 안내 / 주의 대상 / 성분 기준 선택`. 비경구 권장:

```text
효능·효과
사용 안내            ← "복용"→"사용"
사용 부위/방법        ← route별 특수(삽입/도포/점안/부착)
주의 대상
성분 기준 선택
```

route별 특수 문구:
- 좌제/질정: "경구 복용하지 않습니다 / 삽입 방법 / 임부·생리 중 주의"
- 점안: "렌즈 착용 시 / 개봉 후 사용기간 / 다른 점안제와 간격"
- 외용: "사용 부위 한정 / 상처·점막 주의 / (스테로이드) 장기·광범위 금지"
- 파스: "부착 시간 / 같은 부위 연속 사용 주의 / 광과민"
- 트로키/가글: "천천히 녹임 또는 뱉음(삼키지 않음) / 사용 후 음식 제한"

→ 별도 WO `...-ROUTE-TEMPLATE-V1` 권장.

## 9. 100그룹 확장 기여 가능성

**판단: route 축 단독으로도 100 도달 충분(groupable 240 raw / dedup ~100~140). 전체 축 합산 시 100 크게 초과.**

| 축 | groupable(경구/비경구) | 분류 특성 |
| --- | --: | --- |
| 단일·경구 (NORMALIZATION CHECK) | 32 | 자동 3 + 검토강화 21 + 저grounding 8 |
| 복합·경구 (COMBINATION v2) | ~137 Key C (31 ATC 패밀리) | 전부 검토강화 |
| **비경구 route (본 CHECK)** | **240 raw / ~100~140 dedup** | 검토강화·수동, 템플릿 선행 |
| **합계 universe** | **>270** | 100 크게 상회 |

→ 100그룹 draft는 **여러 축 조합**으로 달성 가능. route는 최대 pool이나 **작업량(검토강화·수동)과 템플릿 선행**이 비용. 100 draft 착수 시 **경구(단일+복합) 우선 + route 일부(검토강화 외용/파스/점안)** 혼합이 효율적.
