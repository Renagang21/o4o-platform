# 펀딩 오프라인 운영 정책 V1

> 상태: ACTIVE · 확정일: 2026-10-17 · 근거: 현재 사용자 명시 지시

funding.neture.co.kr의 모금은 운영자에게 오프라인 계좌이체하는 방식을 우선한다.
입금·목표 도달·참여 철회·중지·환급은 운영자가 확인하고 O4O에 기록한다.
은행/통장 조회·자동 입금 대조·PG·자동 송금/환급은 현재 도입하지 않는다.
향후 O4O 결제 흐름도 계좌이체를 원칙으로 수수료를 없애거나 최소화한다.

모집 기한 만료·정원 충족은 추가 참여를 막는 조건이며 자동 성공·실패/단계 판정은 아니다.
운영자가 목표 도달과 모집 결과·진행을 확인한다. 순모금 현황은 확인 입금에서 기록된 환급을 뺀 값이다.
참여 철회·모집 중지·환급 완료는 별도 상태다. 실제 환급과 기록 저장을 구분한다.

공급자 운영자는 비활성화 판단 시 진행 중 펀딩을 확인할 수 있어야 한다.
펀딩 운영자가 해당 펀딩을 직접 중지하고 사후 처리를 오프라인에서 수행·등록한다.
공급자 비활성화에 따른 자동 중지·개설자 승계·대체 담당 지정은 만들지 않는다.
동일 아이디가 여러 서비스를 맡아도 서비스별 권한을 유지한다. 통합 운영자 대시보드는 후속이다.
기존 content-only 경계·오프라인 기록 보존은 유지한다. 모집 기한을 입금/환급/이행 기한으로 전용하지 않는다.
