# OTC-EN-TRANSLATION-GUIDE — 일반의약품 설명서 영문 번역 지침

상태: **Draft V0.2** (2026-07-15) · 대상: **일반의약품(OTC) 전용** · 진입: [DOCUMENT-INDEX](common/DOCUMENT-INDEX.md)

> 이 문서는 완성된 규정이 아니다. **테스트 번역을 시작하기 위한 초안**이다.
> 테스트에서 발견된 문제는 [OTC-EN-TRANSLATION-TEST-LOG](OTC-EN-TRANSLATION-TEST-LOG.md)에 기록하고, 반복되는 것만 이 문서와 [OTC-KO-EN-GLOSSARY](OTC-KO-EN-GLOSSARY.md)에 반영한다.

---

## 1. 범위

- 대상: **일반의약품(OTC) 전용**. 다른 제품군은 이 문서의 대상이 아니다.
- 원문 기준: 식약처 허가 내용 기반으로 이미 확정된 **한국어 정본**.
- 이 문서는 **번역 기준만** 정한다. 설명서를 새로 쓰는 규칙(문체·구성·소구)은 [products/drug/DRUG-WRITING](products/drug/DRUG-WRITING.md)에 있으며 여기서 다시 정하지 않는다.

---

## 2. 번역 원칙

| # | 원칙 |
|---|------|
| T-01 | 한국어 정본을 **그대로** 번역한다. 내용 **추가·삭제·요약 금지**. |
| T-02 | 제목·항목·목록·표의 **구조를 유지**한다. 순서를 바꾸거나 합치지 않는다. |
| T-03 | **숫자·단위·연령·횟수·기간·농도**는 원문 값을 유지한다. 환산·반올림·범위 변경 금지. |
| T-04 | 동일한 한국어 문구는 **항상 동일한 영어 표현**으로 번역한다. 기준은 [GLOSSARY](OTC-KO-EN-GLOSSARY.md). |
| T-05 | 원문에 없는 설명·주석·경고를 **덧붙이지 않는다**. 원문이 모호하면 그대로 두고 TEST-LOG에 기록한다. |
| T-06 | 원문에 오류로 의심되는 내용이 있어도 **번역에서 고치지 않는다**. TEST-LOG에 기록하고 한국어 정본 수정 여부를 별도로 판단한다. |
| T-07 | 번역 후 **원문과 1:1 대조 검수**를 거친다 (§4). |

---

## 3. 작업 순서

```text
1. 한국어 정본 확정본 확보
2. GLOSSARY 확인 (없는 용어는 후보로 메모)
3. 번역
4. 대조 검수 (§4 체크리스트)
5. TEST-LOG 기록
6. 반복 이슈만 GUIDE / GLOSSARY 에 반영 → 버전 갱신 (§5)
```

---

## 4. 검수 체크리스트

번역 1건마다 확인한다.

- [ ] 항목 수가 원문과 같다 (누락·추가 0)
- [ ] 제목·소제목·목록 순서가 원문과 같다
- [ ] 숫자·단위·연령·횟수·기간이 원문과 일치한다
- [ ] GLOSSARY 등재 용어가 등재된 표현으로 쓰였다
- [ ] 요약·의역으로 원문 정보가 줄지 않았다
- [ ] 원문에 없는 문장이 없다

한 항목이라도 불일치하면 수정 후 재검수한다.

---

## 5. 버전 관리

- 이 문서와 GLOSSARY는 각각 **독립 버전**을 가진다 (`V0.1`, `V0.2` …).
- 번역 작업 시 **사용한 GUIDE 버전과 GLOSSARY 버전을 TEST-LOG에 기록**한다.
- 변경은 하단 이력 표에 1줄씩 추가한다.

---

## 6. 다른 언어로의 확장

이 문서는 **영어 전용 규칙을 담지 않는다.** §2 원칙과 §4 체크리스트는 언어 중립이다.
다른 언어(예: 중국어) 추가 시:

- 지침서: `OTC-{LANG}-TRANSLATION-GUIDE.md` — §2·§4를 그대로 상속하고 언어별 예외만 추가.
- 용어표: `OTC-KO-{LANG}-GLOSSARY.md` — 같은 표 구조, 한국어 열은 공유.
- 기록: 언어별 TEST-LOG 또는 본 LOG에 언어 열 추가.
