# OTC-EN-TRANSLATION-GUIDE — 일반의약품 설명서 영문 번역 지침

상태: **Draft V0.5** (2026-07-15) · 대상: **일반의약품(OTC) 전용** · 진입: [DOCUMENT-INDEX](common/DOCUMENT-INDEX.md)

> 이 문서는 완성된 규정이 아니다. **테스트 번역을 시작하기 위한 초안**이다.
> 테스트에서 발견된 문제는 [OTC-EN-TRANSLATION-TEST-LOG](OTC-EN-TRANSLATION-TEST-LOG.md)에 기록하고, 반복되는 것만 이 문서와 [OTC-KO-EN-GLOSSARY](OTC-KO-EN-GLOSSARY.md)에 반영한다.

---

## 1. 범위와 기준

- 대상: **일반의약품(OTC) 전용**. 다른 제품군은 이 문서의 대상이 아니다.
- 원문 기준: 식약처 허가 내용 기반으로 이미 확정된 **한국어 정본**.
- 이 문서는 **번역 기준만** 정한다. 한국어 설명서를 새로 쓰는 규칙은 [products/drug/DRUG-WRITING](products/drug/DRUG-WRITING.md)에 있으며 여기서 다시 정하지 않는다.

**한 줄 기준:**

```text
정보는 한국어 정본을 기준으로 유지하고,
문장은 소비자가 이해하기 쉬운 톤으로 쓴다.
```

즉 **직역이 아니다.** 정보는 지키고 표현은 푼다.

> **톤 기준**: 건강기능식품 외국어 설명서와 같은 소비자 톤을 따른다 ([HFF-DESCRIPTION-RULES-SSOT-V1 §4](products/health-functional-food/HFF-DESCRIPTION-RULES-SSOT-V1.md) — "정본 기반, 영어권 소비자 톤, 단순 번역 아님").
> **단, 의약품이므로 더 엄격하다**: 효능·용법·금기·주의사항은 **정보 손실 없이 전량 유지**하고, 판매 표현을 강화하거나 의학적 내용을 더하지 않는다 (§2 T-04·T-05).

## 2. 번역 원칙

### 2.1 정보 (엄격 — 변경 불가)

| # | 원칙 |
|---|------|
| T-01 | **정보의 기준은 한국어 정본**이다. 정본에 있는 사실만 쓴다. |
| T-02 | **숫자·단위·연령·횟수·기간·농도**는 원문 값을 유지한다. 환산·반올림·범위 변경 금지. |
| T-03 | **효능·효과 / 용법·용량 / 금기 / 사용상의 주의사항**은 누락 금지. 안전 관련 조건(연령 제한·병용 금지·투여경로 등)은 그대로 전달한다. |
| T-04 | 원문에 없는 **의학적 정보·판단·권고를 추가하지 않는다**. 판매 표현을 임의로 강화하지 않는다. |
| T-05 | 원문에 오류가 의심되어도 **번역에서 고치지 않는다**. TEST-LOG에 기록하고 한국어 정본 수정 여부를 별도로 판단한다. |

### 2.2 표현 (유연 — 소비자 톤)

| # | 원칙 |
|---|------|
| T-06 | 영어 문장은 **자연스럽고 이해하기 쉬운 소비자 톤**으로 쓴다. 한국어 어순을 그대로 옮긴 **직역투는 피한다**. |
| T-07 | **재표현(의역)을 허용한다.** 문장 분할·결합, 어순 조정, 쉬운 어휘 선택 가능. 단 T-01~T-05를 침해하면 안 된다. |
| T-08 | 용어는 [GLOSSARY](OTC-KO-EN-GLOSSARY.md)의 **권장 표현을 우선 참고**하되, **문맥에 맞으면 조정할 수 있다**. 표현 고정보다 **의미 정확성과 자연스러움이 우선**이다. |
| T-09 | 소비자 톤으로 바꿀 때 **의미가 달라지지 않아야 한다**. 쉬운 말로 바꾸다 조건·범위가 넓어지거나 좁아지면 안 된다. |
| T-10 | 번역 후 **원문과 정보 대조 검수**를 거친다 (§4). 문장 단위 1:1 대조가 아니라 **정보 단위 대조**다. |

> **경계**: "쉽게 쓴다"는 **표현**에만 적용된다. 정보를 줄이거나 안전 문구를 부드럽게 만드는 것은 T-03·T-09 위반이다.

> ⚠️ **소비자 톤 전환(V0.3)이 새로 연 위험**: 직역에서는 구조적으로 불가능하던 grounding 함정이 재표현(T-07)을 허용하면서 생긴다. 특히 **① "부재를 허용으로"** — 원문에 지시가 *없는 것*을 *해도 된다*로 쓰는 것 — 는 의약품에서 안전 문제가 된다.
> ```text
> 원문 용법에 "식후" 지시 없음        → "언제든 복용하세요"        ✗
> 원문에 병용 관련 언급 없음           → "다른 약과 함께 써도 됩니다"  ✗
> ```
> T-09는 **기존 조건의 왜곡**(넓어짐·좁아짐)을 막고, T-04는 **정보 추가**를 막는다. 위 사례는 지어낸 문장이 없어 "창작 금지" 점검을 통과하므로 **별도로 확인**해야 한다.
> 전 유형(①부재를 허용으로 ②외부 지식 유입 ③전수 비교 없는 최상급 ④허위 차별화 ⑤추론 확장) = [CONTENT-AUTHORING-PRINCIPLES §4-1](content-authoring/CONTENT-AUTHORING-PRINCIPLES.md) (CR-002·003·004, 전 제품군 공통).

## 3. 작업 순서

```text
1. 한국어 정본 확정본 확보
2. 정보 항목 추출 (효능·용법·금기·주의사항·수치)
3. GLOSSARY 권장 표현 확인 (문맥에 안 맞으면 조정 + 후보 메모)
4. 소비자 톤으로 작성
5. 정보 대조 검수 (§4 체크리스트)
6. TEST-LOG 기록
7. 반복 이슈만 GUIDE / GLOSSARY 에 반영 → 버전 갱신 (§5)
```

## 4. 검수 체크리스트

번역 1건마다 확인한다.

**정보 (하나라도 불일치 시 수정 후 재검수)**

- [ ] 효능·효과 / 용법·용량 / 금기 / 주의사항이 누락 없이 담겼다
- [ ] 숫자·단위·연령·횟수·기간·농도가 원문과 일치한다
- [ ] 원문에 없는 의학적 정보·권고가 없다
- [ ] 소비자 톤으로 바꾸면서 의미·조건·범위가 달라지지 않았다
- [ ] **원문이 지시하지 않은 사용법·조건을 "해도 된다"로 쓰지 않았다** (부재≠허용 — §2.2 경계, CR-004)

**표현**

- [ ] 소비자가 읽기에 자연스러운 문장이다
- [ ] 직역투 표현이 남아 있지 않다
- [ ] 판매 표현이 원문보다 강해지지 않았다

## 5. 버전 관리 · 테스트 결과 반영

- 이 문서와 GLOSSARY는 각각 **독립 버전**을 가진다 (`V0.1`, `V0.2` …).
- 번역 작업 시 **사용한 GUIDE 버전과 GLOSSARY 버전을 TEST-LOG에 기록**한다 (**OR-005**).
- 변경은 §7 이력 표에 1줄씩 **같은 커밋에서** 추가한다 (OR-005).

**테스트 결과를 어디에 반영하나** — 새 규칙이 아니라 [DOCUMENT-ARCHITECTURE §3·§6](common/DOCUMENT-ARCHITECTURE.md)(단일 위치 · 공통 우선 · 새 규칙은 CHECK가 아니라 Guide + Registry)의 적용이다. [TEST-LOG](OTC-EN-TRANSLATION-TEST-LOG.md)는 **실행 결과** 문서이므로 규칙이 거기 남으면 안 된다.

| 문제의 범위 | 반영 위치 |
|---|---|
| 그 설명서 1건만 | **TEST-LOG에만** |
| 다른 OTC 번역에도 반복되는 표현 | **[GLOSSARY](OTC-KO-EN-GLOSSARY.md)** |
| 다른 OTC 번역에도 반복되는 기준 | **본 GUIDE** |
| 의약품 전반 규칙 | **[DR Registry](products/drug/DRUG-RULE-REGISTRY.md)** |
| 제품군에 걸치는 규칙 | **[CR Registry](common/CONTENT-RULE-REGISTRY.md)** |

**기존 규칙으로 설명되면 새 규칙을 만들지 않고 그 규칙을 보완한다.** (예: §2.2 의 "부재≠허용"은 신설이 아니라 CR-004 연결이다.)

## 6. 다른 언어로의 확장

이 문서는 **영어 전용 규칙을 담지 않는다.** §2 원칙과 §4 체크리스트는 언어 중립이다.
다른 언어(예: 중국어) 추가 시:

- 지침서: `OTC-{LANG}-TRANSLATION-GUIDE.md` — §2·§4를 그대로 상속하고 언어별 예외만 추가.
- 용어표: `OTC-KO-{LANG}-GLOSSARY.md` — 같은 표 구조, 한국어 열은 공유.
- 기록: 언어별 TEST-LOG 또는 본 LOG에 언어 열 추가.
