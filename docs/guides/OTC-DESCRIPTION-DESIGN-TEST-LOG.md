## 2. 우선 검증 대상 (GUIDE 작성 시 발견 — 최초 테스트에서 확인할 것)

GUIDE 는 코드 실측 기반이지만 **화면 검증 전**이다. 아래는 **가설**이므로 테스트로 확정한다.

| # | 가설 | 확인 방법 | 결과 |
|---|---|---|---|
| P-1 | **B 모달(PC)이 1열로 뜬다** (컨테이너 ~576 < 640) | PC에서 모달 열고 `sd-core` 단 수 확인 | 미확인 |
| P-2 | **A 랜딩이 640 경계에 4px 차로 걸침** (~644) | 실제 컨테이너 폭 측정 (DevTools) | 미확인 |
| P-3 | **긴 영문 단어가 잘림** (줄바꿈 규칙 부재 + `overflow:hidden`) | 긴 성분명을 `sd-item h3` / `sd-chips` 에 넣고 관찰 | 미확인 |
| P-4 | **C 키오스크가 무스타일로 뜬다** (variant 미지정) | 태블릿에서 설명서 슬롯 확인 | 미확인 |
| P-5 | **D 다국어 랜딩이 A·B와 다르게 보인다** (ContentRenderer 미사용) | 같은 설명서를 A와 D에서 비교 | 미확인 |
| P-6 | 브라우저 200% 확대 시 좁은 레이아웃으로 정상 전환 | PC에서 200% 확대 | 미확인 |
