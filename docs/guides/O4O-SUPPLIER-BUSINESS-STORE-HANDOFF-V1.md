## 공급 제안

공급자는 공급 제안을 제출하고 담당 사업의 독립 운영자가 심사한다. 승인은 약국의 구매 자격을 대신하지 않는다. 승인 목록에는 협업체·상품·공급자·제품 원장의 현재 기본 공급 상태를 함께 안내한다. 약국별 사업 가입, 대상 약국, 공급 조건은 기존 서버 인가에서 다시 확인한다. 진열 숨김과 공급 종료는 별개다. 가격 변경은 기존 계약대로 종료 후 새 제안을 사용한다.

## 자료 반려 후 다시 요청

공급자 콘텐츠의 등재 요청 현황에서 제출 시점·최근 변경·반려 사유를 확인한다. 반려 또는 게시 중단된 자료는 ‘원본 수정 후 다시 요청’으로 이동한다. 원본 저장 후 같은 원본·사업이 선택된 요청 화면으로 돌아온다. 내용과 사업을 확인한 뒤 등재 요청을 눌러야 접수된다. 원본이 삭제되거나 사업이 요청을 받을 수 없으면 자동 접수하지 않는다.

원본·검토 사본·약국이 활용한 사본은 별개다. 원본 수정은 이전 사본을 덮어쓰지 않는다. 검토 대기·검토 중·게시 상태에 대한 중복 접수는 기존 서버 계약에 따라 재사용되며, 반려·보관 후 요청은 새 심사 대상이다. 원본의 공개 설정과 협업체 심사·게시는 독립적이다.

## 협업체에서 내 약국으로

가입 약국을 선택한 회원은 승인 제품 또는 게시 자료 카드에서 해당 항목의 내 약국 업무로 이동할 수 있다. Store에서 협업체에서 선택한 약국의 이름을 확인하고 명시적으로 선택한다. 브라우저가 기억한 다른 약국으로 자동 전환하지 않는다. 요청 약국에 접근할 수 없으면 중단하며, 다른 약국을 선택하려면 별도 버튼을 누른다.

제품은 해당 사업의 정확한 제안 하나를 기존 공급 조회 API로 읽는다. 종료되거나 접근할 수 없는 제안을 다른 상품으로 대체하지 않는다. 전체 상품 조회는 별도 선택이다. 자료는 해당 사업·콘텐츠가 지정된 기존 자료 화면으로 이동한다. 이동 자체로 주문·복사하지 않는다.

개인 조합원 자격이나 운영자 자격은 약국 구매 자격을 대신하지 않는다. URL의 사업·약국·항목 값은 이동 힌트이며 서버 권한을 부여하지 않는다. 실제 계정의 제출·승인·주문과 현장 검수는 별도 승인된 범위에서 진행한다.
