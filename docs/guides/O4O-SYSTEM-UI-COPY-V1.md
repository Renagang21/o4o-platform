# O4O 시스템 UI 안내 문체

> 상태: ACTIVE · 작성일: 2026-11-05 · 근거: 사용자 지시, TODO-O4O-STORE-PC-SETUP-UX-V1

모든 활성 서비스와 공통 UI의 시스템 설명·안내·오류·도움말은 합니다체를 사용한다. 버튼은 짧은 동작명으로 표시한다. 사용자 글·외부 자료·AI 작성 지침/검수 자료를 런타임에서 바꾸지 않는다. CSS나 DOM observer로 화면 문장을 일괄 치환하지 않는다.

| 용도 | 이전 예 | 변경 예 |
|---|---|---|
| 설명 | 프로그램을 준비해요. | 프로그램을 준비합니다. |
| 결과 | 연결을 확인했어요. | 연결을 확인했습니다. |
| 안내 | 상태를 확인해 주세요. | 상태를 확인해 주시기 바랍니다. |
| 확인 | 삭제할까요? | 삭제하시겠습니까? |
| 버튼 | 이미 설치했어요 · 연결 확인 | 설치된 프로그램 연결 확인 |

`좋아요`, `개요`, `주요`, `필요` 등 명사/기능명은 요체 종결이 아니다. 명령을 완료 사실로 바꾸지 않으며, 실패/권한 제한을 성공처럼 표현하지 않는다. 불확실한 원인은 단정하지 않는다. 실제 실행/계정 연결/업무 준비는 각각 관측된 증거로 표시한다.

소스 점검용 `scripts/maintenance/formal-ui-copy.mjs`는 services·packages·admin의 AST 텍스트 조각만 대상으로 한다. `--write`는 검토 가능한 소스 변경을 만들며 일반 실행은 남은 규칙 대상 수를 확인한다. 댓글·fixture/mock/seed/prompt/knowledge/data 경로와 AI source-prompt 기대값은 제외한다. 고정된 변환 규칙은 문장 의미의 최종 판정을 대신하지 않으며 diff·화면·관련 테스트를 검토한다. 신규 기능별 문장은 자연스러운 합니다체로 직접 작성한다.
