# O4O 상품설명서 전문 판단·AI 활용 원칙 V1

> **상태**: ACTIVE
> **작성일**: 2026-10-24 · **최종 갱신**: 2026-10-24
> **근거**: 사용자 방침 · [ADR-0003](../../adr/ADR-0003-product-description-professional-and-ai-use.md)
> **규칙**: CR-022 · AR-007 · 진입: [DOCUMENT-INDEX](../common/DOCUMENT-INDEX.md)

## 1. 목적과 적용 범위

O4O 상품설명서는 전문인이 판단하고 소비자에게 실질적인 도움을 주는 데 필요한 정보를 제공한다. AI의 일반적인 방어적 응답 성향을 설명서의 작성·검수 기준으로 삼지 않는다.

이 원칙은 전문인용 B2B 설명서, B2B·B2C·매장 이용을 지원하는 AI 활용용 구조화 설명서, 매장 상품 QR-code용 설명서에 공통 적용한다. 전문 정보의 허용 범위를 B2B에만 한정하지 않는다. 대상에 따라 설명의 깊이·용어·표시 방식을 조정한다.

## 2. 전문 정보의 적극적인 제공 (CR-022)

1. 질병명·증상명·진단 과정·감별 판단·검사 및 평가 항목·제품 선택과 사용 판단에 필요한 전문 정보를 다룰 수 있다. 의료·전문 영역이라는 이유만으로 삭제·거절·완곡어로 대체하지 않는다.
2. 전문인의 판단을 돕는 질문, 판단 근거, 가능성별 비교, 추가 확인 사항, 상담·진료 연결 기준을 구체적으로 제시한다. 질병명 또는 진단 관련 내용이 있다는 사실 자체는 검수 반려 사유가 아니다.
3. 근거가 충분한 내용은 명확하게 서술한다. 획일적인 면책문구나 “전문가에게 문의하세요”만으로 설명을 대신하지 않는다.
4. 근거가 부족하면 부족한 항목과 필요한 확인을 특정한다. 해당 주제 전체를 회피하거나, 약한 표현으로 근거 부족을 덮지 않는다.
5. 전문 판단을 지원하는 내용과 소비자에게 전달할 설명을 구분한다. 전문인이 사용하는 판단 정보는 유지하고, 소비자 안내는 이해할 수 있는 언어로 구성한다.

## 3. 사실·판단의 구분

- 상품 고유 사실·허가 효능·사용법은 해당 상품의 원문 근거를 따른다(CR-002~004). 근거 없는 효능·진단 결과·수치를 만들지 않는다.
- 질병·진단·감별에 관한 전문 참고정보는 출처를 확인할 수 있는 전문 자료를 근거로 별도 구분한다. 상품 허가문서에 진단 과정이 없다는 이유만으로 전문 참고정보까지 배제하지 않는다.
- 제품 사실과 전문 참고정보를 혼합해, 원료 일반지식이나 질병 설명을 해당 제품의 확정 효과로 표시하지 않는다.
- AI는 가능한 판단과 그 근거·불확실성·추가 확인 사항을 제시할 수 있다. 전문인의 검토 전 제안을 확정된 개인 진단이나 처방으로 표시하지 않는다.
- 사용상 중요한 금기·상호작용·위험 신호는 판단에 필요한 위치에 구체적으로 제공한다. 일반적인 경고를 반복하는 방식으로 전문 설명을 대체하지 않는다.
- 회원 전용·전문인 사용이라는 사실만으로 상품군별 허가·표시·광고 기준이나 검수 절차가 면제되는 것으로 해석하지 않는다.

## 4. 용도별 구성

| 용도 | 구성 원칙 |
|---|---|
| B2B 전문인용 | 전문 용어, 질병·진단·감별 맥락, 비교 근거와 확인 사항을 충분히 제공한다. |
| AI 활용용 구조화 설명서 | 상품 사실 / 전문 참고정보 / 판단 지원 / 소비자 안내를 구분하고, 출처·적용 대상·검수 상태·확인일을 식별할 수 있게 구성한다. 전문 정보를 요약 과정에서 소거하지 않는다. |
| 매장 QR-code용 | 소비자의 이해와 매장 상담을 돕는 설명을 제공한다. 질병명·진단 과정 설명을 일괄 금지하지 않고, 일반 설명과 개인별 판단을 구분한다. |

이는 콘텐츠 구성 원칙이며 신규 DB 스키마·API·권한·자동 생성·자동 배포 기능을 도입하는 지시가 아니다.

## 5. AI 작성·활용·검수 (AR-007)

- 프롬프트에 대상 사용자, 사용 맥락, 근거 자료, 필요한 전문 판단 범위, 출력 형식을 명시한다.
- 질병명·진단 과정·감별 판단을 다룬다는 이유만으로 답변이나 저작을 거절하지 않는다. 근거와 적용 범위를 밝히며 필요한 정보를 제공한다.
- 검수는 사실 정확성, 근거, 판단에 대한 유용성, 소비자의 이해 가능성으로 수행한다. 전문 내용을 삭제하거나 면책문구를 늘린 정도를 품질 지표로 삼지 않는다.
- 근거 있는 전문 참고정보와 상품 고유 사실의 구분은 CR-004/AR-002의 보완 규칙이다. 기존 소비자 설명서의 상품 사실을 AI 일반지식으로 확장하는 허가는 아니다.
- 작성 자동화·외부 LLM 호출·전문가 승인·배포 여부는 기존 AR-005/006 및 WORKFLOW의 별도 적용 사항이다.

## 6. QR 설명서와 공식 지식 기반의 관계

**2026-10-29 사용자 구분:** 매장 엑셀 상품으로 구축·활용하는 자료는 AI 상담지원용 구조화 정보다. 공통 상품 QR용 설명서는 전체관리자가 별도 제작·승인하며 일반 사용자에게 원본 제작 기능을 제공하지 않는다. 엑셀 등록/AI 자료 승인으로 QR을 자동 제작·교체하지 않는다. 매장 자체 자료·마케팅 QR과 공통 상품 QR은 별개다. 개발 연결 계약은 [매장 엑셀·AI 자료 흐름](O4O-STORE-PRODUCT-AI-CONTEXT-FLOW-V1.md)을 따른다.

- B2B·B2C·매장 이용에서 AI가 활용하기 좋은 구조화 설명서를 마련하는 것이 현재 방침이다.
- 이전에 제작한 QR-code용 설명서를 공식 데이터베이스로 채택할지는 **판정 보류**다. 이 원칙만으로 기존 QR 설명서를 공식 근거로 승격하지 않는다.
- QR 설명서를 유지·발전시키는 경우 매장은 구조화 설명서와 QR 설명서를 함께 참고할 수 있다. 출처·검수 상태를 구분하며, 상충하는 내용을 AI가 임의로 합치지 않는다.

## 7. 기존 규칙과의 관계

전문 정보의 허용 범위와 용도 구분은 본 원칙을 우선한다. 기존 매장용 설명서의 구매 지원·소비자 중심 목적을 전문인용·AI 활용용 설명서 전체의 단일 목적으로 확대하지 않는다.

기존 상품군별 제작 범위, 접근 권한, 고정 URL·QR, canonical 저장 계약은 별도 결정 전까지 유지한다. 과거 WO·CHECK를 소급 수정하지 않는다.


## 8. 작성 입력과 적용 경로

- 이용 목적은 전문인용(`professional`) / AI 판단·상담지원용(`ai-support`) / 소비자 안내·QR용(`consumer-qr`)으로 구분한다. 형식(상품 설명·QR·번역)과 목적을 혼동하지 않는다.
- 상품 원문과 전문 참고자료는 별도로 입력하며 각각 출처·확인일·검수 상태를 함께 전달한다. 검수 표시는 작성 근거의 상태이며 canonical 승인이나 게시 권한이 아니다.
- 전문 목적은 근거·질병/감별 맥락·확인 질문·선택 판단을 충분히 설명한다. 소비자 목적은 이해하기 쉬운 안내로 구성한다. 동일한 글자 수나 구매 유도 기준을 일괄 적용하지 않는다.
- STORE의 확인된 상품 사실은 B2B에 재사용할 수 있다. 단순 복사 후 저장만으로 전문인용 설명서 완성 판정을 내리지 않는다.
- 매장 상품 등록·상품 연결 자료 제작·설명 편집·QR 작성의 자료 입력은 해당 편집 세션에 사용한다. 근거 입력을 공식 DB에 자동 저장하거나 기존 QR 자료를 공식 지식 기반으로 승격하지 않는다.
- 상품 정보만 받는 기존 건기식 seed 파이프라인은 상품 사실 생성·검수에 한정한다. 전문 참고자료를 임의로 보강하지 않으며, 전문 자료가 필요한 작업은 분리 입력을 지원하는 작성 경로를 사용한다.

## 9. 반복적인 관리자 보정

상품 데이터 보정은 관리자가 기준을 수정·버전 관리하고 대상 상품을 선택하여 작업하는 환경으로 운영한다. 발견 사례를 이유로 기존 데이터를 즉시 수정하거나 일괄 적용하지 않는다. 기준·선택 작업·보완 초안·근거의 저장과 공식 상품 데이터 반영은 구분한다. 실행 절차와 현재 구현 범위는 [관리자 상품 데이터 보정 작업 공간](O4O-ADMIN-PRODUCT-CORRECTION-WORKSPACE-V1.md)을 따른다.
