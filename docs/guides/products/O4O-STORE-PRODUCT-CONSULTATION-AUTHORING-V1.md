# 사용자 AI로 매장 상품 상담자료 작성 V1

> 상태: ACTIVE · 작성일: 2026-10-26 (Asia/Seoul)
> 구현: 개발 branch, 운영 미배포. [작업](../../work-orders/WO-O4O-STORE-PRODUCT-CONSULTATION-AUTHORING-COMPLETION-V1.md)

1. 내 매장 상품에서 안내 작성으로 진입한다. 기존 안내를 확인하고 새 안내 작성 또는 기존 자료 수정 중 하나를 선택한다.
2. 새 안내의 상품 상담자료 영역에서 저장된 상품 원문을 불러온 뒤 **확인한 원문을 상품 사실 근거로 사용**을 누른다. 불러오기만으로 본문/근거를 교체하지 않는다. 기존 입력이 있으면 교체를 확인한다. 긴 원문은 최대 20,000자이므로 필요한 부분을 확인·보완한다.
3. 전문인용·AI 판단/상담지원용·소비자 QR 안내 중 목적과 한국어/영어/일본어/중국어를 선택한다. 상품 사실과 전문 참고정보의 출처·확인일·검수 체크를 각각 작성한다. 전문 용어 자체를 금지하지 않으며 전문 참고를 제품 고유 효과로 바꾸지 않는다.
4. ChatGPT로 작업 → 작업 안내 복사로 자기 AI에서 작성한다. 환자·고객 개인정보는 근거에 넣지 않는다. 이 화면은 외부 계정 연결·LLM 호출을 수행하지 않는다.
5. 결과 HTML을 편집기에 적용하고 미리보기에서 검토한다. 이 단계는 저장·게시가 아니다.
6. 내 자료함 콘텐츠로 저장한다. 기존 서버가 상품 소속과 실제 연결을 검증한다. 클라이언트는 저장된 본문·작성 맥락·상품 연결을 다시 조회해 확인한 뒤 상세 화면으로 이동한다.
7. 재조회 실패 시 입력과 생성된 자료 id를 유지한다. 다시 저장은 같은 자료를 수정·확인한다. 이미 생성됐을 수 있으므로 별도 새 안내를 반복 생성하지 않는다. 응답 유실로 생성 id 자체를 받지 못한 경우까지 서버 멱등성을 새로 제공하지는 않는다.
8. 상세 화면에서 상품/목적/언어를 확인하고 수정하면 근거·검수 표시도 복원된다. 읽기 시점의 상품 원문으로 자동 갱신하지 않는다. 최신 원문 확인은 명시적으로 다시 수행한다.

맥락은 기존 매장 자료 contentJson.productConsultation에 저장하며 상품 정본/공개 설명서/QR/서버 AI/외부 MCP를 수정하지 않는다. 자료가 기존 채널에 이미 연결된 경우 그 활용 영향은 기존 자료함 정책을 따른다. 목적으로 소비자 QR를 선택해도 QR을 생성·게시하거나 공식 상품 DB로 채택하지 않는다.

외부 직접 연결 담당자는 이 web-store 편집 문맥을 참고할 수 있으나 현재 MCP가 해당 메타데이터 계약을 지원한다고 가정하지 않는다. 연결 도구 확장은 별도 담당 작업이다.
