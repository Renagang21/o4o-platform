# GROUPING-PATTERNS — 의약품 그룹핑 반복 패턴 (Knowledge)

상태: Active · 축적형 · V1 (2026-07-08) · 진입: [DOCUMENT-INDEX](../../../common/DOCUMENT-INDEX.md)

> **Rule 아님 — 축적되는 패턴.** 규칙은 [DR-004·DR-005·DR-010](../DRUG-RULE-REGISTRY.md). 본 문서는 그룹핑·분할에서 **반복적으로 나타나는 판단 패턴**을 사례로 축적한다.

---

## 패턴

### P-1. 함량축 분할 — 효능 공유, group_key 분리
- **펙소페나딘 60mg / 120mg**: 효능은 "알레르기비염 완화"로 수렴 → 설명서(효능·주의)는 공유하되 **용법은 함량별 병기**(60mg 1일 2회 / 120mg 1일 1회 식전). canonical 승격 시 `::fexofenadine::60mg` / `::120mg` **2 group_key로 분리**. 양쪽 grounded면 HOLD 불필요.
- 일반화: 같은 성분·효능이라도 **함량이 용법·OTC/RX를 가르면** group_key 분리, 설명서 본문은 효능·주의 공유 + 용법 함량별 병기.

### P-2. 성분별 대표 ↔ 세대/계열 대표 공존 (DR-018)
- 소비자 진입용 "졸림 적은 2세대 항히스타민" 세대 대표 + canonical용 로라타딘·펙소페나딘·세티리진 성분별 대표는 **목적이 달라 공존**. 과병합/과분할 아님.

### P-3. 제형·성분 이중 분리 (같은 제형도 성분계열로 나눔)
- **트로키/스프레이**: 소독계(세틸피리디늄·클로르헥시딘) vs NSAID(플루르비프로펜) = 금기·연령·사용기간 상이 → 별도 대표.
- **구내염 겔**: 스테로이드(트리암시놀론, 감염성 구내염 금기) vs 비스테로이드 → 별도.

### P-4. 과병합 예외 (ATC7이 다른 성분을 묶는 경우)
- **인공눈물 S01XA20**(CMC·트레할로스·히알루론산 등) · **정장 생균 A07FA**(균주별) → ATC 아닌 성분별 분리.

### P-5. spec 첫 토큰 = 용기 용량 ≠ 농도
- 점안·외용 spec 첫 토큰(0.5밀리리터·14밀리리터·20그램)은 병/튜브 용량 → 그룹 분리 기준 아님. 원문 %·mg/g로 농도 재파싱.

## 사용 원칙
- 새 batch에서 그룹핑 판단 시 본 패턴을 참조한다. 새 패턴 발견 시 행 추가(규칙 변경 아님 → Registry 무수정).
