# CONSUMER-WRITING-PATTERNS — 소비자 설명 문체 패턴 (Knowledge)

상태: Active · 축적형 · V1 (2026-07-08) · 진입: [DOCUMENT-INDEX](../../../common/DOCUMENT-INDEX.md)

> **Rule 아님 — 축적되는 표현 패턴.** 규칙은 [CR-003](../../../common/CONTENT-RULE-REGISTRY.md)(과장 금지)·[DR-017](../DRUG-RULE-REGISTRY.md)(필수 블록). 본 문서는 실제 설명서에서 **반복되는 소비자 문체·표현**을 축적한다("무엇을 지켜야 하나"=Rule, "실제로 어떻게 반복되나"=본 Knowledge).

---

## 표현 패턴

| 상황 | 권장 표현 | 피할 표현 |
|---|---|---|
| 사용 목적 | "~에 사용합니다" | "~에 특효입니다" |
| 보조적 효과 | "~에 도움을 줄 수 있습니다" | "~이 확실히 좋아집니다" |
| 사용 권고 | "정해진 용법·용량을 지켜 사용하세요" | "많이 쓸수록 좋습니다" |
| 전문가 연결 | "약사에게 상담하세요" · "약사와 상의하세요" | (생략) |
| 진료 전환 | "병원을 방문하세요" · "진료를 받으세요" | "그냥 견디세요" |
| 주의 대상 | "~한 경우 사용 전 약사와 상담하세요" | "누구나 안심하고 사용" |
| 안전 단정 회피 | "졸릴 수 있으므로 주의하세요"(개인차 명시) | "졸리지 않습니다" |
| 품질 안내(GMP) | "동일한 기준으로 관리됩니다" | "완전히 똑같습니다" |

## 블록별 상투 문형 (재사용)

- **어떤 경우에 사용하나**: "~ 증상을 완화하는 [제형]입니다."
- **사용 방법**: "제품별 허가된 용법·용량을 지켜 사용합니다. [route별 안내]."
- **병원에 가야 하는 경우**: "고열·심한 통증·호흡곤란·증상 지속 시 진료를 받으세요."
- **사용 확인 포인트**: "~인지 ~인지 약사에게 확인하세요."

## 사용 원칙
- 새 설명서 작성 시 본 패턴을 문체 참고로 사용. 새 표현·상투구 발견 시 행 추가(규칙 변경 아님).
- 과장·우월성 단정(CR-003)·근거 없는 창작(CR-004)은 여전히 금지 — 본 문서는 표현 재사용을 돕되 규칙을 대체하지 않는다.
