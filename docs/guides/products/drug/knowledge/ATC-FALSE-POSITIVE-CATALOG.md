# ATC-FALSE-POSITIVE-CATALOG — ATC 오탐 실사례 (Knowledge)

상태: Active · 축적형 · V1 (2026-07-08) · 진입: [DOCUMENT-INDEX](../../../common/DOCUMENT-INDEX.md)

> **Rule 아님 — 축적되는 지식.** 규칙은 [DR-001](../DRUG-RULE-REGISTRY.md)("ATC는 후보 검색용"). 본 문서는 그 규칙을 뒷받침하는 **실제 오탐 사례**를 계속 축적한다. ATC 코드로 route/제형을 확정하면 경구·타경로 품목이 혼입되는 실증 목록.

---

## 카탈로그

| ATC | 의미(치료군) | 오탐 내용 | 실제 route로 걸러야 | 출처 CHECK |
|---|---|---|---|---|
| **R01B / R01BA** | 전신 비충혈제거 | 상당수가 **먹는 감기약**(슈도에페드린 복합, "감기의 여러 증상" 효능) | 효능에 기침·가래·발열·근육통 있으면 종합감기약 → EXCLUDE | RHINITIS-ALLERGY-DRAFT-V1 |
| **R02A** (4자리) | 인후용제 | 631건 중 **528건이 먹는 인후·감기약**(캡슐/시럽/과립/정). 실제 국소(트로키)는 16건뿐 | name 제형(트로키/가글/스프레이) 확인 | ORAL-THROAT-DRAFT-V1 |
| **S01** | 안과용 | **눈영양 경구 연질캡슐**(빌베리·은행엽) 혼입, 세안액(점안 아님) | name/원문 용법(점안 vs 경구) 확인 | NONORAL-STAGE1 · OPHTHALMIC-DRAFT-V1 |
| **A01A** (4자리) | 구강용제 | grounding 0 · 코드만 있고 조성 불명 다수 | 원문 확보 후 판단(HOLD) | ORAL-THROAT-DRAFT-V1 |

## 향후 축적 예정 (관측 시 추가)

- **A07** 정장제: 생균 A07FA는 균주별 별개(과병합 예외, 별도), 효모/다균 조성 DB 부재 케이스.
- **D11 / D01** 피부: 미백·항진균 코드 내 제형·농도 혼재.
- **G02** 여성: 질정↔경구 혼입 가능.

## 사용 원칙

- 새 batch에서 ATC로 후보를 뽑되, **본 카탈로그의 오탐 패턴을 먼저 확인**하고 name·원문으로 route/제형을 확정한다.
- 새 오탐을 발견하면 이 표에 행을 추가한다(규칙 변경 아님 → Registry 무수정).
