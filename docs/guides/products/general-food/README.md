## 1. 확정 정책

O4O는 일반식품의 공통 매장용 상세설명서를 **새로 제작하지 않는다**.

일반식품은 브랜드 콘셉트, 맛·향, 원료 이야기, 제조법, 선물 포지셔닝과 공급자의 마케팅 전략이 판매에 큰 영향을 주므로 신규 콘텐츠는 제조사·브랜드·공급자가 제작하는 것이 더 실질적이다.

기존에 제작된 일반식품 설명서는 삭제하지 않는다.

```text
기존 설명서와 데이터 유지
기존 URL·QR·태블릿·매장 연결 유지
기존 샘플 보존
신규 O4O 공통 설명서 제작 중단
```

이 문서와 하위 샘플은 과거 작업 기록과 기존 콘텐츠 유지·수정 참고용이며, 신규 일반식품 설명서 제작의 정본 가이드로 사용하지 않는다.

## 3. 향후 신규 콘텐츠

일반식품 신규 설명은 다음 경로를 사용한다.

```text
공급자 O4O 등록
→ 공급자·브랜드가 콘텐츠 제작
→ O4O 상품 연결
→ 매장 배포
→ QR·태블릿·POP 등에서 활용
```

공급자가 제작한 설명서의 제작원 표시는 최상위 정책을 따른다.

약국이나 매장이 직접 만드는 제품 콘텐츠는 해당 매장의 자체 콘텐츠 영역에 저장하며 O4O 상품 데이터베이스의 공통 설명서로 관리하지 않는다.
