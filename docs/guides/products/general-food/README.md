# products/general-food — 일반식품(기타가공품·건강즙 등) 매장 콘텐츠 규칙

상태: Active(초판) · 진입: [DOCUMENT-INDEX](../../common/DOCUMENT-INDEX.md)

의약품·건강기능식품·의료기기·의약외품에 속하지 않는 **일반식품(기타가공품, 액상 건강즙, 흑염소 진액, 홍삼/한방 진액 등)** 의 **매장 내(STORE) 콘텐츠 작성 기준**. 공통 규칙([DOCUMENT-INDEX](../../common/DOCUMENT-INDEX.md))을 상속하고, 제품 단위 패턴([O4O-PRODUCT-UNIT-DESCRIPTION-AGENT-GUIDE-V1](../O4O-PRODUCT-UNIT-DESCRIPTION-AGENT-GUIDE-V1.md))을 따른다.

> **초판 근거**: 제품 이미지 1건(담록원 "청정 한방 흑염소 진액 골드") 실제 처리 점검(2026-07-09)에서 도출.
> 샘플 산출물:
> - 흑염소 진액(다크+골드, 전통 보양 톤): [한국어](samples/damrokwon-heukyeomso-jinaek-gold.html) · [중국어(홍금)](samples/damrokwon-heukyeomso-jinaek-gold.zh.html)
> - 리포좀 콜라겐(핑크 뷰티 톤, 이너뷰티): [한국어](samples/elamor-liposome-collagen-glutathione.html) · [중국어(粉金 뷰티)](samples/elamor-liposome-collagen-glutathione.zh.html)
>
> **작업 단계 (순서 고정):**
> 1. 이미지에서 사실 파악(제품명·성분·용량·인증·분류·바코드).
> 2. **상품명 웹 검색으로 이미지에 없는 사실 보강**(제조사·전체 성분·규격·분류·바코드). 이 정보는 **두 용도**로 쓴다: ① 설명서 grounding, ② **O4O 상품 등록 필드**(ProductMaster/Candidate/store_local — 관련 필드가 있으면 등록에 활용). → R10.
> 3. 이미지 확인 정보 + 검색 보강 정보를 결합해 한국어 설명서 내용 작성.
> 4. **한국어 내용을 사용자에게 보여주고 점검받는다 (필수 게이트 — 자동 통과 금지).**
> 5. 사용자 확정 후 → 디자인 적용·저장(디자인 자체는 사용자 검토 불필요).
> 6. 다국어는 한국어 확정 후 대상 언어를 문의받아 진행하며, 외국어·현지 디자인은 판단 대상이 아니라 저장한다.
>
> 즉 **디자인/저장은 자동이되, 한국어 내용은 반드시 보여주고 점검받은 뒤** 넘어간다.

## 0. 사용 맥락 전제 (가장 중요)

이 축의 콘텐츠는 **인터넷에서 소비자에게 노출되는 B2C 광고가 아니다.** **전문가(약사 등)가 있는 매장 내부에서, 상담을 보조하기 위해 QR로 여는 자료**다 (`descriptionType = STORE`).

- 따라서 **B2C 식품표시광고 규제 프레임을 그대로 적용하지 않는다.** 효능·전통 보양·기력 언어를 사용할 수 있다.
- 최종 개인별 적합성 판단은 **매장 내 전문가 상담**이 보완한다(콘텐츠는 상담의 진입·보조 자료).
- 단, 질병을 치료·예방한다는 **의약품형 단정 주장은 지양**한다.

> 이 전제가 무너지면(예: 그대로 인터넷 B2C 노출) 규칙을 다시 세워야 한다. 본 문서는 STORE 맥락 전용이다.

## 1. 작성 규정 (R1~R10)

| # | 규정 | 요지 |
|---|------|------|
| **R1** | **맥락 기반 표현 수위** | 매장 내 전문가 매개(STORE) 전제. B2C 인터넷 규제 프레임 미적용 → 효능·전통 보양·기력 언어 허용. 질병 치료·예방 단정(의약품형)만 지양. 개인 적합성은 전문가 상담으로 보완. |
| **R2** | **라벨/이미지 grounding** | 이미지에 있는 사실만 기재. **없는 항목은 placeholder("확인 필요") 없이 그냥 생략**. 있으면 그대로 적는다. 임의 창작 금지. |
| **R3** | **원료 표기 그대로** | 배합비(%)·주원료/부원료 구분을 라벨 문구대로. 임의 재계산·재구성 금지. |
| **R4** | **한약재 = 원료로만 나열** | 당귀·천궁 등은 원료 목록·전통 보양 맥락으로 소개하되, 개별 성분의 의약품형 효능 단정은 하지 않는다(R1과 함께). |
| **R5** | **등록 계층 판단** | 바코드 있으면 canonical **ProductMaster**(F12: 물리제품 1 = barcode 1 = master 1). 바코드 없거나 매장 전용이면 **store_local_products**(barcode nullable). 콘텐츠 작성 계층과 무관하게 grounding 원칙은 동일. |
| **R6** | **매장 콘텐츠 구조(레이아웃/톤)** | 아래 §2 표준 섹션 구조를 따른다. 효능·시너지·타깃 섹션을 다운시프트 없이 사용하되(STORE 전제), 제품의 실제 강점(전통 보양·국내산·선물)을 살린다. |
| **R7** | **상담 CTA 용어** | 상담 안내 주체는 서비스 중립적으로 **"매장 내 전문성이 있는 도우미"**로 표기. "약사"는 약국(KPA) 맥락 한정. "직원"보다 전문성·신뢰 톤. (다국어: 中 `店内专业人员`) |
| **R8** | **모바일 가독 폰트 크기** | 설명서는 **QR로 여는 모바일 화면**. 본문 ≥15.5px, 리스트/CTA 본문 16px, 태그·라벨 ≥13px, 푸터 ≥12.5px, 제목 27px+. 11~12px 소형 텍스트 지양. base `font-size:16px`. |
| **R9** | **성분 한 줄 풀이** | 소비자는 성분표를 훑는다. 핵심 성분에만 **괄호 한 줄**로 "무엇인지"를 붙인다(전부 아님, 짧게). **효능 단정 금지 → "~로 잘 알려진 성분/원료" 중립 표현.** 카드 본문에 녹여 길이를 늘리지 않는다. 안전성 논란 이력 원료(예: 백수오)는 효능을 붙이지 않고 "전통 원료" 수준으로만. |
| **R10** | **상품명 검색 정보 활용 (2용도 + 채택 필터)** | 상품명 검색으로 얻은 정보는 ① 설명서 grounding, ② **O4O 상품 등록 필드**(제조사·성분·규격·분류·바코드)로 활용한다. **채택 필터**: 사실(성분·제조사·규격·인증)만 채택. **블로그·쇼핑몰의 효능/질병 개선 후기·마케팅 과장(예: "전립선염·잔뇨 개선")은 반영 금지**(R1 재확인). 검색으로 나온 성분은 **라벨 대조 전까지 "확인 필요"**로 표기하고 단정하지 않는다. 검색은 grounding 보강용이지 효능 창작·전이 통로가 아니다. |

## 2. 표준 콘텐츠 구조 (R6)

매장 QR 랜딩/설명서 공통 섹션 순서. (프리미엄 보양·선물 카테고리 견본에서 정립)

1. **후크** — "QR 스캔으로 열어보기"
2. **컨셉 헤드라인 + 성분 삼각(×)** — 배합에 이름 부여, 핵심 원료를 `A × B × C`로
3. **3대 핵심, 한눈에** — 원료별 카드 `[태그] + 이름 + 역할/보양 맥락 + 이런 분께`
4. **함께여서 더 좋은 조합(시너지)** — "각각의 합 그 이상"
5. **이런 분께** — 타깃 상황/페르소나 열거
6. **선물/자가 포지셔닝** — 프리미엄 톤
7. **구성/용량** — 라벨 사실(70ml×30포 등)
8. **매장 상담 CTA** — 이 화면을 매장 내 전문성이 있는 도우미에게 보여주기(R7)

디자인 톤: 제품 패키지 톤을 반영(예: 다크 + 골드). 모바일(QR 스캔) 우선(R8).
**다국어 디자인**: 언어권별 친숙한 톤으로 현지화한다(예: 中 = 홍금(红金) 프리미엄 선물 톤 + 명조 제목 + `韩国原产` 소구). 구조(§2 8단)는 공유하고 톤·서체만 현지화.
