# products/general-food — 일반식품(기타가공품·건강즙 등) 매장 콘텐츠 규칙

상태: Active(초판) · 진입: [DOCUMENT-INDEX](../../common/DOCUMENT-INDEX.md)

의약품·건강기능식품·의료기기·의약외품에 속하지 않는 **일반식품(기타가공품, 액상 건강즙, 흑염소 진액, 홍삼/한방 진액 등)** 의 **매장 내(STORE) 콘텐츠 작성 기준**. 공통 규칙([DOCUMENT-INDEX](../../common/DOCUMENT-INDEX.md))을 상속하고, 제품 단위 패턴([O4O-PRODUCT-UNIT-DESCRIPTION-AGENT-GUIDE-V1](../O4O-PRODUCT-UNIT-DESCRIPTION-AGENT-GUIDE-V1.md))을 따른다.

> **초판 근거**: 제품 이미지 1건(담록원 "청정 한방 흑염소 진액 골드") 실제 처리 점검(2026-07-09)에서 도출.
> 샘플 산출물:
> - 흑염소 진액(다크+골드, 전통 보양 톤): [한국어](samples/damrokwon-heukyeomso-jinaek-gold.html) · [중국어(홍금)](samples/damrokwon-heukyeomso-jinaek-gold.zh.html)
> - 리포좀 콜라겐(핑크 뷰티 톤, 이너뷰티): [한국어](samples/elamor-liposome-collagen-glutathione.html) · [중국어(粉金 뷰티)](samples/elamor-liposome-collagen-glutathione.zh.html)
> - 콸콸포맨(네이비+화이트 시원 톤, 남성/천문동 — R10 검색+질병주장 배제 사례): [한국어](samples/coolman-cheonmundong-liquid-tea.html) · [중국어](samples/coolman-cheonmundong-liquid-tea.zh.html)
>
> **작업 단계 (순서 고정):**
> 1. 이미지에서 사실 파악(제품명·성분·용량·인증·분류·바코드).
> 2. **상품명 웹 검색으로 이미지에 없는 사실 보강**. 검색은 **두 목적**을 함께 수행한다(정상 과정):
>    - (a) **상품 등록 정보** — 제조사·규격·바코드·분류 등 O4O 상품 DB 등록 필드에 쓸 값.
>    - (b) **성분 조사** — 각 성분이 **무엇인지**(원료 정체성·통상 용도) 조사해 설명서의 성분 풀이(R9)에 활용.
>    → 등록 정보와 설명서 근거를 **한 번의 검색에서 함께** 확보한 뒤 다음 단계로. 채택 필터·주의는 R10.
> 3. 이미지 확인 정보 + 검색 보강(등록 필드 + 성분 조사)을 결합해 한국어 설명서 내용 작성.
> 4. **한국어 설명서 "내용"을 사용자에게 (텍스트로) 보여주고 승인받는다 — 필수 게이트.**
>    이 승인 전에는 **디자인 적용도, 다른 언어(번역) 작업도 착수 금지.** 내용이 먼저다.
> 5. 승인 후 → 디자인 적용·저장(디자인 자체는 사용자 검토 불필요).
> 6. 승인된 한국어 기준으로 다국어 진행(대상 언어 문의). 외국어·현지 디자인은 판단 대상이 아니라 저장한다.
>
> 순서 불변: **① 내용 제작 → ② 내용 보여주고 승인(게이트) → ③ 디자인 → ④ 다국어.** 게이트를 건너뛰고 디자인/번역/저장으로 직행하지 않는다.

## 0. 사용 맥락 전제 (가장 중요)

이 축의 콘텐츠는 **인터넷에서 소비자에게 노출되는 B2C 광고가 아니다.** **전문가(약사 등)가 있는 매장 내부에서, 상담을 보조하기 위해 QR로 여는 자료**다 (`descriptionType = STORE`).

- 따라서 **B2C 식품표시광고 규제 프레임을 그대로 적용하지 않는다.** 효능·전통 보양·기력 언어를 사용할 수 있다.
- 최종 개인별 적합성 판단은 **매장 내 전문가 상담**이 보완한다(콘텐츠는 상담의 진입·보조 자료).
- 단, 질병을 치료·예방한다는 **의약품형 단정 주장은 지양**한다.

> 이 전제가 무너지면(예: 그대로 인터넷 B2C 노출) 규칙을 다시 세워야 한다. 본 문서는 STORE 맥락 전용이다.

## 1. 작성 규정 (R1~R10)

| # | 규정 | 요지 |
|---|------|------|
| **R1** | **맥락 기반 표현 수위** | 매장 내 전문가 매개(STORE) 전제. B2C 인터넷 규제 프레임 미적용 → 효능·전통 보양·기력 언어 허용. 질병 치료·예방 단정(의약품형)만 지양. 개인 적합성은 전문가 상담으로 보완. |
| **R2** | **라벨/이미지 grounding** | 이미지에 있는 사실만 기재. **없는 항목은 placeholder("확인 필요") 없이 그냥 생략**. 있으면 그대로 적는다. 임의 창작 금지. |
| **R3** | **원료 표기 그대로** | 배합비(%)·주원료/부원료 구분을 라벨 문구대로. 임의 재계산·재구성 금지. |
| **R4** | **한약재 = 원료로만 나열** | 당귀·천궁 등은 원료 목록·전통 보양 맥락으로 소개하되, 개별 성분의 의약품형 효능 단정은 하지 않는다(R1과 함께). |
| **R5** | **등록 계층 판단** | **바코드 유무와 무관하게 canonical ProductMaster 등록 가능** — 바코드 없으면 O4O 자체 내부코드(`generateInternalBarcode`, GS1 200 대역 EAN-13)를 자동 생성한다(모든 카테고리·의약품 포함). 근거: [WO-O4O-PRODUCT-MASTER-BARCODELESS-REGISTRATION-INTERNAL-CODE-V1](../../../work-orders/WO-O4O-PRODUCT-MASTER-BARCODELESS-REGISTRATION-INTERNAL-CODE-V1.md)(구현 완료). 등록 경로 `POST /api/v1/neture/admin/masters/resolve`(바코드 선택) 또는 관리자 수동 등록 UI. **store_local_products**는 매장 전용 제품용(별개 계층). ⚠️ 과거 "바코드 없으면 ProductMaster 불가"는 정비되어 더 이상 사실 아님. |
| **R6** | **매장 콘텐츠 구조(레이아웃/톤)** | 아래 §2 표준 섹션 구조를 따른다. 효능·시너지·타깃 섹션을 다운시프트 없이 사용하되(STORE 전제), 제품의 실제 강점(전통 보양·국내산·선물)을 살린다. |
| **R6-b** | **판매 관심 유발 (목적 · 전 제품군 공통 핵심 기준)** | ※ 이 기준은 general-food 만이 아니라 **건기식·기타 모든 매장용 설명서 공통** — SSOT: [O4O-PRODUCT-UNIT-DESCRIPTION-AGENT-GUIDE-V1 §4](../O4O-PRODUCT-UNIT-DESCRIPTION-AGENT-GUIDE-V1.md). 매장 콘텐츠의 목적은 **소비자 관심을 만들어 판매를 돕는 것**이다. **성분 나열에 그치지 말고**, 제품을 쓸 때의 **이점·상황 제안·why this product**를 STORE 맥락에서 담는다(원료의 유래·희소성·프리미엄·선물 가치·"이런 분께"의 생활 상황 등). 단 R1 유지 — **질병 치료·예방 단정만 금지**. 즉 "성분 설명서"가 아니라 "사고 싶게 만드는 매장 안내"로 쓴다. |
| **R6-c** | **소비자 화면 문구만 (편집·근무자용 문구 금지)** | 콘텐츠는 **소비자가 그대로 읽는 화면 카피**다. **편집용 라벨**("관심 유발", "왜 이 제품인가", 섹션 목적 표기 등)이나 **매장 근무자용 지시 문구**(운영 안내·판매 스크립트 지시)를 콘텐츠에 넣지 않는다. 소비자에게 노출될 문구만 남기고, 편집 의도는 문구 자체로 녹인다. (자주 혼입되는 실수 — 저장 전 점검) |
| **R7** | **상담 CTA 용어** | 상담 안내 주체는 서비스 중립적으로 **"매장 내 전문성이 있는 도우미"**로 표기. "약사"는 약국(KPA) 맥락 한정. "직원"보다 전문성·신뢰 톤. (다국어: 中 `店内专业人员`) |
| **R8** | **모바일 가독 폰트 크기** | 설명서는 **QR로 여는 모바일 화면**. 본문 ≥15.5px, 리스트/CTA 본문 16px, 태그·라벨 ≥13px, 푸터 ≥12.5px, 제목 27px+. 11~12px 소형 텍스트 지양. base `font-size:16px`. |
| **R9** | **성분 한 줄 풀이** | 소비자는 성분표를 훑는다. 핵심 성분에만 **괄호 한 줄**로 "무엇인지"를 붙인다(전부 아님, 짧게). **효능 단정 금지 → "~로 잘 알려진 성분/원료" 중립 표현.** 카드 본문에 녹여 길이를 늘리지 않는다. 안전성 논란 이력 원료(예: 백수오)는 효능을 붙이지 않고 "전통 원료" 수준으로만. |
| **R10** | **상품명 검색 정보 활용 (2용도 + 채택 필터)** | 상품명 검색으로 얻은 정보는 ① **설명서 grounding + 성분 조사**(각 성분이 무엇인지·통상 용도를 조사해 R9 풀이에 활용), ② **O4O 상품 등록 필드**(제조사·성분·규격·분류·바코드)로 활용한다. **채택 필터**: 사실(성분·제조사·규격·인증)만 채택. **블로그·쇼핑몰의 효능/질병 개선 후기·마케팅 과장(예: "전립선염·잔뇨 개선")은 반영 금지**(R1 재확인). 검색으로 나온 성분은 **라벨 대조 전까지 "확인 필요"**로 표기하고 단정하지 않는다. 검색은 grounding 보강용이지 효능 창작·전이 통로가 아니다. |
| **R6-e** | **모바일 랜딩 깊이 (요약 금지)** | 설명서는 **스마트폰 QR 스크롤 랜딩**이다. 성분 카드 몇 개로 끝내는 "요약" 수준은 판매 관심을 못 살린다. §2의 **히어로→스토리→왜(특징)→핵심 구성→이런 분께→섭취 안내→선물→트러스트→상담**을 갖춰 **충분한 읽을거리**를 제공한다(문단은 짧게 스캔 가능하게). 제품 유래·제법·차별점 스토리를 반드시 담는다. |

## 2. 표준 콘텐츠 구조 (R6)

매장 QR 랜딩/설명서 공통 섹션 순서. **모바일 스크롤형 랜딩** — 성분 카드만 나열하고 끝내면 "요약"처럼 짧아 판매 관심을 못 살린다(R6-e). 아래처럼 **읽을거리를 갖춘 랜딩**으로 구성한다.

1. **후크 / 히어로** — 제품명 + 한 줄 카피 + 핵심 소구(원산지·프리미엄 등)
2. **스토리/도입** — 원료의 유래·제법(발효·추출)·브랜드 이야기 2~3문장으로 몰입 유발
3. **왜 이 제품인가(특징)** — 고함량·고농축·고흡수·인증원료·제법 등 차별점
4. **핵심 구성** — 원료별 카드 `[태그] + 이름 + 정체성(R9)`; 건기식은 승인 기능성 포함
5. **이런 분께** — 타깃 상황/페르소나 (생활 상황 제안)
6. **섭취 안내** — 라벨에 있으면 하루 섭취량·방법(없으면 생략, R2)
7. **선물/자가 포지셔닝** — 프리미엄·선물 가치
8. **트러스트** — 100% 국내산·HACCP·고형분·원산지 인증 등 신뢰 요소
9. **구성/용량** — 라벨 사실
10. **매장 상담 CTA** — 이 화면을 매장 내 전문성이 있는 도우미에게 보여주기(R7)

> 문단은 짧게(스캔 가능) 하되 섹션 수·읽을거리는 충분히. 너무 짧은 카드 요약 수준 지양(R6-e).

디자인 톤: 제품 패키지 톤을 반영(예: 다크 + 골드). 모바일(QR 스캔) 우선(R8).
**다국어 디자인**: 언어권별 친숙한 톤으로 현지화한다(예: 中 = 홍금(红金) 프리미엄 선물 톤 + 명조 제목 + `韩国原产` 소구). 구조(§2 8단)는 공유하고 톤·서체만 현지화.

## 3. 범위·후속

- 본 문서는 **STORE 맥락 콘텐츠 작성 규칙**. 제품 검색·등록·설명서 저장(SPD/store_local)·QR 연결의 **구현 경로**는 별도:
  [IR-O4O-PRODUCT-IMAGE-TO-DESCRIPTION-START-POINT-AUDIT-V1](../../../investigations/IR-O4O-PRODUCT-IMAGE-TO-DESCRIPTION-START-POINT-AUDIT-V1.md)
- 다국어(외국어) 버전은 **한국어 기준본 확정 후**, 대상 언어를 사용자에게 문의하여 진행. 외국어·현지 디자인 판단은 위임 대상이 아니며 저장만 한다.
- 자체 Rule Registry(예: `GF-NNN`)는 사례 누적 시 별도 WO에서 채운다. 과도한 선행 생성 금지.
