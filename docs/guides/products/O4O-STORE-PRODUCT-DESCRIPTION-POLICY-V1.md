# O4O 매장용 상품 상세설명서 정책 V1

> 상태: Active · SSOT · 2026-07-12  
> 진입: [DOCUMENT-INDEX](../common/DOCUMENT-INDEX.md)  
> 적용: O4O 상품 데이터베이스에 귀속되는 매장용 공통 상품 설명서

---

## 1. 최우선 목적

O4O 매장용 상품 상세설명서의 가장 중요한 목적은 **소비자의 구매를 돕는 것**이다.

설명서는 제품 정보를 단순히 나열하는 문서가 아니다. 소비자가 제품에 관심을 갖고, 제품의 장점과 이를 뒷받침하는 신뢰 요소를 이해하여 구매를 고려하도록 만드는 판매 지원 콘텐츠다.

```text
소비자의 관심과 고민
→ 제품의 장점과 선택 이유
→ 구체적인 제품 정보와 공식 근거
→ 제품에 대한 신뢰
→ 구매 또는 매장 문의
```

제품 신뢰는 구매를 제한하기 위한 장치가 아니라, 소비자가 제품의 장점을 안심하고 받아들이고 구매 결정을 내리게 하는 핵심 판매 요소다.

---

## 2. 콘텐츠 성격과 접근 범위

- O4O 상품 데이터베이스와 ProductMaster에 귀속되는 공통 상품 콘텐츠다.
- 특정 약국이나 특정 매장에 귀속되지 않으며, O4O 상품을 활용하는 여러 업종의 매장에서 사용할 수 있다.
- 일반 공개 인터넷 콘텐츠로 제공하지 않는다.
- 유효한 O4O 로그인 사용자에게만 동일한 설명서 본문을 제공한다.
- 상품마다 하나의 고정 URL과 기본 QR을 유지한다.
- 비로그인 사용자는 로그인 또는 가입 후 원래 상품 URL로 복귀한다.
- 설명서 열람은 기본 회원 권한으로 제공하고, 태블릿 편성·POP·캠페인 QR·공급자 배포 등 사업 기능은 별도 entitlement를 적용할 수 있다.

---

## 3. 작성 원칙

### 3.1 구매를 돕는 설명

설명서에는 다음 내용이 드러나야 한다.

- 소비자가 왜 이 제품에 관심을 가져야 하는가
- 어떤 고민·필요·생활 상황과 연결되는가
- 비슷한 제품 중 이 제품을 살펴볼 이유가 무엇인가
- 핵심 원료·함량·기능·제형·구성의 장점이 무엇인가
- 섭취·사용·휴대·선물 측면에서 어떤 가치가 있는가
- 제조사·공식 기능성·품목정보·인증 등 무엇을 믿고 선택할 수 있는가

성분과 공식정보는 설명서의 목적이 아니라 **제품의 매력과 신뢰를 뒷받침하는 근거**로 사용한다.

### 3.2 표현 범위

O4O 로그인 회원 전용 매장 콘텐츠이므로 소비자의 질환·증상·생활 고민, 건강관리 목적, 연령·성별 관심, 가족·선물 상황, 제품 선택 이유를 적극적으로 사용할 수 있다.

다만 다음 최소 기준은 유지한다.

- 확인되지 않은 제품 사실을 만들지 않는다.
- 치료·예방·효과 보장을 단정하지 않는다.
- 원료의 일반 정보를 해당 제품의 확정 효과로 바꾸지 않는다.

주의사항과 제한 문구는 구매 판단에 필요한 범위에서 짧고 명확하게 제공한다. 제품의 장점보다 크게 보이거나 불필요하게 구매 의욕을 떨어뜨리는 형식은 피한다.

### 3.3 제품 신뢰

제품 신뢰는 설명서 전체에서 자연스럽게 보여준다.

- 정확한 원료·함량·섭취량·구성
- 공식 기능성·허가·품목정보
- 제조사·원산지·인증·제형·포장
- 소비자가 실제로 비교하고 선택할 수 있는 구체적인 정보

막연한 홍보문보다 확인 가능한 사실을 제품 장점과 연결해 설명한다.

---

## 4. 품질 판정

가장 먼저 다음을 묻는다.

> 이 설명서를 읽은 소비자가 제품의 장점을 믿고 구매를 고려하게 되는가?

다음 설명서는 완성본으로 승인하지 않는다.

- 성분·함량·공식 원문만 나열한 설명서
- 제품의 매력이나 선택 이유가 보이지 않는 설명서
- 어떤 제품에도 적용할 수 있는 일반적인 문구로 채운 설명서
- 자극적인 표현만 있고 신뢰할 근거가 없는 설명서
- 주의사항과 제한이 중심이 되어 구매를 위축시키는 설명서
- 정보는 정확하지만 소비자의 구매 판단을 돕지 못하는 설명서

## 5. O4O 직접 제작 범위

| 상품군 | 정책 |
|---|---|
| 건강기능식품 | O4O 제작 · 제품 1건 = 설명서 1건 |
| 일반의약품 | O4O 제작 · 기존 의약품 그룹 설명서 특수 트랙 |
| 처방의약품 | 제작하지 않음 |
| 일반식품 | 신규 제작하지 않음 · 기존 설명서는 유지 |
| 화장품 | O4O가 제작하지 않음 · 공급자 제작 영역 |
| 의료기기 | 소비자용 범위와 기준을 별도 확정한 뒤 진행 |
| 의약외품 | 허가정보 기반 제작 기준을 별도 확정한 뒤 진행 |
| 기타 일반제품 | 별도 승인 없이 신규 제작하지 않음 |

기존 일반식품 설명서는 삭제하지 않고 기존 URL·QR·태블릿·매장 활용을 유지한다. 신규 제작의 정본 샘플로는 사용하지 않는다.

---

## 6. 콘텐츠 제작 주체별 구분

### 6.1 O4O 공통 설명서

- O4O 상품 데이터베이스에 저장한다.
- 여러 O4O 사업자와 매장이 공통으로 활용한다.
- 승인된 작성·검수 절차를 거쳐 canonical로 관리한다.

### 6.2 공급자 제작 설명서

- 공급자는 O4O 공급자 회원 및 조직 등록을 먼저 완료해야 한다.
- 공급자가 제작한 설명서 하단에는 다음 정보를 작지만 읽을 수 있는 수준으로 표시한다.

```text
콘텐츠 제작: 공급자 등록 업체명
문의: 공급자 등록 연락처
```

- 제작원 정보는 설명서별 직접 입력값이 아니라 O4O 회원·조직 등록정보에서 자동으로 가져온다.
- 공급자 원본 콘텐츠가 배포되거나 그대로 활용되는 동안 제작원 표시를 유지한다.

### 6.3 약국·매장 자체 콘텐츠

- 약국이나 매장이 만드는 제품 콘텐츠는 해당 매장의 자체 콘텐츠 영역에 저장한다.
- O4O 상품 데이터베이스의 공통 canonical 설명서가 아니다.
- 공급자 제작원 표시 정책을 적용하지 않는다.

---

## 7. 하위 가이드 관계

- 건강기능식품·의약품·의료기기·의약외품 가이드는 이 정책을 상속하고, 상품군별 원천·구조·검수 규칙만 추가한다.
- 일반식품 가이드는 신규 제작 가이드가 아니라 기존 콘텐츠 보존용 Legacy 문서로 관리한다.
- 화장품은 O4O 직접 제작 가이드를 두지 않고 공급자 콘텐츠 작성·배포 정책에서 관리한다.
- 기존 문서가 이 정책과 충돌하면 본 문서를 우선한다.
