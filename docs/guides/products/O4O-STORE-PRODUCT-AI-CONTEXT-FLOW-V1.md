# 매장 엑셀 상품·AI 상담자료 이용 흐름 V1

> 상태: 최초 구현 기록 2026-10-29. 2026-10-31 후속 보완은 PR #910의 개발 branch이며 main 미병합·운영 미배포. [WO](../../work-orders/WO-O4O-STORE-PRODUCT-AI-CONTEXT-FLOW-V1.md)

## 두 자료의 구분

매장 엑셀 상품에 연결하는 **AI 자료**와 전체관리자가 별도 제작하는 **공통 상품 QR 설명서**는 다르다. AI 자료는 B2B·정확한 언어의 승인본을 사용하고, 공통 상품 QR은 기존 STORE 승인본을 표시한다. 엑셀 등록이나 AI 자료 승인으로 QR을 제작·교체하지 않는다. 기존 매장 자체 자료/마케팅 QR은 공통 상품 QR과 별개이며 일반 사용자에게 공통 STORE 원본 제작권한을 추가하지 않는다.

## 매장·관리자 흐름

1. 내 매장 제품 → **엑셀 상품 등록·AI 자료 준비**에서 XLSX/XLS/CSV 첫 시트를 선택한다. 최대 파일 10MB·데이터 5,000행·100열이다. 한도를 넘으면 실패하며 몰래 일부만 처리하지 않는다.
2. 앞 20행에서 머리글을 자동 탐지하며 필요하면 열 이름이 있는 행을 직접 고른다. 바코드·상품명 열을 확인해 대조한다. 가격·POS 코드·재고·주문은 결과/조사 요청문에 포함하지 않고 원본 파일을 저장하지 않는다. 잘못된 바코드는 이름 일치로 자동 우회하지 않는다.
3. 기존 정본명·바코드·제조사·일치 축과 해당 언어 B2B 승인자료 유무를 확인하고 행마다 직접 상품을 선택한다. 이름은 후보이며 업로드/대조만으로 등록·설명 제작·공개하지 않는다.
4. 선택 상품을 명시적으로 매장에 등록한다. 기존 master 등록 API·조직/서비스 소속·멱등 계약을 사용한다. 일부 실패는 행 결과를 유지하고 재시도한다. 매장 변경 후 다음 요청을 보내지 않는다. 기존 공통 설명·가격·QR은 변경하지 않는다.
5. 미확보 자료는 **미확보 자료 조사 요청문 받기**로 내려받아 자기 ChatGPT에서 정부 공개정보→제조사 공식 상세자료 순으로 조사한다. 이름·바코드만 포함한다. 내부 AI 호출·자동 외부 전송은 없다. 공개 근거가 없으면 작성하지 않고 사유만 정리한다. 미식별 상품은 자동 ProductMaster 생성 대상이 아니다.
6. 준비한 `o4o-public-product-descriptions-v1` JSON은 전체관리자가 기존 설명자료 수용 화면에서 B2B로 대조·검토·승인한다. 본문 없는 항목은 저장하지 않는다. 출처·확인일·보관자료 현행성 확인·복수 master 적용은 기존 수동 승인 계약을 따른다.
7. 등록 상품의 **안내 작성 → O4O AI 상담자료 확인**에서 해당 언어 B2B를 읽고 명시적 사용 버튼으로 사실/전문 참고를 각각 옮긴다. 기존 입력 교체는 확인을 요구하고 검수 체크는 다시 확인한다. 작성 결과 저장·사용자 기여는 기존 매장 상담자료 경로를 이용한다.

## 구조화·근거 계약

기존 JSON의 `descriptions[].aiSections`를 선택 필드로 확장한다. 항목은 `{key,title,kind,text,referenceUrls}`이며 kind는 `product-fact`(제품 사실), `professional-reference`(전문 참고), `counseling-support`(상담 판단지원), `unclassified`(미분류)다. 참조 URL은 기존 evidence에 선언된 HTTPS URL만 사용한다. 분류된 항목은 근거가 필수이며 같은 key를 중복할 수 없다. 구조화 입력 없는 기존 sections는 의미를 추정하지 않고 미분류로 보존한다. 분류 표기 자체가 내용의 진위를 인증하지 않는다.

기존 설명 후보 raw_payload에 항목·근거를 함께 저장한다. canonical 원장·유형/언어별 유일성·DB schema는 변경하지 않는다. 자유 HTML 본문을 수정하면 이전 구조화 항목은 해제하며 일반 정본 편집으로 원천과 본문이 달라져도 낡은 항목/출처를 재사용하지 않는다. 구조를 보완하려면 수정한 원천 파일을 재접수·승인한다.

B2B가 없으면 STORE·다른 언어·검토 후보로 대체하지 않는다. 비구조화 본문은 legacy/미분류·출처 확인 필요로 표시한다. 매장 작성 입력의 기존 길이 한도는 유지한다. 기존 약사 상담지원 요청은 구조화 B2B만 추가 근거로 사용하고 질문과 주의사항에 관련된 최대 16개 구조화 항목·항목당 5,000자를 준비하고, 게시 자료·사용자가 확인한 전문 참고를 포함한 전체 입력을 기존 18,000자 예산으로 제한한다. 일부만 사용한 근거는 표시하며 사용자 참고 입력의 예산을 먼저 확보한다. sourceVersion은 B2B 변경도 감지하며 엑셀 업로드만으로 AI를 호출하지 않는다. 상담에서 명시적으로 요청하는 맥락 검색은 [후속 실행 안내](O4O-CONSULTATION-CONTEXT-AND-RUNTIME-V1.md)를 따른다.

## 범위·검증

조회는 선택 조직의 권한과 활성 listing/master를 검증한다. 타 매장·미등록 상품은 거절하고 응답은 no-store다. 파일 대조도 인증·조직 권한·요청 제한을 거친다. 대조 화면/미등록 행은 세션 작업이라 새로고침 후 유지되지 않으며 등록 상품만 기존 목록에 남는다.

운영 계정·DB·실상품·QR·스케줄러·IAM은 변경하지 않는다. 로컬 합성 검증은 운영 검증을 대신하지 않는다. main 병합·배포와 실계정/실제 양식 검증은 통합 담당에게 인계한다.


## 2026-10-31 후속 보완 · PR #910

엑셀 대조에서 `hasAiDescription`은 근거 URL이 있는 분류된 구조화 항목에만 true다. 승인된 자유 본문만 있으면 ‘기존 설명만 있음’, 구조화 항목이 미분류뿐이면 ‘미분류·검토 필요’, 본문/승인본이 없으면 ‘없음’으로 표시한다. 일반 편집으로 본문과 원천이 달라지면 낡은 항목은 재사용하지 않는다. 미확보 자료 조사 요청에서 기존 자유 본문을 구조화 준비 완료로 제외하지 않는다.

엑셀 창의 현황은 현재 매장 고유 master 수·활성 연결 행 수·자체 상품 수와 정확한 B2B/언어의 준비 상태를 나누어 보여 준다. 중복 연결을 확보율에 더하지 않으며 권한 오류를 0%로 표시하지 않는다. 상담 고객 언어 일곱 개의 지원과 중앙 B2B 원천 자료 언어 네 개의 지원은 다르다. 한국어 근거로 고객에게 번역한다고 외국어 원천 자료까지 확보됐다고 계산하지 않는다.

자료는 O4O 전체관리자의 기존 접수·대조·검토·승인 경로에서 관리한다. 매장 엑셀은 취급 연결이며 매장별 표준 설명 DB 복제가 아니다. 매장 편집·기여는 기존 검토 후보로 들어가며 승인만으로 구조화 항목이 생기지 않는다. 구조화 수정 원천은 JSON으로 재접수한다. 기존 상품 보완의 예약 점검/변경 검토 목록은 재사용하되, 그것이 B2B 구조화 원천 자동 생성·정기 승인 기능이라는 뜻은 아니다. 실제 점검 주기·책임자는 운영에서 확정한다. 화면은 ‘관리자 검토·승인 후 갱신, 일정은 운영 절차에 따라 안내, 상품/언어별 준비 차이’를 설명한다.

매장 게시 자료가 현재 활성 취급 상품과 연결되지 않으면 목록에 확인 안내와 제품 동선을 표시한다. 기존 공개키·게시 내용은 삭제하거나 자동 덮어쓰지 않는다. 해당 자료가 현 상담의 근거로 사용 가능한지는 현재 상품·권한 확인으로 따로 판정한다.
