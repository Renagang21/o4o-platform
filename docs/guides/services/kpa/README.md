# services/kpa — 약국(KPA) 콘텐츠 채널 (스캐폴드)

상태: Scaffold (후속) · 진입: [DOCUMENT-INDEX](../../common/DOCUMENT-INDEX.md)

KPA(약국) 서비스의 콘텐츠 **채널·운영 특성**(설명서·POP·QR·태블릿·블로그 등)을 기술하는 자리. 제품군과 직교한다.

- **자체 Rule Registry를 만들지 않는다.** 규칙은 [CR](../../common/CONTENT-RULE-REGISTRY.md)/[DR](../../products/drug/DRUG-RULE-REGISTRY.md)/[AR](../../ai/AI-RULE-REGISTRY.md)에서 Rule ID로 참조.
- 여기에는 약국 채널의 적용 특성(예: 태블릿 진열·POP 인쇄·QR 랜딩)만 둔다.

> 현재는 스캐폴드. 과도한 선행 생성 금지.
