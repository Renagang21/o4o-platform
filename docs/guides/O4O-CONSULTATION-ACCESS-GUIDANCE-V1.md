# 상담 이용 조건 확인 안내 V1

- 작성일: 2026-10-29
- 기준: 역할별 업무공간 V2 §2, 기존 매장 접근·직원 기능 허용 계약.

약사 상담에는 승인된 개인 약사 자격과 현재 약국의 약사 업무 허용이 모두 필요하다. 중앙 담당자의 면허 근거 검토·승인과 경영자의 약국별 사용 확인은 별개다. 유료 기능·협업체 가입은 개인 자격 승인을 대신하지 않는다.

상담 방식에서 ‘개인 약사 자격·약국 업무 허용 확인 필요’가 보이면 My Home에서 개인 자격 상태와 현재 약국의 근무자 설정을 확인한다. 직원은 경영자에게 해당 기능·업무 허용을 요청한다. 기능 미제공 안내는 약국의 기본·유료·협업체 제공 기능과 개인별 허용을 함께 확인해야 한다는 뜻이며, 개인 자격 반려 판정이 아니다.

기존 상담 응답은 자격·약국별 허용의 개별 부족 사유를 반환하지 않는다. 화면은 이를 추정하지 않는다. 자격 조회 실패도 미승인 판정과 구분한다. My Home 이동 실패 시 같은 버튼으로 다시 시도할 수 있으며, 이동 자체가 자격 신청·설정 저장을 실행하지 않는다.

설정 확인 후 원래 상담 화면으로 돌아와 ‘이용 상태 다시 확인’을 누른다. 현재 입력·번역 초안이 초기화되고 현재 계정·약국 기준으로 조회한다. 상담 종료·고객 기기 연결 폐기는 별도 기존 동작이다. 확인만으로 고객 기기 연결이나 직원 업무 허용을 자동 변경하지 않는다.

기능·직원·자격 변경은 각 업무의 권한 있는 담당자가 처리한다. 다른 약국으로 권한이나 상담을 자동 옮기지 않는다. 실제 계정의 권한 회수·두 기기·현장 음성·유료 제공자 품질 검수는 별도다. 원문 장기 이력이나 학습 기능은 추가하지 않는다.

번역 중 서버가 401/403으로 접근을 거부하면 현재 입력·번역을 제거하고 상태 재확인 화면으로 돌아간다. 일반 네트워크 오류에서는 입력을 유지한다.
