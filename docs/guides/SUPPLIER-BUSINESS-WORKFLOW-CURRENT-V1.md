# 공급자 업무 흐름과 마감 검증 안내

> **상태**: ACTIVE
> **작성일**: 2026-10-22 · **최종 갱신**: 2026-10-22
> **근거**: [업무 마감 정비 WO](../work-orders/WO-O4O-SUPPLIER-BUSINESS-CLOSEOUT-V1.md)
> **범위**: 사용자 확정 사항과 이번 구현의 이용 안내. 정본 대체·운영 배포 완료 선언이 아니다.

## 업무 순서

1. 공급자 정보에서 상호·대표자·사업자번호·주소·개인/법인을 확인한다. 개인/법인은 세금계산서 관련 정보이며 거래 자격을 나누는 조건이 아니다. 세금계산서 이메일·정산 정보는 해당 섹션에서 별도로 저장한다.
2. 신규 제품은 기존 검토 요청 경로, 기존 표준 제품은 제품 라이브러리의 공급 연결 경로를 사용한다. 제품 등록은 서비스 게시·협업체 공급 승인·이벤트 시작을 대신하지 않는다.
3. 서비스 게시에서 일반 가격과 게시 여부를 명시적으로 저장한다. 협업체의 특별 공급조건은 공급 제안에서 협업체별로 별도 작성·승인받는다. pharmacy 특별가격도 같은 승인 경로다.
4. 공통 입력을 복사해 여러 협업체의 독립 초안을 만든다. 각 초안의 가격·배송비·무료배송 기준·최소금액·대상·메모를 확인한다. 전체 협업체 공통 정책은 없다. 제출 조건 변경은 기존 제안 종료 후 새 요청이다.
5. 요청 오류가 나면 같은 내용으로 접수 확인을 실행한다. 서버에 이미 접수됐다면 기존 제안과 현재 상태를 돌려주며 새 행을 만들지 않는다. 일부 성공한 묶음에서는 성공분을 다시 보내지 않는다. 조건을 바꾸려면 접수 목록을 확인하고 필요 시 기존 제안을 종료한 후 명시적으로 새 초안으로 전환한다.
6. 주문·배송·재고·정산은 기존 화면과 원장을 사용한다. 상품 노출·신규 주문은 현재 회원 자격을 확인하지만 이미 생성된 주문은 이후 협업체 정지·탈퇴·공급 제안 종료로 결제를 차단하지 않는다. 확정한 가격·배송조건을 유지하고 로그인·선택 약국 소유권·결제 금액/상태/중복 검증은 그대로 적용한다. 결제 전 배송 처리는 허용하지 않는다. 배송 상태 기록은 택배사 실행이나 집하 요청이 아니며 정산 지급 표시는 실제 은행 송금 완료를 검증하는 기능이 아니다. 약국 매장 주문의 기존 Neture 정산 제외 정책도 유지한다.
7. 콘텐츠는 자료함 저장, 커뮤니티 작성, 서비스 등재 요청을 각각 실행한다. 공급자가 제공한 사본은 해당 운영자가 검토한다. 원본 편집이 전달 사본을 자동 수정하거나 게시하지 않는다.

## 초안·대상 약국

- 계정과 서버에서 확인한 공급자 범위별로 같은 탭의 작업 사본을 보관한다. 마지막 사용 후 24시간 이내 사본만 복원하며, 새 브라우저·기기 간 동기화나 서버 초안 저장은 없다. 브라우저의 탭/세션 복구 정책에 따라 사본이 복원될 수 있다.
- 브라우저 보관이 차단되거나 공급자 범위를 확인하지 못하면 화면에 알리고 현재 화면의 입력만 유지한다. 이탈 시에는 내용을 확인한다.
- 전송 중 이탈한 사본은 접수 확인 필요 상태로 복원한다. 복원 자체는 서버 요청·저장·승인을 실행하지 않는다.
- 공용 기기에서는 작업 후 작성 초안을 지우고 로그아웃한다. 초안 삭제는 이미 접수된 제안을 종료하는 행동이 아니다.
- 대상 약국 이름 검색은 본인 제안 이력의 약국만 대상으로 한다. 전 약국 명단을 공개하지 않는다. 신규 대상은 전달받은 조직 ID로 지정한다. 협업체의 active 가입 검증을 생성 단계에 추가하지 않는다.

## 세금계산서 범위

현재는 개인/법인·사업자 기본정보·세금계산서 이메일의 저장·조회와 정산 준비 정보다. 발행기관 API·발행번호·수정/취소 발행·전송 결과 추적은 이번 작업에 포함하지 않는다. 실제 발행 연동에는 발행 주체와 방식의 업무 결정이 필요하다. 이를 임의로 거래 승인·결제 조건으로 추가하지 않는다.

## 현행 메뉴와 과거 기록

- 공급자 상품 메뉴: 내 제품, 제품 등록, 서비스 게시, 판매자 모집, 이벤트·특가, 공급 제안.
- 공급자 유통참여형 펀딩 메뉴는 제거됐다. 이는 독립 펀딩 서비스·원장·과거 이력 폐기를 뜻하지 않는다.
- 협업체 모집의 신규 진입은 종료됐다. 과거 URL의 종료 안내·신규 생성 410과 기존 이력 조회는 유지한다. 일반 판매자 모집은 별개다.
- FROZEN Supplier Domain §2.1의 옛 IA와 §6의 프로그램 표기는 위 메뉴 결정을 아직 반영하지 않은 부분이 있다. [사용자 결정 WO](../work-orders/WO-O4O-SUPPLIER-BUSINESS-INFO-AND-MENU-ALIGNMENT-V1.md)의 적용 범위로 읽으며 정본문서 개정은 별도 절차로 처리한다.
- Supplier Domain §10의 특정 owner 관계 복구 대기와 이후 테스트 계정 로그인/읽기 smoke 성공은 서로 다른 대상이다. 테스트 계정 성공만으로 해당 owner 복구 완료를 선언하지 않는다.
- 과거 WO의 push-only·NOT_RUN은 당시 기록이다. 현재 main/배포 여부는 해당 통합 기록·GitHub에서 확인한다. 본 문서도 미실행 운영 업무를 PASS로 바꾸지 않는다.
