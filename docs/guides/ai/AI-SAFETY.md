# AI-SAFETY

상태: Active · V1 (2026-07-08) · Rule: [AR-004](AI-RULE-REGISTRY.md) · [AR-005](AI-RULE-REGISTRY.md) · 진입: [DOCUMENT-INDEX](../common/DOCUMENT-INDEX.md)

> AI 사용의 안전·금지 규칙.

## 원칙

- **환각·과장·민감정보 노출 금지**(AR-004).
- **O4O는 소비자 설명서 초안을 외부 LLM으로 자동 생성하지 않는다**(AR-005). AI는 편집 보조·정리·요약·분류·검수에 사용하고, 초안의 근거는 공식 원문에서 온다.
- DB 비밀정보·개인정보를 프롬프트/로그/문서에 남기지 않는다(→ CR-014).

## 금지

- 근거 없는 의학적 단정 / 효능 과장 / 안전 경고 누락 / 민감정보 출력 / 승인 전 자동 배포.
