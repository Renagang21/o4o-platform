# AI-GROUNDING

상태: Active · V1 (2026-07-08) · Rule: [AR-002](AI-RULE-REGISTRY.md) · 진입: [DOCUMENT-INDEX](../common/DOCUMENT-INDEX.md)

> AI가 근거 없이 만들어내지 않도록 하는 grounding 규칙. CR-004(Grounding 필수)의 AI 실행형.

## 근거를 두 영역으로 구분한다 (CR-022 · AR-007)

| 영역 | 인정 근거와 작성 범위 |
|---|---|
| 상품 고유 사실 | 해당 제품의 허가사항·공식 원문·확인된 제조사 자료. 성분·함량·효능·용법·금기는 제품별 근거를 따른다. |
| 전문 참고정보·판단 지원 | 출처를 확인할 수 있는 전문 문헌·진료 지침·검수한 전문 자료. 질병·진단·감별·검사·상담 판단의 근거와 적용 범위를 명시한다. 상품 허가문서에 진단 과정이 없다는 이유만으로 이 영역을 배제하지 않는다. |

- 출처·확인일·검수 상태를 근거와 함께 전달하고, 상품 사실과 전문 참고정보를 서로 구분한다.
- 전문 자료의 일반 설명을 해당 상품의 확정 효능·적합성으로 옮기지 않는다.
- 출처 미확인·검수 대기 자료는 확인 필요로 표시한다. 누락된 항목만 특정하며 확인된 정보까지 일괄 회피하지 않는다.
- 상품명·태그·OCR만으로 성분·효능을 추측하지 않는다. 원문을 읽기 좋게 표현하는 것과 새로운 의료 사실을 만드는 것을 구분한다.
- 근거 없이 수치·효능·진단 결과를 만들지 않는다. AI의 검토용 제안과 전문인이 확정한 개인별 판단을 구분한다.
- 번역·요약은 원문의 의미·수치·중요한 사용 조건을 보존한다. 번역 단계에서 새로운 전문 판단을 추가하지 않는다.
