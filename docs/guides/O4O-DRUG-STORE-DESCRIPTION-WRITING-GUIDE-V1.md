# O4O 의약품 설명서 작성 기준 V1

> 작성일: 2026-07-06  
> 적용 대상: O4O 의약품 설명서 작업, 우선 일반의약품 OTC  
> 목적: 성분 중심의 신뢰성 있는 약국 매장용/소비자 안내 설명서 작성 기준을 고정하고, 실제 작성 결과를 반영해 계속 개선한다.

---

## 1. 문서의 목적

이 문서는 O4O 의약품 설명서를 작성할 때 참고하는 기준 문서다.

의약품 설명서는 무작위로 ProductMaster별 작성하지 않는다. 먼저 성분, 함량, 제형, 허가 내용이 같은 제품군을 묶고, 그 그룹에 대해 대표 설명서 1개를 만든 뒤 같은 그룹의 제품에 복사 적용한다.

이 문서는 고정된 최종 규칙이 아니다. 실제 설명서를 만들면서 부족한 점이 발견되면 이 문서를 먼저 업데이트하고, 이후 설명서 작성 품질을 높인다.

---

## 2. 설명서 종류

O4O 상품 설명은 다음 3종으로 본다.

| 구분 | 의미 | 비고 |
|---|---|---|
| B2B용 | 공급자, 사업자, 운영자 대상 설명 | 유통, 공급, 업무 정보 중심 |
| B2C용 | 소비자 대상 설명 | 의약품에서는 화면에 `e약은요`로 표시 |
| 매장용 | QR, POP, 태블릿, 상담 보조용 설명 | 매장 복사본은 O4O 상품 DB에 역반영하지 않음 |

의약품의 경우 화면 라벨은 다음처럼 표시한다.

| 화면 | 표시명 |
|---|---|
| 의약품 상세 | e약은요 |
| 비의약품 상세 | B2C 설명 |
| 여러 상품군이 섞인 리스트 | B2C/e약은요 |

---

## 3. 핵심 원칙

### 3.1 성분 중심

약국 설명서는 제품명이나 브랜드명 중심이 아니라 성분 중심으로 작성한다.

권장 제목:

```text
아세트아미노펜 500mg 정제
이부프로펜 400mg 정제
덱시부프로펜 300mg 연질캡슐
```

피해야 할 제목:

```text
타이레놀 설명서
부루펜 설명서
유명 브랜드 진통제 설명
```

제품명은 연결된 상품 정보나 예시로만 사용한다. 설명서의 기준은 성분, 함량, 제형이다.

### 3.2 포장단위는 설명서 분리 기준이 아님

같은 제품, 같은 성분, 같은 함량, 같은 제형이면 포장단위가 달라도 설명서는 같다.

예:

| 제품군 | 포장단위 | 설명서 |
|---|---:|---|
| 아세트아미노펜 500mg 정제 | 10정 | 동일 |
| 아세트아미노펜 500mg 정제 | 30정 | 동일 |
| 아세트아미노펜 500mg 정제 | 100정 | 동일 |

포장단위, 바코드, 포장 수량은 판매/재고/주문 단위이지 효능, 용법, 주의사항을 나누는 기준이 아니다.

### 3.3 같은 성분/함량/제형 그룹 우선

설명서 작업 단위는 ProductMaster 1건이 아니라 설명 공통 그룹이다.

기본 그룹 기준:

```text
성분 + 함량 + 제형 + 투여경로 + 허가 효능/용법이 같은 일반의약품 그룹
```

우선순위:

```text
허가 회사 수 많은 순
→ ProductMaster 수 많은 순
→ e약은요 원문 보유
→ OTC 확정
```

같은 성분/함량 제품을 허가받은 회사가 많다는 것은 약국 현장에서 많이 쓰이는 대중적 제품군일 가능성이 높다. 먼저 이런 그룹을 정비하면 작업 대비 효과가 크다.

### 3.4 개량 성분은 별도 설명

개량 성분은 같은 계열이라도 동일 설명서로 복사하지 않는다.

예:

| 성분 | 처리 |
|---|---|
| 이부프로펜 400mg 정제 | 이부프로펜 그룹 |
| 덱시부프로펜 300mg 연질캡슐 | 덱시부프로펜 별도 그룹 |

덱시부프로펜은 이부프로펜 계열이지만 같은 성분은 아니다. 개량 성분, 활성 성분 중심, 연질캡슐 제형 등 소비자 선택에 도움이 되는 차이는 별도 설명한다.

> 분류 표기 주의: 설명서의 `분류`(일반의약품/전문의약품)는 O4O 상품 DB의 `drug_category` 값을 기준으로 표기한다. 다만 거담제·소염진통제처럼 현장에서 처방이 동반되는 그룹은 품목별 실제 허가구분이 갈릴 수 있으므로, 매장 사용 시 최종 판매 구분은 약사가 확인한다.

단, 우월성을 단정하지 않는다.

피해야 할 표현:

```text
무조건 더 좋습니다.
부작용이 없습니다.
더 안전합니다.
더 강합니다.
빨리 낫습니다.
```

가능한 표현:

```text
이부프로펜 계열의 개량 성분
활성 성분 중심
연질캡슐 제형
빠른 용출을 고려한 제형
복용 편의성을 고려한 제형
```

### 3.5 함량축은 허가구분(OTC/RX)까지 가를 수 있음

같은 성분이라도 함량이 다르면 허가구분이 달라질 수 있다. 그러므로 설명서 그룹은 반드시 **성분 + 함량 + 제형** 3축으로 묶는다.

실측 예 (O4O DB, 2026-07-06):

| 성분 | 함량 | 제형 | 허가구분 |
|---|---|---|---|
| 나프록센나트륨 | 275mg | 정 | 일반의약품(OTC) |
| 나프록센나트륨 | 550mg | 정 | 전문의약품(RX) |
| 트리메부틴말레산염 | 100mg | 정 | 일반의약품(OTC) |
| 트리메부틴말레산염 | 300mg | 정 | 전문의약품(RX) |

성분이 같아도 고함량은 전문의약품인 경우가 있으므로, 저함량 OTC 설명서를 고함량 제품에 그대로 복사하지 않는다. 그룹 확정 시 함량축을 반드시 검증한다.

> 파싱 주의: O4O `specification` 의 함량 표기는 `mg` 이 아니라 한글 `밀리그램` 이다 (예: `275밀리그램 / 30 / 정 / 병`). 그룹핑 시 단위 표기를 맞춘다.

### 3.6 제형명이 투여경로를 보장하지 않는다

`정`·`캡슐` 같은 제형명이 붙어도 경구 복용이 아닐 수 있다. 그룹 확정 시 원문 용법으로 **투여경로**(경구/질/외용/점안 등)를 반드시 확인한다.

실측 예 (O4O DB, 2026-07-06):

| 성분 | 함량 | 제형명 | 실제 투여경로 |
|---|---|---|---|
| 클로트리마졸 | 100mg | 정 | **질정 — 질 내 삽입(내복 금지)** |

클로트리마졸 100mg "정"은 이름에 `정`이 있지만 칸디다성 질염용 질정이다(원문: "질 내 깊숙이 삽입", "이 약은 질에만 사용하고 내복용으로는 사용하지 마십시오"). 이런 그룹은:

- 요약표/본문의 "복용 안내"를 "**사용 안내**"로 바꾸고 삽입 방법을 기재한다.
- 자동 초안 대상이 아니라 **수동 큐레이션** 대상으로 분류한다.

> 같은 성분·함량이라도 적응증이 다를 수 있다. 예: 디펜히드라민 50mg 연질캡슐은 항히스타민 성분이지만 O4O OTC 원문상 적응증은 **일시적 불면증 완화**(수면유도)다. 성분 계열만으로 효능을 단정하지 말고 원문 적응증을 따른다.

### 3.7 성분 표기변형 정규화

설명서 그룹핑은 상품명 문자열만으로 판단하지 않는다. 같은 성분이 염명, 어순, 기호, 약어, 띄어쓰기 차이로 다르게 표시될 수 있다.

예:

```text
말레인산트리메부틴 = 트리메부틴말레산염
염산세티리진 = 세티리진염산염
덱시부프로펜디.씨 = 덱시부프로펜
엘-카르니틴 = 엘카르니틴 = L-카르니틴
```

이름 파싱만으로 그룹을 만들면 같은 성분이 여러 그룹으로 조각나고, 실제로는 이미 작성한 성분이 가짜 "신규" 그룹으로 잡힌다. 이 문제를 해결하지 않으면 그룹 확장(예: 100그룹) 시 중복 설명서를 만들 위험이 있다.

정규화 우선순위:

```text
1. e약은요 itemSeq 또는 원천 item identifier
2. MFDS 품목기준코드 / 주성분코드
3. 허가 주성분명
4. 성분명 표기변형 사전
5. ProductMaster name 또는 regulatoryName 괄호 성분 파싱
```

가능하면 상위 우선순위(itemSeq·품목기준코드·주성분코드·허가 주성분명)를 사용하고, 부족할 때만 상품명 파싱을 보조로 사용한다.

단, 표기변형이 같은 성분으로 정규화되더라도 **함량, 제형, 투여경로, OTC/RX 여부가 다르면 설명서 그룹은 분리한다**(§3.5·§3.6).

> 실측 근거: `CHECK-O4O-DRUG-OTC-DESCRIPTION-50-GROUP-DRAFT-V1` §5 — 트리메부틴말레산염↔말레인산트리메부틴, 세티리진염산염↔염산세티리진, 덱시부프로펜↔덱시부프로펜디.씨, 엘카르니틴↔엘-카르니틴↔L-카르니틴이 다중 표기로 분산되어 이름 파싱 후보 풀이 조기 소진됨.

### 3.8 저 grounding 그룹 처리

e약은요 원문이 있다는 사실만으로 자동 초안 가능으로 분류하지 않는다. 다음 근거가 충분히 확인되어야 자동 초안 대상이다.

```text
효능·효과 근거
복용/사용법 근거
주의 대상 근거
성분 작용 설명 근거
```

이 근거가 부족한 그룹은 `약사 검토 강화`, `수동 큐레이션`, `보류` 중 하나로 분류한다.

**금지 원칙:**

```text
근거가 부족한 상태에서 AI가 일반 약리 지식으로 설명을 확장하거나 보강하지 않는다.
```

필요하면 허가 원문 또는 추가 공공 원천을 확인한 뒤 작성한다.

> 실측 근거: `CHECK-O4O-DRUG-OTC-DESCRIPTION-50-GROUP-DRAFT-V1` §8 — e약은요 원문이 있어도 커버가 얇은 그룹(은행엽 80mg, 포도엽 180mg, 아르기닌티디아시케이트 200mg 등)은 자동 초안이 아니라 검토·큐레이션 대상으로 분류.

### 3.9 민감 약효군 프레이밍

일부 일반의약품은 OTC라도 소비자 오해나 오남용 위험이 높다. 데이터상 clean(단일성분·100% OTC·경구)하더라도 자동 초안 가능으로만 처리하지 않는다.

민감 약효군 예:

```text
경구피임약
수면유도제
항혈전 / 저용량 아스피린
질정 / 질내 삽입제
강한 NSAID 계열
철분제
간·담도계 약물
```

이 그룹은 자동 초안 조건을 만족하더라도 **기본값을 `약사 검토 강화`로 둔다.**

단, 설명서를 쓰지 말라는 뜻은 아니다. 약국 매장용 설명서는 소비자가 약사에게 문의할 수 있는 환경에서 쓰이므로, 질환명·증상명·사용 목적을 회피하지 않는다. 대신 복용 조건, 주의 대상, 약사 상담 필요 조건을 명확히 적는다.

피해야 할 표현:

```text
안심하고 복용
부담 없이 사용
효과가 빠름
장기 복용 가능
누구나 사용 가능
예방 가능
치료 가능
```

권장 작성 방향:

```text
사용 목적을 구체적으로 설명
복용/사용 조건을 명확히 설명
약사 상담이 필요한 대상을 구체적으로 표시
오남용 가능성을 낮추는 문장 사용
광고처럼 보이더라도 의약품 정보의 신뢰성과 근거를 훼손하지 않음
```

> 실측 근거: `CHECK-O4O-DRUG-OTC-DESCRIPTION-50-GROUP-DRAFT-V1`(데소게스트렐 경구피임약 = 수동 큐레이션·혈전색전증 등 다수 금기) 및 `CHECK-O4O-DRUG-OTC-DESCRIPTION-20-GROUP-DRAFT-V1` §14(아스피린 100mg·수면유도제·활성비타민D·철분 = 약사 검토 강화).

### 3.10 비경구 route는 "복용 안내"가 아니라 "사용 안내"

외용(크림·연고·겔)·파스/첩부·점안·점비/비강·좌제·질정·트로키/구강정·가글은 삼켜 먹는 약이 아니다. 경구 템플릿의 **"복용 안내"를 그대로 쓰면 안 되며 "사용 안내"로 바꾸고**, 요약표에 **"사용 부위/경로"** 항목을 추가한다(클로트리마졸 100mg 질정 선례 §3.6).

권장 구조(경구 §5 대비 변경점만):

```text
요약표에 "사용 부위/경로" 추가
복용 안내 → 사용 안내
사용 안내 아래 "사용 부위/방법" 명시 (삽입/도포/점안/부착/함수)
하단 "성분 기준 선택" GMP 문구는 동일 유지
```

**route별 필수 문구(최소):**

| route | 반드시 포함 |
|---|---|
| 외용 크림·연고·겔 | 사용 부위 한정 · 상처/점막/눈 주위 주의 · (스테로이드) 장기·광범위 금지 · (항생제) 임의 장기사용 금지 |
| 파스/첩부 | 부착 시간 · 상처 부위 금지 · 광과민 · 같은 NSAID 중복 주의 |
| 점안 | 렌즈 착용 시 주의 · 개봉 후 사용기간 · 다른 점안제와 간격 · (충혈완화) 장기연속 금지 |
| 점비/비강 | 사용 횟수 · **연속 사용 제한(반동성 비충혈)** · 심혈관/소아·임부 주의 |

## 4. 문체 기준

### 4.1 기본 톤

설명서는 약간 건조하고, 학술적인 느낌이 있으나 친절해야 한다.

좋은 방향:

- 질환명 회피
- 모호한 표현
- 브랜드 중심 설명
- 너무 긴 설명

### 4.2 질환명과 증상명 사용

AI 에이전트가 질병명이나 증상명을 피하려는 경향을 적용하지 않는다.

매장용 설명서는 약국 내에서 소비자와 약사가 함께 확인하는 설명이다. 소비자에게 정확한 정보를 전달하려면 두통, 치통, 생리통, 관절통, 인후통, 발열, 위장질환, 천식, 간질환 등 실제 질환명과 증상명을 명확히 사용해야 한다.

질환명과 증상명을 피하면 매장에서 쓸모없는 설명서가 된다.

### 4.3 구매 선택을 돕는 표현

매장 설명서는 단순 정보 제공에 그치지 않고 소비자의 합리적 선택을 도와야 한다.

특히 광고 제품만 선택하지 않도록 성분과 함량 기준의 선택을 안내한다.

허용되는 방향:

```text
성분과 함량이 같으면 같은 계열의 약으로 볼 수 있습니다.

```

금지되는 방향:

```text
특정 제품보다 더 좋습니다.
```

## 8. AI 에이전트 작성 지침

AI 에이전트가 설명서를 만들 때 다음을 반드시 따른다.

1. e약은요 원문과 허가사항을 참고한다.
2. 설명서는 성분, 함량, 제형 중심으로 작성한다.
3. 제품명/브랜드명을 설명서 제목으로 삼지 않는다.
4. 질환명과 증상명을 회피하지 않는다.
5. 약국 매장 내 사용을 전제로 약사 상담 문구를 포함한다.
6. 같은 성분, 함량, 제형, 허가 내용이면 같은 설명서를 공유한다.
7. 포장단위는 설명서 분리 기준으로 삼지 않는다.
8. 개량 성분과 다른 제형은 별도 설명서로 작성한다.
9. 허위·과장, 절대적 우월 표현, 치료 보장 표현은 쓰지 않는다.
10. 하단에 `성분 기준 선택` 공통 문구를 포함한다.
