# O4O 의약품 설명서 작성 기준 V1

> 작성일: 2026-07-06  
> 적용 대상: O4O 의약품 설명서 작업, 우선 일반의약품 OTC  
> 목적: 성분 중심의 신뢰성 있는 약국 매장용/소비자 안내 설명서 작성 기준을 고정하고, 실제 작성 결과를 반영해 계속 개선한다.

---

## 1. 문서의 목적

이 문서는 O4O 의약품 설명서를 작성할 때 참고하는 기준 문서다.

의약품 설명서는 무작위로 ProductMaster별 작성하지 않는다. 먼저 성분, 함량, 제형, 허가 내용이 같은 제품군을 묶고, 그 그룹에 대해 대표 설명서 1개를 만든 뒤 같은 그룹의 제품에 복사 적용한다.

이 문서는 고정된 최종 규칙이 아니다. 실제 설명서를 만들면서 부족한 점이 발견되면 이 문서를 먼저 업데이트하고, 이후 설명서 작성 품질을 높인다.

---

## 2. 설명서 종류

O4O 상품 설명은 다음 3종으로 본다.

| 구분 | 의미 | 비고 |
|---|---|---|
| B2B용 | 공급자, 사업자, 운영자 대상 설명 | 유통, 공급, 업무 정보 중심 |
| B2C용 | 소비자 대상 설명 | 의약품에서는 화면에 `e약은요`로 표시 |
| 매장용 | QR, POP, 태블릿, 상담 보조용 설명 | 매장 복사본은 O4O 상품 DB에 역반영하지 않음 |

의약품의 경우 화면 라벨은 다음처럼 표시한다.

| 화면 | 표시명 |
|---|---|
| 의약품 상세 | e약은요 |
| 비의약품 상세 | B2C 설명 |
| 여러 상품군이 섞인 리스트 | B2C/e약은요 |

## 3. 핵심 원칙

### 3.1 성분 중심

약국 설명서는 제품명이나 브랜드명 중심이 아니라 성분 중심으로 작성한다.

권장 제목:

```text
아세트아미노펜 500mg 정제
이부프로펜 400mg 정제
덱시부프로펜 300mg 연질캡슐
```

피해야 할 제목:

```text
타이레놀 설명서
부루펜 설명서
유명 브랜드 진통제 설명
```

제품명은 연결된 상품 정보나 예시로만 사용한다. 설명서의 기준은 성분, 함량, 제형이다.

### 3.2 포장단위는 설명서 분리 기준이 아님

같은 제품, 같은 성분, 같은 함량, 같은 제형이면 포장단위가 달라도 설명서는 같다.

예:

| 제품군 | 포장단위 | 설명서 |
|---|---:|---|
| 아세트아미노펜 500mg 정제 | 10정 | 동일 |
| 아세트아미노펜 500mg 정제 | 30정 | 동일 |
| 아세트아미노펜 500mg 정제 | 100정 | 동일 |

포장단위, 바코드, 포장 수량은 판매/재고/주문 단위이지 효능, 용법, 주의사항을 나누는 기준이 아니다.

### 3.3 같은 성분/함량/제형 그룹 우선

설명서 작업 단위는 ProductMaster 1건이 아니라 설명 공통 그룹이다.

기본 그룹 기준:

```text
성분 + 함량 + 제형 + 투여경로 + 허가 효능/용법이 같은 일반의약품 그룹
```

우선순위:

```text
허가 회사 수 많은 순
→ ProductMaster 수 많은 순
→ e약은요 원문 보유
→ OTC 확정
```

같은 성분/함량 제품을 허가받은 회사가 많다는 것은 약국 현장에서 많이 쓰이는 대중적 제품군일 가능성이 높다. 먼저 이런 그룹을 정비하면 작업 대비 효과가 크다.

### 3.4 개량 성분은 별도 설명

개량 성분은 같은 계열이라도 동일 설명서로 복사하지 않는다.

예:

| 성분 | 처리 |
|---|---|
| 이부프로펜 400mg 정제 | 이부프로펜 그룹 |
| 덱시부프로펜 300mg 연질캡슐 | 덱시부프로펜 별도 그룹 |

덱시부프로펜은 이부프로펜 계열이지만 같은 성분은 아니다. 개량 성분, 활성 성분 중심, 연질캡슐 제형 등 소비자 선택에 도움이 되는 차이는 별도 설명한다.

> 분류 표기 주의: 설명서의 `분류`(일반의약품/전문의약품)는 O4O 상품 DB의 `drug_category` 값을 기준으로 표기한다. 다만 거담제·소염진통제처럼 현장에서 처방이 동반되는 그룹은 품목별 실제 허가구분이 갈릴 수 있으므로, 매장 사용 시 최종 판매 구분은 약사가 확인한다.

단, 우월성을 단정하지 않는다.

피해야 할 표현:

```text
무조건 더 좋습니다.
부작용이 없습니다.
더 안전합니다.
더 강합니다.
빨리 낫습니다.
```

가능한 표현:

```text
이부프로펜 계열의 개량 성분
활성 성분 중심
연질캡슐 제형
빠른 용출을 고려한 제형
복용 편의성을 고려한 제형
```

## 4. 문체 기준

### 4.1 기본 톤

설명서는 약간 건조하고, 학술적인 느낌이 있으나 친절해야 한다.

좋은 방향:

- 단어/구 중심의 상단 요약
- 짧은 문장
- 질환명과 증상명 명확히 사용
- 광고성 과장 금지
- 성분 기준 선택 유도
- 약사 상담 연결

피해야 할 방향:

- 지나치게 친근한 광고 문구
- 질환명 회피
- 모호한 표현
- 브랜드 중심 설명
- 너무 긴 설명

### 4.2 질환명과 증상명 사용

AI 에이전트가 질병명이나 증상명을 피하려는 경향을 적용하지 않는다.

매장용 설명서는 약국 내에서 소비자와 약사가 함께 확인하는 설명이다. 소비자에게 정확한 정보를 전달하려면 두통, 치통, 생리통, 관절통, 인후통, 발열, 위장질환, 천식, 간질환 등 실제 질환명과 증상명을 명확히 사용해야 한다.

질환명과 증상명을 피하면 매장에서 쓸모없는 설명서가 된다.

### 4.3 구매 선택을 돕는 표현

매장 설명서는 단순 정보 제공에 그치지 않고 소비자의 합리적 선택을 도와야 한다.

특히 광고 제품만 선택하지 않도록 성분과 함량 기준의 선택을 안내한다.

허용되는 방향:

```text
성분과 함량이 같으면 같은 계열의 약으로 볼 수 있습니다.
제품명보다 성분과 함량을 기준으로 약사에게 확인하세요.
익숙한 제품명이 아니어도 성분 기준으로 선택할 수 있습니다.
```

금지되는 방향:

```text
특정 제품보다 더 좋습니다.
이 제품이 가장 좋습니다.
효과가 보장됩니다.
부작용이 없습니다.
```

## 5. 설명서 기본 구조

기본 구조는 다음을 권장한다.

```text
제목: 성분 + 함량 + 제형

요약 표
- 성분
- 분류
- 작용
- 주요 증상
- 선택 포인트
- 주의 대상

효능·효과
복용 안내
주의 대상
성분 기준 선택
```

너무 길게 작성하지 않는다. QR, POP, 태블릿에서 읽을 수 있어야 한다.

## 6. 공통 하단 문구

모든 의약품 매장용 설명 하단에는 다음 공통 문구를 넣는다.

```text
성분 기준 선택

의약품은 원료·제조·품질관리 전 과정이 GMP 기준으로 관리됩니다.
같은 성분·함량·제형의 제품은 동일한 기준으로 품질과 효능·효과가 관리됩니다.
제품명보다 성분·함량을 기준으로 약사에게 확인하세요.
```

이 문구의 목적:

- 카피제품에 대한 소비자 거부감 완화
- 성분 중심 선택 유도
- 약사 상담 연결
- 브랜드 중심 구매 편향 완화

주의:

- 첨가제, 제형, 크기, 맛, 복용감은 제품마다 다를 수 있다.
- 따라서 "완전히 같다"라고 표현하지 않는다.
- "동일한 기준으로 품질과 효능·효과가 관리된다"라고 표현한다.

## 7. 작성 예시

### 7.1 아세트아미노펜 500mg 정제

| 항목 | 내용 |
|---|---|
| 성분 | 아세트아미노펜 500mg |
| 분류 | 일반의약품 |
| 작용 | 해열, 진통 |
| 주요 증상 | 발열, 두통, 치통, 생리통, 근육통, 감기 몸살 |
| 선택 포인트 | 위장 부담을 줄이고 싶은 해열진통제 선택 시 고려 |

**효능·효과**  
발열, 두통, 치통, 생리통, 근육통 등 통증 및 열 증상 완화.

**복용 안내**  
허가된 용법·용량에 따라 복용합니다. 감기약, 몸살약, 진통제에 같은 성분이 함께 들어 있는 경우가 많으므로 중복 복용을 확인해야 합니다.

**주의 대상**  
간질환, 음주가 잦은 경우, 다른 해열진통제 복용 중인 경우. 발열이 오래 지속되거나 통증이 반복되면 약사 또는 의사 상담이 필요합니다.

**성분 기준 선택**  
의약품은 원료·제조·품질관리 전 과정이 GMP 기준으로 관리됩니다.  
같은 성분·함량·제형의 제품은 동일한 기준으로 품질과 효능·효과가 관리됩니다.  
제품명보다 성분·함량을 기준으로 약사에게 확인하세요.

**성분 기준 선택**

같은 성분·함량·제형의 제품은 동일한 기준으로 품질과 효능·효과가 관리됩니다.

| 작용 | 점액용해, 거담 |

| 선택 포인트 | 가래가 묽게 배출되도록 돕는 점액용해·거담제 |
| 주의 대상 | 소화성궤양, 중증 신장장애, 간경변, 이 약 과민증 |

**효능·효과**  
급성·만성 호흡기질환에서 가래(점액)를 묽게 하여 배출을 돕는 점액용해·거담에 사용합니다.

**복용 안내**  
성인은 1회 1캡슐(300mg), 1일 2~3회 복용합니다. 급성 호흡기질환에는 연속으로 10일 이상 복용하지 않습니다. 다른 기침·가래약과 함께 복용할 때는 약사와 상의하세요.

**주의 대상**  
이 약에 과민증이 있거나 소화성궤양, 중증 신장장애, 간경변, 시스타티오닌 합성효소 결핍이 있는 경우 주의합니다. 경증·중등도 간장애, 알레르기 반응 경험이 있으면 복용 전 약사와 상담하세요. 가래·기침이 오래 지속되거나 발열·호흡곤란이 동반되면 약사 또는 의사 상담이 필요합니다.

**성분 기준 선택**  
의약품은 원료·제조·품질관리 전 과정이 GMP 기준으로 관리됩니다.  
같은 성분·함량·제형의 제품은 동일한 기준으로 품질과 효능·효과가 관리됩니다.  
제품명보다 성분·함량을 기준으로 약사에게 확인하세요.

## 8. AI 에이전트 작성 지침

AI 에이전트가 설명서를 만들 때 다음을 반드시 따른다.

1. e약은요 원문과 허가사항을 참고한다.
2. 설명서는 성분, 함량, 제형 중심으로 작성한다.
3. 제품명/브랜드명을 설명서 제목으로 삼지 않는다.
4. 질환명과 증상명을 회피하지 않는다.
5. 약국 매장 내 사용을 전제로 약사 상담 문구를 포함한다.
6. 같은 성분, 함량, 제형, 허가 내용이면 같은 설명서를 공유한다.
7. 포장단위는 설명서 분리 기준으로 삼지 않는다.
8. 개량 성분과 다른 제형은 별도 설명서로 작성한다.
9. 허위·과장, 절대적 우월 표현, 치료 보장 표현은 쓰지 않는다.
10. 하단에 `성분 기준 선택` 공통 문구를 포함한다.

## 9. 업데이트 규칙

설명서 작성 중 다음 상황이 발생하면 이 문서를 업데이트한다.

| 상황 | 문서 업데이트 |
|---|---|
| 새 성분군에서 반복되는 표현 기준 발견 | 예시/문체 기준 추가 |
| AI가 질환명 회피 또는 과도한 안전 문구 사용 | 금지/권장 표현 보강 |
| 개량 성분 설명 기준 추가 필요 | 개량 성분 섹션 보강 |
| 소비자 선택 문구가 너무 약하거나 강함 | 성분 기준 선택 문구 조정 |
| 약사 검수에서 반복 지적 발생 | 해당 항목을 기준으로 추가 |
| 법적/표현상 위험 문구 발견 | 금지 표현에 추가 |

업데이트 순서:

```text
문제 발견
→ 이 가이드 문서 수정
→ 다음 설명서 작성에 반영
→ 필요 시 기존 설명서 보정
```
