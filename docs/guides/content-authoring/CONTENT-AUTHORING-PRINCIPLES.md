# CONTENT-AUTHORING-PRINCIPLES — 콘텐츠 유형 공통 작성 원칙

상태: Active · V1 (2026-07-08) · 진입: [DOCUMENT-INDEX](../common/DOCUMENT-INDEX.md)

> 설명서뿐 아니라 QR·POP·블로그·동영상 대본·태블릿 콘텐츠가 **공유하는 작성 원칙**. 각 콘텐츠 유형은 여기에 자신의 형식·채널 특성만 더한다. Rule ID는 [CR](../common/CONTENT-RULE-REGISTRY.md).

---

## 1. 소비자 중심 (CR-001)

- 목적 우선순위: **올바른 선택 > 안전한 사용 > 전문가 상담 연결 > 성분·허가 정보**.
- 성분 설명 자체가 목적이 아니다. 소비자 진입은 증상·용도 축, 정본 단위는 성분·함량(제품군별).

## 2. 원문 우선 (CR-002)

- 공식 원문(허가사항·e약은요 등) > 기억·AI 지식·인터넷·제조사 홍보·브랜드 인지.
- 원문과 충돌하면 원문에 고정하고, 정정 사유를 CHECK에 남긴다.

## 3. 과장 금지 (CR-003)

- 금지 표현: "무조건 더 좋다 / 부작용이 없다 / 더 안전·강하다 / 빨리 낫는다 / 효과 보장 / 누구나 사용 가능 / 장기 사용 가능".
- 우월성 단정 금지. 개량·차이는 사실 수준으로만 기술.

## 4. Grounding 필수 (CR-004)

- 효능·용법·수치·주의는 **원문 근거가 있을 때만** 쓴다. 없으면 만들지 않는다.
- 근거가 있어도 충분성(효능·용법·주의 근거)이 부족하면 검토 강화/수동/보류.
- AI가 일반 지식으로 설명을 확장·보강하지 않는다(→ AR-002).

## 5. 혼동 방지 (CR-005)

- 사용 맥락(투여경로·형태·용도)이 다르면 하나의 콘텐츠로 묶지 않는다.
- "무엇인지/어떻게 쓰는지"를 소비자가 구분할 수 있게 한다.

## 6. 안전성 안내 (CR-006)

- 콘텐츠에 "전문가 상담/진료가 필요한 경우"를 명시한다(고열·심한 통증·호흡곤란·증상 지속 등, 제품군별 기준).

## 7. 원천 부재 = HOLD (CR-007)

- 조성·근거를 확인할 수 없으면 추정으로 채우지 않고 HOLD. HOLD는 실패가 아니라 신뢰성 우선의 안전 판단.
- **근거 부족 제품은 제작하지 않는다** (건기식·의약품·의료기기·의약외품 및 향후 상품군 공통):
  - 제품명·분류가 불명확하거나, 제품 고유의 원료·함량·기능성·사용/섭취방법 등 핵심 근거를 확인할 수 없으면 **설명서를 만들지 않고 HOLD**한다.
  - 다른 제품·유사 제품·원료 일반정보로 부족한 근거를 **대신하지 않는다**.
  - 근거가 부족하다고 **보수적·소극적 문구의 설명서를 만들지 않는다** — 문구를 약하게 쓰는 것이 아니라 **제작 자체를 보류**한다.
- 구분: 근거 충분 → 작성(매력·신뢰를 적극적으로) / 일부 부족하나 보완 가능 → 조사 후 재판정(`source_required`) / 핵심 근거 부족·정체 불명 → **HOLD·미작성**.

## 8. 신뢰 문구 (CR-013)

- 제품군별 하단 공통 문구(예: 의약품 GMP 문구)를 유지한다. "완전히 같다"는 단정은 피하고 "동일한 기준으로 관리된다"로 표현.
