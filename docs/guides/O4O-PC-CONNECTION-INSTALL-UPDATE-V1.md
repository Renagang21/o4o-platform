# PC 프로그램 설치·업데이트

> 상태: ACTIVE · 작성일: 2026-10-27 · 갱신일: 2026-10-29
> Main 첫 자동화 설치 안내 변경을 배포한 뒤에는 메인에서 바로 준비한다. 내 정보 ‘이 PC 연결’은 관리용 진입점으로 유지한다. 실제 사용자 PC 적용 여부는 마지막 버전 확인으로 판단한다.

1. 연결할 Windows 10/11 x64 PC에서 Main에 로그인한다. 처음 자동화 요청 시 서버가 PC 준비 필요로 중단하면 메인에 설치·연결 안내가 열린다. 먼저 준비하려면 메인의 **PC 연결 준비** 또는 약국 주문 준비의 **PC 설치·연결 준비**를 누른다. 일반 대화나 이미 연결된 다른 PC에서 가능한 업무에는 설치를 강요하지 않는다.
2. **설치하기**(업데이트가 필요하면 **업데이트하기**)를 누른 뒤, 받은 `-setup.cmd` 파일을 연다. 설치 파일이 필요한 프로그램을 내려받고 검증·압축 해제·설치를 진행한다. Node·SQLite는 별도 설치하지 않는다. 브라우저가 다운로드한 파일을 자동 실행하지는 않으므로 사용자가 파일을 한 번 열어야 한다.
3. 처음 설치하는 PC인지 묻는 창에서 **예/아니요**를 선택한다. 처음 설치하는 PC에서만 예를 누른다. 기존 사용자에게 새 데이터 생성을 자동 승인하지 않는다. 업데이트할 때는 진행 중 업무를 마치고 열린 PC 연결 프로그램을 정상 종료한다.
4. 설치가 끝나면 PC 연결 프로그램이 실행된다. 원래 화면에서 **연결하기**를 누르고 브라우저가 묻는 PC 연결 권한을 허용한다. 기존 계정 연결이 없으면 같은 클릭으로 기존 승인권·nonce 절차를 진행한다. 실제 실행 releaseId/버전·데이터 상태를 확인하기 전에는 설치 완료로 추측하지 않는다.
5. 버전·재설치·문제 해결 설명은 **도움말** 등 접힌 영역에서 확인한다. 최신 프로그램은 설치 버튼을 접고 연결 확인을 제공한다. 이전 배포본에 간편 설치 파일이 없으면 기존 ZIP/Install.cmd 방식을 안내한다.

간편 설치 파일은 `release.json`에 크기·SHA256을 따로 기록한다. 브라우저가 간편 설치 파일을 먼저 검증하고, 설치 파일은 생성 시 고정된 Main HTTPS 주소·ZIP 크기·SHA256을 확인한 뒤에만 실행한다. 다른 주소로의 리디렉션·PowerShell 정책 우회·관리자 권한 요청은 사용하지 않는다. 보안 정책으로 CMD/PowerShell 실행을 금지한 PC에서 정책을 우회하지 않는다. 기존 ZIP 설치 경로는 유지한다.

메인에서 처음 시작한 요청은 설치 중 페이지를 열어 두면 입력·첨부가 유지된다. 설치·연결 후 **설치·연결 후 요청 계속**을 눌러 기존 서버 검증을 거친다. 자동으로 재실행하지 않는다. 새로고침/페이지 종료 후에는 첨부를 다시 선택해야 한다. 이미 행동이 진행된 작업은 기존 재개·인계 안내를 따른다. 모바일에서는 실행할 Windows PC에서 같은 계정으로 메인의 PC 연결 준비를 진행하고, 원래 요청 기기로 돌아와 계속할 수 있다.

프로그램 설치·계정 연결·데이터 준비는 별개다. 브라우저의 이 PC 연결 권한이 없으면 실제 실행 버전을 확인할 수 없으므로 설치 성공으로 추측하지 않는다. 처음 연결에 필요한 권한은 사용자가 브라우저에서 허용한다.

업데이트는 코드 영역만 바꾼다. 기존 local.db·credentials.json을 삭제하거나 새 파일로 대체하지 않는다. SQLite는 기존 backup·version·migration 절차를 사용한다. 파일 손상·backup 실패·데이터 경로 변경·설치 충돌은 기존 상태를 보존하며 중단한다. 이전 code version은 남겨 두며 자동으로 사용자 데이터를 복원/삭제하지 않는다.

코드 위치는 기본 `%LOCALAPPDATA%/o4o-pc-connection`, 데이터 위치는 기존 `%LOCALAPPDATA%/o4o-local-agent` 또는 기존 `O4O_AGENT_HOME`이다. 다른 데이터 위치를 사용하던 수동 설치는 자동 탐색·이동하지 않는다. 기존 실행 환경의 데이터 경로를 확인한 뒤 설치해야 한다. 연결 정보나 비밀번호를 채팅에 보내지 않는다.

Chrome Extension/기존 native host 등록은 이번 업데이트가 바꾸지 않는다. 확장 연결이 필요한 업무는 기존 연결 상태를 별도로 확인한다. 실제 약국 프로그램·지오영 로그인 및 주문/결제 검증은 이 설치 확인과 다른 단계다.
