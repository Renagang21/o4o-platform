# PC 프로그램 설치·업데이트

> 상태: ACTIVE · 작성일: 2026-10-27
> 배포 후 Main의 내 정보 ‘이 PC 연결’에서 사용하는 절차다. 실제 사용자 PC 적용 여부는 마지막 버전 확인으로 판단한다.

1. 연결할 Windows 10/11 x64 PC에서 Main에 로그인하고 내 정보의 ‘이 PC 연결’을 연다. 약국 주문 준비의 연결·업데이트 링크는 새 탭으로 열린다.
2. ‘Windows PC 설치·업데이트 파일 받기’를 누른다. 파일 크기·SHA256 검증 후 저장한다. ZIP의 **전체 압축을 풀고 Install.cmd**를 실행한다. 포함된 Node runtime을 사용하므로 Node·SQLite를 별도 설치하지 않는다.
3. 기존 PC 연결 프로그램이 켜져 있으면 먼저 업무를 마치고 정상 종료한 뒤 다시 설치한다. 설치기가 임의로 프로그램을 종료하지 않는다.
4. 처음 설치하는 PC인지 묻는 경우, 기존 프로그램 사용자라면 새 PC 설치로 진행하지 말고 기존 데이터 위치를 확인한다. 기본 위치의 기존 DB·연결 정보는 그대로 보존한다. managed 설치의 데이터 경로는 다음 업데이트에도 유지된다.
5. 설치 후 시작 메뉴의 **O4O PC 연결**을 실행한다. 시작 메뉴 등록이 안 되면 설치 폴더의 Start.cmd를 사용한다.
6. Main에서 **설치·업데이트 후 다시 확인**을 누른다. 실제 실행 releaseId/버전과 데이터 준비 상태가 배포본과 일치해야 최신 상태로 표시된다. 아직 계정에 연결하지 않았다면 기존 ‘이 PC 연결’을 진행한다.

프로그램 설치·계정 연결·데이터 준비는 별개다. 브라우저의 이 PC 연결 권한이 없으면 실제 실행 버전을 확인할 수 없으므로 설치 성공으로 추측하지 않는다. 처음 연결에 필요한 권한은 사용자가 브라우저에서 허용한다.

업데이트는 코드 영역만 바꾼다. 기존 local.db·credentials.json을 삭제하거나 새 파일로 대체하지 않는다. SQLite는 기존 backup·version·migration 절차를 사용한다. 파일 손상·backup 실패·데이터 경로 변경·설치 충돌은 기존 상태를 보존하며 중단한다. 이전 code version은 남겨 두며 자동으로 사용자 데이터를 복원/삭제하지 않는다.

코드 위치는 기본 `%LOCALAPPDATA%/o4o-pc-connection`, 데이터 위치는 기존 `%LOCALAPPDATA%/o4o-local-agent` 또는 기존 `O4O_AGENT_HOME`이다. 다른 데이터 위치를 사용하던 수동 설치는 자동 탐색·이동하지 않는다. 기존 실행 환경의 데이터 경로를 확인한 뒤 설치해야 한다. 연결 정보나 비밀번호를 채팅에 보내지 않는다.

Chrome Extension/기존 native host 등록은 이번 업데이트가 바꾸지 않는다. 확장 연결이 필요한 업무는 기존 연결 상태를 별도로 확인한다. 실제 약국 프로그램·지오영 로그인 및 주문/결제 검증은 이 설치 확인과 다른 단계다.
