# 고객 상담의 답변 전송·연결 복구 안내 V1

- 작성일: 2026-10-29
- 작업: [TODO](../work-orders/TODO-O4O-CONSULTATION-CUSTOMER-RECOVERY-V1.md)

고객 화면은 직원 로그인과 분리된 기기 연결 credential로 현재 상담만 조회·전달한다. 직원 cookie·Bearer·약국 선택 header를 보내지 않는다. 답변 문장은 현재 화면 메모리에만 두며 브라우저 저장소에는 기기 연결 정보만 둔다.

조회 또는 답변 전송에서 서버가 401/403으로 접근을 거부하면 공유 안내·입력·음성을 즉시 비우고 기기 연결 정보를 제거해 연결 코드 화면으로 돌아간다. 저장소 접근이 차단된 경우에도 현재 화면의 연결은 해제한다. 직원의 기기 연결 폐기나 권한 변경은 기존 담당 화면·서버 계약을 사용하며 이 동작이 서버 권한을 변경하지 않는다.

새 상담 세대·대기 상태·기기 해제·화면 숨김/종료에서는 이전 전송을 화면 작업에서 분리한다. 이전 답변의 성공·실패·마지막 정리가 새 고객의 입력·안내·전송 잠금을 바꾸지 않는다. 다음 고객은 이전 전송의 timeout을 기다릴 필요 없이 현재 상담에서 답변할 수 있다. 서버는 기존 상담 세대·권한 검증과 미확인 답변 덮어쓰기 방지를 계속 수행한다.

일시적인 네트워크/조회 장애는 자격 거부로 판정하지 않는다. 조회 실패 시 공유 안내와 입력을 화면에서 가리고, 동일 상담 세대를 다시 확인한 경우만 미전송 입력을 복원한다. 전송 실패는 현재 상담 입력을 유지하며 사용자가 다시 시도한다. 응답 유실에 대한 서버 멱등성이나 정확히 한 번 전송을 새로 보장하지 않는다.

연결 정보를 브라우저에 저장하지 못하면 다음에 다시 연결해야 한다는 안내가 현재 연결 동안 남는다. 상담 시작·종료·새 고객 전환은 이 안내를 지우지 않는다. 연결 자체를 지우거나 새 연결을 저장하면 해당 상태에 맞춰 안내를 갱신한다.

합성 검증은 실제 태블릿·현장 음성·약사 언어 품질·운영 권한 회수 검수를 대체하지 않는다. 상담 원문 장기 이력·Task/Memory·학습 기능과 유료 호출은 추가하지 않는다.
