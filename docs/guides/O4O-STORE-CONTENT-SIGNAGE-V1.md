# Store 일반 콘텐츠와 사이니지

사용자 확정: 2026-11-05. 구현 상태는 [TODO](../work-orders/TODO-O4O-STORE-SIGNAGE-WORKSPACE-V1.md).

- 매장 콘텐츠: 문서·상품 설명·POP·QR 등 기존 제작과 활용. 동영상 편성 메뉴를 섞지 않는다.
- 사이니지: 동영상 / 재생목록 / 디스플레이 재생. 목록 화면은 [표준 목록 계약](../architecture/O4O-STANDARD-LIST-WORKSPACE-CONTRACT-V1.md)을 따른다. 매장 재생 일정은 폐기됐다. 기존 `/store/marketing/signage/*`와 서비스 지정 Store 경로는 보존한다. 과거 workspace query는 사이니지를 일반 콘텐츠로 되돌리지 않는다.
- 가져온 경로(커뮤니티/가입 협업체/직접 등록)와 영상 호스팅(YouTube/Vimeo/직접 URL)은 다른 정보다. 알 수 없는 출처를 임의의 협업체로 표시하지 않는다.
- 외부 YouTube 채널 URL은 일반 등록 경로이며 O4O 채널로 옮길 필요가 없다. 개별 영상의 임베드 허용·사용 권한은 확인해야 한다. 채널/재생목록 URL 자체는 개별 영상이 아니다.
- O4O 미디어 보관/YouTube 업로드는 선택 기능이다. 커뮤니티·가입 협업체 자료는 기존 회원·조직 권한으로 조회/가져온다.
- 동영상 체크→선택 영상으로 재생목록 만들기, 또는 재생목록 만들기→동영상 추가. 이름 수정·영상 제거·위아래 순서 변경·미리보기·게시·삭제를 기존 API로 처리한다. 한 건 전용 작업은 단일 선택에서만 허용한다.
- 재생목록에서 제거는 동영상 원본 삭제와 다르다. 원본의 비공개·삭제·임베드 차단은 재생 실패를 만들 수 있으며 미리보기는 현장 기기 실행 보장이 아니다.
- `store_playlists`/스냅샷과 `signage_playlists`/직접 미디어의 저장 모델은 KEEP-LEGACY 정본을 유지한다. 이 UI 분리를 이유로 migration·dual-write를 하지 않는다.

내 매장 자동 연결

약국 경영자 회원 등록 승인에서 매장·owner·기본 회원이 연결된다. Store는 별도 약국 신청을 받지 않는다. 연결 실패는 재확인하고 회원 등록 상태를 점검한다. 다중 실제 매장 또는 명시적 협업체 handoff는 기존 소속 검증과 명시적 선택을 유지한다. 설정에 My Home·매장 선택·이용 사업을 반복 노출하지 않는다. 이용 사업/가입 관리는 `/services`, 매장 정보는 `/store/info`(`/pharmacy` 구 주소 호환)다.
