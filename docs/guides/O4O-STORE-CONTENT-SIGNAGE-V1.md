# Store 일반 콘텐츠와 사이니지

사용자 확정: 2026-11-05. 구현 상태는 [TODO](../work-orders/TODO-O4O-STORE-SIGNAGE-WORKSPACE-V1.md).

- 매장 콘텐츠: 문서·상품 설명·POP·QR 등 기존 제작과 활용. 동영상 편성 메뉴를 섞지 않는다.
- 사이니지: 동영상 보관함 / 재생목록 / 디스플레이 재생. 시간표는 제공하지 않는다. [현행 재생 정책](../baseline/O4O-SIGNAGE-STORE-PLAYLIST-MODEL-BOUNDARY-V1.md)을 따른다. 기존 `/store/marketing/signage/*`와 서비스 지정 Store 경로는 보존한다. 과거 workspace query는 사이니지를 일반 콘텐츠로 되돌리지 않는다.
- 가져온 경로(커뮤니티/가입 협업체/직접 등록)와 영상 호스팅(YouTube/Vimeo/직접 URL)은 다른 정보다. 알 수 없는 출처를 임의의 협업체로 표시하지 않는다.
- 외부 YouTube 채널 URL은 일반 등록 경로이며 O4O 채널로 옮길 필요가 없다. 개별 영상의 임베드 허용·사용 권한은 확인해야 한다. 채널/재생목록 URL 자체는 개별 영상이 아니다.
- O4O 미디어 보관/YouTube 업로드는 선택 기능이다. 커뮤니티·가입 협업체 자료는 기존 회원·조직 권한으로 조회/가져온다.
- 보관함 체크→선택 영상으로 새 재생목록 만들기, 또는 재생목록 생성→보관함 영상 추가. 이름 수정·영상 제거·위아래 순서 변경·미리보기·게시·편성·삭제를 기존 API로 처리한다. 한 건 전용 작업은 단일 선택에서만 허용한다.
- 재생목록에서 제거는 보관함 원본 삭제와 다르다. 원본의 비공개·삭제·임베드 차단은 재생 실패를 만들 수 있으며 미리보기는 현장 기기 실행 보장이 아니다.
- `store_playlists`/스냅샷과 `signage_playlists`/직접 미디어의 저장 모델은 KEEP-LEGACY 정본을 유지한다. 이 UI 분리를 이유로 migration·dual-write를 하지 않는다.

내 매장 자동 연결

약국 경영자 회원 등록 승인에서 매장·owner·기본 회원이 연결된다. Store는 별도 약국 신청을 받지 않는다. 연결 실패는 재확인하고 회원 등록 상태를 점검한다. 다중 실제 매장 또는 명시적 협업체 handoff는 기존 소속 검증과 명시적 선택을 유지한다. 설정에 My Home·매장 선택·이용 사업을 반복 노출하지 않는다. 이용 사업/가입 관리는 `/services`, 매장 정보는 `/store/info`(`/pharmacy` 구 주소 호환)다.

## 매장 콘텐츠 사용 순서 — 2026-11-06

개발·검증 상태는 [콘텐츠 흐름 TODO](../work-orders/TODO-O4O-STORE-CONTENT-FLOW-20261106.md), 메뉴 기준은 [메뉴 정본](../baseline/O4O-STORE-MENU-CANONICAL-TREE-V1.md)의 현재 매장 콘텐츠 절을 따른다. 운영 배포 완료 안내가 아니다.

1. **매장 콘텐츠**에서 저장한 콘텐츠를 검색한다. 출처·가져온 협업체·태그는 필터에서 선택하고 ‘검색·필터 초기화’로 해제한다.
2. 직접 작성은 **새 콘텐츠**, 상품 선택 후 작성은 **더보기(제작·도움말) → 상품에서 만들기**를 사용한다. **자료 가져오기/제공 자료**는 원본을 탐색하는 화면이며 실제 가져오기에서 매장 독립 사본이 만들어진다.
3. 행을 체크하면 편집·제작·QR·POP·PDF 등의 상단 작업이 나타난다. 편집·POP·PDF는 한 개 선택, QR은 직접 작성·제작 자료 한 개 선택이 필요하다. 제작 시작은 자료를 복수 선택할 수 있다.
4. 가져온 사본 한 개를 선택해 **선택 사본 게시 설정**으로 이동한다. 이 화면의 게시됨은 실제 기기 적용·재생 완료가 아니다. 목록 복귀 시 기존 검색·필터를 유지한다.
5. **선택 사본 숨기기**는 선택한 snapshot만 숨긴다. 혼합 선택의 직접 작성·제작 자료는 변경하지 않으며 원본을 삭제하지 않는다. 직접 작성 콘텐츠 삭제는 해당 편집 화면에서 수행한다.
6. 파일·참고 자료는 콘텐츠 목록과 별도로 보관한다. 다국어 상품 안내·사본 게시 설정·출력 및 적용 확인은 **자료 관리**, 가이드·새로고침은 **더보기(제작·도움말)**에서 이용한다.
7. 필요하면 목록 아래 **AI 도움 요청**을 펼친다. AI를 사용하지 않고도 작성·저장·활용할 수 있다.

매장 사본은 원본과 자동 동기화되지 않는다. 현재 협업체 가입 여부는 원본 탐색 권한과 관련하며 이미 보관한 사본의 소유권과 합치지 않는다. 조회 실패는 빈 목록으로 처리하지 않으며 재시도를 제공한다.
