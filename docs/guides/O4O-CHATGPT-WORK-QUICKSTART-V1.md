# ChatGPT에서 O4O 작업 시작하기

> **상태**: ACTIVE
> **작성일**: 2026-11-14 · **최종 갱신**: 2026-11-14
> **근거**: 사용자 요청 — ChatGPT 연결 안내와 거래명세서 문서 보관부터 순차 적용

## 연결과 요청

ChatGPT의 앱·연결 메뉴에서 O4O 서비스 연결을 찾아 연결한다. O4O 로그인 후 사용할 작업공간과 필요한 조회·초안 저장 권한을 선택한다. 연결 메뉴나 지원 기능은 ChatGPT 환경에 따라 다를 수 있다. 앱을 찾을 수 없다면 현재 배포된 연결 방법과 제공 여부를 확인한다.

O4O의 `/mypage/settings` → 외부 AI 연결 → **ChatGPT에서 O4O 작업하기**에서 요청 예시를 복사할 수 있다. O4O의 연결 이력만으로 현재 ChatGPT 채팅에서 도구가 사용 가능한지 단정하지 않는다. 만료되거나 해제된 연결은 ChatGPT에서 다시 연결한다.

처음에는 요청에 ‘O4O’ 또는 ‘O4O 작업’을 넣는 것을 권장한다. 필수 명령어는 아니다. 일반 답변으로 처리됐다면 ‘O4O 자료를 이용해 줘’라고 이어서 요청하면 된다. 기억 기능은 사용자의 ChatGPT 설정과 이용 환경에 따르며 자동 선택을 보장하지 않는다. 외부 작업 요청을 판별하기 위해 O4O 서버에 별도 LLM 분류기를 추가하지 않는다.

## 먼저 이용할 작업

| 작업 | ChatGPT | O4O |
|---|---|---|
| 내 자료 정리 | 자료를 읽어 요약·재작성 | 허용된 자료 검색·조회 |
| 거래명세서 사진 정리 | 사용자가 첨부한 사진·파일을 읽고 확인 표 제시 | 사진 판독을 중복 실행하지 않음 |
| 확인한 결과 보관 | 수정 내용을 반영하고 저장 도구 호출 | 기존 권한·검증을 거쳐 비공개 문서 저장·재조회 |

ChatGPT에서 파일을 선택하거나 첨부해야 한다. 웹과 앱 모두 사용자 PC의 자료 전체를 자동으로 읽는 것으로 안내하지 않는다. 플랫폼별 첨부·웹 작업 도구 제공 여부는 별도로 확인한다.

## 거래명세서 사용 순서

1. ChatGPT에 거래명세서 사진이나 파일을 첨부한다.
2. 다음처럼 요청한다: ‘O4O 작업이야. 거래처·일자·품목·수량·단위·금액을 표로 정리해 줘. 읽기 어려운 곳은 확인 필요로 남기고 아직 저장하지 마.’
3. 사용자에게 표를 보여 준다. 단위·수량·금액·세금 구분 등을 확인하고 수정한다. 모르는 값은 추정해 확정하지 않는다.
4. 확인 후 ‘이 내용을 O4O 내 매장 자료함에 비공개 문서로 저장해 줘’라고 요청한다. 작업공간이 여러 곳이면 저장할 매장을 정한다.
5. 도구 결과의 문서 주소를 열거나 다시 조회해 저장 내용을 확인한다. 동일 저장의 재시도에는 같은 `requestId`를 사용한다.

위 `자료함` 요청 경로는 **문서 보관**이다. 거래장 입력은 아래 별도 절차를 따른다. 거래장 원장 입력·매입 전표 반영·상품 식별 확정·주문·결제는 포함하지 않는다. 사용자 확인은 대화 흐름의 요구사항이며 서버가 별도 승인 증거를 검사하는 기능은 이번에 추가하지 않았다.

## 개발 순서와 다음 경계

| 단계 | 범위 | 이번 결과 |
|---|---|---|
| 1 | 연결·요청 안내, 선택하기 쉬운 도구 설명 | 구현·격리 검증 |
| 2 | 사진 정리 → 사용자 확인 → 문서 보관 | 합성 이미지·문서 저장 격리 시험, 실제 명세서 시험 대기 |
| 3 | 사진 → 확인·수정 → 거래장 반영 | 공통 검증·실제 저장·원본/이력·O4O/ChatGPT 연결 구현. 통합·운영 적용 대기 |
| 4 | 주문 제안·수정 → 공급자별 장바구니 | 후속 작업. O4O는 자료·편집 화면, ChatGPT는 제공되는 브라우저 기능으로 사이트 작업. 주문 확정은 약사 |
| 5 | 자주 쓰는 사이트의 작업 방법 재사용 | 후속 작업. 사이트별 방법·변경일·실패 시 재확인 규칙 관리 |

기존 업무 데이터의 사용자 입력 경로는 매입·사용·판매·잔액 원장을 직접 받아들이지 않는 제한이 있다. 단순 문서 저장을 원장 반영 완료라고 표시하거나 이 제한을 우회하지 않는다. 기존 O4O 자동화의 약사 업무 범위와 비용 절감 장치는 유지한다. ChatGPT에서 외부 사이트를 방문할 수 있는지는 실제 도구·사이트 접근 조건에 따라 검증하며, O4O 앱 연결만으로 브라우저 제어가 제공되는 것은 아니다.

ChatGPT에서 저장할 때는 O4O 모델 호출을 추가하지 않는다. O4O 자체 채팅의 사진 판독은 기존 공급자·사용량 계측 경로를 사용한다. 요금제 연동은 추가하지 않았다. ChatGPT 요금제의 상용 원격 앱 참여는 실제 참여 조건 확인 후 별도로 진행한다. 비용 계산은 이번 범위에 포함하지 않는다.

검증 범위와 남은 실제 자료 시험은 [검증 기록](../checks/CHECK-O4O-CHATGPT-ENTRY-INVOICE-TRIAL-V1.md)을 따른다.

## 사진으로 거래장 입력하기

사진만으로 시작한다. QR이나 공통 상품 등록을 요구하지 않는다. 구현은 개발 branch에 있으며 운영 사용은 통합·migration·배포 확인 후 시작한다.

1. 매장 경영자가 `/work/ledger`에서 매장을 선택하고 서버 보관에 동의한다. PC 누적 자료가 있다면 기존 업무 자료 연결에서 이전을 먼저 진행한다. 전송 중 자료를 쓰거나 중단된 서버 자료를 우회하지 않는다.
2. ChatGPT의 O4O 연결을 새로 연결하며 **거래장 조회**, **거래명세서 초안 서버 저장·수정**을 별도로 허용한다. 기존 자료 조회·문서 초안 권한만으로 거래장을 읽거나 쓰지 않는다. ChatGPT의 도구 목록·동의 화면도 새 범위를 받아야 한다.
3. O4O 메인 또는 ChatGPT에 사진을 첨부하고 ‘이 거래명세서를 O4O 거래장에 입력해 줘’라고 요청한다. O4O는 기존 이용 제한·AI 사용 정책 안에서 판독하고, ChatGPT는 자체 판독 결과를 O4O에 전달한다. ChatGPT 경로에서 O4O LLM을 다시 호출하지 않는다.
4. 반환된 명세서 확인 주소에서 원문 상품명·규격·수량·단위·단가·금액을 확인하고 수정 저장한다. 할인·반올림 차이는 행 조정액과 사유를 명시한다. 수량 단위를 임의로 환산하거나 금액을 계산에 맞춰 바꾸지 않는다.
5. 원본 보관 상태와 약국 프로그램 등록 상태를 확인하고 **거래장에 반영**을 누른다. 이 화면의 직접 확인 전에는 초안이다. ChatGPT의 ‘확정해 줘’만으로 반영하지 않는다.

ChatGPT에 첨부한 사진 원본이 O4O에 자동 전달되는 것으로 안내하지 않는다. 확인 화면에서 사진을 추가할 수 있으며, 원본 없이 반영한다면 미보관 사실을 직접 확인한다. O4O 메인 입력은 전달받은 사진 바이트를 보관한다(기기 원본이 이미 축소된 경우 그 전송본). 사진은 JPEG·PNG·WebP, 각 2MB 이하 최대 8장으로 보관한다. 메인 채팅의 첨부 개수·전송 한도도 적용한다.

필수 거래 값이 불명확하면 반영을 막는다. 상품코드·바코드 등 정비용 메타데이터가 불명확하면 표시를 보존해 관리자에게 전달하며 상품 DB 미등록을 이유로 거래 입력을 막지 않는다. 바코드의 형식·검사 숫자 통과는 실물 상품 식별 확정을 뜻하지 않는다.

동일 사진·문서 식별자·주요 거래 내용으로 중복 가능성을 조회한다. 같은 거래라면 추가 반영하지 않고, 별개 거래라면 사유를 남긴다. 원본과 사용자 수정 이력은 보존한다. 약국 프로그램 원본을 자동 수정·전기하거나 두 자료를 자동 합산하지 않는다. 프로그램 수집본과 사진 거래의 상품 단위 자동 대조는 후속 작업이며 현재 등록 상태를 명시해 별도로 보관한다.

확정한 상품 관찰 정보는 기존 관리자 상품 후보 목록에 pending으로 전달한다. 거래 금액·거래처 정보·사진은 후보에 복사하지 않는다. 신규 상품 생성·표준명·바코드 확정은 관리자의 정기 정비다. 현재 후보 승격 기능의 도메인 제한은 유지하며 사진 후보를 의약품으로 자동 분류하지 않는다. 주문 자동화 발견 자료의 같은 후보 흐름 연결은 별도 후속 작업이다.

서버 보관 철회·중단 시 명세서·사진·수정 이력·재시도 기록과 해당 미처리 후보를 정리한다. 공통 상품에 반영된 사실을 되돌리는 기능은 아니다. 기존 회원 탈퇴·매장 폐업의 업무 소유권과 정리 규칙을 따른다.

구현 범위와 운영 대기는 [사진 거래장 작업 범위](../work-orders/WO-O4O-PHOTO-TRANSACTION-LEDGER-V1.md), 검증 증거는 [연결 검증 기록](../checks/CHECK-O4O-PHOTO-LEDGER-CHAT-INTEGRATION-V1.md)을 따른다.
