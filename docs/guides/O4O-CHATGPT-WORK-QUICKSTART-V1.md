# ChatGPT에서 O4O 작업 시작하기

> **상태**: ACTIVE
> **작성일**: 2026-11-14 · **최종 갱신**: 2026-11-14
> **근거**: 사용자 요청 — ChatGPT 연결 안내와 거래명세서 문서 보관부터 순차 적용

## 연결과 요청

ChatGPT의 앱·연결 메뉴에서 O4O 서비스 연결을 찾아 연결한다. O4O 로그인 후 사용할 작업공간과 필요한 조회·초안 저장 권한을 선택한다. 연결 메뉴나 지원 기능은 ChatGPT 환경에 따라 다를 수 있다. 앱을 찾을 수 없다면 현재 배포된 연결 방법과 제공 여부를 확인한다.

O4O의 `/mypage/settings` → 외부 AI 연결 → **ChatGPT에서 O4O 작업하기**에서 요청 예시를 복사할 수 있다. O4O의 연결 이력만으로 현재 ChatGPT 채팅에서 도구가 사용 가능한지 단정하지 않는다. 만료되거나 해제된 연결은 ChatGPT에서 다시 연결한다.

처음에는 요청에 ‘O4O’ 또는 ‘O4O 작업’을 넣는 것을 권장한다. 필수 명령어는 아니다. 일반 답변으로 처리됐다면 ‘O4O 자료를 이용해 줘’라고 이어서 요청하면 된다. 기억 기능은 사용자의 ChatGPT 설정과 이용 환경에 따르며 자동 선택을 보장하지 않는다. 외부 작업 요청을 판별하기 위해 O4O 서버에 별도 LLM 분류기를 추가하지 않는다.

## 먼저 이용할 작업

| 작업 | ChatGPT | O4O |
|---|---|---|
| 내 자료 정리 | 자료를 읽어 요약·재작성 | 허용된 자료 검색·조회 |
| 거래명세서 사진 정리 | 사용자가 첨부한 사진·파일을 읽고 확인 표 제시 | 사진 판독을 중복 실행하지 않음 |
| 확인한 결과 보관 | 수정 내용을 반영하고 저장 도구 호출 | 기존 권한·검증을 거쳐 비공개 문서 저장·재조회 |

ChatGPT에서 파일을 선택하거나 첨부해야 한다. 웹과 앱 모두 사용자 PC의 자료 전체를 자동으로 읽는 것으로 안내하지 않는다. 플랫폼별 첨부·웹 작업 도구 제공 여부는 별도로 확인한다.

## 거래명세서 사용 순서

1. ChatGPT에 거래명세서 사진이나 파일을 첨부한다.
2. 다음처럼 요청한다: ‘O4O 작업이야. 거래처·일자·품목·수량·단위·금액을 표로 정리해 줘. 읽기 어려운 곳은 확인 필요로 남기고 아직 저장하지 마.’
3. 사용자에게 표를 보여 준다. 단위·수량·금액·세금 구분 등을 확인하고 수정한다. 모르는 값은 추정해 확정하지 않는다.
4. 확인 후 ‘이 내용을 O4O 내 매장 자료함에 비공개 문서로 저장해 줘’라고 요청한다. 작업공간이 여러 곳이면 저장할 매장을 정한다.
5. 도구 결과의 문서 주소를 열거나 다시 조회해 저장 내용을 확인한다. 동일 저장의 재시도에는 같은 `requestId`를 사용한다.

현재 이 경로는 **문서 보관**이다. 거래장 원장 입력·매입 전표 반영·상품 식별 확정·주문·결제는 포함하지 않는다. 사용자 확인은 대화 흐름의 요구사항이며 서버가 별도 승인 증거를 검사하는 기능은 이번에 추가하지 않았다.

## 개발 순서와 다음 경계

| 단계 | 범위 | 이번 결과 |
|---|---|---|
| 1 | 연결·요청 안내, 선택하기 쉬운 도구 설명 | 구현·격리 검증 |
| 2 | 사진 정리 → 사용자 확인 → 문서 보관 | 합성 이미지·문서 저장 격리 시험, 실제 명세서 시험 대기 |
| 3 | 확인한 명세서의 실제 거래장 반영 | 사진 입력의 공통 검증·확인 준비 함수 구현. 저장 API·권한·DB 연결은 후속 작업 |
| 4 | 주문 제안·수정 → 공급자별 장바구니 | 후속 작업. O4O는 자료·편집 화면, ChatGPT는 제공되는 브라우저 기능으로 사이트 작업. 주문 확정은 약사 |
| 5 | 자주 쓰는 사이트의 작업 방법 재사용 | 후속 작업. 사이트별 방법·변경일·실패 시 재확인 규칙 관리 |

기존 업무 데이터의 사용자 입력 경로는 매입·사용·판매·잔액 원장을 직접 받아들이지 않는 제한이 있다. 단순 문서 저장을 원장 반영 완료라고 표시하거나 이 제한을 우회하지 않는다. 기존 O4O 자동화의 약사 업무 범위와 비용 절감 장치는 유지한다. ChatGPT에서 외부 사이트를 방문할 수 있는지는 실제 도구·사이트 접근 조건에 따라 검증하며, O4O 앱 연결만으로 브라우저 제어가 제공되는 것은 아니다.

이번 변경에는 신규 모델 호출이나 요금제 연동을 넣지 않았다. ChatGPT 요금제의 상용 원격 앱 참여는 실제 참여 조건 확인 후 별도로 진행한다. 비용 계산은 이번 범위에 포함하지 않는다.

검증 범위와 남은 실제 자료 시험은 [검증 기록](../checks/CHECK-O4O-CHATGPT-ENTRY-INVOICE-TRIAL-V1.md)을 따른다.

## 사진 기반 거래장 입력 개발 상태

현재 개발 대상은 **사진만**이다. QR 등록·조회나 외부 링크를 요구하지 않는다. 명세서 사진의 항목을 보존하고 ChatGPT에서 읽은 값을 전달받아 수치·필수 항목·미확정 표시를 검사하는 순수 처리부를 추가했다. O4O 자체 채팅에서도 동일 검증을 재사용할 수 있으며 처리부는 AI를 호출하지 않는다.

공통 상품이 없거나 바코드·표준 상품명이 미정이어도 확인 준비가 가능하다. 원문 상품명·업체 상품코드·규격·제조사·바코드는 관리자 정기 정비용 후보로 분리한다. 입력 중 신규 상품을 만들거나 상품명을 통일하지 않는다. 주문 자동화에서 발견한 정보도 후속 단계에서 같은 관리자 검토 흐름에 합류시킨다.

**아직 ChatGPT 도구·화면·운영 저장에 연결하지 않았다.** 새 함수의 확인 준비 결과는 실제 사용자 승인이나 거래장 저장 완료를 뜻하지 않는다. 실제 명세서 일부 사진은 항목 설계 참고에 사용했으며 가림·잘림이 있어 확정 저장하지 않았다. 공개 저장소에는 실제 명세서 원문·업체 정보·사진을 넣지 않았다.

상품명·수량·단위·금액 등 거래 필수 항목이 없거나 확인 필요이면 확인 준비를 차단한다. 바코드·규격 등 정비용 메타데이터가 불명확한 경우는 경고와 미확정 표시를 유지해 관리자에게 넘기며 거래 확인을 막지 않는다. 금액 계산은 소수점 문자열로 검사하고 포장 단위 환산은 하지 않는다. 세금 구분을 알 수 없으면 unknown으로 보존하며 행 금액 합계를 세금 포함 총액으로 바꾸지 않는다. 할인·조정·반올림 때문에 수량×단가와 금액이 다른 명세서는 현재 불일치로 남긴다. 실제 저장 연결 전에 명시적인 조정 근거 처리부터 추가하며, 일치시키려고 원문 금액을 바꾸지 않는다.

[사진 거래장 작업 범위와 다음 단계](../work-orders/WO-O4O-PHOTO-TRANSACTION-LEDGER-V1.md)를 따른다. 기존 프로그램 원본 수집 계약은 별도 경로이며 사진 판독 결과에 가짜 프로그램 출처를 붙여 우회하지 않는다.
