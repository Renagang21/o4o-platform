# Neture 계정 개인정보 처리방침 — 개정 본문 초안

> 상태: DRAFT · 작성일: 2026-10-11 · 게시·시행 전 검토용
> 적용: neture.co.kr 공통 계정. 서비스별 추가 수집·처리 안내는 해당 서비스 신청 시 제공한다.

## 1. 적용 범위와 처리 목적

Neture 운영회사는 Neture 계정의 생성·로그인·이메일 확인·계정 복구·인증 수단 관리,
회원 문의 처리 및 보안 운영을 위해 필요한 개인정보를 처리합니다. 각 서비스의 사업자 증빙,
전문 자격, 소속, 사업 참여 정보는 공통 계정 가입에 일괄 요구하지 않으며 해당 서비스 신청 때
처리 목적과 항목을 안내합니다. 은퇴 서비스는 신규 계정의 적용 서비스 목록에 넣지 않습니다.
기존 서비스의 보유·동의 증빙 의무가 소멸하는 것은 아닙니다.

## 2. 공통 계정에서 처리하는 정보

| 구분 | 항목 | 처리 목적 |
| --- | --- | --- |
| 공통 가입·프로필 | 이메일, 이름, 개인 휴대전화 | 계정 식별·관리, 이메일 확인 및 회원 연락 |
| 이메일 로그인 | 비밀번호 해시 및 인증·재설정 관련 기록 | 로그인·계정 복구. 평문 비밀번호를 저장한다고 안내하지 않음 |
| Google·카카오 인증·연결 | 외부 서비스 구분·사용자 식별자, 제공되는 이메일 및 이메일 확인 여부, 연결 기록 | 계정 인증·회원이 요청한 로그인 수단 연결 |
| 계정 접근·동의 | 이메일 확인 여부, 계정 상태, 정책 문서·버전·본문 hash·승낙 시점, 선택적 마케팅 동의 | 정상 계정 판정·변경 이력 및 동의 증빙 |
| 보안·고객지원 | 로그인 시도·접속·감사 기록, 문의 및 이메일 발송 기록 | 부정 이용 방지·장애 대응·문의 처리 |

개인 휴대전화와 사업장 전화는 별개입니다. 현재 공통 가입에서 휴대전화 본인 인증은 수행하지 않습니다.
Google·카카오가 이름·전화번호를 제공해 공통 필드를 자동 확정하는 것으로 안내하지 않습니다.
카카오 access token은 서버의 코드 교환·사용자 정보 확인에 사용하며 장기 저장하지 않습니다.
외부 인증의 이메일 일치만으로 계정을 자동 연결하거나 합치지 않습니다.

## 3. 서비스별 추가 정보

공통 계정 정보를 중복 입력받지 않습니다. 공급자·약국의 사업자 정보 및 사업자등록증 사본,
약국의 약사 면허번호·약국 전화, 커뮤니티 닉네임·가입 조건, 약국 협력사업의 신청 당시 조건과
추가 설명 등은 해당 서비스 신청에 필요한 범위에서 별도로 안내합니다. 약국 면허증 파일은
받지 않습니다. 새로운 업종·증빙을 추가하는 경우 그 처리 안내를 먼저 검토합니다.
추가 개인정보의 처리 목적·필수/선택·보유 및 삭제 절차는 서비스별 실제 신청 계약과 일치시킵니다.

## 4. 보유·파기

보유기간은 [현행 보유기간 정본](../baseline/O4O-PRIVACY-DATA-RETENTION-POLICY-V1.md) §15를
따르며 이번 개정으로 기간을 변경하지 않습니다. 회원·프로필은 탈퇴 또는 목적 종료 시까지,
일반 문의는 처리 완료 후 1년, 이메일 발송 기록은 1년, 로그인 시도는 30일,
개인정보 접속·감사 기록은 1년을 기본으로 하며 법정 보유 의무가 적용되는 기록은 그 의무를 따릅니다.
백업·Cloud Logging·미디어·AI 등은 해당 저장소와 기능의 실제 이용 여부 및 정본 기간을 대조합니다.
현재 지원하지 않는 계정 탈퇴와 미디어 자동 삭제 연동을 구현 완료로 안내하지 않습니다.

## 5. 위탁·국외 처리·정보주체 권리

기존 공개 처리방침의 실제 운영회사, 개인정보 보호책임자·문의 경로, 정보주체의 권리,
안전성 확보 조치, Google Cloud·메일·활성 AI 처리자 및 국외 처리 정보를 기본 대조 자료로 사용합니다.
공통 계정에서 실제 사용하지 않는 서비스 기능을 필수 처리로 설명하지 않습니다.
Google·카카오 인증 데이터의 이동은 수신 정보와 제공자에게 전송하는 정보를 구분해 확인합니다.
외부 인증이라는 이유만으로 개인정보 제3자 제공·위탁·국외 이전의 법적 분류를 임의 확정하지 않습니다.

## 6. 게시 전 확정할 내용

- 기존 공개 원문의 담당자·연락처 및 운영회사 정보를 legal-profile과 일치시킨 최종 본문.
- Google·카카오 인증의 법적 처리 근거와 필요한 제공자 고지. 기존 동의 UI의 필수 동의와도 대조.
- 적용되는 위탁·국외 처리 및 권리 행사 조항 전체. 운영 계약이 확인되지 않은 항목은 보류 표시를
  제거한 후에만 게시한다. 이 초안 자체를 완성된 처리방침으로 게시하지 않는다.
- 공고·시행일과 새 version. 이용약관 승낙과 개인정보 처리 고지·선택 동의를 구분해 기록한다.
