# Neture 계정 이용약관 — 개정 본문 초안

> 상태: DRAFT · 작성일: 2026-10-11 · 게시·시행 전 검토용
> 적용: neture.co.kr 공통 계정. 서비스별 가입·사업 참여 약관은 별도다.
> 문서 version은 게시 대상 DB의 기존 version을 확인한 후 확정한다. 제목의 V2는 개정안 식별자다.

## 제1조 목적과 적용 범위

이 약관은 Neture 운영회사(이하 회사)와 회원 사이의 neture.co.kr 계정 생성, 인증,
계정 관리 및 서비스 진입에 관한 이용 조건을 정합니다. 운영 주체의 법정정보는 Neture에
공개된 정보를 따릅니다. 각 서비스의 기능·사업 참여·거래 조건은 해당 서비스 가입 또는
참여 신청 시 안내하는 별도 약관과 조건에 따릅니다.

## 제2조 계정과 서비스 이용 자격

회원은 하나의 Neture 계정을 사용합니다. Neture 계정 가입 완료의 기준은 정상 계정과
이메일 소유 확인이며, 별도 메인 수동 승인을 기다리지 않습니다. 서비스 신청·승인은 계정과
구분됩니다. 공통 로그인 또는 다른 서비스의 가입 승인은 해당 서비스의 승인이나 업무 권한을
만들지 않습니다. 서비스 간 세션 이동도 가입·승인·권한 부여를 대신하지 않습니다.

## 제3조 가입과 인증

가입 시 이메일, 이름 및 개인 휴대전화 번호를 입력합니다. 개인 휴대전화는 사업장 전화와
구분하며, 현재 가입 단계에서 SMS 본인 인증은 수행하지 않습니다. 필요한 경우 이메일
확인 절차를 거칩니다. 공통 개인정보는 서비스마다 다시 등록하지 않습니다.
회원은 이메일·비밀번호, Google 또는 카카오 인증을 이용할 수 있습니다. 소셜 가입에는
별도 비밀번호 생성을 요구하지 않습니다. 전체관리자 화면에는 별도의 Google 인증 정책을 적용합니다.

## 제4조 로그인 수단 연결·해제

외부 계정의 이메일 주소가 같다는 이유로 기존 계정을 자동 연결하거나 통합하지 않습니다.
회원이 로그인 수단 연결을 명시적으로 요청하고 기존 계정 및 외부 계정 인증을 완료한 경우
로그인 수단을 추가할 수 있습니다. 다른 회원에게 이미 연결된 외부 계정은 임의로 이전하지 않습니다.
해제 이후에도 이용 가능한 로그인 수단이 남아 있어야 합니다. 두 Neture 회원 계정 자체의
병합은 로그인 수단 연결과 별개이며, 이 약관은 자동 계정 병합을 약속하지 않습니다.

## 제5조 계정 보안과 세션

회원은 본인의 인증정보를 보호하고 타인의 계정을 무단 사용하지 않아야 합니다.
일반 로그아웃은 해당 서비스 도메인의 현재 브라우저 세션에 적용됩니다. 비밀번호 변경 또는
재설정 시 기존 세션은 폐기되며 다시 로그인해야 합니다. 사용자용 모든 기기 로그아웃 기능은
현재 제공하지 않습니다. 공개 Demo는 기능 체험용이며 개인 계정의 수단 연결·비밀번호 변경이나
전체관리자 접근 권한을 제공하지 않습니다.

## 제6조 서비스별 신청

서비스 이용을 원하는 회원은 해당 서비스의 대상, 추가 정보, 신청 조건 및 승인 절차를
확인합니다. 서비스 신청 취소·반려·정지·탈퇴와 Neture 계정 상태는 구분합니다.
서비스별 가입 약관에 동의하지 않은 경우 해당 서비스 신청 또는 이용이 제한될 수 있으나,
그 사실만으로 공통 계정 로그인이나 무관한 다른 서비스의 이용을 거부하지 않습니다.

## 제7조 개인정보와 회원정보 관리

공통 계정 정보의 처리 목적·항목·보유기간·권리 행사 절차는 Neture 개인정보 처리방침에
따릅니다. 서비스별로 필요한 추가 개인정보는 해당 서비스 신청 시 별도로 안내합니다.
회원은 등록한 정보가 변경된 경우 제공되는 프로필 관리 기능 또는 안내된 문의 경로를 통해
정정할 수 있습니다. 계정 삭제·서비스 탈퇴는 실제 제공하는 절차와 법정 보유 의무에 따르며,
지원하지 않는 즉시 자동 파기 기능을 약속하지 않습니다.

## 제8조 운영·이용 제한과 이의 제기

회사는 서비스 안정성과 회원 권리 보호를 위해 필요한 범위에서 계정 이용을 제한할 수 있습니다.
일반 제한은 사전 안내를 원칙으로 하고, 긴급한 보안 위협·불법 행위·타인 권리 침해 등에는
필요한 조치를 우선한 뒤 안내할 수 있습니다. 회원은 공개된 문의 경로로 이의를 제기할 수 있습니다.
서비스별 승인 권한은 각 서비스의 역할·가입 및 사업자 관계에 따라 행사합니다.

## 제9조 변경 공고와 재동의

변경 내용·이유·시행일을 일반 변경은 시행일 7일 전부터, 회원에게 불리하거나 중요한 변경은
30일 전부터 게시합니다. 필요한 경우 이메일 등으로 추가 안내합니다. 기존 회원에게 새 약관의
명시적 동의를 요청하며 계속 이용만으로 동의를 간주하지 않습니다. 동의 문서의 ID·version·본문
hash 및 동의 시점을 보존합니다. 서비스별 약관의 변경은 해당 서비스의 적용 범위로 안내합니다.

## 부칙 및 게시 전 대조

공고일·시행일은 공고 기간을 결정한 뒤 확정합니다. 이 초안은 게시된 원문이 아닙니다.
기존 v1의 권리·의무, 콘텐츠 권리, 손해배상·책임 제한, 분쟁·준거법 조항은 현행 게시 원문과
대조해 Neture 계정에 적용할 부분을 최종 본문에 포함해야 합니다. 사업·거래·교육·서비스별 조항을
공통 계정 약관에 일괄 적용하지 않습니다. 운영회사 법정정보는 기존 게시 원문 및 legal-profile과
일치시켜 확정하며, 담당자 개인정보를 검토안에 복제하지 않습니다.
