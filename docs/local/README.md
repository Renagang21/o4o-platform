테스트 계정 기준 파일은 `TEST-ACCOUNTS.local.md` 하나입니다.
리팩터링 이전 계정과 이전 기준 파일 `TEST-ACCOUNT.txt`는 계정 출처로 사용하지 않습니다.

파일 확보·검증 절차는 [SETUP.md](../../SETUP.md#테스트-계정-찾기--브라우저운영-검증-전)를 따릅니다.
