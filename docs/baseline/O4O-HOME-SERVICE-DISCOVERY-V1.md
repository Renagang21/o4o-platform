# O4O 대표 홈 서비스 탐색 · 약국 협력사업 용어 정본

> **상태**: ACTIVE · 설계 확정 / 화면 구현 미적용
> **확정일**: 2026-10-10 · **근거**: 사용자 대표 홈 설계 논의 및 용어 적용 지시
> **적용 범위**: 대표 홈의 서비스 발견·분류·안내 문구. 가입·승인·권한·주문 계약 변경 없음.

## 1. 표준 용어

사업의 사용자용 명칭과 현행 문서 표현은 **약국 협력사업**으로 통일한다. 종전 ‘세미프랜차이즈’, ‘세미프렌챠이즈’는 과거 기록을 읽기 위한 별칭이다. 특정 프랜차이즈 계약이나 공동 소유 구조를 뜻하지 않는다. 각 사업은 독립적으로 약국을 지원하고 자체 가입·승인·업무를 운영한다.

`semi_franchises`, `semi_franchise_memberships`, `semi_franchise_operators`, `semi_franchise_id`, 기존 파일명·URL·서비스 키는 기술 식별자로 유지한다. 이 문서 정비는 DB migration이나 런타임 문구 변경이 아니다. 조사·검증 기록과 완료된 과거 작업 문서는 당시 표현을 보존한다.

`pharmacy.neture.co.kr`의 사용자용 명칭은 **O4O 약국 경영지원**, 소개는 **“O4O를 이용하는 약국 내에서의 업무를 지원하는 약국 개설자 서비스”**로 한다. 내부 `kpa-society`는 공개 이름으로 사용하지 않는다.

## 2. 대표 홈 구성

대표 홈은 약업계 사용자가 필요한 활동을 찾는 출발점이다. 약국·공급자 두 사용자 유형을 주요 서비스로 강조하는 배치를 용도별 전체 서비스 탐색으로 대체한다.

표시 순서는 공통 헤더 → **O4O AI** → 로그인 사용자의 내 업무·서비스 → 전체 서비스 탐색 → 소식 → 문의·푸터다. AI 입력은 첫 화면에서 보이며, 비로그인 사용자의 실제 업무 실행에는 로그인 안내를 유지한다. 이용 자격 확인은 기존 계약을 따른다.

전체 서비스 탐색은 로그인 여부·가입 여부와 무관하게 제공한다. 공개 탐색, 가입·신청 가능 여부, 실제 업무 권한은 별도로 판단한다. 준비 중 카드를 활성 서비스나 가입 가능한 서비스로 계산하지 않는다.

교육·학습을 커뮤니티·단체활동에 모으는 것은 **대표 홈 탐색 분류**다. 강의 앱·서브도메인·데이터·권한을 커뮤니티로 통합하는 결정이 아니다. 기타의 항목을 ‘의료기관 업무’라는 고정 분류로 제한하지 않는다.

대표 홈 `neture.co.kr`은 현재 위치다. 관리자 `admin.neture.co.kr`은 권한이 있는 사용자의 관리 진입으로 제공한다. 은퇴한 Retail·PharmacyHub는 서비스 탐색에 포함하지 않는다. 병원 관련 기존 경로와 Cafe24 연동 같은 기술 경로는 실제 공개 제공 여부를 확인하며, 새 서브도메인을 임의로 만들거나 운영 중이라고 표시하지 않는다.

## 4. 준비 중 항목의 동작

### Partner

대표 홈에 **O4O Partner · 준비 중** 카드를 포함한다. 클릭하면 어떤 서비스인지 설명하는 준비 중 페이지를 제공한다. 우선 계획 경로는 대표 홈의 `/services/partner`다. 예약된 `partner.neture.co.kr`의 실제 DNS·배포 준비가 확인되면 연결 경로를 정비한다. 예약 주소에 곧바로 연결해 접속 실패를 만들지 않는다.

소개 페이지는 서비스명, 준비 중 상태, 확정된 서비스 목적, 대표 홈으로 돌아가기, Contact Us를 제공한다. Partner의 구체적인 사업 내용은 아직 확정되지 않았으므로 수수료·역할·가입 조건·출시일을 만들어 설명하지 않는다. Legacy Partner의 판매·권한·API를 재활성화하거나 공급자 기능을 Partner로 이동하는 결정이 아니다.

### 준비 중인 약국 협력사업

만성질환관리·약국/약사협동조합·창고형 약국을 지금부터 탐색 목록에 표시한다. 클릭하면 **“준비 중입니다”** 안내 팝업을 표시한다. 팝업에는 해당 사업명과 닫기 버튼을 제공한다. 미확정 일정·가입·승인을 약속하지 않는다.

팝업은 키보드로 열고 닫을 수 있고, 제목을 보조기기에 전달하며, Escape·닫기 후 원래 카드로 초점을 돌려준다. 준비 중 카드가 비활성 버튼처럼 보이면서 클릭 가능성을 숨기지 않도록 안내 동작을 표시한다.

## 5. 서비스 진입·로그인·문의 정책

각 서비스에 별도 **Home 메뉴·서비스 소개 화면을 두지 않는다**. 서비스 진입은 실제 콘텐츠 목록이나 업무 화면으로 연결하고 메뉴는 해당 서비스의 기능으로 구성한다. 모든 화면에서 O4O 대표 홈으로 돌아가는 공통 진입을 제공한다. 준비 중인 Partner의 설명 페이지는 앞서 확정한 예외다. 기존 소개 화면 제거는 별도 legacy 제거 트랙과 조율한다.

| 서비스 | 기본 접근 정책 | Contact Us |
|---|---|---|
| 커뮤니티 | 서비스 진입 공개·공개 항목 열람. 각 항목에서 이용 자격 판정 | 없음. 운영 문의·신고는 해당 기능으로 제공 |
| 강의 · 교육·학습 | 서비스 진입 공개·공개 항목 열람. 각 강의·자료·활동에서 이용 자격 판정 | 필요 |
| 공급자 | 로그인 필요 | 필요 |
| 유통참여형 펀딩 | 로그인 필요 | 필요 |
| 각 약국 협력사업 | 로그인 필요. 사업별 가입·승인 정책 유지 | 필요 |
| 내 매장 | 로그인·조직 소속·업무 권한 확인 | 없음 |
| 기타 서비스 | 로그인 필요를 기본으로 하고 항목별 확인 | 서비스 목적에 따라 결정 |

커뮤니티·강의에서 글쓰기·수강·제한 자료 등의 이용 자격은 각 항목에서 확인한다. 공개 진입과 모든 기능의 무제한 이용을 혼동하지 않는다. 나머지 서비스의 로그인 요구는 현재 기준이며 실제 테스트 결과와 사용자 결정에 따라 변경할 수 있다. 대표 홈의 전체 서비스 발견 정책과 서비스 내부 로그인 요구는 별개다.

대표 홈의 헤더와 푸터에는 **Contact Us / 문의하기**를 노출하고 기존 `/contact`로 연결한다. 공급자·펀딩·강의·각 약국 협력사업은 해당 서비스 문의 경로를 제공한다. 커뮤니티와 내 매장에는 사업용 Contact Us를 두지 않는다.

### 약국 협력사업 참여자 공간 — 사용자 승인 / 구현 대상

각 사업자가 운영하는 자료·게시판·참여자 활동 공간을 해당 약국 협력사업 서비스 안에서 제공한다. 사용자가 2026-10-10 이 방향의 구현을 승인했다. 공통 커뮤니티는 업계 전체의 교류에 집중하고, 협력사업 서비스에서는 가입 전 참여 조건·신청 경로와 승인 후 자료·활동·업무를 제공한다. 별도 소개 Home을 만들지 않는다.

공통 커뮤니티는 약업계 전체의 정보·교류·단체활동, 각 협력사업은 참여 신청·사업 자료·참여자 게시판·업무 도구·Contact Us, 내 매장은 해당 약국의 실제 업무를 담당한다. 기존 게시판 기능과 원장을 재사용하며 사업별 회원 승인·콘텐츠 소유권·운영자 격리를 유지한다. 화면과 진입 경로를 옮기며 게시물·회원 데이터의 DB 이전이나 권한 자동 부여를 하지 않는다. 현행 pharmacy 서비스의 참여자 경로는 `/businesses/:businessKey/*`이고 기존 community 주소는 사업 서비스로 연결한다. 구현·검증 결과는 후속 WO/CHECK에서 기록한다.

## 6. 구현·검증 인계

대표 홈 탐색 개편은 문서 정비 상태다. 사업 참여자 공간과 서비스 진입·메인 복귀 구현은 별도 PR에서 진행한다. 대표 홈 컴포넌트, Partner 설명 페이지, 준비 중 팝업, 실제 화면 문구는 후속 구현 대상이다. 구현 시 서비스 목록·상태의 중복 정의를 줄이고, 공개 전체 목록과 개인 업무 목록을 같은 권한 목록으로 취급하지 않는다.

검증 기준은 로그인 전후 전체 목록 노출, AI 첫 화면 배치, 세 사업 팝업, Partner 설명 페이지·메인 복귀·문의 링크, 모바일·키보드 접근, 준비 중 항목의 가입/업무 권한 미생성이다. 서비스별 Home 제거·공개 커뮤니티/강의 접근·항목별 이용 자격·로그인 요구·Contact Us 배치도 검증한다. 코드·운영 반영 완료는 후속 PR과 검증 결과로 별도 기록한다.

관련 정본: [서브도메인 의미](O4O-SUBDOMAIN-SERVICE-SEMANTICS-V1.md), [역할·업무공간](O4O-ROLE-WORKSPACE-ARCHITECTURE-V1.md), [인증·가입](O4O-NETURE-AUTH-AND-SERVICE-MEMBERSHIP-V1.md).

사업 참여자 공간은 community_key 설정을 가입 자격으로 취급하지 않는다. 기존 연결 주소가 없으면 `business:<businessKey>`를 서버에서 해당 사업의 `sf:<UUID>` 원장에 해석하여 같은 승인·소속·운영자 조건을 적용한다. 게시판 개설은 이 공간에서 명시적으로 신청·처리하며 기본 주소 조회가 DB 생성이나 자동 승인을 수행하지 않는다.
