## 1. 표준 용어

사업의 사용자용 명칭과 현행 문서 표현은 **약국 협력사업**으로 통일한다. 종전 ‘세미프랜차이즈’, ‘세미프렌챠이즈’는 과거 기록을 읽기 위한 별칭이다. 특정 프랜차이즈 계약이나 공동 소유 구조를 뜻하지 않는다. 각 사업은 독립적으로 약국을 지원하고 자체 가입·승인·업무를 운영한다.

`semi_franchises`, `semi_franchise_memberships`, `semi_franchise_operators`, `semi_franchise_id`, 기존 파일명·URL·서비스 키는 기술 식별자로 유지한다. 이 문서 정비는 DB migration이나 런타임 문구 변경이 아니다. 조사·검증 기록과 완료된 과거 작업 문서는 당시 표현을 보존한다.

`pharmacy.neture.co.kr`의 사용자용 명칭은 **O4O 약국 경영지원**, 소개는 **“O4O를 이용하는 약국 내에서의 업무를 지원하는 약국 개설자 서비스”**로 한다. 내부 `kpa-society`는 공개 이름으로 사용하지 않는다.

### 1.1 독립 약국 협력모델 서비스와 내 약국 (2026-10-16 사용자 확정)

약국 협력모델은 각각 **독립된 서비스**다. 약국 개설약사는 이용하려는 협력모델 서비스에서 가입을 신청하고, 해당 서비스 운영자가 심사·승인한다. 만성질환관리는 `pharmacy.neture.co.kr`과 별도의 약국 협력모델 서비스이며, pharmacy 가입을 만성질환관리 가입의 선행 조건으로 삼지 않는다.

```text
약국 개설약사 → 협력모델 A 서비스에서 가입 신청 → A 서비스 운영자의 승인
             → 내 약국에 A 서비스가 제공하는 기능·제품·콘텐츠 표시 및 이용
             → 협력모델 B도 B 서비스에서 별도로 가입·승인 후 제공 부분 표시
```

- **각 협력모델 서비스**: 자기 서비스의 가입·승인·회원 커뮤니티·콘텐츠·B2B 공급 승인 등 운영 업무를 담당한다.
- **내 약국(공통 내 매장)**: 약국 개설약사가 가입하여 승인받은 협력모델의 제공 기능을 모아 실제 약국 업무를 수행한다. 협력모델 가입·승인의 주체가 아니며, 내 약국 이용 자격만으로 개별 협력모델 기능을 열지 않는다.
- 약국 개설·조직 소속 확인과 협력모델별 가입·승인은 다른 축이다. 한 모델의 승인을 다른 모델의 승인으로 대체하지 않고, 표시 여부뿐 아니라 실제 조회·실행에서도 해당 모델의 이용 자격을 확인한다.
- 공통화 대상은 약국 경영자에게 필요한 가입·승인 절차의 구현 방식, 승인 결과 전달, 내 약국 연결이다. 기존 pharmacy 서비스 아래에 만성질환관리를 종속시키거나 pharmacy 회원을 자동 가입시키는 뜻이 아니다.

### 1.2 만성질환관리 서비스의 업무 배치

| 영역 | 만성질환관리 서비스 | 승인받은 약국 개설약사의 내 약국 |
|---|---|---|
| 가입·회원 | 해당 서비스 가입 신청·심사·승인·회원 관리 | 승인 결과에 따라 해당 서비스의 제공 부분 표시 |
| B2B | 공급자의 참여 약국 대상 제품 공급 신청 검토·승인·관리 | 이용 가능한 공급 제품 조회·주문 등 약국 업무 |
| CGM | 해당 회사 API 연결과 서비스 운영 | CGM 서비스 실제 이용 |
| 무료혈당기 | 사업 운영·제공 내역 관리 | 소비자가 전달한 코드를 입력하여 무료혈당기 제공 |
| 콘텐츠 | 직접 제작하거나 공급자에게 받아 등록·관리 | 참여 약국이 자료를 가져와 활용 |
| 회원 커뮤니티 | 해당 서비스를 이용하는 승인 회원의 참여 공간·콘텐츠 공유 | 공유 콘텐츠를 가져와 내 약국에서 이용 |

CGM API 규격과 무료혈당기 코드 검증·사용 처리 규격은 별도 확인이 필요하다. 위 표는 사용자 확정 업무 배치이며 기능 구현·실연동 완료 기록이 아니다. 기존 CarePharm 코드의 독립 커뮤니티 연결이나 기술 serviceKey가 이 사업 구조를 대신 결정하지 않는다. 대표 홈의 현재 진입 주소는 §3·§4의 2026-10-18 사용자 확정을 따른다.

## 2. 대표 홈 구성

대표 홈은 약업계 사용자가 필요한 활동을 찾는 출발점이다. 약국·공급자 두 사용자 유형을 주요 서비스로 강조하는 배치를 용도별 전체 서비스 탐색으로 대체한다.

2026-10-18 사용자 정정: 로그인 전·후 모두 표시 순서는 공통 헤더 → 화면 전체 폭의 슬라이드 Hero → O4O AI → 서비스 목록 → 소식 → 문의·푸터다. Hero가 본문 최상단이고 AI는 그 바로 아래에 둔다. AI를 서비스 목록 아래로 이동하지 않는다. 로그인 전은 공개 전체 서비스, 로그인 후는 서버가 확정한 가입 서비스를 먼저 표시하고 가입·이용 상태를 안내한 뒤 다른 서비스 소개를 아래에 표시한다. 서비스 배너에는 짧은 한 줄 설명을 제공한다. My Home 직접 진입은 본문 요약 카드 대신 로그인과 같은 상단 계정 영역에 둔다.

공개 탐색, 가입·신청 가능 여부, 실제 업무 권한은 별도로 판단한다. 준비 중 카드는 활성 서비스나 가입 가능한 서비스로 계산하지 않는다. 조회 실패·로딩 중에는 미가입으로 단정하지 않고 공개 전체 목록을 유지한다. AI 요청·첨부·세션·업무 실행 권한은 기존 경계를 따른다.

### 2.1 My Home과 대표 홈의 구분

개인 통합 공간의 이름은 **My Home**이며 [명칭·역할·진입 정본](O4O-MY-HOME-CANONICAL-V1.md)을 따른다. 대표 홈은 로그인 여부와 무관하게 전체 서비스를 발견하는 출발점, My Home은 로그인한 본인의 참여 서비스·커뮤니티 활동·경영 현황·계정 설정을 여러 화면에서 확인하는 공간이다. 대표 홈은 가입 서비스 우선과 다른 서비스 소개를 제공하며, 개인 통합 공간은 상단 My Home으로 연결한다.

로그인 후 공통 헤더에 My Home 직접 링크를 표시하고, 매장 업무 권한이 있는 사용자에게는 **My Home · 내 매장**을 구분해 제공한다. 독립 서비스에서도 같은 이름과 공통 위치로 돌아올 수 있게 한다. My Home은 별도 서비스 소개 Home이 아니며 각 서비스에 Home 메뉴를 두지 않는 §5와 충돌하지 않는다. 실제 URL 연결·모바일 배치·QR 통계 화면을 구현·배포했다. 로컬 fixture·운영 공개 화면은 검증했으며 실제 로그인 계정 검증은 구현 CHECK의 제한을 따른다.

## 4. 준비 중 항목의 동작

### Partner

대표 홈에 **O4O Partner · 준비 중** 카드를 포함한다. 클릭하면 어떤 서비스인지 설명하는 준비 중 페이지를 제공한다. 현재 제공 경로는 대표 홈의 `/services/partner`다. 예약된 `partner.neture.co.kr`의 실제 DNS·배포 준비가 확인되면 연결 경로를 정비한다. 예약 주소에 곧바로 연결해 접속 실패를 만들지 않는다.

소개 페이지는 서비스명, 준비 중 상태, 확정된 서비스 목적, 대표 홈으로 돌아가기, Contact Us를 제공한다. Partner의 구체적인 사업 내용은 아직 확정되지 않았으므로 수수료·역할·가입 조건·출시일을 만들어 설명하지 않는다. Legacy Partner의 판매·권한·API를 재활성화하거나 공급자 기능을 Partner로 이동하는 결정이 아니다.

### 약국 협력사업 진입 (2026-10-18 사용자 확정)

만성질환관리·약국/약사협동조합·창고형 약국은 위 운영 서비스 주소로 직접 연결한다. 대표 홈의 과거 “준비 중입니다” 팝업은 제거한다. 링크를 제공하는 것은 자동 가입·승인이나 모든 기능의 이용 권한을 뜻하지 않는다. 로그인 전 공개 탐색과 로그인 후 다른 서비스 소개 모두 같은 주소를 사용하고 각 서비스의 기존 인증·가입·조합별 이용 자격 판정을 유지한다. Partner의 준비 중 소개는 별도 정책으로 유지한다.

커뮤니티·강의에서 글쓰기·수강·제한 자료 등의 이용 자격은 각 항목에서 확인한다. 공개 진입과 모든 기능의 무제한 이용을 혼동하지 않는다. 나머지 서비스의 로그인 요구는 현재 기준이며 실제 테스트 결과와 사용자 결정에 따라 변경할 수 있다. 대표 홈의 전체 서비스 발견 정책과 서비스 내부 로그인 요구는 별개다.

대표 홈의 헤더와 푸터에는 **Contact Us / 문의하기**를 노출하고 기존 `/contact`로 연결한다. 공급자·펀딩·강의·각 약국 협력사업은 해당 서비스 문의 경로를 제공한다. 커뮤니티와 내 매장에는 사업용 Contact Us를 두지 않는다.

### 약국 협력사업 참여자 공간 — main 반영 / 운영 배포 완료

각 사업자가 운영하는 자료·게시판·참여자 활동 공간을 해당 약국 협력사업 서비스 안에서 제공한다. 사용자가 2026-10-10 이 방향의 구현을 승인했고 PR #376·#393으로 main에 반영됐다. 공통 커뮤니티는 업계 전체의 교류에 집중하고, 협력사업 서비스에서는 가입 전 참여 조건·신청 경로와 승인 후 자료·활동·업무를 제공한다. 별도 소개 Home을 만들지 않는다.

공통 커뮤니티는 약업계 전체의 정보·교류·단체활동, 각 협력사업은 참여 신청·사업 자료·참여자 게시판·업무 도구·Contact Us, 내 매장은 해당 약국의 실제 업무를 담당한다. 기존 게시판 기능과 원장을 재사용하며 사업별 회원 승인·콘텐츠 소유권·운영자 격리를 유지한다. 화면과 진입 경로를 옮기며 게시물·회원 데이터의 DB 이전이나 권한 자동 부여를 하지 않는다. pharmacy 서비스의 기본 회원 초기화면은 `/`이며 게시글은 `/community`, 사업 자료는 `/materials`, 참여 상태는 `/my/participation`에서 제공한다. 이전 `/businesses/pharmacy/*` 주소는 대응하는 화면으로 연결하고 다른 사업 키의 `/businesses/:businessKey/*` 경로는 유지한다. 기존 community 주소는 사업 서비스로 연결한다. 참여자 공간·대표 홈 복귀는 [PR #376](https://github.com/Renagang21/o4o-platform/pull/376), 게시판 미개설 사업 접근 보완은 [PR #393](https://github.com/Renagang21/o4o-platform/pull/393)으로 반영됐다. 회원 초기화면 후속 정비는 [PR #414](https://github.com/Renagang21/o4o-platform/pull/414)로 main에 병합됐고 운영 배포됐다. 병합 commit은 `c3d81b8b3b9961762763fb0b049a1de670c9ceab`, 운영 serving commit은 후속 문서 PR #415를 포함한 `3bf6b9828e0e83bc9d67744cb5ed1295c2e67209`다. 두 commit 사이의 약국 코드·공통 패키지는 동일하다. [Promote 38053501667](https://github.com/Renagang21/o4o-platform/actions/runs/38053501667)의 revision 검증·트래픽 전환·serving SHA 재확인이 성공했고 `production` 상태는 `DEPLOYED · deploy: kpa-society`다. 운영 파일을 정상 TLS로 취득한 PC·모바일 합성 회원 검증 10상황과 비로그인 진입·이전 URL 연결 8상황을 통과했다. 실제 회원 계정 로그인·실제 세션 교환은 테스트 계정 SSOT가 없어 미검증이다.

### 약국 경영지원 회원 초기화면 — 2026-10-18 사용자 개편 지시

`pharmacy.neture.co.kr`에서는 로그인한 가입 약국에게 현재 사업의 소식·본부 콘텐츠·운영 자료·제품 정보·회원 활동을 바로 제공한다. 일반 커뮤니티(`community.neture.co.kr`)와 별개이며 사업 가입·승인과 기존 상세 복귀를 유지한다. 다른 가입 사업 모아보기는 My Home, 거래와 실행 업무는 내 매장에 둔다. 현재 pharmacy에는 사업별 특별 서비스가 없다.

상단에는 작은 사업명·화면 제목과 사업 소식·운영 자료·제품 정보·회원 게시판·이용 안내를 제공한다. 사업 소식·제품 정보는 기존 루트의 해당 영역, 운영 자료와 게시판은 기존 상세 경로로 연결한다. 별도 소개 Home·Home 메뉴나 없는 분류의 빈 게시판을 추가하지 않는다. 내 매장은 기존 프로필 메뉴와 같은 매장 이용 자격을 갖춘 사용자에게 상단 계정 영역의 고정 연결과 기존 계정 메뉴에서 제공하고 큰 중복 업무 안내 상자는 두지 않는다.

본문은 중요 공지·최근 게시판 공지 → 실제 게시된 본부 소식(Hero/광고) → 운영 자료 → 제품 정보 → 회원 이야기 → 이용 지원 순으로 구성한다. 일반 홍보 문구를 큰 기본 Hero로 반복하지 않는다. 기존 운영자의 사업별 전시 편집·게시·예약 계약과 광고 표시는 유지하되, 게시 전이나 조회 실패를 기본 홍보 슬라이드로 대체하지 않는다. 정상적인 빈 공지·회원 글은 큰 빈 카드로 나열하지 않고 오류는 빈 결과와 구분해 재시도를 제공한다. 게시판 공지는 기존 고정/announcement 유형을 사용하며 작성자를 표시한다. 그 유형만으로 본부 작성물이라고 추정하지 않는다. 본부 전시 소식은 기존 운영자 게시 원장으로 구분한다.

운영 자료는 기존 승인된 약국 선택·게시 원장으로 조회하고 제목/요약에서 상세로 이동한다. 원문을 매장 사본으로 가져오는 기존 독립 복사 흐름을 유지한다. 제품 정보는 현재 선택 약국이 이용 가능한 기존 공급 항목의 제품명·공급자만 표시하며 가격·주문·정산은 내 매장에서 수행한다. 독립된 제품 카탈로그나 추천 순위 원장은 추가하지 않는다. 교육·행사는 기존 콘텐츠로 안내할 수 있으며 별도 수강·예약 서비스를 전제하지 않는다.

미승인 사용자는 작은 사업 안내와 신청 경로만 보며 회원 게시글·자료·전시를 조회하지 않는다. 담당 운영자에게 매장 소유자용 자료 조회를 요구하지 않는다. 게시판 미개설·계정/사업/선택 약국 전환에서도 기존 권한과 범위를 유지한다. 공통 웹 앱을 사용하는 메가팜 및 다른 사업 키도 이 표시 구조의 영향 대상으로 검증하며 사업별 업무를 통합하지 않는다.

이번 변경의 TODO·코드/문서 대조와 검증은 [회원 메인 재구성 TODO](../work-orders/TODO-O4O-PHARMACY-MEMBER-HOME-REORGANIZATION-V1.md)에 기록한다. 정책 갱신이나 push만으로 main 통합·운영 배포 완료를 판정하지 않는다. 이번 구현은 PR #704로 main에 반영됐고 Delivery #39127701475의 약국 웹 verified rollout·production DEPLOYED와 공식 실행 파일을 확인했다. Neture 배포는 [Promote 38036663868](https://github.com/Renagang21/o4o-platform/actions/runs/38036663868), 변경된 5개 웹 앱의 배포 버전 재확인은 [Promote 38037109376](https://github.com/Renagang21/o4o-platform/actions/runs/38037109376)에서 성공했다. 실행 기록은 [서비스 진입·메뉴 정비 WO](../work-orders/WO-O4O-SERVICE-ENTRY-AND-NAVIGATION-ALIGNMENT-V1.md)를 참고한다. 그 WO의 병합 전 대기 표기는 당시 기록으로 보존한다.

당시 PC·모바일에서 로그인 전후 전체 목록, 준비 중 사업 팝업의 Escape·초점 복귀, Partner 접근·복귀, 공개 진입·로그인 경계를 검증했다. 당시 준비 중이었던 세 사업의 상태는 그 시점의 기록이다. 현재 진입 상태와 배치 기준은 §2·§3 및 아래 회귀 기준을 따른다.

### 현재 회귀 기준 (2026-10-18)

- 로그인 전·후 모두 전체 폭 Hero → AI 순서로 표시한다. AI 다음 게스트는 공개 전체 서비스, 회원은 실제 가입 서비스·이용 상태와 다른 서비스 소개를 표시하며 소식은 그 뒤에 둔다(§2). 약관 미동의·가입 상태에 따른 AI 실행 제한은 유지한다.
- 세 협력사업은 §3의 실제 호스트로 연결하고 준비 중 팝업을 열지 않는다. 공개 탐색·로그인 후 소개·참여 회원 바로가기를 모두 검증한다. CarePharm·메가팜 참여자를 pharmacy 개인 가입을 요구하는 진입으로 우회시키지 않는다.
- Partner 준비 중 소개·메인 복귀·문의, 병원 도구의 문서 탐색, 모바일·키보드 접근과 실제 route 없는 메뉴 미노출을 유지한다.
- 공개 진입과 가입·승인·업무 권한은 구분한다. 주소 연결을 업무 기능 전체의 운영 검증으로 간주하지 않고 테스트 실행 범위와 실제 계정·HTTPS 미검증 범위를 기록한다.
