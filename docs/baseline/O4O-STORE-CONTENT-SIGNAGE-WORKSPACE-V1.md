# 내 매장 콘텐츠·사이니지·자동 연결 기준

상태: ACTIVE. 사용자 확정: 2026-11-05. 구현·검증 상태는 [TODO](../work-orders/TODO-O4O-STORE-SIGNAGE-WORKSPACE-ALIGNMENT-V1.md)와 [CHECK](../checks/CHECK-O4O-STORE-SIGNAGE-WORKSPACE-ALIGNMENT-V1.md)로 구분한다.

## 화면과 업무

‘매장 콘텐츠’는 일반 콘텐츠와 사이니지로 나눈다. 일반 콘텐츠는 기존 자료함·상품 설명·POP·QR 등 제작/편집 업무다.
사이니지에는 **동영상함**과 **재생목록**이 있다. 동영상함에서 사용할 영상을 모으고 재생목록에서 선택·추가·제거·순서 변경한다.
목록 생성/이름 수정/삭제를 지원한다. 목록에서 항목 제거는 동영상 원본 삭제와 다른 작업이다.
‘매장 운영’은 기존 목록을 골라 TV/태블릿에 적용하고 필요한 재생 시간을 설정하는 진입이다.

동영상 출처는 커뮤니티, 가입한 약국협업체, 매장 경영자 직접 등록이다. 출처를 보존하며 동영상함에서 함께 찾는다.
외부 YouTube/Vimeo 영상은 원본 URL·제공자 정보를 보관하고 임베드로 재생한다. O4O 채널 소유/OAuth 연결을 외부 영상 등록 전제로 요구하지 않는다.
O4O에 보관된 파일과 기존 등록/업로드·재생 엔진을 재사용한다. 원본 제공자의 재생 제한/실패는 정상 안내·복구 경로로 처리한다.
가입 협업체의 게시 자료에 포함된 지원 영상만 가져올 수 있다. 서버가 매장·사업 가입·자료 게시 상태·선택 URL을 다시 확인한다.
사본은 매장 소유다. 원본 수정·협업체 탈퇴가 이미 가져온 사본을 자동 수정/삭제하는 뜻은 아니다.

## 매장 연결과 메뉴

약국경영자로 통합 가입하여 승인받으면 약사 자격·조직·owner·약국 연결 원장·기본 업무가 함께 연결된다.
별도 ‘내 매장 신청’ 화면과 최초 신청 writer는 폐기한다. 약국 연결 원장과 서버의 소유/이용 자격 검증은 유지한다.
매장명은 서버가 연결한 조직에서 읽으며 테스트 계정 전용 프런트 분기를 만들지 않는다.
일반 화면의 매장 선택 메뉴는 제거한다. 실제 복수 조직/직원/다른 서비스의 내부 문맥·명시적 권한 검사를 없애거나 임의의 첫 매장으로 바꾸지 않는다.

My Home은 상단 공통 헤더 진입을 사용한다. 매장 보조 메뉴에 반복하지 않는다.
‘이용 사업’과 ‘이용 사업·가입 관리’는 `/services` 한 업무로 통일한다. 실제 제공 사업만 표시한다.
사용자용 명칭은 **약국대상 세미프렌챠이즈 서비스**다. 내부 DB/API 식별자는 명칭 때문에 일괄 rename하지 않는다.
약국경영자 승인과 독립 사업의 가입·승인은 별개다. 회원 자격만으로 모든 협업체에 자동 가입시키지 않는다.

매장 정보의 정식 경로는 `/store/info`다. `/pharmacy`와 과거 약국 신청 URL은 정식 진입으로 연결한다.
조회 실패는 존재하지 않는 약국 게이트로 보내지 않고 제자리에서 권한/연결/통신 오류를 안내하고 재시도한다.
사업자 변경 요청·매도·폐업·직원 초대/해제는 각각 기존 My Home/Admin/매장 경영자 절차를 유지한다.

## 저장·권한 경계

이번 화면 분리는 새 재생용 테이블, Channel 복구, 목록 자동 교체, 데이터 이전을 뜻하지 않는다.
`store_playlists`의 사본 항목과 운영자 `signage_playlists`의 media 항목을 합치지 않는다.
[기존 목록 경계](O4O-SIGNAGE-STORE-PLAYLIST-MODEL-BOUNDARY-V1.md)와 [태블릿 재생 기준](O4O-SIGNAGE-CANONICAL-PLAYBACK-PATH-V1.md)을 유지한다.
영상 추가는 서버가 확인한 목록 소유 매장과 같은 조직의 영상을 사용한다. 요청 body로 다른 조직을 지정해 우회할 수 없다.

공개 Demo 준비 코드는 registry에 등록된 합성 계정만 대상으로 한다. 계획 digest·현재 상태·관리자 실행자 검증을 거쳐야 하며,
실제 회원의 자격을 추정 승인하거나 기존 반려·철회를 자동 해제하지 않는다. PR 단계에서 운영 데이터 준비를 실행하지 않는다.
