트니프렌즈 키즈아이케어비타민 A

(주)알피바이오 제조 · 1일 1회 1캡슐

이 제품은 1일 섭취량(1회 · 1캡슐)에 비타민 A 210μg를 표시량으로 담았습니다(표시 기준 130mg당). 비타민 A의 영양기능은 아래 공식 인정 범위와 같습니다.

왜 이 제품인가

  • 1일 1회(1캡슐) 섭취로 비타민 A 210μg
  • 대장균군 음성 — 식약처 신고 기준 적합
  • 고유의 향미가 있고 이미, 이취가 없는 진한 빨간색의 내용물을 함유한 밝은 적갈색의 타원형 츄어블 연질캡슐 · (주)알피바이오 제조

비타민 A 영양기능 (공식 인정 기능성)

  • 어두운 곳에서 시각 적응을 위해 필요
  • 피부와 점막을 형성하고 기능을 유지하는데 필요
  • 상피세포의 성장과 발달에 필요

섭취방법 (공식 표기 그대로)

1일 1회1회 1캡슐씹어 섭취

표시 기준

비타민 A 표시량(210μg/130mg)의 80~150%
성상 고유의 향미가 있고 이미, 이취가 없는 진한 빨간색의 내용물을 함유한 밝은 적갈색의 타원형 츄어블 연질캡슐
대장균군 음성
유통기한 제조일로부터 24개월까지
보관 직사광선과 고온다습한 곳을 피하여 습기가 적고 건조한 곳에 보관하십시오. 어린이의 손이 닿지 않는 곳에 보관하십시오.
