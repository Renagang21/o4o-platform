제트엽산프로엽산

코뉴 제조 · 1일 1회 1정

이 제품은 1일 섭취량(1회 · 1정)에 엽산 1700μg를 표시량으로 담았습니다(표시 기준 1000mg당). 엽산의 영양기능은 아래 공식 인정 범위와 같습니다.

왜 이 제품인가

  • 1일 1회(1정) 섭취로 엽산 1700μg
  • 대장균군 음성 — 식약처 신고 기준 적합
  • 고유의 향미가 있고 이미, 이취가 없는 회황색의 점박이가 있는 노란하얀색의 타원형 정제 · 코뉴 제조

엽산 영양기능 (공식 인정 기능성)

  • 세포와 혈액생성에 필요
  • 태아 신경관의 정상 발달에 필요
  • 혈액의 호모시스테인 수준을 정상으로 유지하는데 필요

섭취방법 (공식 표기 그대로)

1일 1회1회 1정물과 함께

표시 기준

엽산 표시량(1700μg/1000mg)의 80~150%
성상 고유의 향미가 있고 이미, 이취가 없는 회황색의 점박이가 있는 노란하얀색의 타원형 정제
대장균군 음성
유통기한 제조일로부터 24개월
보관 직사광선을 피하고 서늘한곳에 실온 보관

이런 분께

  • 매일 엽산 섭취를 챙기고 싶은 분
  • 정 형태를 선호하는 분
  • 간편하게 영양 균형을 관리하고 싶은 분
