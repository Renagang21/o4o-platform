이 제품은 비오틴 360μg, 비타민 A 400μg, 비타민 B1 40mg, 비타민 B12 800μg, 비타민 B2 16mg, 비타민 B6 26mg, 비타민 C 400mg, 비타민 D 4μg, 비타민 E 160mg, 비타민 K 400μg, 엽산 160μg를 표시량으로 담은 11원료 복합 건강기능식품입니다. 각 원료의 공식 인정 기능성은 아래와 같습니다.

왜 이 제품인가

  • 1일 2회 섭취로 비오틴 360μg, 비타민 A 400μg, 비타민 B1 40mg, 비타민 B12 800μg, 비타민 B2 16mg, 비타민 B6 26mg, 비타민 C 400mg, 비타민 D 4μg, 비타민 E 160mg, 비타민 K 400μg, 엽산 160μg
  • 대장균군 음성 — 식약처 신고 기준 적합
  • 이미, 이취가 없는 미황색의 제피정제 · 주식회사 아리너스 제조

  • 비타민 A
    • 어두운 곳에서 시각 적응을 위해 필요

    • 상피세포의 성장과 발달에 필요
  • 비타민 B1
    • 탄수화물과 에너지 대사에 필요
  • 비타민 B12

  • 비타민 B2

  • 비타민 B6
    • 단백질 및 아미노산 이용에 필요
    • 혈액의 호모시스테인 수준을 정상으로 유지하는데 필요
  • 비타민 C

  • 비타민 D
    • 칼슘과 인이 흡수되고 이용되는데 필요
    • 뼈의 형성과 유지에 필요
    • 골다공증발생 위험 감소에 도움을 줌
  • 비타민 E
    • 유해산소로부터 세포를 보호하는데 필요
  • 비타민 K
    • 정상적인 혈액응고에 필요
    • 뼈의 구성에 필요
  • 엽산

    • 세포와 혈액생성에 필요
