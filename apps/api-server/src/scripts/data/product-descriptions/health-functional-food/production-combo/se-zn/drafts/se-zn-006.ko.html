왜 이 제품인가

  • 1일 1회(1포) 섭취로 셀레늄 55μg, 아연 8.5mg
  • 대장균군 음성 — 식약처 신고 기준 적합
  • 고유의 향미가 있고 이미, 이취가 없는 밝은 청회색의 알갱이가 있는 흰색의 분말 · 동서바이오팜(주) 안성공장 제조
