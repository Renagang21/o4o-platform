일양 씹어먹는 비타민D 3000 IU비타민 D

일양약품(주) 제조 · 1일 1회 1캡슐

이 제품은 1일 섭취량(1회 · 1캡슐)에 비타민 D 75μg를 표시량으로 담았습니다(표시 기준 400mg당). 비타민 D는 칼슘과 인이 흡수되고 이용되는데 필요하며, 뼈의 형성과 유지에 필요한 영양성분입니다.

왜 이 제품인가

  • 1일 1회(1캡슐) 섭취로 비타민 D 75μg
  • 대장균군 음성 — 식약처 신고 기준 적합
  • 고유의 향미가 있고 이미, 이취가 없으며 노란 연두색의 내용물을 함유한 진한 노란색의 타원형 츄어블연질캡슐 · 일양약품(주) 제조

비타민 D 영양기능 (공식 인정 기능성)

  • 칼슘과 인이 흡수되고 이용되는데 필요
  • 뼈의 형성과 유지에 필요
  • 골다공증 발생 위험 감소에 도움을 줌

섭취방법 (공식 표기 그대로)

1일 1회1회 1캡슐씹어 섭취

표시 기준

비타민 D 표시량(75μg/400mg)의 80~180%
성상 고유의 향미가 있고 이미, 이취가 없으며 노란 연두색의 내용물을 함유한 진한 노란색의 타원형 츄어블연질캡슐
대장균군 음성
유통기한 제조일로부터 24개월
보관 연질캡슐은 수분, 열에 의한 영향에 민감하므로 열원이나 직사광선을 피해 서늘한 곳에 보관하십시오.(온도 30℃ 이상, 상대습도 75% 이상에서는 캡슐이 변형될 수 있습니다.)어린이의 손이 닿지 않는 곳에 보관하시고 병을 개봉한 상태로 공기중에 방치하거나 다른 용기에 보관할 경우 인습에 의해 반점이 생길 수 있으므로 주의하십시오.캡슐기제를 천연유래의 색소를 사용하여 내용물이 비칠 수 있으며, 간혹 색이 변하는 경우가 있으나 품질에는 이상이 없습니다.연질캡슐은 수분, 열에 의한 영향에 민감하므로 열원이나 직사광선을 피해 서늘한 곳(건냉암소)에 보관하십시오. 어린이의 손이 닿지 않는 곳에 보관하십시오.

이런 분께

  • 캡슐 형태를 선호하는 분
