이 제품은 1일 섭취량(1회 · 1정)에 비타민 D 25μg를 표시량으로 담았습니다(표시 기준 300mg당). 비타민 D는 칼슘과 인이 흡수되고 이용되는데 필요하며, 뼈의 형성과 유지에 필요한 영양성분입니다.

왜 이 제품인가

  • 1일 1회(1정) 섭취로 비타민 D 25μg
  • 대장균군 음성 — 식약처 신고 기준 적합
  • 미황색 원형 정제 · 한국바이오팜(주)에이치피 제조

비타민 D 영양기능 (공식 인정 기능성)

  • 칼슘과 인이 흡수되고 이용되는데 필요
  • 뼈의 형성과 유지에 필요
  • 골다공증 발생 위험 감소에 도움을 줌

섭취방법 (공식 표기 그대로)
