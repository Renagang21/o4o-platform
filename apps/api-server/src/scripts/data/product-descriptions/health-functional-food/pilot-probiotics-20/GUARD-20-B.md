## 소배치 B 판정 — **PASS (수정 0건)**

**20-A(최초 검출 3) → 20-B(최초 검출 0).** 차이는 하나뿐이다 — **작성 전 가드에서 "쓰면 안 되는 수치·표현"을 먼저 확정하고 초안을 썼다.**

- §A 가 5건을 **2:3 으로 갈랐다**: 1포 중량 명시 2건(B-3·B-4) → 1일 총량 표기 / 미표시 3건(B-1·B-2·B-5) → 총량 미기재. 추정했다면 3건 전부 오류.
- §0-4 가 실효: 원문 섭취 지시가 **"직접 O" 2건 vs "물과 함께"만 3건**으로 갈렸다. "분말이니 물 없이"로 일반화했다면 3건 오류.
- **B-4 냉장**은 근거 있는 실제 차별점 → 사실로 기술. 동시에 나머지를 "냉장 불필요"로 쓰지 않았다(부재≠허용).
- 제품명 트랩 3건(W이너밸런스·패밀리·디땅트) 전부 무유도 — 이름은 인용만.
