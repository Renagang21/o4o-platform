## §A 판정 요약 — 5건이 2:3 으로 갈림

| # | 제품 | 제조사 | 균수/기준량 | 1포 중량 | 1일 총 균수 |
|---|---|---|---|---|---|
| B-1 | 트리맥스바이오틱스 | 렉스팜 | 10억/3g | **미표시** | **산출 불가** |
| B-2 | 닥터파이토 비피아이 | 비피도 | 50억/2g | **미표시** | **산출 불가** |
| B-3 | W이너밸런스 | 오투바이오 | 50억/2g | **2g 명시** | **50억** |
| B-4 | 닥터트루 패밀리 | 케비젠 | 100억/2g | **2g 명시** | **100억** |
| B-5 | 프로바이오티끄 디땅트 | 메디바이오랩 | 30억/1,500mg | **미표시** | **산출 불가** |

→ **1포 중량 표시 여부가 총량 산출을 가른다.** "1회 1포" 만 있고 포 중량이 없으면 기준량(2g/3g/1,500mg)이 1포인지 알 수 없다 → **추정 금지**.

## §0-4 검증 — "분말이니 물 없이" 함정

원문의 섭취 지시가 제품마다 **명확히 다르다**. 분말이라는 이유로 일반화하면 전부 틀린다.

```text
B-1  "직접 또는 충분한 물과 함께"   ← 직접 섭취 O (원문 명시)
B-2  "직접 또는 물과 함께"          ← 직접 섭취 O (원문 명시)
B-3  "충분한 물과 함께"             ← 직접 섭취 언급 없음 → "물 없이" 금지
B-4  "음용수와 함께"                ← 직접 섭취 언급 없음 → "물 없이" 금지
B-5  "물과 함께"                    ← 직접 섭취 언급 없음 → "물 없이" 금지
```
**5건 중 2건만 "직접" 섭취가 원문에 있다.** 나머지 3건에 "물 없이 간편하게"를 쓰면 ① 위반.
