## 소급 정정 1건 — 20-A A-5

20-C 잠금("저균수 → 입문용 해석 금지")을 **20-A 에 소급 적용**하니 A-5(비피스앤, 1억)의
`이런 분께 > "배변활동·장 건강을 **이제 챙겨보려는 분**"` 이 해당 → **"배변활동·장 건강이 신경 쓰이는 분"** 으로 수정(ko·en).
→ **잠금은 신설 시점 이후만이 아니라 기존 산출물에 소급 적용해야 한다**(같은 파일럿 내 일관성).

## 소배치 C 판정 — **PASS (실제 위반 0 / 표현 조정 1)**

- **핵심**: 키즈 2건·온가족 1건 **전부 연령별 섭취량 없음** → 대상 소구 전면 차단. 사용자 예측이 정확히 적중.
  주의사항의 "어린이가 함부로 섭취하지 않도록 지도"는 오히려 **어린이 단독 섭취를 경계**하는 문구 → 어린이 소구의 근거가 될 수 없음.
- §A 가 1:4 로 가름 — C-5 만 1포(1g)=기준량(1,000mg) 명시 → 총량 표기. 나머지 4건 미기재.
- C-3 냉장 **0~10℃** = B-4 "냉장"보다 구체 → 온도까지 사실 기술.

## 3개 소배치 누적 — 최초 검출 추이

```text
20-A  작성 후 가드만        최초 검출 3  (실제 위반 3 — 최상급 2 + 부재추론 1)
20-B  작성 전·후 이중 가드   최초 검출 0  (실제 위반 0)
20-C  작성 전·후 이중 가드   최초 검출 3  (실제 위반 0 — 오탐 2 + 표현 조정 1)
```
→ **작성 전 가드 도입 이후 실제 위반 0 이 2개 소배치 연속 재현.** 20-C 의 검출 3건은 전부 **가드가 과검출한 것**이며(오탐), 이는 가드가 느슨해서가 아니라 **엄격해서** 생긴 것 → 사람 판정이 붙는 한 안전한 방향.
