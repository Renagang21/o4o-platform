## §0. 20-C 작성 전 잠금

```text
제품명에 키즈·어린이·온가족·패밀리 포함
  → 제품명 자체는 그대로 표기
  → 어린이 적합·가족 모두 섭취 가능 주장 금지
  → 연령별 섭취량 또는 대상 연령이 공식 원문에 있을 때만 대상 소구 허용

연령별 섭취방법 명시        → 해당 연령 구간을 정확히 서술 가능
성인·어린이 구분 없이 1일 섭취량만 → 어린이용 단정 금지
제품명만 키즈              → 이름 이상의 연령 적합성 주장 금지

+ 저균수 → 입문용·부담 적음·순한 제품 해석 금지
+ 온가족 → 가족 모두 적합 근거로 사용 금지
+ 어린이 대상이라도 맛·섭취 용이성·기호성 추정 금지
+ 분말·스틱 → 물 없이 일반화 금지
+ 연령별 섭취량 다르면 ko/en 숫자·구간 그대로
+ 성인 기준량 → 어린이 기준 환산 금지
```

## §0-1. **핵심 실측 — 키즈/온가족 3건 전부 연령별 섭취량 없음**

```text
슬리문 키즈 30억 유산균 : "1일 1회, 1회 1포(1g)를 충분한 물과 함께 섭취하십시오."   ← 연령 구분 0
오달달 키즈 유산균      : "1일 1회, 1회 1포를 직접 섭취하시기 바랍니다."             ← 연령 구분 0
온가족 생유산균         : "1일 1회, 1회 1포를 직접 또는 물과 함께 섭취하십시오."      ← 연령 구분 0
```
→ **3건 모두 제품명에만 키즈/온가족이 있고 원문에는 대상 연령이 없다.** 어린이·가족 소구 **전면 금지**. 주의사항의 "어린이가 함부로 섭취하지 않도록 지도"는 오히려 **어린이 단독 섭취를 경계**하는 문구다.
(대조: 20-D 디노키즈생유산균은 `9세 이상/4~9세/6개월~4세` 연령별 명시 → 그 제품만 연령 서술 가능.)

## 소급 점검 — 20-A A-5(비피스앤 1억)에 저균수 트랩이 있었는가
