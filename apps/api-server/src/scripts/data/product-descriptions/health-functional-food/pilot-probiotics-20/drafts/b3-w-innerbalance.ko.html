왜 이 제품인가

  • 표시 기준량 2g = 1포 = 하루 섭취량 — 세 값이 일치해 계산이 필요 없습니다
  • 1포당 프로바이오틱스 50억 CFU = 1일 섭취 50억 CFU
  • 1일 1회 1포 — 하루 한 번으로 끝
  • 대장균군 음성 — 식약처 신고 기준 적합
