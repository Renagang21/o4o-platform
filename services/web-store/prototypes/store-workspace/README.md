# 내 매장 PC·모바일 웹 배치 초안

> **상태**: DRAFT
> **작성일**: 2026-10-13 · **최종 갱신**: 2026-10-13
> **근거 WO**: [WO-O4O-STORE-WORKSPACE-WEB-PLAN-V1](../../../../docs/work-orders/WO-O4O-STORE-WORKSPACE-WEB-PLAN-V1.md)

[기획 및 기능 대응표](../../../../docs/platform/store/DESIGN-O4O-STORE-WORKSPACE-WEB-V1.md)의 검토용 인터랙티브 화면이다.
별도 모바일 앱이 아니라 같은 HTML·CSS·JavaScript가 PC·모바일 웹에 반응형으로 표시된다.

## 열기

`index.html`을 브라우저에서 직접 열 수 있다. 외부 패키지·폰트·이미지·네트워크 연결은 필요 없다.
로컬 HTTP 검토가 필요하면 저장소 루트에서 다음을 실행하고 로컬 브라우저에서 해당 포트를 사용한다.

```bash
python3 -m http.server 4327 --bind 127.0.0.1 --directory services/web-store/prototypes/store-workspace
```

현재 Vite entry·public·서비스 라우트에서 참조하지 않는 독립 초안이다.
production 메뉴·API·권한·Core·저장 자료에 영향을 주지 않는다.

## 한 번에 검토할 흐름

1. 네 상단 메뉴와 각 메뉴의 하위 업무·AI 자리를 확인한다.
2. 콘텐츠 작업실 → 자료 가져오기 → 내 자료함에 가져오기 → 해당 자료로 제작한다.
3. QR·사이니지·태블릿·POP 중 형태를 고르고 제목·본문·언어 표시를 편집한다.
4. 미리보기 → 초안 저장 → 저장한 자료 활용하기 → 사용 위치 선택 → 예시 적용 확인을 진행한다.
5. 활용 현황에서 작업실로 돌아가 수정하고, 다시 저장한 후 활용한다.
6. 모바일 웹에서도 같은 흐름과 메뉴가 유지되는지 확인한다.

자료 원본·매장 독립 사본·제작 결과·배치의 관계를 설명하기 위한 합성 데이터다.
브라우저 메모리만 사용하며 새로고침하면 초기화된다. 실제 저장·게시·복사·인쇄·주문·결제·AI 호출은 없다.
언어 선택은 자료의 언어 표시만 바꾼다. 자동 번역하지 않는다.
미리보기는 배치 예시이며 실제 QR 코드·Screen Set·사이니지 렌더러가 아니다.

AI 패널은 메뉴 성격과 선택 자료에 맞는 도움 예시를 보여 준다.
네 개의 독립 비서를 만들지 않는다. O4O 공통 비서의 업무별 진입을 검토하는 자리다.
향후 다국어 상담은 준비 중 표시와 비활성 버튼으로 구분한다.
